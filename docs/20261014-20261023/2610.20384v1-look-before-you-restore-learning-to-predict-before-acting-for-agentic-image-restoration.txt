ABSTRACT
Agents for mixed-degradation image restoration typically learn what a tool does
to an image only after running it: failed calls waste computation and harmful
outputs go unnoticed until too late. We propose PreActIR, an agentic restoration
framework that predicts tool consequences before execution. For each candidate
tool, a tool-conditioned world model forecasts changes in residual degradation,
image quality, and fidelity, together with the risk of harm and the uncertainty of
the prediction. The agent executes the top-ranked candidate, and an independent
verifier commits or rolls back its output before the agent replans from the observed
state. PreActIR also audits whether performance is limited by the selector or by
the candidate space, and studies targeted tool adaptation as a controlled way to
expand that space. In a controlled evaluation that fixes the candidate pool, verifier,
and budget and employs reference-annotated degradation states, PreActIR uses
42.5% fewer real tool calls and 63.4% fewer rejected calls than reactive, execute-
then-evaluate trial and error, while improving Y-PSNR by 0.92 dB.

INTRODUCTION
Image restoration has advanced rapidly for individual degradations such as noise, blur, rain, haze,
low light, compression, and low resolution (Zhang et al., 2017; 2018a; Wei et al., 2018; Chen et al.,
2018; Zamir et al., 2020; Chen et al., 2021; Zamir et al., 2021; 2022; Chen et al., 2022; Liang
et al., 2021; Tu et al., 2022; Wang et al., 2021; Zhang et al., 2021). In practice, however, several
degradations often coexist and interact, making restoration a sequential decision problem in which
each intervention changes both the image state and the value of later actions. Recent agentic systems
coordinate specialized tools through perception, planning, execution, and feedback (Zhu et al., 2025;
Zuo et al., 2025; Li et al., 2026; Shao et al., 2026). Most of them follow an execute–observe–replan
loop (Yao et al., 2023): a tool’s effect on a given image is known only after it has run, failed calls
still cost computation, and harmful side effects go unnoticed until afterwards.
Recent agents reduce the number of trials with trained planners and stored experience (Jia et al.,
2026; Zhu et al., 2026a; Wang et al., 2026), and a few methods score actions in advance:
DiTTo (Choi and Oh, 2026) learns a simulator and a per-action quality predictor for trajectory con-
struction, and the concurrent Causal-AgentIR (Gao et al., 2026) estimates plan utility from a causal
memory of past executions. Neither trains a tool-conditioned consequence model for deployment-
time decisions. A separate question is whether the tool set itself is the limit: even a perfect selector
fails if no reachable tool sequence yields a good result. Agents can add experts (Choi and Oh, 2026)
or fine-tune tools together with the planner (Zhu et al., 2026a), but a poor result alone does not tell
whether the selector chose badly or no good candidate was reachable—two cases that call for dif-
ferent fixes. As illustrated in Fig. 1, reactive execution pays for an outcome before seeing it, and it
is usually unclear whether the selector or the tool set is the binding limit.

We propose PreActIR, an agentic restoration framework built around the idea that an agent should
predict what a tool will do before calling it. A tool-conditioned world model takes each candidate
tool and predicts the changes in residual degradation, image quality, and fidelity, along with content
damage, the probabilities of benefit and harm, and the uncertainty of these predictions. The agent
ranks candidates by these predictions and executes only the top one. Because predictions can be
wrong, an independent post-execution verifier checks the actual output and commits or rolls it back;
the agent then replans from the observed state. We call this the predict–act–verify loop.
A separate diagnostic asks whether the selector or the tool set is binding. An offline candidate-
frontier audit uses test references post hoc to find the best result reachable from the fixed candidate
pool, separating selector headroom from tool-space limits. We then adapt one existing tool on
external replay data and measure how it shifts both the attainable frontier and the deployed system.
Our contributions are as follows:
• A tool-conditioned world model that predicts how each candidate tool changes residual
degradation, quality, and fidelity, along with benefit and harm probabilities and uncertainty,
so that tools can be ranked and their risk estimated before execution.
• A predict–act–verify loop that executes only the top-ranked tool and lets an independent
verifier commit or roll back its output; in a matched replay with reference-annotated states,
it makes 42.5% fewer real calls and 63.4% fewer rejections than reactive trial and error.
• A candidate-frontier audit that distinguishes tool-selection limitations from candidate-
space constraints by characterizing attainable fidelity–perception trade-offs. It quantifies
the headroom available through better selection within a fixed pool and examines how
targeted tool adaptation expands the attainable frontier.

RELATED WORK
All-in-One and Agentic Image Restoration.
All-in-one image restoration addresses multiple
degradations within a unified model using degradation-aware representations, multimodal guidance,
or adaptive expert routing (Li et al., 2022; Potlapalli et al., 2023; Kong et al., 2024; Luo et al., 2024;
Conde et al., 2024; Zhang et al., 2025; Jiang et al., 2024; Cui et al., 2025; Zamfir et al., 2025; Zhang
et al., 2026). These methods learn a fixed policy without predicting tool effects before execution.
Agentic restoration instead coordinates specialized models through perception, planning, execution,
and feedback, building on reinforcement-learned toolchains (Yu et al., 2018; 2022). MLLM con-
trollers reason about degradations and coordinate experts (Chen et al., 2024a; Lin et al., 2025; Zhou
et al., 2025; Wei et al., 2026); AgenticIR, MAIR, 4KAgent, SEAR, HybridAgent, and FAPE-IR add

exploration with rollback, multi-agent or recursive execution, tree search, fast–slow coordination,
and frequency-aware planning (Zhu et al., 2025; Jiang et al., 2026; Zuo et al., 2025; Cui et al., 2026;
Li et al., 2026; Liu et al., 2026); and others target rain, inscriptions, or photo retouching (Yu et al.,
2026; Zhu et al., 2026b; Xiong et al., 2026). In these systems a tool’s effect is observed only after it
runs, and SEAR’s tree search scores candidates by real rollouts.
Learned Tool Selection and Pre-Execution Estimation.
Restore-R1, TIR-Agent, and OPERA
train the planner with perceptual or metric rewards (Lu et al., 2026; Jia et al., 2026; Zhu et al., 2026a),
and OPERA also fine-tunes the tools; SkillIR reuses skills from past executions (Shao et al., 2026),
and PaAgent retrieves tool-specific experience from a portrait bank of restoration tools (Wang et al.,
2026). These methods improve the choice of tool but do not predict what it will do. DiTTo (Choi
and Oh, 2026) learns a restoration simulator and a per-action quality predictor, but uses them to
build order-aware training trajectories. The concurrent Causal-AgentIR (Gao et al., 2026) keeps a
causal memory graph of past executions, curated by a learned memory-operation policy, and scores
plans before execution by multi-hop reasoning over retrieved memory paths, with a critic and roll-
back afterwards. Pre-execution scoring and rollback are therefore not new on their own. PreActIR
differs in that it trains a consequence model on real transitions and queries it for every candidate at
deployment time, predicting separate outcomes rather than collapsing them into a single score; it
also audits whether the selector or the tool set limits performance.
World Models and Predict-before-Act Agents.
World models learn action-conditioned dynam-
ics so that an agent can evaluate actions in imagination before acting (Ha and Schmidhuber, 2018;
Hafner et al., 2019). Probabilistic models quantify their own uncertainty (Chua et al., 2018), short
rollouts limit compounding model error (Janner et al., 2019), and a model need not reconstruct obser-
vations if it predicts only decision-relevant quantities (Schrittwieser et al., 2020). Among language
agents, PreAct predicts action results before acting (Fu et al., 2025), and WebDreamer uses an LLM
to simulate each candidate web action before choosing one (Gu et al., 2025). Those predictions are
free-form text from a pretrained model, whereas restoration tool outcomes are continuous and multi-
dimensional, and fidelity to the unknown clean image is unobservable at test time. Our consequence
heads are instead supervised with uncertainty estimates on real tool transitions; we plan one step
ahead by default and rely on a post-execution verifier to catch the remaining prediction errors.

3.2
OVERVIEW
PreActIR follows a predict–act–verify loop (Fig. 2). A tool-conditioned world model predicts struc-
tured action consequences before execution (Sec. 3.3), and an independent verifier commits or rolls
back each executed action (Sec. 3.4). An offline candidate-frontier audit then checks whether the
candidate space limits performance, and targeted tool adaptation is studied as a controlled way to
expand it (Sec. 3.5).

4
EXPERIMENTS
4.1
DATASETS AND EXPERIMENTAL SETUP
PreActIR is evaluated on MiO100 (Kong et al., 2024) under the AgenticIR protocol (Zhu et al.,
2025), with 160 official compound-degradation states from 20 clean-image identities for training and
1,440 test images across Groups A–C. We use five-fold cross-fitting with disjoint clean-image identi-
ties between fitting and outer validation. The base tool set A contains 33 restoration actions covering
eight degradation types. Sec. 4.2 (Tables 1–2) reports the full system, in which the world model pre-
ranks root actions, only high-value roots are executed and expanded, and cross-fitted candidate-value
models select the output, with a fixed output blend for Groups A and B (Appendix C). For Group C,
it also includes a HAT-S operator (Chen et al., 2023) adapted on 4,000 external degradation-matched
pairs, without MiO100 HQ images or test references (Appendix G). Controlled planner comparisons
(Secs. 4.3–4.4) use matched candidate pools and tool sets.
Metrics are PSNR, SSIM (Wang et al., 2004), LPIPS (Zhang et al., 2018b), MANIQA (Yang et al.,
2022), CLIP-IQA (Wang et al., 2023), and MUSIQ (Ke et al., 2021); PSNR and SSIM are computed
on the Y channel of YCbCr.
4.2
MIO100 MAIN RESULTS
Table 1 compares PreActIR with representative all-in-one and agentic methods on MiO100. PreAc-
tIR achieves the highest SSIM on all three groups and the highest PSNR on Groups A and C. On
Group A it also leads in LPIPS and MANIQA (22.61 dB, 0.292, and 0.383; SSIM 0.717), and on
Group B it leads in MANIQA, CLIP-IQA, and MUSIQ. On Group C it leads in PSNR and SSIM
(21.05 dB and 0.604) but trails 4KAgent on the three perceptual metrics. Qualitative comparisons in
Fig. 4 show similar trends (more examples in Appendix D).
On the paired real-world set (Table 2), PreActIR leads on MANIQA, CLIP-IQA, and MUSIQ (0.389,
0.525, and 57.33), but its PSNR (22.64 dB) falls behind all other agents (SEAR reaches 24.41 dB),
pointing to a fidelity–perception trade-off on this set that deserves further investigation. Qualitative
results are in Fig. 5.

4.5
CANDIDATE-FRONTIER AUDIT AND TARGETED TOOL ADAPTATION
No amount of better prediction helps if no reachable candidate is good enough. We therefore au-
dit whether Group C is limited by selection or by what the 33-action tool set can produce. Us-
ing test references post hoc, we score all 21,385 frozen Group C candidates and solve an exact
one-candidate-per-state mixed-integer program that maximizes mean Y-PSNR subject to a floor on
mean MUSIQ; sweeping the floor traces the attainable fidelity–perception frontier of the fixed pool
(Fig. 7a). This oracle is not deployable, but it shows where the ceiling is. The deployed fixed-pool
configuration lies well inside the frontier: at its MUSIQ level, a reference-assisted selection from the
same pool reaches 21.74 versus 19.97 dB Y-PSNR, leaving 1.77 dB of selector headroom. Adapting
HAT-S on 4,000 external replay pairs expands the pool for the 200 low-resolution states and raises
the attainable frontier by 0.50 dB at the final MUSIQ level. Our final Group C system builds on a
different fixed-pool configuration and fuses the adapted tool’s output into the low-resolution states;
it reaches 21.05/0.604 Y-PSNR/Y-SSIM at MUSIQ 54.78 but still lies 0.7 dB below the fixed-pool
frontier. On the two low-resolution combinations it exceeds the fixed-pool oracle, while the other
two retain 1.6–2.6 dB of selector headroom (Fig. 7b). Tool adaptation is one practical route to a
better operating point, but closing the selector headroom offers a larger gain.

CONCLUSION
We presented PreActIR, an agentic restoration framework that looks before it restores: a tool-
conditioned world model predicts the consequences of each candidate tool before execution, and
an independent verifier commits or rolls back the executed one. In controlled replays with matched
candidates, verifier, and budget, predicting before acting substantially reduces real and rejected tool
calls while improving restoration quality, and on MiO100 the full system achieves the best overall

yond single-step ranking.

ADDITIONAL METHOD DETAILS
A.1
WORLD-MODEL ARCHITECTURE
The world model receives a 256 × 256 image, the degradation-state estimates for the D = 8 degra-
dation types, and one of the |A| = 33 tool actions. The image encoder contains four stages with
channel dimensions [32, 64, 128, 256]. The first stage uses a 5 × 5 stride-2 convolution, while the
remaining stages use 3 × 3 stride-2 convolutions. Each stage is followed by a two-layer residual
block with GroupNorm and SiLU activations.
The deepest visual features are aggregated using global-average pooling and action-mask-weighted
pooling, and both are projected to 256 dimensions. They are concatenated with 16-dimensional
presence/severity features, a 48-dimensional tool embedding, a 24-dimensional target-degradation
embedding, and three scalar inputs for action strength, mask area, and relative compute cost. The
resulting 603-dimensional representation is processed by two width-384 Linear–LayerNorm–SiLU–
Dropout blocks with dropout 0.15. Separate heads on these shared features output Gaussian means
and log variances for the eight-dimensional degradation change ∆d, the four-dimensional proxy-
quality change ∆q, the two-dimensional Y-channel fidelity change ∆f, and the scalar content dam-
age d, together with binary logits for beneficial, harmful, and severely harmful outcomes. The
damage mean is passed through a sigmoid, and all predicted log variances are clipped to [−6, 2].
The action mask, region area, and strength are retained as a general action interface. The OOF exper-
iments in Secs. 4.3–4.4, however, use global actions with fixed strength ω = 1. We therefore do not
claim independently validated regional control or strength generalization in the current experiments.

OPEN-LOOP RANKING: PROTOCOL AND ADDITIONAL RESULTS
This appendix complements Sec. 4.3. All results use the same 160 clean-identity-disjoint OOF
states. These states were also used during policy development, so they serve as a controlled mecha-
nism test rather than an untouched test-set estimate.
E.1
PROTOCOL
Candidate pool.
For each state, the pool contains every eligible action under the four degradation
targets with the highest OOF presence probability; low resolution is always among the four targets
when the long side of the input is at most 512 pixels. Five slow actions are excluded: MAXIM for
haze, motion blur, noise, and rain, and DiffBIR (Lin et al., 2024) for low resolution. This yields
2,147 executed candidates (13.4 per state on average). The pool is fixed before any ranker is applied
and is not prescreened by the world model or any scalar scorer. Realized outcomes are used only for
evaluation.
Methods.
All deployable methods score the same pool from pre-execution inputs and commit their
top-ranked action; ties are broken by action name. Tool prior ranks each tool by its mean realized
∆FY on the 14 fit identities of the fold, ignoring the image and the degradation state. Degradation
routing selects the target with the highest predicted presence and then the tool with the highest mean
realized ∆FY for that target on the fit identities. The Direct scorer is a separately trained network
with a single output head that regresses the same Y-channel fidelity target yf as the world model’s
fidelity head (Appendix A.2); it shares the world model’s folds, inputs, backbone, training rows,
and optimization protocol (one seed per fold), but is trained with the Gaussian NLL only, without
Lf
rank. The world model ranks candidates by the frozen one-step utility Ut(a) of Eq. (8); WM-F
ranks them by the fidelity head’s prediction v alone. Oracle selects the candidate with the highest
realized ∆FY . Random is the analytic expectation of a uniform choice within each state.
Outcome labels.
A selection is harmful if ∆PSNRY < −0.05 dB, ∆SSIMY < −0.005, or the
mean RGB proxy-quality change is negative, which is exactly the label used to train the harm head
(Appendix A.2). It is severe if ∆PSNRY ≤−1 dB or ∆SSIMY ≤−0.05.
Statistics.
Intervals are 95% percentile intervals from 10,000 clean-identity cluster-bootstrap
draws that resample the 20 identities with replacement; HR is recomputed as a ratio of means in
every draw. The rank correlation rs is the Spearman correlation between predicted scores and real-
ized ∆FY , computed within each state and then averaged.

G.2
EXTERNAL REPLAY CONSTRUCTION
To expand the Group C candidate frontier, we construct 4,000 training pairs from external images
using the official AgenticIR degradation operators. The replay set consists of
• 2,518 rain+noise+×4 degradation pairs;
• 1,228 clean-image ×4 pairs; and
• 254 real paired hazy images with additional official motion-blur and ×4 degradation.
No MiO100 HQ image is used during tool adaptation.
G.3
REPLAY-ADAPTED SUPER-RESOLUTION TOOL
We use HAT-S (Chen et al., 2023) as the expandable super-resolution tool and further train it for
4,000 iterations on the external replay data.
On a fixed external validation set of 120 pairs, Y-PSNR/Y-SSIM improve from 24.84/0.7432 before
adaptation to 26.85/0.7692 after 4,000 iterations.
The frozen adapted tool is applied only to the 200 Group C states that contain low resolution; other
states retain the original high-perceptual-quality candidates.
G.4
FINAL GROUP C CANDIDATE FUSION
For Group C, the final candidate is constructed as
IC = (1 −α)Ip + αIsr + κ (Ip −Gσ(Ip)) ,
(29)
where Ip denotes the original high-perceptual-quality candidate, Isr the replay-adapted super-
resolution candidate, and Gσ a Gaussian smoothing operator.
We use
α = 0.62,
κ = 0.12,
σ = 1.5.
This expanded candidate moves the deployed Group C operating point beyond the descriptive F1–F4
trend (Appendix G.1). It does not exceed the reference-assisted fixed-pool oracle, so it demonstrates
a practical intervention rather than a necessary capacity expansion.
