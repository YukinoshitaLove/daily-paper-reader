## 摘要
单步生成模型能够实现快速的文本引导图像编辑，但往往会对本应保持不变的区域引入非预期变化。时间聚合可在不同噪声水平上稳定编辑场，却使其空间分配对可靠性的局部变化不敏感。因此，仅靠时间稳定性并不能保证空间一致的编辑。为解决这一局限，我们提出 ER-Chord，一种无需训练、无需反演的可靠性引导空间重分配框架。我们的关键见解是：相邻噪声水平下编辑场之间的一致性可为分配编辑强度提供局部可靠性信号。我们将该分配建模为等能量优化，在保持原始编辑方向与总控制能量的同时，根据局部可靠性重新分配控制能量。该建模具有唯一全局解，可利用现有编辑场评估高效计算，且无需额外调用去噪器。在 PIE-Bench 和 TEdBench 两个基准上的实验表明，该方法优于当前最先进的单步编辑基线，在多个生成骨干网络上均取得一致增益，并实现了更优的源图像保持。项目页面为 https://github.com/Peizeli1/ER-Chord。

## Abstract
One-step generative models enable fast text-guided image editing, yet they often introduce unintended changes to regions that should remain unchanged. Temporal aggregation stabilizes editing fields across noise levels, but leaves their spatial allocation insensitive to local variations in reliability. Consequently, temporal stability alone does not ensure spatially consistent editing. To address this lim- itation, we propose ER-Chord, a training-free and inversion-free framework for reliability-guided spatial redistribution. Our key insight is that agreement between editing fields at neighboring noise levels provides a local reliability signal for allocating editing strength. We formulate this allocation as an equal-energy op- timization that redistributes control energy according to local reliability while preserving the original editing directions and total control energy. This formu- lation admits a unique global solution that can be efficiently computed using existing field evaluations, requiring no additional denoiser calls. Experiments on two benchmarks, PIE-Bench and TEdBench, demonstrate improvements over state-of-the-art one-step editing baselines, achieving superior source preservation alongside consistent gains across multiple generative backbones.The project page is at https://github.com/Peizeli1/ER-Chord.

## 1. 核心问题与整体含义

- **研究背景**：单步扩散/流模型（SD-Turbo、InstaFlow、SwiftBrush-v2 等）把采样压缩为一次网络前向，可实现实时文本引导编辑；但编辑真实图像时，必须在引入目标语义变化的同时保持源图身份、结构与非编辑区域不变。
- **现有方案局限**：免训练、免反演的传输式编辑（以 ChordEdit 为代表）通过对相邻噪声水平（t−δ 与 t）的源→目标代理场做**时间聚合**来稳定单步编辑场。但该聚合权重是全局标量、对所有空间位置一视同仁，每个像素的编辑强度只是端点场混合的"被动结果"。
- **核心洞察**：不同空间位置上，两个端点场的**一致性程度差异很大**——有些区域跨噪声层控制向量稳定一致，有些区域则明显分歧。均匀的时间聚合忽略了这种空间可靠性差异，会把大量更新错误地注入本应保持不变的背景，产生颜色渗漏与伪影。
- **问题定位**：**时间稳定性并不等价于空间一致性**；"空间幅度分配"是时间聚合之外一个尚未被处理的关键自由度。论文据此区分"控制场何处可靠"与"语义编辑应发生在何处"，并提出用端点一致性作为内在可靠性信号来重分配编辑强度。

## 2. 方法论

- **核心思想**：保留 ChordEdit 已给出的局部编辑方向与总控制能量，只重新分配各空间位置的幅度；可靠性高（端点一致）的位置获得更大乘子，可靠性低的位置被压低，整体能量守恒，避免"全局减弱编辑"这种虚假的保真提升。
- **基础场**：对每个空间位置 p，时间聚合 Chord 场为
  - `uC(p) = t/(t+δ)·Rt−δ(p) + δ/(t+δ)·Rt(p)`
  - 其中 `Rt−δ`、`Rt` 为两个相邻噪声时刻的源→目标代理场。
- **可靠性信号**：
  - 信号幅度 `sp = ‖uC(p)‖₂`；端点分歧 `dp = ‖Rt(p) − Rt−δ(p)‖₂`；
  - 归一化一致性分数 `cp = clip[0,1]( sp / max{sp + κ·dp, εc} )`，κ≥0、εc>0；
  - cp 越大表示端点越一致（相对局部控制幅度而言），它只是"时间一致性"信号，不代表语义正确性。
- **等能量重分配优化**：
  - 目标函数：`min_u ½Σ‖u(p) − uC(p)‖₂² + μ/2·Σ(1−cp)²‖u(p)‖₂²`，约束 `‖u‖_F² = EC`（EC 为原 Chord 场总能量），0≤μ<1；
  - 第一项保持对原场的保真，第二项惩罚低一致性位置的能量，等式约束保证总能量严格不变。
- **定理 3.1（唯一方向保持解）**：
  - 令 `ap = 1 + μ(1−cp)²`，则存在唯一标量 `η* ∈ [−μ, 0]`，使
  - `uER(p) = uC(p) / (ap + η*)`，即 `uER(p) = mp·uC(p)`，`mp = 1/(ap + η*)`；
  - η* 是方程 `Σ ‖uC(p)‖₂²/(ap + η)² = EC` 的唯一根。
- **求解与性质**：
  - 对 η 在 [−μ, 0] 上做一维二分（≤32 次迭代，CPU <0.01 s），复杂度 O(K·C·H·W)，仅通道归约与逐元素运算，**不增加任何去噪器调用**；
  - 乘子范围 `1/(1+μ) ≤ mp ≤ 1/(1−μ)`，且 cp 越大 mp 越大；方向不变、总能量不变；
  - 空间能量份额关系 `πER_p = mp²·πC_p`；
  - 附录还给出可靠性加权能量证书（命题 A.1）与对偶根界（命题 A.2），可收紧二分区间。
- **整体流程**：复用 ChordEdit 的两个端点场 → 计算一致性分数与权重 → 二分求 η* → 施加空间乘子 → 标准 Chord 更新 → 目标条件清理（cleanup 阶段不变）。

## 8. 局限与可改进之处

- **可靠性信号的语义盲区**：端点一致性 `cp` 只度量"两个相邻噪声时刻的控制向量是否同向同幅"，并不判断该处**是否应当被编辑**。若目标语义与源图在某区域本就高度相似，或两时刻恰好一致地"错误"（例如一致地渗漏到邻近背景），该方法仍可能把能量集中到错误位置。论文虽在文中承认这一点，但缺少针对"一致但错误"情形的定量分析。
- **超参敏感性未系统考察**：`μ=0.25`、`κ=1.0` 全程固定且未在外部基准上调参，这保证了比较公平，但也意味着**未报告 μ、κ 的敏感性曲线**。μ→0 退化为原 ChordEdit，μ→1 时乘子动态范围扩大到 [1/2, ∞)，极端值是否引发过增强伪影尚不清楚。
- **掩码依赖与评价口径**：PIE-Bench 的保真指标均在给定编辑掩码之外计算，而 ER-Chord 本身并不使用掩码。因此"背景保持提升"在无掩码的真实应用（如整图风格迁移、无明确编辑区域）中能否复现，缺少验证。
- **基准覆盖有限**：外部泛化仅在 TEdBench（100 例）上验证，规模偏小；且未在该基准上与其他单步编辑方法做同等规模系统对比。定性结果主要来自 PIE-Bench，类别覆盖的均衡性未说明。
- **统计稳健性不足**：未报告多随机种子下的均值±方差或置信区间，+0.57 dB 这类增益在单步随机采样下的波动幅度未知；虽采用成对比较（paired by source example），但未给出显著性检验。
- **方法定位的边界**：ER-Chord 是**对既有传输式单步编辑器的后处理式增强**，其收益上限受制于 ChordEdit 端点场本身的质量；对多步扩散或反演类方法是否适用（它们没有"两个相邻噪声时刻的代理场"这一结构）未作讨论。
- **算力透明度**：未报告 GPU 型号/数量，复现计时与显存的绝对可比性受限；亦未讨论在更高分辨率（如 1024²）下二分求解与逐元素运算的开销变化。

## 9. 总体评价与启示

- **定位**：这是一篇**问题驱动、增量精确**的方法论文——不提出新架构或新训练范式，而是在已有免训练单步编辑管线上识别出一个被忽略的自由度（空间幅度分配），并用一个带等式约束的凸二次规划给出闭式结构 + 一维求根的精确解。
- **核心贡献的可迁移性**："用内在一致性信号作为可靠性权重，在能量守恒约束下重分配"这一思路并不限于 Chord 场：任何"多源聚合 → 单一控制场"的免训练编辑方法（如多尺度特征注入、多步引导平均）都可能存在类似的"聚合权重全局均匀"问题，可借鉴其等能量重参数化 + 标量对偶求解的构造。
- **方法论严谨度**：理论部分（存在性、唯一性、方向保持、乘子界、对偶根界、可靠性加权能量证书）与实验部分（全量 700 例、两类消融、跨 3 骨干、700 例数值残差诊断）形成闭环，且主动报告"信号不代表语义正确性"这一负面边界，学术诚实度较高。
- **实际价值**：零额外 NFE、零训练、显存与耗时几乎不变（0.37 s vs. 0.38 s/图），对实时单步编辑场景具有直接工程价值；+0.57 dB PSNR 与一致的 CLIP 双指标提升虽幅度温和，但在"总能量严格相等"的约束下更具说服力。
- **后续可探索方向**：将可靠性信号从"时间端点一致性"扩展到"跨尺度/跨条件一致性"；引入轻量的语义先验（如文本-图像跨注意力图）与一致性信号联合加权，以缓解"一致但错误"；在无掩码、高分辨率与视频编辑场景中验证泛化性。
