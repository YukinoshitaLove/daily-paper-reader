## 摘要
潜扩散模型近期在真实世界图像超分辨率（Real-SR）中取得了显著进展。然而，现有方法始终表现出一种持续的跷跷板效应：提升感知真实感会损害结构保真度。我们认为，这一效应并非扩散模型所固有，而在很大程度上源于当前主流两阶段框架的架构约束。为应对这一挑战，我们提出 PixelSR，一种新颖的、直接在像素空间中运行的单阶段像素扩散 Transformer，用于 Real-SR。具体而言，PixelSR 包含两个核心设计：像素空间条件扩散与正交流解耦。前者通过整合空间对齐的低分辨率条件、视觉语义引导和轻量纹理细化，建立有效的像素空间复原框架，从而绕过 VAE 压缩并能够直接在 RGB 空间中端到端优化。作为补充，后者将非对称流目标分解为低秩语义分量和无噪声正交纹理分量。通过将这些分量路由到专门分支，它实现了相互干扰更小的解耦优化。得益于这些设计，我们的 PixelSR 在忠实保留结构内容的同时恢复出感知真实的细节。跨多个基准的大量实验表明，PixelSR 不仅取得了有竞争力的性能，而且有效缓解了保真度—真实感跷跷板效应。

## Abstract
Latent diffusion models have recently achieved remarkable progress in Real-world Image Super-Resolution (Real-SR). However, existing methods consistently exhibit a persistent seesaw effect: enhancing perceptual realism compromises structural fidelity. This effect, we argue, is not intrinsic to diffusion models, but largely stems from the architectural constraints of prevailing two-stage frameworks. To address this challenge, we propose PixelSR, a novel single-stage Pixel Diffusion Transformer for Real-SR that operates directly in pixel space. Specifically, PixelSR consists of two core designs: Pixel-space Conditional Diffusion and Orthogonal Flow Decoupling. The former establishes an effective pixel-space restoration framework by integrating spatially aligned LR conditioning, visual semantic guidance, and lightweight texture refinement, thereby bypassing VAE compression and enabling end-to-end optimization directly in RGB space. Complementarily, the latter decomposes the asymmetric flow target into a low-rank semantic component and a noise-free orthogonal texture component. By routing these components to specialized branches, it achieves decoupled optimization with reduced mutual interference. Benefiting from these designs, our PixelSR restores perceptually realistic details while faithfully preserving structural content. Extensive experiments across multiple benchmarks demonstrate that PixelSR not only achieves competitive performance, but also effectively mitigates the fidelity--realism seesaw effect.

  1. **VAE 有损重建**：预训练 VAE 丢弃高频细节与细粒度结构，从根本上限制结构保真度上限；
  2. **两阶段流水线割裂**：潜空间生成与像素解码无法端到端优化，重建误差与近似误差在两级间级联累积。
- **由此引出关键问题**：能否绕过潜空间瓶颈，直接在像素空间执行 Real-SR？
- **像素空间建模的新挑战**：仅绕过 VAE 并不自动解决权衡问题。标准流匹配的速度目标 `v := ϵ − x0` 将全维噪声预测与干净图像重建耦合，迫使单一网络同时承担“高层语义生成”（依赖生成先验）与“低层纹理恢复”（要求严格像素对齐）两类冲突角色，形成任务纠缠。
- **研究意义**：论文试图论证跷跷板效应是框架约束而非模型本质，并提出单阶段像素空间端到端新范式，为调和生成先验与严格结构保真提供原则性基线。

## 2. 方法论

### 2.1 核心思想
- 提出 **PixelSR**：单阶段像素扩散 Transformer，直接在 RGB 空间端到端完成 Real-SR。
- 两大支柱：
  - **PCD（像素空间条件扩散）**：构建有效的像素空间复原骨干，绕过 VAE 编解码；
  - **OFD（正交流解耦）**：将非对称流目标显式分解为低秩语义分量与无噪正交纹理分量，分配给专用分支，降低优化干扰。

### 2.2 预备知识（流匹配参数化演进）
- 采用 Rectified Flow 线性概率路径：`xt = (1−t)x0 + tϵ`，速度 `v = ϵ − x0`，CFM 损失为 `E‖v̂θ − v‖²`。
- **v-prediction**：网络直接预测 `v`，需保留全维噪声，在像素空间极难。
- **x0-prediction**：网络输出 `x̂0`，再换算 `v̂ = (xt − x̂0)/t`；避免预测全维噪声，但 t→0 时数值病态。
- **AsymFlow 非对称目标**：用秩 r 正交投影 `P = AAᵀ`（`AᵀA = I_r`）定义 `uA := Pϵ − x0`；`P=I` 退化为 v-prediction，`P=0` 近似 x0-prediction，可平衡低秩噪声预测与全维干净图像预测。但 AsymFlow 仍将 `uA` 作为单一整体目标输出。

### 2.3 PCD：像素空间条件扩散（三处关键设计）
- **空间对齐 LR 条件**：LR 图像 `y` 重采样后与噪声状态 `xt` 通道拼接 `ht = Concat(xt, ỹ) ∈ R^{B×2C×H×W}`，再按 p×p 切块嵌入为 DiT token `f0 = PatchEmbed_p(ht)`，为每个噪声位置提供稠密结构约束。
- **视觉语义引导**：冻结 DINOv2-B/14 提取高层语义 `z = Πvis(Evis(y))`，经交叉注意力注入每个 DiT block，补偿严重退化下像素条件语义不足的问题。
- **轻量纹理精修**：引入由 PiT blocks 组成的 Pixel Decoder，将每个 p×p 区域表示为 p² 个像素级 token `q0 = PixelEmbed_p(ht)`；DiT 最终特征展开为 patch 级条件 `cpat`，通过 AdaLN 注入 PiT block，在全局结构/语义上下文下细化局部纹理。
- 基础 PCD 以 x0 预测输出完整干净图像，并用 CFM 损失优化。

### 2.4 OFD：正交流解耦（核心创新）
- **正交目标分解**：利用投影性质得
  - `P uA = P v`（低秩子空间内保留随机速度预测）；
  - `(I−P)uA = −(I−P)x0`（正交补完全无噪，退化为干净图像残差的确定性重建）。
  - 两分量位于相互正交子空间，预测目标互不重叠。
- **语义–纹理解释**：可视化显示投影分量主要保留全局内容与粗结构，正交补集中于边缘、文字模式与高频纹理。据此将 `P uA` 关联语义生成、`(I−P)uA` 关联纹理重建（后者还提供无噪监督）。
- **投影基构造**：比较三种方案——联合学习的正交基、基于像素统计的 SVD 基、与预训练 VAE 潜 token 做 Procrustes 对齐的基；实验表明 **Procrustes 基最优**。关键点：VAE 仅离线用于初始化投影器，**不参与 PixelSR 的训练与推理**，只提供对齐起点而非强加有损重建瓶颈。
- **任务对齐分支分配**：全局聚焦的 DiT 骨干负责语义预测 `û∥ = P ûsem`；局部聚焦的 Pixel Decoder 负责纹理预测 `û⊥ = (I−P) ûtex`，实现预测空间隔离。
- **全秩速度恢复与训练**：由 `xt = x0 + tv` 与分解式推出
  - `v̂ = û∥ + (1/t)[(I−P)xt + û⊥]`；
  - 用标准 CFM 损失对全秩目标 `v` 优化。由于两分支预测误差处于正交子空间，其内积交叉项为零，可联合训练而不混合优化信号。
- **推理**：恢复的速度直接交由标准 ODE 求解器积分，采样流程无需修改。
- **关键超参**：秩 `r=16`、patch 尺寸 `p=16`；`r=16` 同时对应 f8c4 VAE 下每个 16×16 RGB patch 的 2×2×4=16 个潜系数，便于维度对齐的 Procrustes 拟合；最小噪声尺度 0.05。

## 5. 实验结果与主要发现

### 5.1 主要定量结果
- **整体排名**：在 4 个 benchmark、8 个对比方法上，PixelSR 取得**平均排名第一**的聚合结果，且是少数能在参考指标与无参考指标上同时进入前列的方法，直接支撑“跷跷板效应可被框架设计缓解”的核心论断。
- **参考保真度**：在 LSDIR 验证集等合成评测上，PixelSR 的 PSNR/SSIM/LPIPS 优于 StableSR、DiffBIR、OSEDiff、SinSR、CODSR 等潜空间方法，说明绕过 VAE 确实抬高了结构保真度上限；与 DiT4SR、DiT-SR 等像素/Transformer 类方法相比亦具竞争力。
- **感知真实感**：在 MUSIQ、MANIQA、DeQA 等无参考指标上，PixelSR 与最强感知导向方法（如 OSEDiff、COSRD）处于同一水平区间，未出现为保真度而显著牺牲真实感的退化。
- **跨域泛化**：在 ScreenSR（文字/UI 高频结构）与自建 UGCSR（真实流媒体退化）上优势更明显，说明像素空间对齐对文字、边缘等高频内容的恢复尤为关键，也呼应了“潜空间压缩丢失高频细节”的动机分析。

## 6. 贡献与意义
- **范式层面**：提出单阶段像素空间 Real-SR 端到端框架，证明无需 VAE 潜空间亦可高效训练扩散 Transformer，挑战了“潜空间是 Real-SR 必由之路”的默认假设。
- **方法层面**：OFD 将非对称流目标分解为正交的语义/纹理分量并分配给专用分支，为“生成先验”与“像素保真”的冲突提供可操作的结构性解法；其零交叉项性质使联合训练在理论上无信号混合。
- **工程层面**：Procrustes 初始化巧妙复用 VAE 的潜结构知识而不引入其推理瓶颈，是一种“借知识不借瓶颈”的轻量做法。
- **评测层面**：构建 UGCSR 真实退化 benchmark，补充了现有评测在真实流媒体场景下的空白。

## 7. 局限性与待验证问题
- **算力与效率透明度不足**：像素空间高分辨率扩散的计算开销通常高于潜空间，论文虽报告参数量与单卡测试环境，但缺少与潜空间方法的训练/推理成本对比，难以判断效率代价。
- **高分辨率可扩展性**：实验主要在 512×512 级别，像素空间 token 数随分辨率平方增长，向 2K/4K 扩展的可行性未充分讨论。
- **秩 r 与 patch 尺寸的敏感性**：r=16 与 f8c4 VAE 的维度对应关系较强，若换用其他压缩率 VAE 或纯手工设定，最优 r 是否稳定尚需更多证据。
- **理论解释偏经验**：语义/纹理与两个正交子空间的对应主要依赖可视化与频率分析，缺乏更严格的理论刻画。
- **UGCSR 的独立性**：自建 benchmark 由作者提出，其退化分布与评测公平性有待社区复现检验。

## 8. 结论
论文以“跷跷板效应源于两阶段 LDM 框架而非扩散本质”为出发点，提出 PixelSR 单阶段像素空间扩散 Transformer，并通过 PCD（空间对齐条件、语义引导、PiT 纹理精修）与 OFD（正交流分解 + 语义/纹理分支分配）在多个 benchmark 上同时改善保真度与感知质量。其核心价值在于提供了一个原则性的像素空间基线，并把“如何在一个网络中调和生成与复原”这一难题转化为可分解、可监督的结构设计问题。
