## 摘要
盲一体化图像恢复必须在测试时无任务标签的情况下，使共享模型适应异构且有时混合的退化。我们提出 WaFIR，一种解码器模块，它将特征分解为 Haar 子带，用紧凑的傅里叶描述子对每个子带进行概括，并将其路由到由提示条件化的谱调制专家。与图像级频率条件化不同，WaFIR 在子带级别做出路由决策，从而在保留骨干网络所学任务上下文的同时实现频率特定处理。在去噪、去雨和去雾的统一训练与评估协议下，WaFIR 在三项任务上的平均 PSNR 相较 PromptIR 基线提升 0.48 dB，相较近期的 Up-Restorer 提升 0.38 dB。容量匹配与路由控制实验表明，该增益不能仅由额外参数解释。在未见噪声强度下，基于描述子的路由比离散标签条件化的替代方案更稳健，并在复合退化下保持相当性能；路由分析表明，不同退化类型下专家使用呈现稳定的子带依赖性。这些结果支持将子带频率结构作为盲图像恢复中基于提示的条件化的一种可解释补充。代码见 https://anonymous.4open.science/r/WaFIR/README.md

## Abstract
Blind all-in-one image restoration must adapt a shared model to heterogeneous and sometimes mixed degradations without a task label at test time. We introduce WaFIR, a decoder module that decomposes features into Haar subbands, summarizes each subband with a compact Fourier descriptor, and routes it to prompt-conditioned spectral modulation experts. Unlike image-level frequency conditioning, WaFIR makes routing decisions at the subband level, enabling frequency-specific processing while retaining the task context learned by the backbone. Under a unified training and evaluation protocol for denoising, deraining, and dehazing, WaFIR improves average PSNR over the three tasks by 0.48 dB over the PromptIR baseline and by 0.38 dB over the recent Up-Restorer. Matched-capacity and routing controls show that the gain is not explained by additional parameters alone. On unseen noise intensities, descriptor-based routing is more robust than a discrete label-conditioned alternative and remains on par under compound degradations, while routing analyses show stable subband-dependent expert use across degradation types. These results support subband frequency structure as an interpretable complement to prompt-based conditioning for blind image restoration. Code is available at https://anonymous.4open.science/r/WaFIR/README.md

## 一、核心问题与研究动机

- **核心问题**：盲一体化图像恢复（blind all-in-one image restoration）要求同一个模型在测试时**没有任务标签**的情况下处理异构退化，甚至混合退化（去噪、去雨、去雾）。
- **现有方法局限**：PromptIR、AdaIR、Up-Restorer 等方法通常用**图像级**的条件信号（学习到的提示、退化嵌入、全局特征摘要）来做自适应，这种信号只能反映整体恢复上下文，**无法分辨退化能量在不同频带上的分布**。
- **频率观察**：不同退化在频域上具有可区分的结构特征：
  - 雾主要改变**低频分量**（LL 子带能量 +23%）；
  - 雨条纹把方向性能量集中在**中高频子带**（HL +69%）；
  - 噪声在频谱上近似均匀，但因自然图像谱随频率衰减而在**高频占主导**（HH 实际 +2214%）。
- **核心假设**：这些频谱特征可直接从中间特征计算得到（无需退化标签），因此**子带级频率结构**比全局摘要更适合作为路由信号，而提示特征提供互补的任务上下文。

## 二、方法论

### 2.1 总体思路
- 在 PromptIR 的**三个解码器层级**（L3/L2/L1，通道 384/192/96）的提示生成步骤之后插入 **SPMoE（Spectral Mixture-of-Experts）模块**：
  `f'_ℓ = S_ℓ(f_ℓ, p_ℓ)`；其余骨干不变，令 S_ℓ 为恒等映射即可**精确还原 PromptIR**（即插即用）。

### 2.2 关键技术流程
1. **Haar 小波分解**：对特征 x 做单级 2D Haar DWT，得到 `[LL; LH; HL; HH] ∈ R^{B×4C×H/2×W/2}`；归一化因子 1/√2 使变换为**酉变换**，IDWT 可无损重建，且无参数、O(N) 复杂度。
2. **6 维傅里叶描述子**（每个子带独立计算，参数为零）：
   - d0 = 全局能量均值；d1 = 幅度谱方差（噪声→平坦谱）；d2 = 低频/DC 能量（雾）；d3 = 高频能量（噪声、锐边）；d4 = 水平频带（雨、方向模糊）；d5 = 垂直频带。
   - 四个子带分别得到 d_LL, d_LH, d_HL, d_HH ∈ R^{B×6}。
3. **谱路由器与稀疏 Top-k 门控**：
   - 融合描述子与**平均池化的提示向量**：`r = [d; p̄]`；
   - 两层 MLP 输出 E=4 个专家 logits：`g = W₂·GELU(W₁r)`；
   - **top-k=2** 稀疏选择后 softmax 归一化，其余权重置 0；每样本每子带的计算量随 E 增长保持固定。
4. **傅里叶专家（谱调制）**：
   - rFFT2 得幅度 m 与相位 φ；
   - 幅度：`m' = max(m·(1+tanh(a)) + b, 0)`，a、b 由提示条件 MLP 逐通道预测，tanh 把缩放限制在 (0,2)，max 保证非负；
   - 相位：`φ' = φ + tanh(c)·(π/4)`，扰动限制在 ±45°，**最后一层零初始化**使训练初期近似恒等；
   - `ŝ = irfft2(polar(m', φ'))`，再经深度可分离 3×3 + 逐点卷积做空间细化。
5. **跨子带交互与残差门控**：
   - 四子带拼接后经 **分组 1×1 卷积（g=C 组）** 交互（仅 4C 参数），再 IDWT 重建；
   - 输出：`x' = x + γ⊙Conv1×1(r)`，γ 为**零初始化**的逐通道门控，保证训练起点等价于 PromptIR。
6. **训练目标**：`L = L_rec(ℓ1) + λ·L_lb`，λ=0.01；**逐子带负载均衡损失** `L_lb = (1/S)Σ_s Σ_e (w̄_{s,e} − 1/E)²`，防止专家坍缩，且避免全局平衡约束下的“子带固定配对”退化解。
