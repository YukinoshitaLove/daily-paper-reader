## 摘要
大多数视频编辑系统仍缺乏显式的分层视频表示，这限制了它们执行逼真合成、对象重用和一致性操作的能力。这一局限性在视频对象插入和视频图层分解中尤为突出，由于缺乏显式的前景图层监督，现有方法依赖隐式推理或逐场景优化。我们引入了TriLayer，这是一个大规模的三元组视频数据集，包含对齐的合成、背景和前景视频，其中前景图层同时包含对象外观和相关视觉效果。这种显式监督使模型能够直接学习分层视频表示，而非隐式推断。基于此数据集，我们提出了DBL-Diffusion，这是一个双分支扩散框架，通过共享去噪和跨分支交互，联合建模RGB合成和RGBA前景图层。我们在两个任务中实例化了该框架：用于分层对象插入的DBL-Insert，生成显式RGBA图层以实现逼真合成和灵活后期编辑；以及用于视频图层分解的DBL-Decompose，利用三元组监督恢复前景和背景图层。实验表明，显式图层建模显著提升了插入保真度和分解质量。

## Abstract
Most video editing systems still lack explicit layered video representations, limiting their ability to perform realistic compositing, object reuse, and consistent manipulation. This limitation is especially pronounced in video object insertion and video layer decomposition, where existing methods rely on implicit inference or per-scene optimization due to the absence of explicit foreground-layer supervision. We introduce TriLayer, a large-scale triplet video dataset containing aligned composite, background, and foreground videos, where the foreground layers include both object appearance and associated visual effects. This explicit supervision enables models to learn layered video representations directly rather than inferring them implicitly. Building on this dataset, we propose DBL-Diffusion, a dual-branch diffusion framework that jointly models RGB composites and RGBA foreground layers through shared denoising and cross-branch interaction. We instantiate the framework in two tasks: DBL-Insert for layered object insertion, which generates explicit RGBA layers for realistic compositing and flexible post-editing, and DBL-Decompose for video layer decomposition, which recovers foreground and background layers using triplet supervision. Experiments demonstrate that explicit layer modeling substantially improves both insertion fidelity and decomposition quality.

## 一、论文的核心问题与整体含义

当前视频编辑系统普遍缺乏**显式的分层视频表示**（前景/背景/合成），导致以下问题：
- **视频对象插入**：现有方法多为隐式修补或仅基于 RGB 合成，无法生成包含阴影、反射等视觉效果的前景图层，合成的真实感和后编辑灵活性受限。
- **视频图层分解**：现有方法因缺少前景层真值监督，只能依赖逐场景优化或隐式推断，难以推广，且无法精确分离透明效果。

本文的**核心思路**是：**通过显式的前景–背景–合成三元组监督，让模型直接学习分层视频表示**，从而同时提升插入保真度和分解精度，并支持灵活的图层级编辑。

## 二、方法论

### 2.1 TriLayer 数据集
构建了首个大规模**三元组视频数据集**：
- 每个样本包含**合成视频（composite）**、**背景视频（无对象及效果）**、**前景视频（RGBA，含对象及阴影等效果）**。
- 数据管线：采集野外视频 → VLM 过滤 → 前景掩码提取（Grounded‑SAM2）→ 背景重建（ROSE）→ 混合 Gen‑Omnimatte / MatAnyone / SAM2 生成 RGBA 前景层 → 多轮人工过滤。
- 最终得到 **3,964** 个高质量三元组，覆盖 229 个对象类别，提供对象名和 VLM 生成的外观/效果描述文本。

### 2.2 DBL‑Diffusion 双分支扩散框架
- 基于 **VACE** 扩散 Transformer，采用**RGB 分支**和**RGBA 分支**。
- RGB 分支预测场景级合成视频；RGBA 分支预测含透明度的前景层（使用 WAN‑alpha 的 RGBA VAE）。
- 两个分支通过**联合交叉注意力**双向交互，共享去噪骨干。
- **DBL‑Insert**：输入背景视频、文本提示、边界框序列、编辑后的首帧；RGBA 分支生成前景层，RGB 分支生成合成视频。最终使用 RGBA 前景与背景进行 alpha 混合，实现逼真且可编辑的插入。
- **DBL‑Decompose**：输入合成视频、对象描述、对象名称、对象掩码序列；RGB 分支去除前景恢复背景，RGBA 分支输出前景层。

### 2.3 训练策略
- RGB 分支采用 **LoRA**（域内适应），RGBA 分支采用 **DoRA**（支持分布外学习，如透明度、效果），构成混合 LoRA–DoRA 训练。
- 使用**解耦时间步采样**（每个分支独立采样噪声级别），在整流流（rectified flow）框架下联合优化速度预测损失。

## 三、实验设计

### 3.1 数据集与基准
- **插入任务**：TriLayer 构建的 **LayeredVid‑Benchmark**（85 个视频，包含多种对象和运动）。
- **分解任务背景重建**：使用 **Movie** 和 **Kubric** 基准。
- 内部 **VFX 数据集**（1,155 个三元组，测试用 15 个），用于验证半透明效果（火、烟等）的处理能力。

### 3.2 对比方法
- **视频对象插入**：AnyV2V、ReVideo、VACE‑Inp（标准修补）、VACE‑C（背景‑合成监督）、VACE‑F（背景‑前景监督）等。
- **图层分解**：
  - 前景层比较：Gen‑Omnimatte、OmnimatteZero。
  - 背景重建比较：Omnimatte 系列、D2NeRF、LNA、DiffuEraser、Propainter 等。

### 3.3 评估指标
- 插入：ViCLIP‑T（文本‑视频对齐）、VBench 质量指标（背景/主体一致性、运动平滑度、美学、成像质量）、CLIP‑I / DINO‑I（主体一致性）。
- 分解与背景重建：PSNR、SSIM、LPIPS、FID（感知质量）。
- 用户研究：20 人、10 段视频，评估主体一致性、插入合理性、提示对齐、整体质量；背景和前景分解质量。

## 四、资源与算力

- 基于 **Wan2.1‑VACE‑1.3B** 扩散 Transformer。
- 训练：**3 个 epoch**，AdamW 优化器，学习率 \(1\times 10^{-4}\)。
- LoRA 秩 128（RGB），DoRA 秩 32（RGBA）。
- 推理：**50 步采样**，生成 81 帧、分辨率 480×832 的视频。
- 硬件：所有实验在**单张 NVIDIA A100 80GB GPU** 上进行；推理约需 **1 小时/样本**。
- 未明确报告训练总时长。

## 五、实验数量与充分性

- **对比实验**：插入任务与 5 种现有 / 变体方法在 LayeredVid‑Benchmark 上定量对比；分解任务与 7 种方法在两个公开基准上对比。
- **消融实验**：

  - 前景条件信号（首帧编辑信息 / 对象掩码引导）的消融。
  - 解耦时间步采样的消融（定量，PSNR/SSIM/LPIPS/FID）。
- **应用验证**：图层级编辑（背景替换、对象复制、重着色等）、场景感知编辑、VFX 半透明元素插入与分解。
- **用户研究**：20 人参与，10 段视频，评分插入和分解的感性质量。
- 整体实验**较为充分**，覆盖多个任务、多种指标，消融验证关键设计选择，主观评价增强说服力，但 VFX 数据集规模较小，且仅定性展示。

## 六、主要结论与发现

- 显式三元组监督（TriLayer）使模型能够直接学习分层视频表示，克服了以往方法的隐式推断瓶颈。
- 双分支架构（RGB + RGBA）通过联合交叉注意力和解耦训练，能同时生成场景合成和包含效果的前景图层。
- **DBL‑Insert** 相比单分支或修补方法，在主体一致性、背景保持、插入真实感和后编辑灵活性上均显著提升。
- **DBL‑Decompose** 在保持合理视觉质量的同时，生成更清晰的前景层（含效果），背景重建虽然像素级指标可能略低于纯重建方法，但感知质量更优。
- 框架支持图层级编辑、场景感知效果生成以及半透明 VFX 处理。

## 七、优点

- **数据集贡献**：首个提供显式前景‑背景‑合成三元组的大规模视频数据集，填补行业空白。
- **方法创新**：首次将双分支扩散架构用于视频的分层建模，RGBA 分支直接输出包含效果的前景图层，支持透明度与阴影等。
- **统一框架**：同一骨干可同时用于插入和分解两个任务，且均可输出显式图层，便于编辑。
- **训练策略合理**：混合 LoRA/DoRA 及解耦时间步采样有效稳定了分层学习。
- **实验全面**：涵盖定量、定性、消融、用户研究和多种应用场景。

## 八、不足与局限

- **复杂物理交互**：对高度动态的运动、复杂物理现象（如流体、严重遮挡）处理仍不力。
- **计算开销大**：双分支扩散架构导致训练和推理成本高，生成一段 81 帧视频需要 1 小时。
- **分辨率与时长限制**：当前仅验证 480×832、81 帧，扩展到更长或更高分辨率尚未评估。
- **VFX 数据集规模小**：仅为内部 1,155 个片段，泛化到多种特效可能不足。
- **潜在数据偏差**：TriLayer 来源于特定网站，经 VLM 和人工过滤，可能导致对象类别、环境分布存在偏斜。
- **分解时背景重建的像素指标**：由于采用生成范式，PSNR/SSIM 可能不如专注重建的方法，更适合需感知自然度的场景。
- **未与部分最新方法对比**：如 OmniInsert、InsertAnywhere 等因代码未公开无法比较。
