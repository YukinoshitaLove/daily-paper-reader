## 摘要
近期，诸如 Flux.1-Kontext 等遵循指令的图像编辑器实现了文本驱动编辑，但缺乏对编辑应用位置和强度的细粒度控制。现有方法要么提供连续但全局的控制，要么提供固定强度的空间局部编辑。据我们所知，尚无方法同时支持显式空间定位、逐区域连续强度以及对多个主体的独立同步控制。我们提出 LOCI（多主体图像编辑的局部连续控制，LOcalized Continuous control for multi-subject Image editing）。给定包含逐主体区域和指令的多主体图像，LOCI 以独立选择且连续可调的强度编辑每个主体，例如逐渐让一个人变老，同时给另一个人添加胡须，并将跨区域泄漏降至最低。LOCI 将用于空间隔离的主体级注意力绑定与 Regional LoRA 层相结合，该层用与空间布局对齐的逐 token 缩放向量替代 LoRA 的标量系数。单个适配器在一个抑制点训练，推理时通过重新缩放其区域残差即可获得连续的编辑强度。在多主体场景上的实验表明，与基线相比，LOCI 在保持对编辑强度连续控制的同时，实现了较强的编辑保真度，并显著降低了跨区域干扰。

## Abstract
Recent instruction-following image editors such as Flux.1-Kontext enable text-driven editing but lack fine-grained control over where and how much an edit is applied. Existing approaches provide either continuous but global control or spatially localized editing at a fixed strength. To our knowledge, none jointly supports explicit spatial localization, continuous per-region strength, and independent simultaneous control of multiple subjects. We present LOCI (LOcalized Continuous control for multi- subject Image editing). Given a multi-subject image with per-subject regions and instructions, LOCI edits each subject at an independently chosen, continuously adjustable strength, for instance gradually aging one person while adding a beard to another with minimal cross-region leakage. LOCI pairs subject-level attention binding for spatial isolation with a Regional LoRA layer that replaces the LoRA's scalar coefficient with a per-token scaling vector aligned to the spatial layout. A single adapter is trained at one suppression point, and continuous edit strengths follow by rescaling its regional residual at inference. Experiments on multi-subject scenes demonstrate that LOCI achieves strong edit fidelity with significantly reduced cross-region interference compared to baselines, while maintaining continuous control over edit strength

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：以 Flux.1-Kontext 为代表的指令式（instruction-following）图像编辑器已能通过文本提示完成高质量编辑，但用户只能通过语言指定“改什么”，无法精确指定“改哪里”“改多少”。
- **现有方法的两条技术路线**：
  - **连续编辑类**（Concept Sliders、SliderEdit、Kontinuous Kontext 等）：提供连续强度控制，但只能通过文本间接定位主体。语言定位不够精确，无法区分“左侧第二只狗”这类同类别多实例；控制信号不与图像区域绑定，因此无法独立设定多个主体的强度，编辑也容易扩散到相邻区域。
  - **区域绑定类**（masked inpainting、IDAttn、LoMoE、区域 LoRA 组合等）：借助 mask 或注意力实现空间隔离，但只在单一固定强度下应用编辑，无法在“源图像”与“完全编辑”之间连续插值。
- **核心问题**：据作者所知，尚无方法能同时支持显式空间定位、逐区域连续强度和多主体独立同步控制。
- **整体含义**：LOCI 将“指令、空间支撑（box/mask）、连续控制系数”三者绑定为编辑的基本单元，在单次前向传播中让每个主体以独立、连续可调的强度被编辑，同时抑制跨区域泄漏，从而弥补上述两类方法之间的空白。

## 2. 方法论

### 2.1 核心思想
- 用 **Regional LoRA** 把 LoRA 的标量缩放系数 β 替换为逐 token 的缩放向量 λ，并让 λ 与“主体索引的 token 划分”对齐。
- 用 **Instance-Disentangled Attention（IDAttn）** 在注意力层做主体级隔离。
- 关键点：仅仅“在区域内写残差”不够，因为注意力会把影响扩散出去；**必须在训练时就使用与推理相同的 IDAttn 路由**，才能得到“区域局部化”的编辑方向，之后逐区域缩放才有意义。

### 2.2 技术细节与流程
- **基座**：冻结的 Flux.1-Kontext（MMDiT，19 个双流块 + 38 个单流块），采用 rectified-flow 目标。
- **Token 划分**：序列为 `Z = Ztext ‖ Ztarget ‖ Zcontext`；文本流按主体拼接为 `T1‖…‖TN`；目标/上下文 latent 按区域划分为 `Ln`、`Cn`，区域外为背景 `Lu`、`Cu`。
- **像素掩码到 token 网格的门控**：`Gn(j) = max_{p∈c(j)} Mn(p)`，即 token 覆盖块内任一像素属于主体即置 1（1024×1024 → 64×64 token 网格，每个 token 对应 16×16 像素）。
- **逐 token 缩放向量**：
  - 文本 token `Zj ∈ Tn`：`λj = αn`
  - 图像 token 命中某区域：`λj = α_{n⋆(j)}·Gn(j)`，重叠时取最大 α（最保守，即最少编辑）
  - 背景 token：`λj = 0`（不接收 LoRA 残差）
  - 代入后每层计算 `yj = Wxj + λj·ΔWxj`。
- **IDAttn 路由**：在 softmax 中加入 `Ω ∈ {0,−∞}` 的加性偏置；外层块 0–9 与 47–56 使用**协调（harmonization）**模式（主体图像 token 可读取全部视觉 token，恢复光照/背景连贯性），中间块 10–46 使用**解耦（disentanglement）**模式（各主体 token 仅在自己分区内注意，且分区外不能读取其指令块 Tn）。
- **单区域抑制训练**（无需成对编辑数据）：
  - 用同一源图与噪声水平做两次预测：`vref = F_R(Xt, Xsrc, e_neu)`（中性指令“keep the image the same”），`vadapt = F_λ_R(Xt, Xsrc, e)`（真实指令 + 适配器，α=1）。
  - 目标为 detached 的 `vref`，只在区域掩码 m 对应的目标 token 上计算归一化 MSE：`L = Σ mj‖vadapt,j − vref,j‖² / Σ mj`。
  - 两次前向共享路由 R，避免让适配器同时学习“抑制编辑”和“补偿路由差异”。
- **多区域推理**：训练只用单主体，推理时把 N 个 α 组装成同一个 λ 向量，同一适配器无需重训即可支持任意主体数量；α=1 为中性（不编辑），α=0 为名义编辑，α<0 为外推。

## 3. 实验设计

### 3.1 数据与 Benchmark
- **自建多主体评测集**：128 个场景、427 个“主体–区域–指令”三元组，每场景 2–7 个主体，涵盖人物、动物、车辆、家具及混合构图。
- **构建方式**：作者逐场景撰写规格，用 **Flux.2** 生成源图（1024×1024、28 步、guidance 3.5），人工筛选主体数量正确者；再用 **Grounding-DINO + SAM2** 离线生成 box 与 mask，并按从左到右排序固定主体编号。
- **重要设计**：生成器（Flux.2）与推理时被编辑的冻结编辑器（Flux.1-Kontext）不同，且与训练数据 HQ-Edit 不相交，避免“自评自”。
- **无空间接口的基线**：改用位置语言（如“最左边的狗”“从右数第二个人”）指定目标。

### 3.2 四个评测协议
- **协议 A（单目标编辑）**：只给一个主体指令，扫描其控制值。
- **协议 B（独立多控制）**：所有主体都有指令，但只移动一个控制，其余固定在 α=1。
- **协议 C（联合编辑）**：所有主体同时以 α=0 编辑，与 α=1 的中性输出对比。
- **协议 D（二维控制）**：双主体场景，两个控制各取 7 档 `{−1, −2/3, −1/3, 0, 1/3, 2/3, 1}`，构成 7×7 响应面，用于分离“自身控制响应”与“他人控制串扰”。

### 3.3 对比方法
1. SliderEdit（Selective Token LoRA，多指令变体，无 mask/box/路由）
2. SliderEdit + IDAttn（推理时事后拼接）
3. IDAttn only（仅路由，无 LoRA，无连续控制）
4. Regional LoRA without IDAttn（用相同掩码抑制目标训练，但全注意力）
5. **LOCI（本文）**

### 3.4 评价指标
- 协议 A/B：外推（CLIP、SigLIP 最大目标相似度）、解耦（LPIPS-Alex/VGG、DINOv2、ArcFace 与源图距离）、方向相关性（α 与相似度的 Spearman 秩相关）、平均范围（轨迹最大–最小相似度差）。
- 协议 C：区域成功率、最差区域 ΔCLIP。
- 协议 D：预期响应（自身控制引起的区域变化）、语义串扰、感知串扰（均以“他人控制引起的变化 / 自身控制引起的变化”度量）。
- 作者明确**弃用** SliderEdit 的 continuity score，理由是分箱统计对顺序和尺度均不敏感，噪声轨迹反而得分高（附录 B 给出论证）。

## 4. 资源与算力

- **训练硬件**：8×H200 GPU，数据并行，每卡 1 个样本（有效 batch size 8）。
- **训练规模**：10,000 步；训练数据来自 HQ-Edit，经 VLM 分类指令、Grounding-DINO + SAM2 生成掩码、过滤后得到 **22,482 个训练样本**（覆盖 21,962 条不同指令）；两个需要训练的方法（方法 4 与方法 5）各训练一个 rank-16 LoRA。
- **训练配置**：AdamW（lr=7×10⁻⁵，weight decay 10⁻⁵）、cosine schedule + 500 warmup、梯度裁剪 1.0、梯度检查点、logit-normal 时间步采样（μ=0, σ=1）、guidance embedding 3.5、无 SNR reweighting；LoRA 以 fp32 存储，主干以 bf16 计算。
- **推理配置**：1024×1024、28 步去噪、guidance 3.5、seed 0。
- **序列长度**：文本 512-token T5 编码截断至每指令块前 200 位，加 4096 噪声 token 与 4096 源图 token，单区域训练样本共 8,392 token。
- 论文未报告总 GPU 小时数或单次训练墙钟时间。

## 5. 实验数量与充分性

- **定量实验规模**：4 个协议 × 5 种方法（协议 B、D 仅对 slider-capable 方法），共 2 张主表（表 1、表 2），427 条轨迹参与 A/B 统计。
- **消融设计**：方法 3/4/5 分离“仅路由”“仅区域适配器”“两者结合”；方法 2 与方法 5 对比“事后拼接”与“路由感知训练”，构成较清晰的二×二式组件分析。
- **定性实验**：正文 4 个双主体场景（图 3），附录另有两个四主体场景（图 4、图 5），每个场景含“单独扫主体 1 / 单独扫主体 2 / 同时扫”三行。
- **充分性评估**：
  - **优点**：协议设计较系统，尤其协议 D 的二维网格能揭示协议 C 端点比较看不到的串扰；明确弃用有缺陷的 continuity 指标并给出替代诊断；聚合时先在源图内平均再跨图平均（附录 C），处理了同一源图多条样本的相关性。
  - **不足**：仅一个自建 benchmark（128 场景、427 三元组），规模偏小且为合成图像；仅一个基座模型（Flux.1-Kontext）；未与 Kontinuous Kontext、Concept Sliders、Differential Diffusion 等做定量对比（部分仅在相关工作/附录中讨论）；无用户研究；定性示例数量有限。
  - **公平性**：对无空间接口的基线给予位置语言提示，训练数据与推理基座设置一致，生成器与编辑器分离，整体比较条件较为公平；但“事后拼接”基线的训练细节未完全展开，其劣势可能部分来自训练/推理不匹配之外的实现因素。

## 6. 主要结论与发现

- **保真度与保持性同时最优**：在协议 A/B 下，LOCI 在 CLIP 与 SigLIP 两个编码器上均取得最高外推和最低解耦（LPIPS/DINOv2/Identity），打破了“编辑越强、保持越差”的常见权衡，说明其保持性并非来自“编辑更弱”。
- **连续控制质量最好**：方向相关性最负（排序最可靠）、平均范围最大（语义幅度最宽）。
- **联合编辑**：仅 IDAttn 的区域覆盖率最高（0.9153）但无连续控制；LOCI（0.9099）接近其覆盖率，同时保留逐主体滑杆，说明连续控制几乎不牺牲覆盖率。
- **二维控制揭示组件互补**：无路由的区域适配器“响应强但串扰最差”（甚至差于原始 SliderEdit），符合“编辑方向空间纠缠”的预期；事后拼接“隔离好但响应弱”；只有**在推理路由下训练**才能同时获得最强预期响应与最低串扰（语义 0.2211、感知 0.1860），不过相对事后拼接的感知

串扰优势幅度有限（说明“事后拼接”在纯隔离指标上仍是强基线，LOCI 的增益主要体现在“隔离与响应强度的联合最优化”上）。

- **控制语义的可解释性**：α=1 对应“不编辑/中性”，α=0 对应“名义编辑强度”，α<0 为外推；协议 A/B 中相似度随 α 单调下降、方向相关性为负且绝对值最大，说明该标量确实构成“编辑量”的有序刻度，而非仅是一个开关。协议 D 的 7×7 响应面进一步显示，LOCI 的响应主要沿对角线（自身控制轴）集中，非对角线（他人控制轴）上的变化被明显压低，这正是“逐区域连续强度 + 主体级隔离”共同作用的结果。
- **定性表现**：在双主体与四主体场景中，LOCI 能在保持其他主体与背景不变的前提下单独增强或减弱某一主体的编辑（如只改左侧狗的毛发、只给某一个人加帽子），而基线在移动一个滑杆时会出现相邻主体被连带修改或整图色调漂移的现象；四主体场景中这种差异更为明显，说明方法对主体数量的扩展具有一定鲁棒性（无需重训）。
- **组件结论**：消融支持“路由感知训练”是必要条件而非可选技巧——仅在推理时施加 IDAttn（方法 2）能得到较好的空间隔离，但由于适配器在训练时见过的是全注意力下的梯度，其学习到的编辑方向与推理时的路由不匹配，导致响应幅度被削弱；反之，只在区域内写残差而不做路由（方法 4），编辑方向本身在空间上就是纠缠的，逐区域缩放只会把这种纠缠按比例放大。两者结合（方法 5）才使“区域局部化的编辑方向”与“逐区域缩放”在语义上自洽。
- **覆盖率的解读**：仅 IDAttn 的区域成功率略高于 LOCI，但前者没有连续控制、无法逐主体调节强度；LOCI 以极小代价（0.9153 → 0.9099）换取完整的滑杆能力，这一差距在定性上难以察觉，属于可接受的权衡。

## 7. 局限性

- **评测规模与真实性**：benchmark 为自建、仅 128 个场景 / 427 个三元组，且源图由 Flux.2 合成而非真实照片；主体类别虽覆盖人物、动物、车辆、家具，但对遮挡严重、极小目标、密集同类实例（如人群）等困难构图的覆盖未知。
- **单一基座**：全部实验基于 Flux.1-Kontext，未验证方法在 SD3/FLUX.1-dev、其他 MMDiT 或 UNet 架构上的可迁移性；IDAttn 的“外层协调 / 内层解耦”分层区间（0–9、47–56 协调，10–46 解耦）是针对该模型深度手工选定的，换模型需重新调参。
- **依赖外部定位模块**：box/mask 由 Grounding-DINO + SAM2 离线提供，论文未评估定位误差（漏检、框偏移、mask 边界不准）对编辑质量的影响，也未讨论端到端联合定位的可能性；实际使用中用户需自行提供区域，交互成本高于纯文本方法。
- **对比范围有限**：未与 Kontinuous Kontext、Concept Sliders、Differential Diffusion 等提供连续或区域控制的代表性方法做定量比较，部分仅在相关工作或附录中定性讨论；“事后拼接”基线（方法 2）的训练细节披露不足，其响应偏弱可能部分源于实现差异而非方法论本身。
- **训练数据与任务的偏置**：训练集来自 HQ-Edit 的 22,482 个样本，指令分布与掩码质量继承自该数据集；方法只训练单区域抑制目标，多主体行为完全依赖推理时的 λ 组装，缺少对“多区域同时训练”这一设定是否更优的实证。
- **评价指标的间接性**：外推/解耦均以 CLIP、SigLIP、LPIPS、DINOv2、ArcFace 等代理指标度量，缺少人类偏好研究；作者虽论证并弃用了 continuity score，但替代指标（方向相关性、平均范围）仍是轨迹级统计，对“编辑是否正确遵循指令语义”的判定依赖编码器本身。
- **算力与成本**：8×H200、10,000 步的训练成本对学术复现不算低；论文未报告墙钟时间与推理开销，而 IDAttn 的分块掩码注意力在主体数增多时（分区变细、掩码更稀疏）的实际加速/开销比未被讨论。

## 8. 启示与潜在影响

- **“控制信号必须与推理路径一致”是一条可推广的训练原则**：论文最有价值的洞察未必是某个模块，而是“若推理时会改变注意力路由，训练时就必须用同一路由计算目标”，否则适配器学到的方向与部署时的方向错位。这一原则可迁移到其他“推理时施加空间/结构约束”的适配器训练场景（如分层生成、局部风格迁移、视频区域编辑）。
- **把标量控制提升为逐 token 向量**是连接“全局强度滑杆”与“区域绑定编辑”的简洁桥梁：无需改动 LoRA 结构，仅需一个与 token 划分对齐的 λ 向量，即可在单次前向中实现多主体独立控制，且天然支持主体数在推理时变化。
- **用参考预测构造自监督目标**（中性指令下的 vref 作为 detached 目标、只在目标区域算损失）提供了一种不依赖成对编辑数据的训练范式，可复用于其他“希望模型在某区域逼近某参考行为”的适配任务。
- **对交互范式的启示**：LOCI 把编辑单元定义为“指令 + 区域 + 系数”三元组，接近专业修图软件中“选区 + 调整层 + 不透明度”的心智模型，为图像编辑器的 UI 设计（每个主体一根滑杆）提供了可直接落地的技术支撑。
- **对评测实践的启示**：协议 D 的二维响应面与“语义/感知串扰”分解，比单点端点比较更能揭示多主体控制方法的真实差异；作者对 continuity score 缺陷的分析也提醒社区，轨迹类指标需对顺序与尺度敏感才有判别力。

## 9. 总体评价

LOCI 针对一个界定清晰且确有空白的问题——指令式编辑器中“空间定位 + 逐区域连续强度 + 多主体独立控制”三者不可兼得——给出了结构简单、动机自洽的解法：Regional LoRA 提供逐 token 缩放，IDAttn 提供主体级注意力隔离，二者通过“路由感知的单区域抑制训练”耦合。实验在四个互补协议上系统比较了五个方法，结论一致且方向明确：LOCI 在保持编辑保真度的同时显著改善解耦与串扰，并几乎不牺牲区域覆盖率；消融有效地把增益归因于组件组合而非单一模块。

其主要不足在于评测的广度而非深度：单一自建合成 benchmark、单一基座、缺少与更多连续/区域控制方法的定量对比、缺少用户研究。因此论文的说服力更多来自“机制清晰 + 内部对照严谨”，而非“大规模外部验证”。作为一篇方法论文，它的问题定义、组件设计与训练策略的一致性值得借鉴；若后续能在真实图像、多基座与定位噪声条件下补充验证，其结论的普适性会更强。
