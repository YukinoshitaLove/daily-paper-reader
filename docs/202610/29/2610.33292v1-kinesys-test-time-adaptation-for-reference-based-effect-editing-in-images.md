## 摘要
视觉效果往往通过参考来展示比用文字描述更容易。我们研究效果参考编辑，即参考图像展示所需的视觉效果，语言则指明应以哪些属性引导编辑。现有的单次编辑技术往往难以实现细粒度编辑，导致对源内容产生非预期改动或偏离参考效果。我们提出 KINESYS，一种用于效果参考编辑的测试时自适应框架，它结合参考感知与源感知反馈，在迁移所需效果的同时保留原始画面的构图与内容。为确保 KINESYS 能够产生一组多样化且保留源内容的编辑结果，我们开发了一种稳健的优化策略，在多个噪声样本和多次优化运行中对生成模型进行微调。基于 VLM 评判、源内容保留指标（LPIPS、TPIPS）以及用户研究的评估表明，KINESYS 在源内容保留方面优于最先进的图像编辑器；在效果迁移方面，它与 Nano Banana 2 保持竞争力，并优于开放权重编辑器。

## Abstract
Visual effects are often easier to demonstrate via reference than to describe in words. We study effect-reference editing, where a reference image shows a desired visual effect and language identifies which properties should guide the edit. Existing single-pass editing techniques often fail to make fine-grained edits, resulting in unintended changes to source content or deviations from the reference effect. We introduce KINESYS, a test-time adaptation framework for effect-reference editing that combines reference-aware and source-aware feedback to transfer the desired effect while preserving the composition and content of the original shot. To ensure KINESYS can produce a diverse set of edits that preserve the source, we develop a robust optimization strategy in which the generative model is fine-tuned across multiple noise samples and optimization runs. Evaluation with VLM judges, source preservation metrics (LPIPS, TPIPS), and a user study shows that KINESYS outperforms state-of-the-art image editors in source preservation; on effect transfer, it remains competitive with Nano Banana 2 and outperforms open-weight editors.

## 1. 核心问题与整体含义

- **研究背景**：视觉特效（烟、火、爆炸、积雪、水洼、船尾浪、阴影、车身凹陷等）往往难以用文字精确描述，用参考图演示更自然。论文研究 **effect-reference editing（效果参考编辑）**：给定源图、效果参考图、编辑指令、若干参考 grounded 的是/否问题以及可选 mask，要求把参考图中的目标效果迁移到源图，同时保持源图构图、相机视角、物体布局和主体外观。
- **核心矛盾**：单次编辑模型容易“编辑不足”或“编辑过度”。编辑不足表现为效果弱、泛化；编辑过度则会把参考图中的无关内容带入源图，或改变主体、视角、场景布局。关键挑战是：**效果迁移要足够强，同时源内容要保持**。
- **整体含义**：KINESYS 不依赖特效专用训练数据或目标编辑图，而是针对每个请求在测试时对生成器做轻量自适应，使艺术家能从同一参考效果获得多个保留源图的变体。这一定位面向实际 VFX 工作流：参考图定义“要什么效果”，源图约束“什么不能变”。

## 2. 方法论

### 2.1 总体框架

- 输入包括：源图、效果参考图、编辑指令、参考 grounded 的 yes/no 问题、可选编辑 mask。
- 基础生成器为 **FLUX.2 Klein 4B**，冻结基座、文本编码器和反馈模型，仅用 **LoRA** 更新生成器参数。
- 对每个请求进行测试时自适应：每步渲染多个固定噪声候选，由两类互补 VLM 反馈评分并更新 LoRA；最终得到一个可对新鲜噪声采样、产生多种效果变体的编辑器。

### 2.2 互补反馈：参考感知 VQA + 源感知 EditReward

- **参考感知 VQA**：冻结的 Gemma 4 E4B-it 接收“效果参考图 + 候选编辑图”，回答 Q 个问题；每个问题的期望答案为 “Yes”。  
  \[
  L_{\text{VQA},i}=-\frac{1}{Q}\sum_{\ell=1}^{Q}\log p_{\text{VLM}}(a_\ell \mid r,y_i,q_\ell)
  \]
  该项促使候选更清晰地实现参考效果，但 VQA 看不到源图，无法直接判断源内容是否被误改。
- **源感知 EditReward**：EditReward 接收源图、指令和候选编辑，输出指令遵循分 \(R_{i,\text{follow}}\) 与视觉质量分 \(R_{i,\text{quality}}\)，取平均：
  \[
  R_{\text{ER},i}=\frac{R_{i,\text{follow}}+R_{i,\text{quality}}}{2},\quad
  L_{\text{ER},i}=-R_{\text{ER},i}
  \]
  该项抑制非预期源内容改动和视觉伪影。
- 单候选目标：
  \[
  L_i=\lambda_{\text{VQA}}L_{\text{VQA},i}+\lambda_{\text{ER}}L_{\text{ER},i}
  \]
  实现中取 \(\lambda_{\text{VQA}}=1,\ \lambda_{\text{ER}}=2\)。

### 2.3 稳健优化：多噪声候选、候选加权、多样性惩罚、多独立运行

- **多候选固定噪声**：每个 fine-tuning run 使用 \(N=3\) 个固定噪声样本，在整个优化过程中复用；每步从每个噪声渲染一个候选，使反馈可追踪各候选的进展。
- **候选加权**：对 EditReward 分数做指数滑动平均、跨候选标准化并按 softmax 得到权重 \(\alpha_i\)，更新时 detach 并固定。表现差的候选被降权但不丢弃。
- **多样性惩罚**：为防止固定噪声候选在共享目标下坍缩到相似外观，在可编辑区域内计算候选 latent 之间的 RBF 相似度：
  \[
  D=\frac{1}{N(N-1)}\sum_{i}\sum_{j\ne i}\exp\left(-\frac{d_{ij}}{h_i}\right)
  \]
  其中 \(d_{ij}\) 为候选 \(i\) 当前 latent 与候选 \(j\) 上一步 latent 的均方距离，带宽 \(h_i\) 用中位数启发式并 detach。总体目标为：
  \[
  L_{\text{pop}}=\sum_{i=1}^{N}\alpha_i L_i+\lambda_{\text{div}}(t)D
  \]
  \(\lambda_{\text{div}}(t)\) 在前 60% 优化步中衰减到 0，早期鼓励多样性，后期聚焦 VQA 与 EditReward。
- **多独立运行与剪枝**：启动 \(K=5\) 个独立 fine-tuning run，每个 run 有自己的 LoRA 参数和固定噪声集合，互不共享参数或候选。按最近 VQA/EditReward 反馈在 checkpoint 边界剪枝：5→3→2。
- **checkpoint 选择**：每个保存的 checkpoint 用一个**held-out 噪声样本**渲染评估图，选择 EditReward 最高的 LoRA 参数 \(\phi^\star\)。该 held-out 噪声不参与 fine-tuning 梯度。
- **实现细节**：LoRA rank 16，作用于 transformer attention 与 FFN；AdamW，学习率 \(5\times10^{-5}\)；最多 \(T=100\) 步；bf16；4 步 flow；guidance scale 1.0；参考条件最长边 384 像素；源图与参考图下采样到最长边不超过 768 像素并按 16 对齐。
