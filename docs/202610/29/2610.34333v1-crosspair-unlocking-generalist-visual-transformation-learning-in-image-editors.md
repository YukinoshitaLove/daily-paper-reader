## 摘要
语言模型能够根据示例切换任务，但视觉领域仍常常依赖分别用于修复、编辑和风格化的独立系统。一个前后示例只有在可迁移的变化能够与展示该变化的场景分离时，才能提供共享指令。我们提出 CrossPair，它适配预训练的多模态图像编辑器，以从单个示例对中迁移多样化的变换。示例前图像、示例后图像和查询图像在其原生 VLM 与 VAE 通路中承担固定角色：VLM 提取操作语义，VAE 保留精细外观与结构。一个仅在训练时使用的、变化感知的 DINOv3 目标函数对齐内容不同场景间的特征变化方向，引导输出遵循示例所示的关系，而无需推理时编码器。我们构建了 Transform-360K，将来自条件表示、修复、编辑、虚拟试穿和风格化的过滤后图像对按共享变换进行分组。在由 Relation252K 衍生的已见和留出变换上，该方法相比已发布系统提升了目标一致性和编辑方向相似度。消融实验表明，语义示例通路与视觉示例通路具有互补性，且 DINO 关系对齐进一步增强迁移；Transform-360K 训练还提升了留出操作的聚合得分。

## Abstract
Language models switch tasks from demonstrations, but vision still often relies on separate systems for restoration, editing, and stylization. A before--after example offers a shared instruction only if the transferable change can be separated from the scene that demonstrates it. We introduce CrossPair, which adapts a pretrained multimodal image editor to transfer diverse transformations from one exemplar pair. Exemplar-before, exemplar-after, and query images take fixed roles in its native VLM and VAE pathways: the VLM extracts operation semantics, while the VAE retains fine appearance and structure. A training-only, change-aware DINOv3 objective aligns feature-change directions across content-distinct scenes, guiding the output to follow the demonstrated relation without an inference-time encoder. We construct Transform-360K by grouping filtered pairs from conditional representations, restoration, editing, virtual try-on, and stylization under shared transformations. On Relation252K-derived seen and held-out transformations, \method improves target agreement and edit-direction similarity over released systems. Ablations show that the semantic and visual exemplar routes are complementary and that DINO relation alignment further strengthens transfer; Transform-360K training also improves aggregate held-out-operation scores.

## 1. 核心问题与研究动机

- **背景困境**：语言模型可以通过少量示例切换任务，而视觉领域仍普遍采用分立系统分别处理图像修复、编辑、风格化、虚拟试穿、条件表示生成等任务，缺乏统一的“示例驱动”任务接口。
- **核心问题**：许多视觉变换“示易名难”——“做成陶瓷质感”“改变视角”这类描述无法精确规定纹理、几何以及哪些内容应保持不变。一对前后示例（before–after pair）同时揭示了“变化”与“不变量”，可作为跨任务的共享指令。
- **关键难点**：示例中展示的变化与其参考场景高度耦合（entangled），而查询图像内容与示例不同，模型必须把“可迁移的变换规则”从“承载该变换的场景”中剥离出来，再施加到内容不相交的查询图上，同时保持查询内容可辨识。
- **形式化目标**：求解视觉类比 `xr : yr :: xq : yq`，推理时仅可见 `(xr, yr, xq)`，可选文本提示 `p`。
- **整体含义**：论文主张把“单对示例迁移”作为通用视觉变换的统一接口，并证明可以直接在预训练多模态编辑器的原生通路中实现，而无需为每个示例做适配或引入额外的推理期关系编码器。

## 2. 方法论

### 2.1 核心思想
- 在预训练编辑器 **Qwen-Image-Edit-2511** 的原生 **VLM 语义通路**与 **VAE 视觉通路**中，为 `(示例前, 示例后, 查询图)` 赋予**固定角色顺序**，实现“语义抽象 + 细粒度外观”双空间条件化。
- 引入**仅训练期使用**的、变化感知的 **DINOv3 关系对齐目标**，显式约束“预测的查询变化方向”与“示例展示的变化方向”一致；推理时该分支完全移除。
- 只训练图像生成器中的 **rank-128 LoRA**，VLM、VAE、基座生成器与 DINOv3 全部冻结。

### 2.2 基础生成框架（Rectified Flow）
- 直线插值路径：`zt = (1−σt)·z0 + σt·z1`，`z1 ~ N(0,I)`，目标速度 `u*t = z1 − z0`。
- 流匹配损失：`L_flow = E[w(t)·‖v̂t − u*t‖²]`，其中 `w(t)` 为 Qwen 调度器固定的训练权重（非学习得到）。
- 单步可微干净潜变量估计：`ẑ0 = zt − σt·v̂t`，用于解码出可微预测图 `ŷq = D_vae(ẑ0)`。
- 仅对**查询目标** `z0 = E_vae(yq)` 加噪并计分。

### 2.3 角色有序的双空间示例条件化
- VAE 条件：`C_vae = cat{ P(E_vae(I)) : I ∈ [xr, yr, xq] }`，保留颜色、纹理、形状与局部结构。
- VLM 条件：`C_vlm = E_vlm([xr, yr, xq], p)`，在“新查询源”语境下推断“应迁移什么操作”。
- 二者互补：仅 VLM 会压缩外观关键证据；仅 VAE 则使变换与参考内容纠缠。融合后同时提供抽象与保真，且**不新增任何可训练或推理期编码器**。

### 2.4 变化感知 DINOv3 关系对齐（训练期）
- **动机**：流匹配只监督端点，而视觉类比还要求两个“变化”相等，即 `R(xr,yr) ≈ R(xq,ŷq)`，且 `xr ≠ xq`。像素差或跨场景 patch 匹配均不可行（内容无关、未变区域会主导全局均值）。
- **稠密变化定位**（同一场景内、同位置计算）：
  - 变化分数 `c_i^d = 1 − f̄_i(I⁻_d)ᵀ f̄_i(I⁺_d)`，`d ∈ {r, q}`
  - 归一化软变化图 `w_i^d = (c_i^d)^α / (Σ_j (c_j^d)^α + ε)`，实验中 `α = 1`
  - 示例与查询的变化图**独立估计**，可关注不同空间位置（适合同一操作作用于不同物体/布局）。
- **跨内容关系聚合**：
  - `r_d = norm( Σ_i w_i^d [ f̄_i(eI⁺_d) − f̄_i(I⁻_d) ] )`，其中示例侧 `eI⁺_r = yr`，查询侧 `eI⁺_q = ŷq`
  - 加权求和把空间分布式编辑压缩为**场景级变换向量**；归一化消除响应幅度差异，只比较“特征如何移动”。
  - **从不假设示例 patch i 对应查询 patch i**，patch 配对只在同一场景内部进行。
- **关系损失**：`L_DINO-rel = 1 − r_qᵀ · sg[r_r]`（`sg` 为停止梯度），只让 `f̄(ŷq)` 保留输入梯度；不直接做预测特征与目标特征的匹配。
- **低噪可靠监督门控**：`g(σt) = max(0, (σmax − σt)/σmax)`，`σmax = 0.5`，高噪声阶段抑制结构监督。
- **总损失**：`L = L_flow + λ_dino · E[g(σt)·L_DINO-rel]`，`λ_dino = 0.003`。
- 实现细节：冻结 DINOv3 ViT-7B/16，输入 224×224，取 14×14=196 个 patch token（去 CLS 与 register token）；查询侧变化权重由**停止梯度**的目标图计算（target 信息仅通过“定位”进入损失）。

### 2.5 Transform-360K 数据语料
- **变换规范化**：每条候选归一化为 `(x, y, g)`，`g` 记录最细粒度可验证操作及其方向（如 RGB→depth 与 depth→RGB 视为不同；风格/服装用身份 ID；空间编辑用离散化视角/距离/旋转增量）。
- **六条构建流水线**：低级视觉修复、条件表示映射、虚拟试穿、参考/分割感知、风格迁移、受控几何变换。
- **质量过滤**：通用检查（可读性、分辨率、去重、变化非平凡但有界）+ MLLM 语义审计（操作可见、非目标内容一致、伪影不能解释差异）+ 各流专属判据。
- **跨对记录构造**：同一操作键 `g` 下要求内容/场景身份不同，拒绝自配对与同场景配对，抽一对作 `(xr,yr)`、另一对作 `(xq,yq)`；并按关系频率与来源族平衡。
- **规模**：**91,010 条四图记录**（364,040 个记录级图像槽位），覆盖 **8,000+ 细粒度关系**；来源占比示例：低级视觉 22.03%、风格 16.53%、Relation252K 19.34%、试穿 14.86%、条件表示 12.80%、参考/分割 11.47%、空间变换 2.36%。
