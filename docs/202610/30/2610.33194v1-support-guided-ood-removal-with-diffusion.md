## 摘要
许多真实世界信号会受到分布未知的局部结构化扰动污染：音乐录音中间歇出现的背景噪声、照片上盖印的水印、投射阴影。我们研究从包含此类局部分布外（OOD）污染的观测 $y$ 中恢复干净信号 $x$ 的任务。我们提出支持引导的OOD去除方法 SORD（Support-guided OOD Removal with Diffusion），这是一种仅使用两个要素来恢复 $x$ 的迭代算法：污染支持区域的二值图，以及一个在干净信号上预训练的单一扩散模型。SORD 不需要任何成对数据，也不需要污染的统计模型。我们在自然图像和人脸上评估 SORD，这些数据包含空间局部污染，如手写数字、其他图像、水印和阴影；同时也在不同乐器的音频录音上评估，这些录音包含时间局部污染，如其他乐器和人声。在给定相同扩散先验和相同掩码的情况下，SORD 与后验采样修复方法相比具有竞争力，且通常优于后者；它也优于需要为每个源单独训练扩散模型的源分离基线；在若干基准上，还优于在成对干净与污染信号上训练的监督网络。代码发布于此：https://github.com/voilalab/SORD。

## Abstract
Many real-world signals are corrupted by localized, structured perturbations whose distribution is unknown: an intermittent background noise in a music recording, a watermark stamped on a photograph, a cast shadow. We study the task of recovering a clean signal $x$ from an observation $y$ containing such a localized out-of-distribution (OOD) corruption. We propose Support-guided OOD Removal with Diffusion, SORD, an iterative algorithm to recover $x$ using only two ingredients: a binary map of the corruption support and a single diffusion model pretrained on clean signals. SORD does not require any paired data or any statistical model of the corruption. We evaluate SORD on natural images and human faces with spatially localized corruptions including handwritten digits, other images, watermarks, and shadows, as well as audio recordings of different musical instruments with temporally localized corruptions including other instruments and human speech. SORD is competitive with, and often outperforms, posterior-sampling inpainting given the same diffusion prior and the same mask, source-separation baselines that require a separate diffusion model for each source, and, on several benchmarks, supervised networks trained on paired clean and corrupted signals. The code is released here: \href{https://github.com/voilalab/SORD}{https://github.com/voilalab/SORD}.

## 1. 核心问题与研究动机

- **问题设定**：真实信号常被**局部化、结构化、分布未知**的扰动污染，例如录音中短暂出现的背景噪声、照片上的水印、投射阴影。论文研究从观测 $y$ 中恢复干净信号 $x$ 的任务，建模为 $y = x + M_\Omega \odot n$，其中 $n$ 为任意结构化污染，$M_\Omega$ 将其限制在已知支撑 $\Omega$ 内，且**不对 $n$ 作任何分布假设**。
- **现有方法的局限**：
  - *监督修复*（水印/阴影专用网络）：需成对干净-污染数据，且只能处理训练分布内的污染类型。
  - *后验采样/扩散逆问题*（DPS、RePaint 等）：需已知测量模型或似然，通常假设高斯/泊松等简单噪声，难以刻画具有空间、语义或时间结构的污染。
  - *源分离*（SGM、MSDM 等）：需为污染类或每个源单独训练生成先验，遇到未预期的污染类即失效。
- **核心主张**：用**结构先验（污染发生在何处/何时）替代污染的统计先验**。只需一个在干净信号上预训练的扩散模型 + 污染支撑二值图，无需配对数据、参数化污染分布或污染类生成模型。支撑估计通常比污染分布建模容易得多（可借助异常检测/分割方法）。
- **关键洞察**：与标准 inpainting 不同，$\Omega$ 内的观测并非"缺失"，而是干净信号与未知结构化污染的**叠加**，仍携带关于 $x_\Omega$ 的信息，应被逐步复用而非丢弃。

## 2. 方法论：SORD

### 2.1 总体思想
- 以扩散 inpainting 作为**初始化**，随后通过**信号–污染交替分解**逐步从 $\Omega$ 内测量中回收信息；用多个扩散样本的**方差**量化重建不确定性，并据此自适应设定精炼步长与停止准则。

### 2.2 算法流程（Algorithm 1）
- **输入**：观测 $y$、支撑 $\Omega$ 与掩码 $M_\Omega$、干净信号去噪器 $D_\theta$（实验用 DDIM）、inpainting 算子 $R_\theta$（实验用 RePaint）、样本数 $K$、最大迭代 $M$、噪声调度 $\{\sigma_m\}$、停止阈值 $\tau_{\text{stop}}$。
- **初始化**：抽取 $K$ 个 inpainting 样本 $\hat{x}_0^{(k)} \leftarrow R_\theta(y,\Omega)$，并估计 $\Omega$ 上的不确定性
  $\sigma_0^\star = \sqrt{\frac{1}{|\Omega|}\sum_{i\in\Omega}\mathrm{Var}(\{\hat{x}_{0,i}^{(k)}\}_{k=1}^K)}$。
- **主循环**（$m=1,\dots,M$，对每个样本 $k$）：
  1. **估计残差（污染）**：$n_m^{(k)} = M_\Omega \odot (y - \hat{x}_{m-1}^{(k)})$。
  2. **扩散精炼污染估计**：$\tilde{n}_m^{(k)} = D_\theta(n_m^{(k)} + \sigma_{m-1}^\star \epsilon,\ \sigma_{m-1}^\star)$，$\epsilon\sim\mathcal{N}(0,I)$。注意此处仍用**干净信号**扩散模型，仅在小噪声级下精炼残差细节（消融见表 6）。
  3. **测量一致性**：$\tilde{x}_{m,i}^{(k)} = y_i - \tilde{n}_{m,i}^{(k)}$（$i\in\Omega$），$i\notin\Omega$ 时保持 $y_i$。
  4. **先验精炼**：$\hat{x}_m^{(k)} = M_\Omega \odot D_\theta(\tilde{x}_m^{(k)} + \sigma_m \eta,\ \sigma_m) + (1-M_\Omega)\odot y$，把估计拉回干净数据分布。
- **不确定性更新**：$\sigma_m^\star = \sqrt{\frac{1}{|\Omega|}\sum_{i\in\Omega}\mathrm{Var}(\{\hat{x}_{m,i}^{(k)}\}_{k=1}^K)}$。
- **自适应停止**：若 $\sigma_{m-1}^\star - \sigma_m^\star \le \tau_{\text{stop}}\,\sigma_{m-1}^\star$，返回 $K$ 个样本均值；否则继续至 $M$ 轮。
- **三个组件**：① inpainting 初始化；② 不确定性决定精炼尺度、交替"解释观测—重建信号"；③ 同一不确定性驱动停止准则。

### 2.3 非加性污染的适配
- **水印（alpha 合成）**：$y=(1-\alpha)\odot x+\alpha\odot w$。推断时**不提供真实逐像素不透明度 $\alpha$**，人为引入模型失配，仍用加性流程处理。
- **阴影（乘性）**：$y = x\odot s$。测量一致性更新在**对数强度域**进行（$\log y = \log x + \log s$），但扩散先验仍作用于图像域（对 $x$、$s$ 的估计，而非其逐像素对数）。

## 3. 实验设计

### 3.1 数据集与场景
- **图像加性局部污染**：CelebA 64×64（100 张测试图），污染为 MNIST 数字、32×32 自然图像块、16–48 随机尺寸 CIFAR-10 块。
- **音频时域局部干扰**：Slakh2100，10 秒、22.05 kHz 片段；目标源 + 单一干扰源，干扰限制在覆盖一半片段的连续窗口 $\Omega$；目标含 piano/guitar/bass/drums；区分 MSDM 词表内（IV）与词表外（OOV）干扰源；SIR 0 dB、5 dB 及未归一化 $g=1$。
- **水印**：CLWD 测试集（64×64，99 张，支撑约占 14%）；FFHQ 与 Imagenette 256×256（各 25 张，用 12 个 CLWD 训练集 logo 合成，支撑约占 3%）。
- **阴影**：ISTD 64×64（100 张真实阴影，支撑约 17%）；以及将 ISTD 阴影场合成到 FFHQ/Imagenette 256×256（各 25 张）的跨域测试。

### 3.2 评价指标
- 图像：**仅在 $\Omega$ 内**计算 PSNR（避免未改动像素主导指标）。
- 音频：干扰窗口内 **SI-SDRi**。

### 3.3 对比基线
- **同先验、同掩码的后验采样**：DPS-Inpaint、DPS（高斯似然，均值取 oracle $\mu=\mu_n$ 或 $\mu=0$）。
- **源分离/多先验**：SGM（Stevens et al., 2025，干净图与污染分别用扩散先验）及其 mask 投影变体；MSDM（Mariani et al., 2024，多源扩散），含加入语音先验的增强版。
- **监督专用方法**：水印的 PatchWiper、SLBR；阴影的 ShadowDiffusion、ShadowFormer（均在配对数据上训练）。
- **实现细节**：$K=32$（音频主实验 64）、$M=6$、$\sigma_m$ 从 0.4 线性降至 0.1；DDIM + RePaint；256×256 用 1000 步、64×64 用 250 步反向采样。
