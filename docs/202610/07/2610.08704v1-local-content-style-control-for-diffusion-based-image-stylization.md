## 摘要
基于潜在扩散模型的图像风格化将两个可独立细化的轴纠缠在一起：一个区域描绘的是什么，以及它是如何被描绘的。此类流程仅暴露全局控制，但专业修图需要有意为之的、区域特定的控制。我们将 ControlNet + IP-Adapter 风格化流程中已有的两个条件权重从全局标量提升为逐位置的空间图，从而在单次生成过程中实现内容与风格的局部、逐轴控制。由于这两个权重作用于不相交的路径，独立调整它们可涵盖一个 2x2 的修图词汇表，从自由重生成到身份保持。我们验证了编辑仅限于被修图的区域，并且每个权重主要引导其自身的轴。我们的方法无需重新训练，并可原样嵌入任何此类流程。

## Abstract
Image stylization with latent-diffusion models entangles two independently refined axes: what a region depicts and how it is depicted. Such pipelines expose only global controls, yet professional retouching demands deliberate, region-specific control. We lift two conditioning weights already present in a ControlNet + IP-Adapter stylization pipeline from global scalars to per-location spatial maps, yielding local, per-axis control of content and style in a single generative pass. Because the two weights act on disjoint pathways, adjusting them independently spans a 2x2 retouching vocabulary, from free regeneration to identity preservation. We validate that edits stay confined to the retouched region and that each weight predominantly steers its own axis. Our approach requires no retraining and drops unchanged into any such pipeline.

# 论文总结：Local Content-Style Control for Diffusion-based Image Stylization

## 1. 核心问题与研究动机

- **背景**：基于潜在扩散模型（LDM）的图像风格化把"一个区域画什么（内容）"和"怎么画（风格）"纠缠为两个可独立细化的轴，但这类流程（如 ControlNet + IP-Adapter）只暴露**全局标量控制**。
- **核心矛盾**：专业修图/平面设计需要**逐区域、分轴**的刻意控制（例如只锁定主体结构、只放松背景风格），而现有全局控制无法满足。
- **已有工作的缺口**：
  - Paint-with-words、MultiDiffusion 等操控的是**文本通路**，与内容/风格通路正交；
  - 区域布局/接地类工作空间化的是"条件什么"，而非"某条通路在某位置有多强"；
  - 空间化 IP-Adapter 缩放是业界已知技巧，但**只针对风格**；
  - SmartControl 空间化 ControlNet 缩放，但只用于**放松单一结构条件**，且依赖学习到的预测器。
  - 尚无工作把"空间内容强度"与"空间风格缩放"耦合起来。
- **整体含义**：作者把非真实感渲染（NPR）中"参数空间绘画"的局部抽象度控制思想迁移到生成式风格化，使扩散模型也能实现 region-by-region 的专业修图控制。

## 2. 方法论

### 2.1 核心思想
- 观察到标准 ControlNet + IP-Adapter 流程中已存在两个标量条件权重：
  - **ControlNet 强度 `s`** → 控制对内容结构的遵循程度；
  - **每个 IP-Adapter 块的图像缩放 `λ_b`** → 控制对图像提示风格的遵循程度。
- 将这两个标量分别**提升为逐位置空间图** `s(p)`、`λ_b(p)`，两条通路互不相交，因此可独立调节。

### 2.2 关键技术细节
- **内容轴（空间化 ControlNet）**：ControlNet 分支把噪声潜变量 `z_t` 编码为特征图 `h`，把控制图像（Tile）编码为控制嵌入 `c`，原公式为 `h̃ = h + s·c`。将其改为逐位置形式：`h̃(p) = h(p) + s(p)·c(p)`，其中 `s ∈ R^{H×W}`（潜空间分辨率），在通道维广播；均匀图可精确复现原标量行为。
- **风格轴（空间化 IP-Adapter）**：每个注入块在文本注意力上叠加解耦的图像注意力项：`Z_new = Attn(Q,K,V) + λ_b·Attn(Q,K',V')`。将 `λ_b` 提升为 `λ_b(p)`；在加速友好的注意力布局下，图像注意力输出形状为 `[B, C, 1, HW]`（每个潜位置一个特征向量），故 `λ_b(p)` 直接按通道广播，**不改变注意力计算本身**，仅改变该块的缩放输入形状；均匀图同样精确复现标量。
- **分辨率语义**：像素级控制图经抗锯齿下采样到各调制点。内容调制经下采样块**多尺度传播**（细处锐、粗处柔）；风格调制天然更粗（SDXL 上限 64² 潜分辨率）。这种不对称契合两类因素：结构需要精细空间控制，风格的空间分配是低频语义选择。
- **2×2 修图词汇表**：内容以 `s = 0.5` 为平衡默认值（锁定/放松），风格以 `λ_b = 1.0` 为满强度（通常只放松）。组合出四种操作：自由重生成（默认）、结构保持、风格弱化、身份保持。由于 Tile 输入即内容图像，内容锁定会挤占部分风格化，可通过区域内同步抬高 `λ_b` 抵消。

### 2.3 流程要点（文字描述）
- 输入：源图 + 掩码（或由深度/分割等先验自动生成的逐像素控制图）+ 风格图 + 文本提示。
- 用户对指定区域编辑 `s(p)` 与/或 `λ_b(p)`，其余区域保持默认值。
- 单次生成即完成局部、分轴编辑，无需重训练、无需二次合成。

## 3. 实验设计

- **数据集/场景**：内容与风格均取自 DIV2K（物体与场景），构建 **(内容, 风格, 种子)** 三元组。
- **Benchmark 设定**：`N = 300` 个三元组（10 内容 × 10 风格 × 3 种子）。
- **验证的两条假设**：
  - **H1（局部性）**：局限于区域 `R` 的编辑应主要改变 `R` 内部。度量：远场变化 `ℓ∞`（距 `R` 超过 0.25 图像宽度的像素上，与同种子基线的平均空间 LPIPS），并分别相对于"`R` 内响应""风格化幅度""种子重掷"归一化（越低越局部）。
  - **H2（特异性）**：内容应主要载荷于结构，风格应主要载荷于纹理。度量：容错边缘一致性（结构）、VGG-Gram 纹理距离、Lab 色度调色板距离（均对源图），使用带符号探针响应（负值 = 趋向源图）。
- **对比对象**（定性/论述层面）：
  - 全局标量（非局部）；
  - 区域文本提示（操控不同通路）；
  - "先风格化再合成"（合并两个独立去噪结果）。
- **消融维度**：内容锁定 `s → 0.8`；风格放松 `λ_b → 0.7` 与 `λ_b → 0.4`（剂量效应）。

## 6. 主要结论与发现

- **H1 局部性成立**：远场变化 `ℓ∞` 仅为 `0.13–0.24×`（相对内部响应/风格化幅度/种子重掷），即使存在自注意力与残差耦合，编辑仍主要局限于被修图区域。
- **H2 特异性成立**：内容锁定在结构（边缘）上占主导；风格放松的纹理响应随剂量增强（`λ_b → 0.4` 时纹理响应 `-0.063`），调色板响应基本持平；风格放松对结构无改变或略有恢复（边缘响应 `-0.004 ~ -0.006`）。
- **单次生成即可实现分轴局部控制**，且**无需重训练**、可原样嵌入任何同类 ControlNet + IP-Adapter 流程。
- **控制图可自动化生成**：可由深度、分割等逐像素先验导出，复现 NPR 中"注视/显著性引导的抽象度控制"。
- **连续地图支持渐变过渡**：在固定区域内扫描风格缩放与内容强度，可使区域从摄影感平滑过渡到完全风格化。

## 7. 优点

- **极简且通用**：不改网络结构、不训练、不加模块，仅把两个已存在的标量改为空间图，属"即插即用"式改动。
- **通路解耦的设计洞察**：利用内容（ControlNet）与风格（IP-Adapter）作用路径不相交这一事实，天然获得分轴控制，理论干净。
- **实现友好**：空间图在注意力布局下恰好按通道广播，不改变注意力计算；均匀图可精确退化为标量，向后兼容。
- **多尺度语义合理**：内容多尺度传播、风格粗粒度分配的不对称设计有明确动机。
- **验证相对严谨**：统一噪声、最坏情况配置（11 个块全带风格）、三重参照归一化的局部性度量。
- **实用性强**：给出 2×2 修图词汇表与深度/分割驱动控制图等具体用例，贴合专业修图需求。

## 8. 不足与局限

- **作者自述局限**：
  - 风格定位比内容**更粗**（SDXL 风格调制上限 64² 潜分辨率）；

  - 4 步蒸馏采样器只能**粗略解析中间强度**；

- **实验覆盖不足**：
  - 单一 backbone / 单一 ControlNet 类型 / 单一蒸馏采样器，**跨模型泛化未知**；

  - 300 三元组规模有限，DIV2K 场景偏向自然图像，**未覆盖设计类、图形类素材**。
- **偏差与公平性风险**：
  - H2 的探针响应为带符号值且不同探针尺度不可直接比较，只能列内比较，解释力有限；

- **应用限制**：
  - 面向 Apple Neural Engine 优化，其他平台部署表现未验证；
  - 编辑依赖用户提供或先验生成的控制图，**自动掩码/学习先验仍列为未来工作**；
  - 空间多风格分配、小物体 crop-and-refine 等尚未实现。
