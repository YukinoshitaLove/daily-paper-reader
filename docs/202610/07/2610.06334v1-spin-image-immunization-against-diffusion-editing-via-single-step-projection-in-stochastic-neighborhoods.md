## 摘要
扩散模型极大地推动了指令引导的图像编辑，同时也引发了对未经授权图像操纵的担忧。图像免疫通过向输入图像添加不可感知的扰动来破坏后续编辑，从而应对这一风险。由于图像发布时编辑请求未知，保护应当在用于构造扰动的指令之外仍然有效。现有免疫方法要么需要代价高昂的全轨迹反向传播，要么使用中间目标，而其后继去噪过程可能削弱其效果。同时，单一推理路径对替代去噪延续提供的反馈有限。为应对这些挑战，我们提出 SPIN，一个通过在局部随机轨迹邻域上进行单步投影来实现图像免疫的框架。从早期去噪状态出发，SPIN 在同一指令下生成随机邻近状态，并通过单步投影预测其干净隐变量，而无需完整展开。随后，我们优化一个有界输入扰动，以最大化这些预测与干净编辑参考之间的平均偏差，促使扰动破坏多种可能的编辑结果。在两个图像编辑器上的实验表明，保护性能显著提升；在已见指令下以及在更具挑战性的未见指令设置下，SPIN 在所有六项指标上均优于对比方法。

## Abstract
Diffusion models have greatly advanced instruction-guided image editing, while also raising concerns about unauthorized image manipulation. Image immunization addresses this risk by adding imperceptible perturbations to an input image to disrupt subsequent edits. Since editing requests are unknown at image release, protection should remain effective beyond the instruction used to construct the perturbation. Existing immunization methods either require costly full-trajectory backpropagation or use intermediate objectives whose effects may be weakened by subsequent denoising. Meanwhile, a single inference path provides limited feedback about alternative denoising continuations. To address these challenges, we propose \textsc{SPIN}, a framework for image immunization via one-step projection over local stochastic trajectory neighborhoods. Starting from an early denoising state, \textsc{SPIN} generates stochastic neighboring states under the same instruction and predicts their clean latents through one-step projection without full unrolling. We then optimize a bounded input perturbation to maximize the average deviation of these predictions from a clean-edit reference, encouraging the perturbation to disrupt multiple possible editing outcomes. Experiments on two image editors demonstrate substantial gains in protection performance, with \textsc{SPIN} outperforming compared methods across all six metrics under seen instructions and in the more challenging unseen instruction setting.

## 1. 核心问题与研究动机

- **背景**：指令引导的扩散编辑模型（如 InstructPix2Pix、SD3 驱动的 UltraEdit）大幅降低了图像篡改门槛，公开图像面临未授权编辑风险，可能侵害隐私、声誉或制造误导性内容。
- **图像免疫思路**：在图像发布前加入不可感知的有界扰动，破坏后续编辑过程，属于"主动防御"。
- **核心矛盾**：
  - 编辑请求在图像发布时**未知**，保护必须泛化到构造扰动时未使用的指令；
  - 直接对最终编辑输出反传需贯穿完整去噪轨迹，计算代价高昂；
  - 中间表示/中间状态类目标（编码器特征、交叉注意力、早期去噪状态）的偏差可能在后续去噪中被削弱；
  - 单一推理路径只能提供有限反馈，容易对特定采样轨迹过拟合。
- **整体含义**：论文提出 SPIN，旨在构建一种**输出导向、无需完整展开、且跨多条可能轨迹有效**的保护信号，使扰动在已见与未见编辑指令下均能破坏编辑结果。

## 2. 方法论：SPIN 框架

### 2.1 核心思想

- 从**早期去噪状态**出发，通过**单步投影**预测干净潜变量，以预测结果与固定"干净编辑参考"的偏差作为可微的保护代理信号；
- 在**局部随机轨迹邻域**内采样多条候选延续，聚合并最大化其平均偏差，降低对单一推理路径的依赖，提升对未见指令的泛化。

### 2.2 问题形式化

- 源图像 $x$，编辑指令 $c$，冻结编辑器 $G_\theta$，采样随机性 $\omega$；
- 保护目标：$\delta^\star = \arg\max_{\|\delta\|_\infty \le \varepsilon} \mathcal{L}(G_\theta(x_\delta,c;\omega), G_\theta(x,c;\omega))$，仅优化 $\delta$，模型参数冻结。

### 2.3 单步投影（Outcome-Oriented Single-Step Projection）

- 对噪声预测模型（$z_t = a_t z_0 + b_t \epsilon$）：
  $\hat{P}^\epsilon_t = \frac{z_t - b_t \hat{\epsilon}_\theta(z_t,t|E(x_\delta),c)}{a_t}$；
- 对流匹配模型（$z_t = (1-t)z_0 + t\epsilon$）：
  $\hat{P}^v_t = z_t - t \hat{v}_\theta(z_t,t|E(x_\delta),c)$；
- 该投影利用当前状态的一次模型预测直接估计干净潜变量，**跳过剩余采样步骤**，无需完整展开；
- 参考潜变量 $z_{\text{ref}}$ 由干净输入跑一次完整原生编辑得到，优化全程固定不变，偏差在共享的干净潜空间中以**余弦距离**度量。

### 2.4 随机轨迹邻域构造

- 设共享原生前缀为 $F_{0:j}$，当前保护输入得到中间状态 $z_j(\delta)$；
- 用编辑器特定的随机转移 $T_j$ 采样 $K$ 个候选状态 $z^{(k)}_{j+1} = T_j(z_j(\delta), \xi_k; x_\delta, c)$，$\xi_k \sim \mathcal{N}(0,I)$；
- 对每个候选做单步投影得到 $\tilde{z}^{(k)}_0$；
- **流匹配编辑器（SD3）**：采用 Flow-GRPO/Flow-TTRL 风格的随机转移，含基于速度–得分关系的漂移修正项，$g_j = \lambda\sqrt{t_j/(1-t_j)}$，$\lambda=0$ 退化为原生 Euler 更新；
- **噪声预测编辑器（IP2P）**：利用原生 Euler-Ancestral 采样器，温度 $\tau$ 控制邻域尺度，$\tau=1$ 恢复原生转移。

### 2.5 扰动优化

- 目标函数：$\hat{J}_K(\delta) = \frac{1}{K}\sum_{k=1}^{K} d_{\text{cos}}(\tilde{z}^{(k)}_0, z_{\text{ref}})$，其中 $d_{\text{cos}}(a,b)=1-\frac{\langle a,b\rangle}{\|a\|_2\|b\|_2}$；
- 候选噪声采样一次后**全程固定**，构成固定的样本平均目标；
- 用**投影梯度上升（PGD）**更新：$\delta^{(n+1)} = \Pi_{\mathcal{C}(x)}[\delta^{(n)} + \eta \cdot \text{sign}(\nabla_\delta \hat{J}_K)]$，每次迭代重算前缀、生成候选、聚合偏差并投影回 $\ell_\infty$ 球与像素有效范围；
- 默认设置：$\varepsilon = 8/255$，20 步 PGD，步长 $1/255$，分支位置 $j=1$，IP2P 中 $\tau=2$，$K=4$。

## 6. 主要结论与发现

- SPIN 在已见指令下 ISR 达 **90%（SD3）** 与 **94%（IP2P）**，未见指令下达 **85%** 与 **91%**，六项指标全部优于对比方法；
- 未见指令下相对基线的优势比已见指令更大，说明随机邻域优化确实提升了跨指令泛化；
- 单步投影比随机扰动显著增大最终潜空间余弦距离、降低 PSNR、提高 LPIPS，证明其作为输出导向代理信号的有效性；
- K 从 1 增至 4 持续提升保护效果，增至 8 收益不稳定且耗时大增，故 K=4 为较优折中；
- 早期分支与早期投影能产生更大的候选多样性和最终输出偏差，支持"早期布局阶段干预"的设计选择；
- ε 超过 8/255 后输出偏差增益有限而输入失真明显，故 ε=8/255 为合理选择；
- SPIN 在输入保真度（PSNR、SSIM、VIFP、FSIM、LPIPS）上多数指标优于基线，同时保持可接受的时间成本。

## 7. 优点

- **方法层面**：
  - 单步投影避免了贯穿完整去噪轨迹的反传，显著降低优化成本，同时保持"面向最终输出"的代理目标；
  - 随机邻域采样将单条轨迹的过拟合风险转化为对多条可能延续的鲁棒优化，直接服务于未见指令泛化；
  - 统一框架适配流匹配与噪声预测两类编辑器，通过编辑器特定的随机转移实例化，通用性较好；
  - 理论推导较完整（附录 C 给出流匹配漂移修正的得分–速度关系推导）。
- **实验层面**：
  - 同时报告"保护强度"与"输入保真度/效率"，避免只追求破坏性而忽略实用性；
  - 消融覆盖投影有效性、邻域规模、分支位置、扰动预算等关键设计维度；

## 8. 不足与局限

- **实验覆盖有限**：仅评估 InstructPix2Pix 与 SD3 两个编辑器，未验证对其他扩散编辑模型（如 UltraEdit、基于 DiT 的编辑器）或视频编辑的适用性；基准仅 500 张图，规模偏小。
- **依赖代理编辑器与干净参考**：优化需要白盒访问编辑器梯度并预先计算 $z_{\text{ref}}$，在完全黑盒或无法获取干净编辑参考的场景下适用性受限。
- **后处理鲁棒性未讨论**：未评估保护扰动对 JPEG 压缩、缩放、裁剪、噪声等常见图像后处理的鲁棒性（尽管对比方法中 DCT-Shield 专门关注此点）。
- **超参依赖**：分支位置 $j=1$、温度 $\tau=2$、K=4、ε=8/255 等为特定设置，跨模型/跨分辨率的最优配置需重新调参。
- **计算成本并非极低**：SPIN 单图约 16 秒（SD3）、10.58 秒（IP2P），虽优于 PhotoGuard-D（311 秒），但仍高于部分轻量基线（如 PhotoGuard-E 8.4 秒）。
- **评估偏差风险**：ISR 依赖 LLM 评委，可能存在模型偏好或判定不一致；严格一致规则虽降低假阳性，但也可能低估保护效果。
- **伦理双刃剑**：论文在伦理声明中承认同一机制可能被用于干扰合法编辑工作流，建议仅在用户拥有或授权保护的图像上使用，但实际部署中难以完全约束。
