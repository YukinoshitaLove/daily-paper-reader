## 摘要
指令引导的图像编辑应当只改变指令所指的内容，而让图像其余部分保持不变。在双重无分类器引导（CFG）中，编辑器会在每个去噪步骤用全局权重组合两个方向：一个朝向指令编辑推进，另一个拉回源图像。我们提出注意力范围引导（ASG），这是一种采样器封装，可将这些权重变为空间化的。它从编辑器已经计算出的指令注意力中读取一张软支撑图，在支撑度低的位置削弱文本引导，在支撑度高的位置增强图像锚定。该封装无需训练、无需外部掩码，也不增加额外的网络评估。在完整的 MagicBrush 与 PIE-Bench++ 划分上，ASG 提升了面向保持性的指标，在 MagicBrush 的四项指标中领先三项，并在 PIE-Bench++ 的背景 PSNR 上取得领先。一项去除空间分配的剂量匹配对照在 PIE-Bench++ 上最多损失 0.73 CLIP，这证实增益来自空间分配本身。

## Abstract
Instruction-guided image editing should change what the instruction names and leave the rest of the image untouched. In dual classifier-free guidance (CFG), an editor combines two directions at every denoising step, one that pushes toward the instructed edit and one that pulls back toward the source image, using global weights. We introduce Attention-Scoped Guidance (ASG), a sampler wrapper that makes these weights spatial. It reads a soft support map from the instruction attention that the editor already computes, then weakens text guidance where support is low and strengthens image anchoring where support is high. The wrapper requires no training, no external mask, and no additional network evaluation. On the full MagicBrush and PIE-Bench++ splits, ASG improves preservation-oriented metrics, leading three of four MagicBrush metrics and PIE-Bench++ background PSNR. A dose-matched control that removes the spatial placement loses up to 0.73 CLIP on PIE-Bench++, confirming that the spatial allocation itself carries the gain.

# Attention-Scoped Guidance（ASG）论文总结

## 1. 核心问题与整体含义

- **研究动机**：指令引导图像编辑的理想行为是"只改动指令所指内容，其余区域保持不变"。但 InstructPix2Pix（IP2P）类扩散编辑器常违反该边界：一次局部替换会重新生成整个场景，改变主体身份或篡改未指定区域。
- **问题根源**：在双重无分类器引导（dual CFG）中，编辑强度由两个**全局标量**控制——文本编辑方向权重 `ct=7.5` 与图像锚定方向权重 `ci=1.5`，每个像素获得完全相同的"改与保"混合比例。指令只在局部成立，但引导权重是全局的，导致局部支撑的编辑"泄漏"到无关像素。
- **关键观察**：作者用 10 例探针发现，编辑器自身的**指令交叉注意力**在去噪全过程中始终保持空间结构，无论编辑成功还是失败；但失败样本与成功样本的注意力集中度统计（top-10% 质量比仅 0.13–0.16）无法区分二者。结论是：空间信号**已经存在**，只是采样器从未将其与编辑耦合。
- **定位差异**：S-CFG 已在文生图任务中对单一文本引导权重做空间重标定；ASG 的独特之处在于处理**指令编辑中的双 CFG 组合**，用同一张支持图同时调制两个残差方向。
- **整体含义**：把"引导强度"从全局标量升级为"由注意力派生的空间分配"，在不训练、不引入外部掩码的前提下缓解编辑–保持权衡。

## 2. 方法论

### 2.1 核心思想
- 复用编辑器**已经计算**的指令交叉注意力，构造一张软支撑图 `M(x)`；在支撑低处削弱文本编辑方向、在支撑高处增强图像锚定方向，其余流程（重组合、采样轨迹）完全不变。

### 2.2 基础形式
- IP2P 每步评估三个预测：无条件 `εu`、图像条件 `εi`、指令条件 `εt`，组合为
  `εs(x) = εu(x) + ct[εt(x) − εi(x)] + ci[εi(x) − εu(x)]`
- 两个方向定义为文本编辑方向 `dt = εt − εi` 与图像身份方向 `di = εi − εu`。

### 2.3 注意力派生支持（关键技术细节）
- 注意力 `A_k^s(x)` 取自**半 latent 分辨率**的交叉注意力层，跨头、跨层平均；`I` 为指令中的非特殊 token。
- 支撑按步骤累积、并在第 10 步后冻结：
  `as(x) = Σ_{j=0}^{min(s,10)−1} Σ_{k∈I} A_k^j(x)`，且 `a0(x)=0`。
- 逐图 min–max 归一化到公共尺度，再用 sigmoid 形成软过渡：
  `ā(x) = (a(x) − min a) / (max a − min a + ε)`，`M(x) = σ(10[ā(x) − 0.5])`，`ε=10⁻⁶`。
- **峰均比旁路**：`rpm = max a / mean a`；当 `rpm < 1.5` 说明注意力弥散、无可用空间信号，则整体旁路，回退到官方系数 `(7.5, 1.5)`。第 0 步也强制旁路。
- 设计理由：累积多步可平滑单步注意力噪声；早期步骤决定全局布局、后期步骤细化局部纹理，因此在布局确定阶段读取支持并冻结。

### 2.4 空间化双引导
- 文本编辑方向在低支持处被削弱：`Gt(x) = glo + (7.5 − glo)M(x)`，默认 `glo = 0`。
- 图像锚定在高支持处被增强：`Gi(x) = 1.5 + (ghi − 1.5)M(x)`，剂量 `ghi = 3.0`。
- 重组合：`εs^AS(x) = εu(x) + Gt(x)dt(x) + Gi(x)di(x)`。
- 显式增量形式：`Δεs(x) = −7.5[1 − M(x)]dt(x) + (ghi − 1.5)M(x)di(x)`。
  - `M=0` 时取消文本编辑方向、保留默认锚定；`M=1` 时保留原文本引导、仅增强锚定；中间值连续插值。
- **可恢复性**：当 `M ≡ 1` 且 `ghi = 1.5` 时严格退化为原采样器（此时 `Gt=7.5` 与 `glo` 无关）。
- 默认剂量下，`M=0.5` 的像素获得 `Gt=3.75`、`Gi=2.25`，即半强度编辑压力 + 适度增强锚定；连续权重保证过渡区无可见接缝。
- **算法流程（Algorithm 1）**：s=0 用官方系数并开始采集 `A0`；s=1–9 用逐渐增长的支持 `Ms`（门控使用第 0 至 s−1 步的注意力）；s=10–49 使用冻结的 `M10`（使用第 0–9 步注意力）；每步照常评估三次预测并重组合更新 latent。

## 6. 主要结论与发现

- **主结果**：ASG 在 MagicBrush 四项指标中领先三项——独立协议 CLIP-I **0.9296**、L1 **0.0624**，迭代协议 L1 **0.0901**；迭代 CLIP-I 以 0.8961 略低于 DIM 的 0.8981。
- **背景保持**：PIE-Bench++ 背景 PSNR 达 **82.173**，为最高，比最好的语义基线高约 1.15 dB（DIM）与 0.95 dB（Kontinuous Kontext）；在 171 个局部编辑上扩大到 4.7 dB 与 3.9 dB；比最好的背景 PSNR 基线 InstructDiffusion（81.591）高 0.582 dB。
- **语义编辑指标**：DIM 与 Kontinuous Kontext 在 PIE-Bench++ 的 CLIP-W/CLIP-E 上更强，说明 ASG 处于权衡的"保持端"。
- **相对基线提升**：完整系统比基础 IP2P 在独立协议上提升 **0.0787 CLIP-I** 与 **0.0511 L1**；相对已针对该 benchmark 微调的 MagicBrush-IP2P，仅靠采样即提升 **0.0119/0.0117**（独立）与 **0.0112/0.0141**（迭代）。
- **增益来源归因**：注意力集中度无法区分成功与失败（top-10% 质量稳定在 0.13–0.16），说明支持图的作用是**空间门控**而非成功信号。逐图均值替换空间图（剂量精确匹配、仅去掉空间放置）在 PIE-Bench++ 上最多损失 **0.73 CLIP**，而背景 PSNR 仅变化 0.06 dB——证明增益来自空间分配本身，且"压平"地图对保持性帮助很小。
- **分支作用**：仅文本门控贡献了大部分提升；仅图像锚定在 incumbent 上优于 uniform CFG 但明显弱于文本门控；两者叠加得到完整方法，并把灾难性 turn 从 13 降至 8。
- **剂量边界**：`ghi` 从 1.5 升到 3.0 时两项指标均改善；升到 4.5 时 CLIP-I 下降、新增 3 个灾难性 turn，且全部为**删除类编辑**，说明过强锚定会抵抗被请求的删除。
