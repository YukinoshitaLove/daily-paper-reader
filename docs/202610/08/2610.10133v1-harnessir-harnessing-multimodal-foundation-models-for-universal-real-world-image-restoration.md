## 摘要
真实世界的低质量图像会遭受复杂的混合退化，包括但不限于噪声、模糊、大气效应等。近期的智能体方法通常将真实世界图像恢复（Real-IR）建模为在任务特定的单退化恢复模型上进行顺序工具调用的问题。然而，这一范式存在根本性局限，因为复杂的真实世界退化无法按退化类型逐个干净地逆转，而且以任务特定模型作为工具会限制智能体系统的能力上限。在这项工作中，我们提出 HarnessIR，一种通过利用多模态基础模型（MFM）作为执行器来实现 Real-IR 的智能体框架。HarnessIR 包含五个阶段：感知与诊断、按需工具调用、提示组合、执行，以及验证驱动的精修。与依赖由任务特定模型组装而成的工具链的先前智能体 Real-IR 方法不同，HarnessIR 将恢复需求、感知诊断和证据输入到一个 MFM 中，由其在单遍中执行恢复，随后通过验证阶段判断结果是否需要进一步处理。在我们的框架下，现成的 MFM 能出色地处理恢复任务，在广泛使用的 MiO100 合成基准上取得最先进的结果。更重要的是，通过利用 MFM 的强大泛化能力，HarnessIR 在先前智能体 IR 系统常常难以应对的具有挑战性的真实世界场景中提供了出众的恢复质量。代码可在 https://github.com/PolyU-VCLab/HarnessIR 获取。

## Abstract
Real-world low-quality images suffer from complex mixed degradations, including but not limited to noise, blur, atmospheric effects, etc. Recent agentic methods usually model real-world image restoration (Real-IR) as a sequential tool calling problem over task-specific single-degradation restoration models. This paradigm, however, is fundamentally limited because complex real-world degradations cannot be cleanly undone degradation by degradation, and the tool used for task-specific models caps the capability of the agent system. In this work, we present HarnessIR, an agentic framework for Real-IR by harnessing a multimodal foundation model (MFM) as the executor. HarnessIR consists of five stages: perception and diagnosis, on-demand tool invocation, prompt composition, execution, and verification-driven refinement. Unlike prior agentic Real-IR methods that rely on tool chains assembled from task-specific models, HarnessIR feeds the restoration requirements, the perceptual diagnosis, and the evidence into an MFM that performs restoration in a single pass, followed by verification stages to determine whether the result warrants further processing. Under our harness, off-the-shelf MFMs handle restoration tasks remarkably well, achieving state-of-the-art results on the widely used MiO100 synthetic benchmark. More importantly, by exploiting the strong generalization ability of MFMs, HarnessIR delivers compelling restoration quality on challenging real-world scenes where previous agentic IR systems often struggle. Codes is available at https://github.com/PolyU-VCLab/HarnessIR.

## 1. 核心问题与整体含义（研究动机与背景）

- **真实世界图像退化的复杂性**：真实拍摄的低质量（LQ）图像往往同时遭受噪声、模糊、大气效应（雾/雨/雪）、低光照、JPEG 压缩等多种**混合退化**，这些退化相互耦合，难以用单一退化类型建模。
- **现有范式的根本局限**：
  - **All-in-One / Multi-in-One 方法**：多数仍假设输入只含单一可识别退化，在无约束真实场景中表现受限。
  - **Agentic IR 方法**（如 AgenticIR、4KAgent 等）：将 Real-IR 建模为对任务特定单退化恢复模型的**顺序工具调用问题**，由 VLM 感知退化并规划工具调用序列。
- **四条关键缺陷**：
  1. 将耦合的混合退化近似为一系列专门恢复操作的顺序执行，但许多真实退化无法被干净地分离或按序逆转；
  2. 规划器把细粒度内容/退化描述转换为工具调用序列时**丢失大量有用信息**；
  3. 任务特定恢复工具**泛化能力差**，限制了整个系统的泛化上限；
  4. 多数方法在合成混合退化上开发和评估，而真实退化相互交互，难以模拟。
- **MFM 的机遇与挑战**：生成式多模态基础模型（如 Nano Banana 2、GPT-Image-2.5）将 IR 视为编辑问题，具有强大生成与泛化能力，但**朴素提示会导致过度生成、重绘文本和内容**，保真度难以保持。
- **核心主张**：问题不在于 MFM 不能做 Real-IR，而在于**如何提示它们、配合辅助工具、在合适步骤中执行**。论文提出 HarnessIR，将智能体的动作原语从"恢复工具调度"转向"MFM harnessing"。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
- 使用**单个冻结的 MFM 作为执行器**，不调度任何任务特定恢复工具。
- 辅助工具（OCR、人脸检测、深度估计、语义分割）仅作为**证据提供者**，而非恢复链中的环节。
- 通过精心设计的 harness（提示 + 控制流 + 证据 + 验证逻辑）激发并约束 MFM 的恢复能力。

### 五阶段流程
1. **感知与诊断（Perception and Diagnosis）**：诊断器 V_d 读取 LQ 图像 x 和用户请求 r，输出内容描述、退化分析（类型/严重度/位置/证据）以及需要调用的辅助工具计划 π。
2. **按需工具调用（On-Demand Tool Invocation）**：执行计划，收集证据 e（OCR 字符串与置信度/边框、人脸框、深度图、语义分割图）。简单图像可能无需调用工具。
3. **提示组合（Prompt Composition）**：组合器 V_c 将 (x, r, d, e) 转换为**单一文本指令** p，将证据融入图像描述而非以列表附加，并结合通用恢复领域知识。
4. **执行（Execution）**：执行器 E 接收 (x, p)，单次生成恢复结果。
5. **验证驱动精修（Verification-driven Refinement）**：验证器 V_v 基于 NR-IQA 分数、与 x 的亮度/颜色/SSIM 比较、请求 r 和恢复要求判断是否满意；不满意则写出修正意见，组合器针对**原始 x** 重新写指令再执行。

### 关键公式
- 先前 Agentic IR：$\hat{y}^{(k)} = f_{t_k}(\hat{y}^{(k-1)})$，顺序通过任务特定网络；
- HarnessIR：$\hat{y}^{(k)} = E(x, p^{(k)})$，执行器固定，仅改变提示；最终 $\hat{y} = \hat{y}^{(k^*)}$。
- 最多允许 **3 轮执行**；若均未被接受，返回验证器选出的最佳候选。

### 关键设计细节
- **诊断与组合分离**：最终指令必须在诊断器选定工具并获取证据后才能编写。
- **证据文本化**：视觉证据（深度图、分割图）直接给执行器可能引入伪影（如语义标签颜色泄漏），故由组合器转为语言。
- **从 LQ 重做而非就地修复**：若上轮输出失败，其内容可能已被篡改，不是可靠的起点；HarnessIR 每轮都从原始 x 出发，避免错误累积。
- **验证器不看执行指令**：使结果按"恢复任务本应做什么"评判，而非按"我们要求执行器做什么"评判。
- **角色专用 brief**：诊断器、组合器、验证器由同一冻结 VLM（Gemini-3.7-Flash）以三种角色提示实例化。

## 6. 主要结论与发现

- **MiO100 上**：HarnessIR-NB2 在多数指标上最优；相比直接使用 NB2，PSNR +1.40 dB、LPIPS 改善 0.03、DF-Score +4.1；HarnessIR-GPT 相比直接 GPT-Image-2.5，PSNR +1.75 dB、LPIPS 改善 0.06、DF-Score +18.1。
- **Real-Paired-200 上**：HarnessIR-NB2 PSNR +2.69 dB 达 26.63 dB，DF-Score 62.0；HarnessIR-GPT PSNR +2.87 dB，DF-Score 从 40.1 升至 60.2；均远超先前最佳 DF-Score 38.8。
- **Real-NoGT-200 上**：HarnessIR-NB2 DF-Score 62.9，HarnessIR-GPT 49.3，远高于先前最佳 32.0。
- **消融结论**：
  - 逐步增加信息（详细请求 → 单 VLM 分析 → 辅助工具视觉证据 → 文本证据）持续提升性能；文本证据最佳（PSNR 26.01，DF-Score 59.6），避免视觉地图伪影。
  - **Redo from LQ 优于 In-place refinement**（DF-Score 62.0 vs 57.2），验证了从原始输入重做的必要性；仅 37% 图像触发重做。
  - HarnessIR 不依赖特定 VLM，Gemini-3.7-Flash 在性能与成本间平衡最佳。
- **用户研究**：HarnessIR-NB2 获 48.3% 选票，HarnessIR-GPT 获 28.1%，两者合计 **76.4%**，显著领先其他方法。
- **成本**：最终系统 $0.129/张，低于 AgenticIR（$0.137）和 4KAgent（$0.190），同时 DF-Score 更高。
- **核心发现**：收益来自 **harness 的协同设计**，而非执行器本身；harness 能激发执行器潜力但无法提升其上限（如 HarnessIR-GPT 在 PSNR/SSIM 上仍弱）。

## 7. 优点

- **范式创新**：首次将 agentic IR 的动作原语从"恢复工具调度"转为"MFM harnessing"，用 MFM 单次执行替代任务特定模型顺序链，避免误差传播。
- **推理时框架**：完全 inference-only，无需训练或微调，易于部署和适配新 MFM。
- **证据文本化设计**：将深度图、分割图等结构化/视觉证据转为语言，避免直接输入视觉地图导致的伪影，契合 MFM 语言接口。
- **Redo from LQ 策略**：理论上合理（失败输出内容可能被篡改）且实验验证有效，优于就地修复。
- **验证器设计细致**：不让验证器看到执行指令，避免"按指令符合度"而非"按任务正确性"评判。
- **评估协议改进**：指出 NR-IQA 可奖励幻觉，提出 Δ 指标和 DF-Score，并做了人类对齐（87% vs NR-IQA 50.8–67.1%）与跨评估器一致性验证（PLCC 0.85–0.94）。
- **成本效益分析详尽**：给出 per-image 成本、调用次数、runtime，并与先前 agentic 方法对比，证明质量提升不以高昂成本为代价。
- **消融系统全面**：覆盖执行器输入、精修策略、VLM 选择、成本四个维度。
- **用户研究规模较大**：5000 票、随机顺序、盲测，结论与定量指标一致。

## 8. 不足与局限

- **依赖在线 API**：需访问在线 VLM 和 MFM API，与 AgenticIR、4KAgent 等相同，但限制了离线/隐私敏感场景的部署。
- **无法提升执行器上限**：harness 只能激发和调控执行器已有能力，不能提高其性能天花板；如 GPT-Image-2.5 生成先验强但像素对齐差，PSNR/SSIM 仍弱。
- **自评偏差风险**：DF-Score 由团队开发的 VLM 评估器给出，虽验证了人类对齐和跨评估器一致性，但仍非完全独立第三方评估。
- **真实测试集规模有限**：Real-Paired-200 和 Real-NoGT-200 各 200 张，虽覆盖多退化类型，但每类样本量较小（如某些类别仅 6–25 张）。
- **部分基线缺失真实集结果**：MAIR、TIR-Agent、SEAR、OPERA 因代码未公开，仅引用 MiO100 结果，真实场景对比不完整。
- **未涉及视频/其他模态**：仅针对静态图像恢复，未讨论视频恢复或多帧场景。
- **推理成本与延迟**：最终系统平均 3.90 次 VLM 调用 + 1.45 次 MFM 调用 + 2.40 次辅助工具调用，runtime 64.3s/张，对实时应用不友好。
- **重做收益不均**：仅 37% 图像触发重做，收益集中在困难尾部样本，平均提升不代表所有图像均改善。
- **验证器判断依赖 VLM**：验证器本身的可靠性未做独立量化评估，可能漏判或误

判。
- **辅助工具的可靠性未充分讨论**：OCR、人脸检测、深度估计、分割工具在极端退化（浓雾、极低光照）下本身可能失效或给出错误证据，论文未量化工具失败对最终结果的影响。
- **超参数固定**：最多 3 轮执行、验证阈值等均为固定设定，未分析其对不同退化类型的敏感性。
- **内容保真度的细粒度评估不足**：虽有 F-Score 与用户研究，但对小字体文本、人脸身份一致性等高风险区域的定量评估（如文本识别准确率、人脸 ID 相似度）着墨较少。

## 9. 启示与可拓展方向

- **"Harness 而非 Tool Chain"的思路可迁移**：该范式不限于图像恢复，可推广到视频复原、音频增强、3D 重建等同样存在"混合退化 + 基础模型强大但难控"问题的领域，核心是把智能体设计重心从"挑选专用模型"转向"如何组织证据、指令与验证"。
- **证据文本化的普适价值**：对任何以语言为原生接口的生成式基础模型，将结构化/视觉证据转为自然语言，可能比直接注入视觉条件更稳健，这为多模态提示工程提供了可复用的设计原则。
- **验证驱动闭环的重要性**：把 NR-IQA、与原始输入的保真度对比、用户请求三者结合作为"验收标准"，并允许从原始输入重做，是抑制生成模型幻觉与漂移的通用机制。
- **可探索的改进点**：
  - 引入**自适应重做预算**（按退化难度动态决定轮数）以降低平均延迟；
  - 用**轻量本地模型**替代部分 VLM 角色（如验证器），减少 API 依赖与成本；
  - 建立**工具可靠性估计**，在证据置信度低时降权或跳过；
  - 面向**文本/人脸等关键区域**设计专门的保真度约束与评估指标；
  - 探索**视频与多帧一致性**扩展。

## 10. 总体评价

HarnessIR 的核心贡献不在于提出新的恢复网络，而在于**重新定义了 agentic 图像恢复的动作空间**：从"调度任务特定恢复工具"转向"驾驭多模态基础模型"。它用冻结 MFM 作为唯一执行器，配合诊断器、组合器、验证器三角色，以及按需调用的辅助工具作为证据来源，构建了一个完全推理时、无需训练、可即插即用新 MFM 的框架。

论文在方法设计上有若干值得称道的细节：证据文本化避免视觉伪影、每轮从原始 LQ 重做以避免错误累积、验证器不看执行指令以保持评判独立性。评估方面，作者敏锐地指出 NR-IQA 可能奖励幻觉，提出 Δ 与 DF-Score，并做了人类对齐与跨评估器一致性验证，态度较为审慎。实验覆盖合成与真实、有 GT 与无 GT、多执行器、多 VLM、多消融维度，并有 5000 票规模盲测用户研究支撑，整体充分性较好。

局限同样清晰：依赖在线 API、无法突破执行器性能上限、自评偏差风险、真实测试集规模有限、推理延迟较高（约 64.3s/张）、部分基线在真实集上缺失。这些问题多属"范围与成本"层面的取舍，而非方法性硬伤，但确实限制了其直接落地于实时或隐私敏感场景。

**一句话总结**：HarnessIR 证明了——当生成式多模态基础模型足够强大时，Real-IR 的瓶颈可能不在"用什么模型恢复"，而在"如何设计 harness 去激发、约束并验证它"；这为智能体化底层视觉任务提供了一个值得跟进的新范式。
