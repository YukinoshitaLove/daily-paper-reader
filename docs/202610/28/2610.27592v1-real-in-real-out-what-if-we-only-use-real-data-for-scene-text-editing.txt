## Abstract 

Aiming to modify textual content while preserving the original style, Scene Text Editing (STE) has significant practical value in many applications. STE typically requires paired images before and after editing for training. However, recent approaches rely heavily on synthetic paired data and complex disentanglement strategies. They struggle to faithfully capture the diversity and complexity of natural scenes, often producing artifacts or hallucinations. In this work, we challenge the common practice and investigate whether STE can be driven by turning each real sample into its own paired supervision. Concretely, we explore multiple ways to disrupt the original image (e.g., Crop, Shuffle, Mask) to construct self-paired training data, and build a strong baseline ( TextRIRO ) upon a conditional diffusion architecture. Our experiments show that combining character-column shuffling with image cropping (Shuffle&Crop) effectively destroys text semantics while preserving key style cues, enabling the model to learn editing behaviors directly from the real text image. With this concise yet real-oriented design, TextRIRO achieves promising performance in both accuracy and visual realism across real-world benchmarks, substantially mitigating the synthetic-to-real domain gap. Furthermore, we leverage TextRIRO to build TextRIRO-3M , a large-scale realistic dataset for long-text recognition by concatenating edited and original images. Experimental results show that training recognition models with TextRIRO-3M significantly improves recognition accuracy, demonstrating that TextRIRO provides highly useful training resources for downstream tasks. Overall, TextRIRO lifts STE to realistic, reliable, and widely applicable new levels.

## 1 Introduction 

Scene Text Editing (STE) aims to extract the style of the given text and replace it with a new string, while maintaining both visual realism and style consistency [36]. STE is typically formulated as a generative task, and its applications grow with the advancement of generative models. It addresses practical needs such as replacing text in images for artistic creation and also facilitates various downstream scene text tasks. Notably, STE shows significant potential in generating data [39] for scene text recognition (STR) [6, 10, 11, 48], as it can generate samples with the same style but different content from existing images.

However, it is hardly possible to get different texts with the same background style in real-world scenarios. To address this, previous methods [20, 29, 36, 38, 43] rely heavily on synthetic data, as shown in Fig. 1(a). On the one hand, two-stage explicit disentanglement methods [29, 36, 38] use rendering tools to synthesize paired images with identical style but different text over a background image, followed by foreground-background separation and fusion. But they fail to separate text from the background, resulting in incomplete removal of the source text, as shown in cases (1) and (2) in Fig. 1(e). On the other hand, implicit disentanglement approaches [20, 43] leverage various pre-trained models to extract features for directly generating target images, which is less controllable, resulting in hallucinations such as case (3), with misspelled or missing characters. Recent efforts [9, 22, 26] have explored semi-supervised learning with real data by erasing itself and writing back or paired training using pseudo-labeled data, as illustrated in Fig. 1(b). Nevertheless, synthetic data still remains dominant. As evident from the editing results in Fig. 1(e), this branch of methods easily leads to case (4): even when the target text is generated, it often appears mismatched in style or contains visible artifacts. Furthermore, inpainting-based STE paradigms (Fig. 1(c)) mask the text region and attempt to restore it using surrounding context [2, 4, 15, 39]. However, the lack of sufficient style cues makes it difficult to recover the desired appearance, as shown in Fig. 1(f). We are motivated by an observation that prior work has under-emphasized: the domain gap in STE is primarily a data problem, and only secondarily an architecture problem. We therefore ask the simplest possible version of the question: 

What if we only use real data for scene text editing, with neither synthetic triplets nor expensive paired collection? 

The core challenge is to extract stable style guidance from the source text image while suppressing the 2side effect from semantic text content. Our key insight is that scene text style mainly lies in low-level cues such as color, texture, and illumination, while semantic text is a high-level sequential structure. Based on this, we explore multiple self-paired real-data schemes that force the model to focus on style rather than semantics. Specifically, we experiment with (i) shuffling and recombining the text region either column-wise or block-wise (Shuffle), (ii) cropping local sub-regions (Crop), and (iii) masking parts of the original image (Mask). Empirically, we find that combining column-wise Shuffle with Crop (Shuffle&Crop) achieves the best performance. To realize the idea, we propose TextRIRO , a conditional diffusion model that takes only Real data as Input and produces Realistic Output for scene Text editing. During training, TextRIRO applies “Shuffle&Crop” to a real text image to separate its style and semantics, and then reconstructs the original image. By removing the reliance on synthetic data, it overcomes the bottleneck of high-quality generation during inference. For style features, we process them into multi-scale representations and then inject them into the conditional U-Net using the ControlNet-like process [45] for efficient integration. For text encoding, we use an STR pre-trained encoder [16] to extract character-level features, which improves text understanding and enables robust STE transfer. TextRIRO removes the need for explicit or implicit disentanglement and avoids using the synthetic domain as the main training support. On real benchmarks for STE, it produces more realistic results with markedly reduced “synthetic flavor.” It also achieves higher accuracy on equal-length editing and variable-length editing tasks. These results show that self-paired training on real data effectively moves STE toward realistic generation. We further ask whether STE can help STR data generation [39, 40, 42]. We find that TextRIRO already outperforms existing STE methods, but the editing accuracy still limits direct use as training data. We then use STE as data expansion by concatenating the original image with its edited counterpart. This preserves style but adds content, which yields high-quality, scene-consistent samples for long-text recognition. Starting from the labeled real dataset U14M-Filter [7, 16], we build a 3M-scale dataset, TextRIRO-3M . On Union14M-Benchmark [16], training an STR model on mixed TextRIRO-3M and real data improves overall accuracy by 1.91% over a real-only baseline, and improves the Multi-words subset by 3.28%. These gains indicate that current STR training data are not saturated and STE-based synthetic data substantially boost STR. In summary, our main contributions are as follows: • We propose TextRIRO, a novel STE method that trains solely on real data via self-paired supervision. It performs realistic editing without explicit or implicit disentanglement, and it alleviates artifacts and hallucinations caused by the synthetic-to-real domain gap. • TextRIRO achieves more realistic and accurate edits on real benchmarks and attains state-of-the-art (SOTA) performance under the stronger criterion of “training with edited data.” • Built on TextRIRO, we create TextRIRO-3M, a large-scale realistic composite dataset for long-text recognition. It significantly improves STR, which validates both the realism and the utility of our edited data and demonstrates that STE effectively benefits STR.

Later works expand capabilities: SwapText [38] handles curved text, STEFANN [29] focuses on character-level control, and TextStyleBrush [20] leverages StyleGAN2 [19] for self-supervised style-content disentanglement. Frameworks like AnyText [33] and AnyText2 [32] unify multilingual editing via ControlNet [45]. TextCtrl [43] disentangles style conditions directly in diffusion models. Meanwhile, DARLING [44] unifies scene text editing, removal, and recognition tasks to leverage these tasks to disentangle task-specific features and RS-STE [9] utilizes scene text recognition to assist scene text editing. These two approaches highlight synergy across scene text tasks. 

Data Perspective on STE Model advancements in STE are closely tied to the evolution of training data. Early methods use synthetic paired data by rendering tools, e.g., SRNet-Datagen [36]. To include real-world data, RewriteNet [22] uses masked regions and MOSTEL [26] proposes an erasing and writing-back strategy. UMM-based RS-STE [9] adopts reverse self-supervision on real images. In diffusion-based STE, some models (e.g., TextCtrl [43]) disentangle features using synthetic data, while others [3, 33] view STE as masked image inpainting, releasing large real datasets like Anyword-3M [33] and MARIO-10M [3]. However, style consistency can be difficult when context lacks similar references. Benchmarks and datasets for application are also advancing: ScenePair [43] provides high-quality real-world evaluation, and TextSSR [39] generates millions of edited images for STR tasks, demonstrating STE’s broader utility. 43 Method

3.1 Self-Paired STE Data 

Most prior data pipelines [26, 36] construct Isrc , T tgt , I tgt triplets primarily from synthetic text images. The domain gap between synthetic and real scenes limits the ability of STE models and their applications to downstream scene text tasks. Recent methods [9, 26] introduce some real data for unpaired training, yet synthetic samples remain dominant and only partially bridge this gap.

When using an image as Isrc , our goal is to remove its textual content while preserving its style. This motivates a simple strategy: scrambling the original image disrupts content while retaining stylistic features. However, since text comprises discrete characters, excessive shuffling fragments glyphs and impairs shape consistency. This presents a trade-off: we aim to maximize content removal but minimize stylistic degradation. (1) Text typically aligns along its long axis, and its content and length are known. We exploit this structural prior by dividing the image along its long axis into L (L is the number of characters) equal bins. By reordering these bins, we generate the source image Isrc (see “Shuffle” in Fig. 2), thereby breaking semantic continuity while maintaining local appearance cues. (2) Stripe-based shuffling alone is insufficient for complex text layouts, such as curved or multi-oriented arrangements. To address this, we propose an alternative that reconstructs the image through its sub-patches. The global text arrangement is locally preserved: tilts and curvature manifest within contiguous sub-images. We form Isrc by cropping the original image (as illustrated by “Crop” in Fig. 2), yielding self-paired data that retain the stylistic integrity of intricate layouts. (3) Combining these two strategies results in a more robust and diverse self-paired mechanism. As shown in Fig. 2 (“Shuffle then Crop”), with probability pshuffle , shuffling is applied before cropping. Otherwise, cropping is applied directly to the original image. 3.2 Model Architecture 

With the constructed self-paired triplets, TextRIRO maps the perturbed source image Isrc and target text Ttgt 

into style and text control signals for a ControlNet-like diffusion generator [45], as shown in Fig. 2. The style encoder follows TextCtrl [43]: a ViT backbone [5] extracts image representations, and a lightweight spatial pyramid aggregates them into multi-scale features that are additively injected into the U-Net. For text, we keep character-level encoding [43, 47] but replace synthetic glyph/CLIP pre-training with an autoregressive STR objective on real scene text [16, 30]. This improves real-domain character awareness and aligns recognition with editing. The generator contains a VAE for latent mapping, a U-Net for denoising, and the above style/text encoders. The VAE and text encoder are frozen, while the style encoder and U-Net are jointly trained with the standard noise-prediction diffusion objective conditioned on style and text. This design is intentionally simple and backbone-agnostic: stronger diffusion backbones or conditioning modules can be substituted when more compute is available. We also evaluate a DiT-based conditional control alternative in Tab. 5, where ControlNet-style multi-scale injection remains more effective for fine-grained scene text editing. Detailed feature equations, tokenization, and the training loss are provided in Appendix Sec. 6.1. 

3.3 Generating Long-Text Recognition Data 

After training TextRIRO, we generate a style-matched image with the same length but different content for each real input. To ensure correctness, we filter generated samples with an STR model trained on real data and keep only instances whose predicted text matches Ttgt . We then concatenate each filtered image with its original reference to build long-text recognition data, doubling the sequence length. The detailed pipeline and visualizations are illustrated in Fig. 2 (d). This procedure substantially broadens coverage for rare scenarios, such as long and multi-word instances, and it establishes a practical connection between STE and STR.

STR Training Proxy Task. Although we employ a strong recognizer, it cannot reflect absolute editing accuracy. Following TextSSR [39], we use the edited text to train an STR model and treat it as a proxy evaluation of the realism and accuracy of generated text. Only sufficiently realistic and accurate synthetic data will improve downstream recognition performance. This also serves as a practical measure of whether editing models can effectively generate usable training samples. We apply each STE model to U14M-Filter, editing each image with the same alternative string of equal length, and train STR models with edited images and their edited labels, then evaluate them on the STR protocol. Tab. 3 confirms previous trends: MOSTEL’s outdated architecture and data strategy result in poor performance. TextCtrl and RS-STE utilize different architectures and training data, yet achieve similar results, with only a 0.90% difference in average accuracy. Both methods follow training paradigms dominated by synthetic data, revealing the upper bound and bottleneck of such approaches, as the domain gap between synthetic and real data persists despite model optimization. In contrast, TextRIRO’s self-paired training paradigm leverages real data to overcome this bottleneck, yielding an average accuracy of 86.67%, representing a 9.78% improvement over the next-best approach. This advantage is even more pronounced on irregular samples, with an 11.69% gap, highlighting TextRIRO’s ability to supplement scarce training domains.

DiT-Based Variant. We also try to instantiate TextRIRO with DiT-based conditional control, using Omini-Control [31] as a representative lightweight condition-injection method. This variant can be trained under our self-paired real-data formulation, but its ScenePair performance remains behind the ControlNet-based TextRIRO. The main reason is that OminiControl-style conditioning injects image conditions in a compact token-level manner, which is parameter-efficient and general, but relatively coarse for scene text. For text editing, small local deviations can change character identity or introduce artifacts. Therefore, ControlNet’s multi-scale feature injection is better suited because it preserves and transfers local style cues at several spatial resolutions. In addition, the OminiControl paper reports that, despite its minimal and universal design, it is not uniformly superior to ControlNet across all controlled generation settings. We therefore use ControlNet 9as the default backbone and leave more specialized DiT-based fine-grained control as future work.

## 5 Conclusion 

In this paper, we have introduced TextRIRO, a scene text editing method that, for the first time, learns editing purely from real data through a self-paired supervision scheme. By disrupting semantic content via targeted shuffle and crop operations while maintaining style, we eliminated dependence on synthetic triplets and bypassed the need for explicit or implicit disentanglement modules. Our diffusion-based model achieves near-realistic fidelity and robust content accuracy, effectively narrowing the synthetic-to-real gap that limits previous STE approaches. Comprehensive experiments on multiple benchmarks demonstrate that TextRIRO surpasses existing STE methods in both correctness and visual realism. Additionally, we create a large-scale, realistic long-text recognition dataset, TextRIRO-3M. Training STR models on it yielded significant gains, proving that high-realism STE continues to propel STR performance beyond current saturation points. Naturally, TextRIRO excels in English thanks to abundant real scene text data, but such multilingual data is scarce. Future work will focus on accurate and realistic multilingual STE in low-resource settings.

6.3 Datasets and Implementation Details 

Training Datasets. Our self-paired pipeline uses the text label and, in particular, its length, but it does not require character segmentation. For Shuffle, we split the image width into nsplit ∈ 2, L equal-width columns, where L is the label length, and randomly permute the columns. Crop takes a horizontal contiguous sub-interval. Thus, a character may be cut by a column boundary. This is intentional because the purpose is to remove readable semantics while retaining local visual style. We train our STE model and the STR baseline on Union14M [16], currently the largest available scene text dataset. Specifically, we adopt a filtered version of its labeled subset, denoted as U14M-Filter [7], which contains 3.22M annotated text instances. Note that training in a completely label-free manner is theoretically infeasible, because the definition of STE inherently requires specifying the edited text. 

Evaluation Datasets. To evaluate scene text editing performance under real-world conditions, we first employ the ScenePair [43], which comprises 1,280 pairs of carefully collected, real-world text images. Furthermore, we construct benchmarks for equal-length and variable-length text editing using six widely-used text recognition datasets: IIIT 5K-Words (IIIT [24]), ICDAR2013 (IC13 [17]), Street View Text (SVT [34]), ICDAR2015 (IC15 [18]), Street View Text-Perspective (SVTP [25]), and CUTE80 (CUTE [27]), which we collectively refer to as the Common Benchmarks. Additionally, we assess data quality using Union14M-Benchmark [16], which includes seven subsets: Curve (CUR), Multi-Oriented (MLO), Artistic (ART), Contextless (CTL), Salient (SAL), Multi-Words (MLW), and General (GEN). 

Implementation Details. We use MAERec [16] both for text-encoder pre-training and as our STR proxy baseline, training for 20 epochs under the settings established by the OpenOCR framework [7]. TextRIRO builds upon SD 2.1 for the VAE and SD 1.5 for the U-Net backbone [28]. The extensively pre-trained VAE in SD 2.1 is well-suited for scene text tasks. The U-Net requires its parameters to be unfrozen for training, so the specific version has minimal impact. Meanwhile, SD 1.5 uses a smaller dimension ( dim = 768 ) and can directly match the feature dimension of the text encoder. All images are resized to 64 × 256 and those with aspect ratios less than 1 : 2 are rotated 90 ◦ counterclockwise to match the target resolution. We use a batch size of 256, apply an initial learning rate of 1 × 10 −5, and train for 15 epochs on 8 NVIDIA V100 GPUs. During inference, we use 20 sampling steps and a classifier-free guidance (CFG) scale of ω = 2.2. For the 15 generation of the TextRIRO-3M dataset, we use only reference images whose original text contains at least 4 characters. Consequently, the minimum label length in TextRIRO-3M is 8. For the other STE models, we use their officially reported results when available. Otherwise, we use their released official checkpoints and the default inference hyperparameters to ensure a fair comparison. 

Training–inference protocol. During training, the style condition is the perturbed view of the same real image and the target text is its original label. At inference, the source is an unperturbed real image and the target is a new string. This is an unavoidable residual mismatch because coherent real source–target pairs with different text are not available at scale. Shuffle&Crop is designed to reduce the mismatch by producing a real-image-derived style condition whose semantics are destroyed but whose local appearance remains realistic. The self-paired objective also provides a content-disentanglement constraint: the source condition has disrupted text order, while the target text is supplied only through the text encoder. If semantic content leaked through the style path, the model would copy the disrupted content rather than render the correctly ordered target. Consistently, the identity (None) ablation in Fig. 4 collapses to an ACC of 4.37, showing that an unperturbed source encourages copying instead of text-conditioned editing. 

Computational Overhead and Runtime Efficiency. We report the computational requirements for both the STR pre-training and U-Net fine-tuning stages, which use 36 GPU-hours and 180 GPU-hours, respectively. For inference, we evaluate our method on a single NVIDIA V100 GPU with diffusion_steps set to 20 and a batch size of 32. Processing 10,000 batches requires 18 hours, corresponding to an average inference time of 0.20 seconds per image.

6.4 Additional Editing Evaluation 

Per-image style fidelity beyond FID. FID is established as the evaluation metric in MOSTEL [26], and TextCtrl [43] continues to use the same evaluation code to report FID on ScenePair, so we keep it for comparability. For each generated image, we compare it against its corresponding ScenePair reference image and report LPIPS (perceptual similarity), SSIM (structural similarity), and PSNR (pixel-level fidelity). Lower LPIPS and higher SSIM and PSNR indicate better agreement with the paired reference. LPIPS measures per-image perceptual and structural similarity, and FID measures how close the overall image distribution is to the reference distribution. TextRIRO achieves the best results on both in Tab. 12, which indicates that it generates images closer to the real distribution. PSNR and SSIM, in contrast, are per-image pixel-level metrics that are sensitive to small spatial shifts, anti-aliasing, and valid appearance variations in rendered text. Because the ScenePair reference images are manually collected and not strictly pixel-aligned pairs, even a more realistic generation can score lower on these metrics simply because its pixels do not exactly match the reference.

## 7 Visualization 

7.1 Character-Aware Embeddings 

The STR pre-trained text encoder endows TextRIRO with strong character awareness. To further evaluate its encoding capabilities, we visualize the embeddings of several text samples using t-SNE [23], as illustrated in Fig. 7. Overall, words with similar character compositions or comparable text lengths are positioned closer together, while sufficient separation is maintained between distinct samples. For example, the characters ‘1’ and ‘l’ possess different semantic meanings but exhibit similar glyphs, resulting in ‘1024’ and ‘l024’ being embedded in close proximity. Traditionally, glyph-pre-training is required for such nuanced feature representations, yet STR pre-training achieves this directly. Additionally, the variations ‘there’, ‘There’, ‘THere’, and ‘THERE’ are embedded near each other, reflecting their shared underlying structure, yet each maintains a distinct position. This separation prevents case confusion in text generation, thereby enabling accurate character-level generation.

7.4 Bad Cases and Discussion 

It is important to acknowledge that our STE approach is not without limitations. Fig. 11 illustrates three common failure cases, along with the corresponding causes and potential solutions: 1. Long Text: The text encoder used in our training pipeline is pre-trained from the STR model, which is primarily trained on datasets containing short text, resulting in limited capacity for capturing long text dependencies. Additionally, TextRIRO is trained on the same datasets, further constraining its ability to handle long text. To address this, we are inspired by the construction of the TextRIRO-3M dataset: we segment long text into shorter fragments, synthesize each fragment individually, and then concatenate these fragments to form the final long text. This approach leverages the inherent strengths of short text synthesis while enabling robust long text generation. 2. Curved Text and Complex Geometry: As shown in Fig. 11, TextRIRO recognizes that the input is not standard horizontally aligned text, but may interpret highly curved text as slanted. Crop preserves local tilt and curvature, and near-vertical inputs are rotated in preprocessing. Consequently, TextRIRO achieves equal-/variable-length accuracy of 64.87/48.12 on CUTE and 79.69/42.31 on SVTP, outperforming the compared baselines. Tab. 4 further isolates the operator contribution. However, extreme curvature and large geometric deformation remain difficult because regular layouts dominate the training data. Future work should incorporate finer-grained control points, similar to TPS modules in STR, to enable more precise geometric control. 3. Special Symbols and Languages: The synthesis of special symbols remains challenging because of both sparse training coverage and the current vocabulary/data coverage. This also restricts cross-lingual generalization: the self-pairing operation itself is language-agnostic, but sufficiently large real labeled datasets are currently much more available for Latin scripts than for low-resource languages. Collecting balanced real labeled data with broader character and language coverage is necessary for stable multilingual generation. Style preservation and disentanglement. Shuffle preserves stroke thickness because it permutes equal-width columns without rescaling them. Crop can change apparent stroke scale, but the two operators are complementary: pure-Shuffle instances remain in training with non-trivial probability (approximately 20% for an average label length of five) and anchor stroke-width preservation, while Crop supplies the scale variation needed for variable-length editing. The style encoder is not given an explicit transformation-type label, and it learns from the mixed perturbation distribution. Together with the disrupted semantics in the source and the separate text condition, this prevents simple content copying, as further supported by the None ablation described above. These mechanisms do not eliminate every failure case, but explain why the combined operator is more robust than either component alone. 

## 8 Responsible Research Notes 

Broader impacts and safeguards. TextRIRO can support benign applications such as visual content localization, accessibility, and realistic STR data generation, but scene text editing can also be misused to falsify text in images. We therefore intend to release code, data-construction scripts, and TextRIRO-3M with clear research-use and acceptable-use notices, retain STR-based quality filtering, and encourage provenance tracking or watermarking when the technology is deployed. 

Existing assets and licenses. The work uses publicly available academic datasets, model components, and baselines, all cited in the main paper and bibliography. Users of released artifacts will be instructed to follow the original licenses and terms for Union14M, U14M-Filter, ScenePair, the STR benchmarks, Stable Diffusion components, and compared open-source STE models.
