## 摘要
实时视频生成、交互式世界模型和设备端图像合成几乎已成为现实。扩散Transformer（DiT）能够实现出色的样本质量，使瓶颈转移到模型本身的吞吐量上。自然图像本质上具有稀疏性，因为图像的大部分区域通常是背景，对场景内容贡献很小，且易于去噪。DiT未能利用这种稀疏性，因为它们以静态且统一的方式处理图像token。我们提出MoDDiT，一种简单的架构修改，学习在MLP和自注意力操作中对token进行路由。通过独立地在两个模块中路由token，MoDDiT允许MLP中的动态计算分配随token、图像和去噪时间步而变化。使用MoDDiT从头训练图像生成模型，可显著降低训练和推理的计算成本，仅处理少至12.5%的token。通过提高稀疏性和模型深度，MoDDiT降低了成本，并相较于未路由的基线提升了生成性能。学习到的分配具有可解释性，揭示了计算如何随视觉内容和噪声水平变化。我们还使用MoDDiT训练视频生成模型，其中分配与运动相关，并将稠密双向视频模型蒸馏为稀疏自回归学生模型。

## Abstract
Real-time video generation, interactive world models, and on-device image synthesis are almost a reality. Diffusion Transformers (DiT) achieve excellent sample quality, shifting the bottleneck to the throughput of the models themselves. Natural images are inherently sparse, as large portions of an image are often background, contribute little to the scene content, and are easy to denoise. DiTs fail to exploit this sparsity, as they process image tokens statically and uniformly. We propose MoDDiT, a simple architecture modification that learns to route tokens through both MLP and self-attention operations. By routing tokens through both blocks independently, MoDDiT allows for dynamic compute allocation in MLPs that varies across tokens, images, and denoising timesteps. Using MoDDiT to train image generation models from scratch significantly reduces computational costs of training and inference, processing as few as 12.5% of the tokens. By increasing sparsity and model depth, MoDDiT reduces costs and improves generation performance over unrouted baselines. The learned allocation is interpretable, revealing how computation varies with visual content and noise level. We also use MoDDiT to train video generation models, where allocation correlates with motion, and to distill a dense bidirectional video model into a sparse autoregressive student.

## 1. 核心问题与研究动机

- **背景**：扩散 Transformer（DiT）已成为图像/视频生成的主流架构，样本质量优异，瓶颈从“质量”转向“吞吐/延迟”。实时视频生成、交互式世界模型、端侧图像合成对推理成本极为敏感。
- **核心观察**：自然图像与视频本质上是**信息稀疏**的——大片背景、静态物体对场景内容贡献小、去噪容易（视频中静止 patch 甚至可直接从上一帧复制）。
- **问题**：DiT 对**所有 token 静态、均匀地**施加全部自注意力与 MLP 计算，完全不利用这种稀疏性，导致算力被浪费在“简单”区域。
- **已有方法的不足**：
  - TREAD 只在训练期随机绕过 token，推理仍稠密；
  - DyDiT / DyDiT++ 依赖辅助损失控制 FLOPs，且训练时需全量自注意力（稀疏仅用于推理）；
  - DiffMoE / Expert Race 需额外的容量预测器或多专家分支；
  - 多数方法难以在保持张量形状的同时做**逐样本**可变容量，导致 ragged batch、GPU 并行效率低。
- **目标**：一种**极简的架构改动**，让 token 在 MLP 与自注意力中**独立路由**，从而在训练与推理**两侧**都真实降低 FLOPs，无需辅助路由损失、无需后处理、无需 ragged batch。

## 2. 方法论

### 2.1 核心思想
- 在每个 Transformer 块前加一个**微型路由器**（两层 MLP），对每个 token 独立打分，用 top-K 选择决定该 token 是否“经过”该块；未被选中的 token 通过残差**旁路**（bypass）保留原值。
- **自注意力与 MLP 使用各自独立的路由器**：注意力路由为**固定容量**（每样本 K 个），MLP 路由允许**动态、跨样本的容量分配**。

### 2.2 路由机制细节
- 路由器 $R_\phi$ 对 token $t_i$ 输出标量 logit；训练时用 **Gumbel top-K** 引入探索：
  $\tilde r_i = R_\phi(t_i) + \tau g_i,\quad g_i \sim \text{Gumbel}(0,1)$
  对温度 $\tau$ 退火（ImageNet 上按余弦从 5 衰减到 0），早期鼓励探索、后期趋于确定性 top-K。
- 路由器同时充当**门控**，被选中 token 的块输出乘以 $r_i = \sigma(R_\phi(t_i))$ 后再做残差相加；这样路由器可直接从任务损失获得梯度（类似 MoE 的 gating）。
- 路由器最后一层初始化为 0，使初始门控恒为 0.5，训练稳定。

### 2.3 MLP 的动态分配（关键设计）
- **训练时**：把 batch 维与 token 维**合并**，在单卡上选全局 top-$(B\cdot K)$。由于同 batch 内样本属于不同类别、不同扩散步，模型自然学会**按类别与噪声水平**分配算力。
- **推理时**（通常 $B=1$）：若仍取 top-$(1\cdot K)$ 会丢失上述动态性并造成分布偏移。因此改为**跟踪一个 logit 阈值** $T$，使 $p(R_\phi(t_i)\ge T)=c$（$c=K/N$ 为目标容量），并用
  $T \leftarrow T + \alpha(\hat r - c)$
  在线更新（$\hat r$ 为干净分数超过阈值的 token 比例）。这与 Expert Race 的“对 top-K 截断值取平均”不同。
- 由于只是 gather/scatter + 固定形状张量，**不需要 ragged batch**，可在多 GPU 上高效并行。

### 2.4 自注意力的固定容量路由
- 自注意力矩阵维度由样本内 token 数决定，同 batch 内必须等长才能向量化，故**每样本固定选 K 个** token。
- 设计空间：可分别路由 query（输出）与 key/value（上下文）。作者试验了四种方案（仅输出门控、共享 value/output 门控、双路由器、稀疏 Q + 稠密 KV），发现**没有一致最优**，最终选最简单的“仅输出门控”（$RAV$）。
- 额外引入 **16 个 register token**（Darcet et al., 2023），帮助吸收 attention sink、使分配掩码与语义区域对齐，序列长度 272。

### 2.5 与 FLOPs 对齐的架构构造
- 将 DiT 的**交替块替换为两个 MoDDiT 块**，使 50% 容量模型与同配置 DiT 的 FLOPs 大致相当（实测 +2.8%），从而做“等算力”公平比较。

## 6. 主要结论与发现

- **图像（ImageNet, 512 步）**：50% MoDDiT 在算力持平（170.3 vs 165.4 TFLOPs/image）下全面优于 DiT：FID 4.390 vs 5.069、IS 233.1 vs 208.9、Recall 0.505 vs 0.488；25% 档在 **−21.7% FLOPs** 下仍有更好 FID/sFID/IS；12.5% 档在 **−33.7% FLOPs** 下与 DiT 竞争力相当（FID 5.081 vs 5.069，Recall 更高）。
- **视频（1X）**：12.5% ST-MoDDiT 在 0.5/1/2 秒处 PSNR 提升 **+0.68 / +0.38 / +0.21 dB**，同时 denoiser TFLOPs 降低 **36.92%**（注意参数量反而更大：942.7M vs 651.2M）。
- **蒸馏（Wan2.1 + Self-Forcing）**：Funnel50 / Funnel20 的 VBench 总分仅比稠密基线低 **4.93% / 5.35%**，Transformer FLOPs 降低 **16.88% / 23.98%**（计入共享 text encoder + VAE 后为 12.94% / 18.38%）；损失集中在“多物体”“空间关系”类目，说明稀疏化倾向于把算力集中到图像局部、削弱跨区域关系建模。
- **可解释性**：
  - 分配量随**噪声降低（小 t）而上升**，且不同容量模型间的分配差与 loss 差大致成比例——模型把多出的容量花在低噪声阶段以降低 loss；
  - 分配与**类别 latent 方差**正相关（50% 档 r=0.581, R²=0.338；容量越低相关性越弱，12.5% 档 r=0.411），即高方差、边界复杂的类别获得更多迭代精修；
  - 视频中分配与**帧差（运动幅度）**强正相关，静态区域被大量跳过。
