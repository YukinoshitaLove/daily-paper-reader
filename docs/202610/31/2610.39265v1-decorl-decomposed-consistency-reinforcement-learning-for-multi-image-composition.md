## 摘要
多图像合成（MICo）是大规模图像编辑模型的一项关键但具有挑战性的能力，其中一致性会随着参考图像数量的增加而迅速下降。虽然监督微调（SFT）可以使模型具备基本的 MICo 能力，但它仅对合成图像提供隐式监督，并且往往难以学习多个参考图像之间可靠的物体级对应关系。我们提出 DeCoRL，一个通过将整体 MICo 一致性分解为物体级一致性来提升 MICo 一致性的强化学习（RL）框架。DeCoRL 首先在参考图像之间建立与指令相关的物体对应关系，并定位生成图像中对应的区域。然后，它使用在单物体一致性标注上训练的基于 VLM 的奖励模型来产生细粒度、逐物体的反馈，并将其聚合为多物体一致性奖励以指导 RL 后训练。我们进一步提出 DeCo-Bench，一个涵盖 2 至 6 张参考图像合成的基准。在 DeCo-Bench 和公开的 MICo-Bench 上的实验表明，MICo 一致性得到持续提升。

## Abstract
Multi-image composition (MICo) is a critical yet challenging capability for large-scale image editing models, where consistency degrades rapidly as the number of reference images increases. While supervised fine-tuning (SFT) can equip models with basic MICo ability, it provides only implicit supervision on the composed image and often fails to learn reliable object-level correspondence across multiple references. We propose DeCoRL, a reinforcement-learning (RL) framework that improves MICo consistency by decomposing holistic MICo consistency into object-level consistency. DeCoRL first establishes instruction-relevant object correspondences across reference images and localizes the corresponding regions in the generated image. It then uses a VLM-based reward model trained on single-object consistency annotations to produce fine-grained, object-wise feedback, which is aggregated into a multi-object consistency reward to guide RL post-training. We further introduce DeCo-Bench, a benchmark covering compositions from 2 to 6 reference images. Experiments on DeCo-Bench and the public MICo-Bench demonstrate consistent improvements in MICo consistency.

## 1. 核心问题与研究背景

- **任务定义**：多图像合成（Multi-Image Composition, MICo）要求模型同时接收一条编辑指令与多张参考图像，将多个参考对象联合合成到一张生成图中，并保持各对象的身份、属性与语义绑定。
- **核心痛点**：一致性随参考图数量增加而快速退化。模型需要在“多对一”的模糊对应关系中判断每个生成实体应继承哪张参考图的哪些视觉属性，歧义随输入数量迅速放大。
- **现有方案局限**：主流做法依赖大规模（常为合成）多图编辑数据 + 监督微调（SFT）。SFT 只对最终合成图提供隐式监督，未显式教授跨参考图的物体级对应与绑定，导致参考图增多时出现身份混淆、属性泄漏、对象遗漏。
- **RL 路线的障碍**：RL 后训练依赖可靠奖励，但对 MICo 做“整体打分”本身是病态判断——即使 GPT-4o 等强 VLM 评估器也因跨图注意力有限而不可靠。
- **论文主张**：将难以可靠评估的**整体 MICo 一致性**分解为对“指令相关、可定位物体”的**物体级一致性检查**，并以此作为奖励设计原则，而非绑定某个特定评估器、定位模型或 RL 优化器。

## 2. 方法论

### 2.1 核心思想
- 先建立指令相关物体的跨参考图对应关系，再对每个“参考物体–生成物体”配对独立打分，最后聚合为多物体一致性奖励，驱动扩散模型 RL 后训练。
- 分解是方法论内核；VLM 解析、Grounding DINO 定位、CoT 奖励建模、Diffusion NFT 优化器均属可替换的模块化实现。

### 2.2 流程与关键技术细节

- **阶段一：多图 SFT 初始化**
  - 基座为 Qwen-Image-Edit-2511；因原模型难以稳定支持 3 张以上参考图，先做覆盖 1–6 张参考图的 SFT。
  - 数据：MICo-150K + UniPic 3.0，约 47 万训练样本；另加 Nano-consistent-150K 用于单图编辑。
  - 参考图按“共享总像素预算”等比缩放（先算总面�积 U，缩放因子 f=√(P/U)，P 约 1024²），控制视觉 token 总量。
  - 训练目标为 flow matching：对目标 latent 加噪构造 z_t=(1−t)z_tgt+tε，模型以参考 latent、时间步、指令为条件预测速度场，损失为预测速度与真值速度（ε−z_tgt）的 L2 误差；时间步从 logit-normal 分布采样。

- **阶段二：单物体一致性奖励模型**
  - 以 Qwen3-VL-32B 为骨干，在 PaCO-RL-Dataset 上用 LoRA 微调，采用**带思维链（CoT）的标注**（解释 + yes/no 判定），以避免仅 yes/no 监督的低熵捷径过拟合。
  - 推理时解码若干步，找到首个最高 logit 为 yes 或 no 的位置，用 sigmoid(ℓ_yes − ℓ_no) 作为 [0,1] 连续分数；若未出现则记 0。

- **阶段三：指令相关物体对应构建**
  - 用 VLM 联合理解指令与全部参考图，识别指令显式要求的对象，并为每张参考图中的每个实例赋予开放词表标签，形成标注物体集合 O={(i, j, label_ij)}。
  - 对每个标签在对应参考图上运行 Grounding DINO，保留 top-1 检测框（经阈值与 NMS 后处理），裁剪得到参考物体 crop。
  - 该步骤把“整体 MICo”转化为一组已对齐的物体实例，并排除背景与无关实体的干扰。

- **阶段四：多物体一致性奖励**
  - 对每个标签在生成图上同样用 Grounding DINO 取 top-1 框并裁剪，得到生成 crop。
  - 将参考 crop 与生成 crop 等比缩放后送入单物体奖励模型得到 s_obj；若参考中存在但生成图中未检测到该物体，则该物体奖励置 0，显式惩罚漏生成。
  - 聚合为均值 S = (1/N)Σ s_ij，N 为有效参考物体数。作者明确说明均值聚合本身不保证各物体均衡提升。

- **阶段五：Diffusion NFT 后训练**
  - 同一指令下采样 K 个样本，按组内均值/方差归一化并裁剪得到 [0,1] 权重 r_k（式 12），构造正向/负向速度 v⁺、v⁻，损失为加权组合（式 13）；再加入对参考模型的速度正则（式 14），总目标 L=λ_NFT·L_NFT+λ_Reg·L_Reg。
  - 为缓解 reward hacking，额外引入通用 VLM 奖励（Qwen3.5-122B-10A），惩罚不自然输出、结构畸变与合成伪影，并抑制局部 crop 评分看不到的全局不合理物体–主体交互。
  - 超参：LoRA r=32，λ_NFT=1，λ_Reg=1e−4，β=1，组大小 16，每样本 8 个 prompt。

## 3. 实验设计

- **自建基准 DeCo-Bench**：覆盖 2/3/4/5/6 张参考图，每档 40 例，共 200 例，参考图均为真实照片。评测时裁剪指令相关物体，用 Gemini-3.1-Pro 对“参考 crop–生成 crop”逐对打分（0–10），样本分为物体级分数均值，再按参考图数量与总体聚合。评测 prompt 明确要求只关注目标实体、比较大色块与类别相关核心特征（生物看身份特征，非生物看形状/结构/材质/图案），并排除视角与光照干扰。
- **公开基准 MICo-Bench**：四个任务——Object Centric（138）、Human Centric（168）、HOI（291）、De&Re（300）；总分为 W×SC×PQ，其中 W 为源图保留比例（人脸用 ArcFace 余弦相似度、非人脸用 VLM 校验），SC=√(PF×SR)，PQ=√(Naturalness×Artifacts)。
- **对比方法**：
  - 开源：Qwen-Image-Edit-MICo、Qwen-Image-Edit-UniPic3.0、FLUX.2-dev；
  - 闭源：Seedream4.0 (2K)、Nano-Banana-Pro（MICo-Bench 另含 Nano-Banana）；
  - 自身基线：Qwen-Image-Edit2511、+SFT、+DeCoRL。
- **消融与诊断**：
  - 单物体奖励模型消融：vanilla VLM 奖励 vs. CoT 训练奖励（DeCo-Bench 全档 + 训练动态曲线：多物体分数与 banned prompt 数）；
  - MICo-Bench 四指标（PF/SR/Naturalness/Artifacts）逐项对比；
  - 奖励评估器独立验证：EditReward-Bench 上与人类标签的一致率；
  - Grounding 诊断：1 万训练样本上 VLM 校验标签–crop 匹配率（94.6%）；
  - 最优/最差物体奖励随 checkpoint 的变化曲线；
  - 附录提供大量定性可视化（DeCo-Bench 与 MICo-Bench 各任务）。

## 4. 资源与算力

- **SFT**：32×H800，总 batch size 128，训练 24,000 步；AdamW（β1=0.9，β2=0.999，ε=1e−8，weight decay 1e−2），学习率 2e−5。
- **RL 后训练**：32×H800，LoRA r=32，组大小 16，每样本 8 prompt；AdamW（ε=1e−10，weight decay 1e−4），学习率 3e−4。
- **单物体奖励模型**：8×H800，LoRA rank 32，学习率 1e−4，训练 2,200 步。
- 另需调用 Grounding DINO、Qwen3-VL-32B、Qwen3.5-122B-10A 等大模型做在线奖励计算，但论文未给出这部分推理开销的量化（GPU 时/单样本成本）。

## 5. 实验数量与充分性

- **规模**：两个基准（200 例 + 897 例）、约 8 个对比系统、3 组主要消融（奖励模型、MICo-Bench 四指标、vanilla vs trained reward）、2 项诊断（EditReward-Bench、Grounding 匹配率）、2 条训练动态曲线，另加大量定性图。
- **充分之处**：
  - 覆盖 2–6 张参考图的难度梯度，能体现“随参考数增加收益更明显”的趋势；
  - 同时在自建基准与独立开发的公开基准上验证，缓解“只在自己的指标上有效”的质疑；
  - 加入奖励评估器的独立人类一致性验证（0.721 vs vanilla 0.354，且高于 GPT-4.1 的 0.602、GPT-5 的 0.669）；
  - 报告 PF 略降（8.76→8.69），主动说明不是单一指标被过度优化。
- **不够充分之处**：
  - 缺少“整体奖励 vs 物体级奖励”在**同等 RL 训练条件下**的受控对照，这是论文核心论点的最直接证据，作者也承认这是未来工作；
  - 未报告与 Flow-GRPO 等其他 RL 优化器的匹配训练比较（仅称早期探索资源开销更大、更敏感）；
  - 未做均值聚合与其他聚合方式（如最小值、加权、自适应）的对比；
  - 主实验仅一个编辑骨干（Qwen-Image-Edit-2511），未验证跨骨干泛化；
  - DeCo-Bench 每档仅 40 例，规模偏小，且与训练奖励同源（in-domain），存在指标–奖励对齐偏差；
  - 缺少人工主观评测与置信区间/显著性检验。

## 6. 主要结论与发现

- **一致性随参考图增多而退化**是普遍现象，闭源强模型（Seedream4.0、Nano-Banana-Pro）在 5–6 图复杂场景同样出现物体外观不一致。
- **DeCo-Bench**：baseline 6.22 → +SFT 7.05 → +DeCoRL **8.16**；超过全部开源基线（MICo 5.17、UniPic 6.02、FLUX.2-dev 7.10）与 Seedream4.0 (2K)（7.76），仍低于 Nano-Banana-Pro（8.69）但差距缩小；6 图档提升最显著（6.15→7.61）。
- **MICo-Bench**：22.90 → 37.58（+SFT）→ **54.03**（+DeCoRL），超过 Nano-Banana-Pro 的 51.76；Human Centric（30.49→56.21）与 De&Re（45.50→64.42）提升最大。
- **指标分解**：SR 7.01→7.64、Naturalness 6.54→8.01、Artifacts 5.76→6.64 均提升，PF 基本持平略降，说明改进并非单指标 reward hacking。
- **奖励质量决定 RL 效果**：vanilla VLM 奖励仅 7.05→7.21，CoT 训练后达 8.16；训练中多物体分数由 <0.5 提升到 >0.6 并持续上升，banned prompt 数从 0 开始增长，说明奖励信号被稳定学习。
- **最差物体也改善**：worst-case 物体奖励 0.3012→0.7423，best-case 0.6712→0.8412，说明收益不只来自最容易的物体（但不证明均值聚合最优）。
- **总体结论**：分解式物体级奖励是可扩展的 MICo RL 后训练与评测方案。

## 7. 优点

- **奖励设计有清晰的方法论主张**：把“不可靠的整体判断”转为“可定位、可逐项核验的局部判断”，并显式惩罚漏生成物体，逻辑自洽且易解释。
- **模块化、可替换**：明确区分“分解原则”与“VLM/Grounding DINO/Diffusion NFT 的具体选型”，便于后续替换评估器或优化器。
- **工程细节扎实**：参考图共享像素预算缩放、CoT 监督避免低熵捷径、token 级 yes/no 概率作为连续奖励、组内归一化 + 参考正则 + 辅助 VLM 奖励抑制 reward hacking。
- **评测设计较严谨**：DeCo-Bench 的评测 prompt 明确“只评目标实体、比较大色块、区分生物/非生物特征、排除视角与光照干扰”，降低评估噪声；MICo-Bench 采用单参考对比以避免跨图注意力过载。
- **诚实报告负面/中性结果**：PF 略降、Nano-Banana-Pro 仍领先、均值聚合不保证均衡、Grounding 指标仅为诊断代理等均主动说明。
- **诊断实验有说服力**：奖励模型在 EditReward-Bench 上显著优于未调版本并超过通用强模型；best/worst-case 曲线回应了“只优化简单物体”的质疑。

## 8. 不足与局限

- **奖励–指标同源偏差**：DeCo-Bench 针对可定位物体级一致性设计，与训练奖励同构，属 in-domain 评测；虽有 MICo-Bench 补充，但仍缺系统的评估器偏差研究。
- **覆盖范围有限**：仅支持最多 6 张参考图，超出范围可靠性未验证；只覆盖可定位物体的身份与外观，难以刻画抽象风格、空间关系、交互与绑定约束。
- **依赖链脆弱**：效果依赖 VLM 解析、Grounding DINO 定位与同类别实例匹配的准确性；crop 无法完整表达物体上下文，匹配失败会直接污染奖励。
- **奖励黑客与评估偏差风险**：VLM 评分可能被利用；辅助通用 VLM 奖励只是缓解手段，未量化其贡献。
- **缺少关键受控实验**：无“整体奖励 vs 物体级奖励”匹配训练对照；无不同聚合策略对比；无跨骨干/跨优化器验证；无与 GRPO 类方法的公平比较。
- **统计与规模**：DeCo-Bench 每档 40 例，样本量偏小；未报告方差、置信区间或显著性检验；缺少人类主观评测。

- **成本与可复现性**：在线奖励链路需同时调用 VLM 解析、Grounding DINO 定位、单物体奖励模型与辅助通用 VLM 奖励；RL 阶段每个 prompt 采样 8 个样本、组大小 16，并需 32×H800，整体训练与推理开销显著高于普通 SFT。论文未给出端到端 GPU 时、单样本奖励成本、Grounding 推理延迟与失败重试成本的量化，也未讨论缓存参考图解析、离线预计算标签、降低采样数等降本方案对效果的影响，因此复现与部署成本仍不够透明。

## 9. 总体评价与启示

- **贡献定位**：论文的核心贡献不是提出新的扩散模型结构，而是把 MICo 的 RL 奖励从“整体评分”重构为“指令相关物体的跨图配对评分”，并给出可运行的模块化实现。这一奖励设计原则比具体选型更具迁移价值。
- **证据链强度**：实验在“奖励模型质量—训练动态—多基准指标—定性可视化”上形成了较连贯的证据链，且同时报告自建基准与公开基准，增强了结论可信度。但最关键的“整体奖励 vs 物体级奖励”同条件受控对照缺失，使因果归因仍留有余地；更稳妥的表述应是“物体级分解在当前实现下显著优于弱整体奖励，并在多图场景带来稳定增益”，而非“整体奖励路线不可行”。
- **方法启示**：对多参考图生成任务，奖励设计应优先解决“对应关系”而非仅提高评分模型容量；将模糊的多对一判断拆成可定位、可逐项核验的局部判断，是降低评估歧义的有效路径。同时，显式惩罚漏生成物体、加入通用质量奖励与参考正则，说明奖励工程需要与 reward hacking 防护同步设计。
- **适用边界**：该方法更适合参考图数量较多、目标对象可被开放词表检测、身份与外观一致性优先的合成编辑场景；对抽象风格迁移、复杂空间关系、物体间交互、不可定位属性以及超过 6 张参考图的情形，现有证据不足，需谨慎外推。
- **后续研究方向**：优先补做匹配算力与训练步数下的奖励粒度对照；比较均值、最小值、加权与自适应聚合策略；研究 Grounding/VLM 解析误差向奖励传播的鲁棒性；将分解对象从实体一致性扩展到关系、风格与空间约束；并在更多编辑骨干与 RL 优化器上验证泛化性。
- **实践建议**：若用于工程落地，应把参考图解析与标签生成尽量离线化、缓存化，并对 Grounding 失败、标签–crop 不匹配和奖励异常值设置回退策略；评测上应补充人工主观评测、置信区间与显著性检验，避免仅依赖与训练奖励同源的自动指标。
