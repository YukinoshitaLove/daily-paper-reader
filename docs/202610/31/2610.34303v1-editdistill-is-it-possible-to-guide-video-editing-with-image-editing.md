## 摘要
近年来图像编辑的进展使得细粒度且高度可控的视觉修改成为可能。然而，在视频编辑中实现同等程度的可控性仍是一个开放挑战，尤其是在精确局部编辑、动态时序效果以及跨帧一致光照方面。本文提出 EditDistill，一个从图像编辑中蒸馏图像级视觉变换以指导视频编辑的框架。具体而言，给定源视频和编辑提示，我们首先使用现成的图像编辑模型生成初始视频帧的编辑版本。随后，我们将该原始图像-编辑图像对的视觉变换蒸馏为一个紧凑表示，称为编辑描述符。该描述符通过我们的轻量融合模块注入视频扩散模型，从而引导去噪过程朝向期望的编辑。为使视频轨迹与所展示的图像编辑对齐，同时保持运动和布局，我们采用编辑描述符对齐损失和 DINO 结构一致性损失进行训练，并在流匹配下推导出等价的推理时引导公式。大量实验表明，我们的方法在标准基准上取得了强劲性能，并在多种场景下生成高质量的视频编辑结果。更多细节和视频请参见匿名网页：https://yu-shaonian.github.io/EditDistill-Web/。

## Abstract
Recent advances in image editing have enabled fine-grained and highly controllable visual modifications. However, achieving similar levels of controllability in video editing remains an open challenge, particularly for precise local edits, dynamic temporal effects, and consistent lighting across frames.In this paper, we propose EditDistill, a framework that distills image-level visual transformations from edits to guide video editing.Specifically, given a source video and an edit prompt, we first generate an edited version of the initial video frame using an off-the-shelf image editing model. We then distill the visual transformation of this original-edited image pair into a compact representation termed an edit descriptor.This descriptor is injected into a video diffusion model through our lightweight fusion module, which steers the denoising process toward the desired edit. To align the video trajectory with the demonstrated image edit while preserving motion and layout, we train with edit-descriptor alignment and DINO structural consistency losses, and derive an equivalent inference-time guidance formulation under flow matching.Extensive experiments demonstrate that our method achieves strong performance on standard benchmarks and produces high-quality video editing results across diverse scenarios.   - 前景与背景难以**联合一致地编辑**，逐帧编辑方法（如 I2VEdit）忽略去噪过程的对齐，导致闪烁、编辑衰减或污染邻近区域。
- **核心洞察与假设**：这类复杂编辑在**图像域**已容易实现；单张编辑参考帧可编码编辑意图（包括动态效果的视觉签名），而时序展开交由视频扩散先验完成。
- **研究问题**：能否把现代图像编辑模型的可控性**蒸馏**出来，用于引导细粒度且时序一致的视频编辑？论文给出肯定回答。

## 2. 方法论

### 2.1 总体框架：两阶段因子分解

- 将问题分解为 `d = E_φ(E(I_s, I_e))` 与 `V_e = G_θ(V_s, p, d)`：
  - **Stage I** 回答“应该施加什么视觉变化”，把图像对的变换压缩为 1024 维**编辑描述符** d；
  - **Stage II** 回答“变化应在每帧何处、如何呈现”，把 d 注入冻结的视频扩散模型。
- 解耦设计的价值：编辑提取与时间渲染分离，只需训练轻量注入模块。

### 2.2 Stage I：Delta VAE 描述符蒸馏

- 用**冻结 Wan VAE** 编码源图与编辑图得 `z_s, z_e`；二者经共享 CGS stem（卷积+GroupNorm+SiLU）得 `f_s, f_e`，并显式构造特征差 `Δf = f_e − f_s`，拼接 `[f_s, f_e, Δf]` 后送入编码器。
- **多尺度编码**：3 个尺度，每尺度含 2 个残差块 + Transformer 块 + 下采样，末端 4 个 Transformer 块 + 自适应平均池化 + MLP，预测对角高斯后验 `q_φ(d|z_s,z_e)=N(μ_φ, diag(σ²_φ))`，训练时重参数采样，推理取均值。
- **非对称解码**：解码器只看 `z_s` 与 `d`，以残差形式重建 `ẑ_e = z_s + D_ψ(z_s, d)`；通过 FSCG 层做 FiLM 调制、自注意力保源结构、交叉注意力路由描述符；**编辑目标从不经 skip connection 泄漏**，迫使信息通过紧凑描述符传递。
- **损失**：`L_Distill = λ1‖ẑ_e−z_e‖₁ + λ2‖ẑ_e−z_e‖₂² + λ_kl KL(q_φ‖N(0,I))`。
- **语义结论**：d 不是目标图像也不是固定 mask，而是“变换算子”；注意力可视化显示局部编辑集中于变化区域，全局编辑（重打光、风格化）响应更广但有结构。

### 2.3 Stage II：描述符引导的视频扩散

- 基座为 **Wan2.1-I2V-14B**（Flow Matching），**骨干完全冻结**，仅训练注入模块（约 480MB，<4% 参数）。
- **注入模块**：先经共享 MLP stem `d̄ = MLP(LN(d)) + d`，再经三个互补分支：
  - **交叉注意力**：`h + CrossAttn(Q(h), K(d̄), V(d̄))`，按 token 决定“在哪里改”，适配局部编辑并具备逐帧重定位能力；
  - **FiLM**：`γ(d̄)⊙h + β(d̄)`，γ 初始化为 1、β 为 0，适配全局外观/光照/风格；
  - **加性低秩残差**：`h + W_up σ(W_down[h; d̄])`，提供低秩编辑偏置；
  - **零初始化门控融合** `h_out = h + tanh(ξ)·Σ(...)`，ξ 初始为 0，训练起点与原始骨干逐位一致，训练中逐渐打开。
  - 默认每 3 个 Transformer 块插入一次。
- **训练目标**：
  - 流匹配损失 `L_FM = E‖v_Θ(x_t,t,c,d) − (ε−x_0)‖²`，一步干净估计 `x̂_0 = x_t − t·v_Θ`；
  - 编辑对齐损失 `L_edit = (1/N)Σ‖E_φ(x̂_0,n, x̂^C_0,n) − d‖²`（与无描述符条件的参考预测比较，强制每帧诱导的特征位移等于 d）；
  - DINO 结构一致性 `L_DINO = (1/N)Σ‖Ψ(x̂_0,n) − Ψ(v^s_n)‖²`（DINO 对语义结构敏感、对局部外观不敏感，故能惩罚结构漂移而不压制编辑）；
  - 总目标 `L = L_FM + α_edit·L_edit + α_DINO·L_DINO`（α_edit=0.5，α_DINO=0.2）。
- **推理时引导**：由 score–velocity 恒等式 `∇_{x_t} log p_t(x_t) = −v_θ/t`，可将两辅助目标写成梯度引导 `v_edit = v_θ − t(α_edit∇L_edit + α_DINO∇L_DINO)`，实现“训练期条件化 + 免调优测试期控制”的统一公式（附录给出算法：每步计算一步干净预测、算损失、梯度裁剪后修正速度）。
