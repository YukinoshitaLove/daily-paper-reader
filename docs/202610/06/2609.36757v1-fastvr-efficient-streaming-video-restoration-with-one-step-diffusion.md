## 摘要
基于扩散的视频复原能够恢复逼真的细节，但其实际部署受限于两个效率瓶颈：昂贵的 VAE 编码和解码，以及扩散 Transformer（DiT）中全自注意力的二次计算成本。本文提出 FastVR，一个构建于一步扩散模型之上的流式视频复原框架，在单块 H20 GPU 上以 11 FPS 处理 1080p 视频的同时，提供出色的复原质量和时序一致性。为提高推理效率，FastVR 将轻量级 VAE 与分块因果注意力相结合，大幅降低了计算成本。在训练阶段，它进一步采用速度一致性正则化和连续轨迹学习，从而提升复原质量。大量实验表明，FastVR 比所评估的扩散基线更高效，同时在合成和真实世界基准上达到最先进性能。我们希望这项工作能够推动社区的进一步发展。

## Abstract
Diffusion-based video restoration recovers realistic details, but its practical deployment is limited by two efficiency bottlenecks: costly VAE encoding and decoding, and the quadratic cost of full self-attention in diffusion transformers (DiTs). This paper presents FastVR, a streaming video restoration framework built on a one-step diffusion model, which delivers strong restoration quality and temporal consistency while processing 1080p video at 11 FPS on a single H20 GPU. To improve inference efficiency, FastVR combines a lightweight VAE with chunk-wise causal attention, which substantially reduces the computational cost. During training, it further adopts velocity consistency regularization and continuous trajectory learning, which improve restoration quality. Extensive experiments show that FastVR is more efficient than the evaluated diffusion baselines while achieving state-of-the-art performance on synthetic and real-world benchmarks. We hope that this work supports further progress in the community.

## 1. 核心问题与研究背景

- **任务定位**：视频复原（Video Restoration）旨在从模糊、噪声、压缩、下采样等退化视频中恢复视觉保真且时序一致的内容，实际部署中要求高分辨率长视频在有限算力/内存下低延迟处理。
- **传统方法局限**：重建类方法（BasicVSR、BasicVSR++）在严重退化下纹理过于平滑；扩散方法虽能生成逼真细节，但带来极高计算开销。
- **两大效率瓶颈**：
  - **VAE 编解码开销**：SeedVR2 报告因果视频 VAE 占 100 帧 720p 视频总运行时间的 95% 以上，DUO-VSR 亦指出 VAE 是一步流程的主要开销。
  - **DiT 全自注意力二次复杂度**：全局注意力成本随 token 数平方增长。
- **一步扩散的遗留问题**：DOVE、SeedVR2、DUO-VSR 等一步方法虽加速显著，但丢弃了扩散的渐进修正机制，端点回归（endpoint regression）易产生过平滑结果。
- **核心研究问题转向**：不再是单纯减少采样步数，而是要在**自编码成本、注意力复杂度、优化稳定性、复原保真度、时序一致性**之间取得端到端平衡。
- **整体含义**：FastVR 提出一个基于一步扩散的流式视频复原框架，在单张 H20 GPU 上以 **11 FPS** 处理 1080p 视频，兼顾质量与效率。

## 2. 方法论

### 2.1 核心思想
- 以 **Wan2.2-TI2V-5B** 为基础，构建一步流式复原模型。
- 针对采样加速后凸显的两大瓶颈：**轻量 VAE** 降低编解码成本；**分块因果注意力（chunk-wise causal attention）** 降低 token 交互成本并支持在线流式处理。
- 用**连续轨迹学习 + 速度一致性正则**替代传统端点回归，提升一步预测的优化稳定性与细节恢复能力。

### 2.2 关键技术细节

**（1）轻量级 VAE**
- 基于 lightweight autoencoding [3] 与条件解码 [28]；编码器将 LQ 帧映射为与预训练 Wan DiT 兼容的隐表示。
- 解码器以 LQ 帧为额外条件重建视频，直接提供结构信息，减轻仅从压缩隐表示重建的负担。
- 与 DiT 分离训练，采用像素级 ℓ1 + LPIPS 感知损失；编解码均支持带缓存特征的增量时序处理，保证流式推理中间内存有界。
- 推理时冻结轻量 VAE；两阶段 DiT 训练使用原始冻结的 Wan VAE 编解码器。

**（2）分块因果注意力**
- 将隐序列划分为不重叠的 k 个时序位置的块，每块仅关注自身与紧邻前一块。
- 时序可见性掩码定义为：当 ⌊i/k⌋ − ⌊j/k⌋ ∈ {0, 1} 时 M_{i,j}=1，否则为 0；在每一自注意力层施加，块内保持双向注意力。
- 训练时整序列并行处理并由掩码约束；推理时按块顺序流式复原，使用 KV 缓存。
- 复杂度收益：时序注意力成本从 O(T²) 降为 **O(Tk)**，KV 缓存大小 **O(k)** 与视频长度无关。

**（3）两阶段隐空间–像素训练**

*Stage I：隐空间轨迹学习*
- 轨迹参数化（t=0 对应 HQ 端点，t=τ 对应 LQ 端点）：
  - z_t = (t/τ)·z_LQ + (1 − t/τ)·z_HQ
  - 对应速度 u_t = ∂z_t/∂σ_t = (z_LQ − z_HQ)/σ_τ
- 轨迹损失：L_traj = E‖v_θ(z_t, t, c_∅) − u_t‖²₂，随机时间步采样使模型接触不同退化程度的中间状态。
- **速度一致性正则**：采样 t′∼U(0,t)，用欧拉更新 ẑ_t′ = sg[z_t + (σ_t′ − σ_t)·v_t]（sg 为停止梯度），并以自蒸馏方式约束：
  - L_vc = E‖v_t − sg[v_θ(ẑ_t′, t′, c_∅)]‖²₂
- Stage I 总目标：**L_I = L_traj + L_vc**。

*Stage II：像素空间细化*
- 从 z_LQ（t=τ）出发，一步更新得 ẑ = z_LQ − σ_τ·v_θ(z_LQ, τ, c_∅)，再由冻结 Wan VAE 解码器重建 x̂ = G_Wan(ẑ)。
- 损失：**L_II = L_ℓ1(x̂, x_HQ) + L_DISTS(x̂, x_HQ)**，梯度穿过冻结解码器回传至 DiT 参数。
- 目的：解决隐空间误差与像素空间保真度非线性不对应的问题，使预测隐表示适配解码器重建特性。

### 2.3 推理流程
- 冻结轻量编码器将 LQ 视频映射为紧凑隐表示 → 一步 Wan DiT（因果注意力，按时间块与空间瓦片）预测复原速度 → 冻结轻量解码器结合 LQ 帧重建输出。
