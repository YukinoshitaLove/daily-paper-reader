## 摘要
结构化图像（如图示、图表和流程图）本质上是符号化的，可以用可编辑格式紧凑表示，但在实践中，它们常被渲染为图像，因而无法进行图形化编辑。这种不匹配给希望将现有图形内容的修改版本整合到新材料中而无需手动重建的研究人员、工程师和设计师带来了重大挑战。在本研究中，我们提出了 Back2Struct，它通过直接从图像表示中恢复矢量图形代码（SVG/XML），“使结构化图像再次可编辑”。给定结构化图形的图像，Back2Struct 预测语义对象级的 SVG/XML 代码，显式编码文本、形状、拓扑和布局，而非执行低层像素矢量化。生成的代码可以无缝导入 PowerPoint 等工具，使用户能够在保持结构保真度的同时编辑、精修、重新样式化和复用图形内容。除了在真实 SVG token 序列上进行监督微调外，我们进一步用基于奖励的学习优化 Back2Struct，以更好地匹配部署时要求：输出应在语法上有效、适当简洁，并在视觉上忠实于输入图示。具体而言，我们设计了一个复合奖励，联合鼓励 SVG/XML 可编译性、与参考代码的长度一致性，以及生成图形与真实图形之间的结构或语义相似性。这些互补信号引导模型生成不仅在训练分布上更接近，而且在实践中更完整、可编辑和可渲染的 SVG。实验表明，Back2Struct 在准确率、可编辑性、有效性和用户对齐方面优于基线。数据集和代码见：pengyu965.github.io/Back2Struct.github.io

## Abstract
Structured images, such as diagrams, charts, and flowcharts, are inherently symbolic and can be compactly represented in an editable format, yet in practice, they are often rendered as images, and therefore not graphically editable. This mismatch presents a significant challenge for researchers, engineers, and designers who wish to incorporate modified versions of existing graphic content into new materials without manually reconstructing it. In this study, we presentBack2Struct, which "makes structured images editable again" by directly recovering vector graphics code (SVG / XML) from image representations. Given an image of a structured graphic, Back2Struct predicts semantically object-level SVG / XML code that explicitly encodes text, shapes, topology, and layout, rather than performing low-level pixel vectorization. The generated code can be seamlessly imported into tools such as PowerPoint, allowing users to edit, refine, restyle, and reuse graphic content while preserving structural fidelity. Beyond supervised fine-tuning on ground-truth SVG token sequences, we further optimize Back2Struct with reward-based learning to better match deployment-time requirements: the output should be syntactically valid, properly concise, and visually faithful to the input diagram. Specifically, we design a composite reward that jointly encourages SVG / XML compilability, length consistency with the reference code, and structural or semantic similarity between the generated and ground-truth graphics. These complementary signals guide the model to produce SVGs that are not only closer to the training distribution, but also more complete, editable, and renderable in practice. Experiments show that Back2Struct improves accuracy, editability, validity, and user alignment over baselines. Dataset and code are available at: pengyu965.github.io/Back2Struct.github.io
