## 摘要
基于指令的图像编辑采用规划器-渲染器流水线：视觉语言模型（VLM）首先将指令转换为编辑计划，然后扩散模型执行该计划。仅使用最终图像奖励训练此类系统效率低下，因为糟糕的编辑结果无法揭示额外优化应更侧重于规划器还是渲染器，即使在规划器主导的情况下，也难以在自由形式的推理轨迹中定位问题。我们提出DARS，一种用于这种两阶段设置中双层信用分配的强化学习框架。在模块间，多计划多渲染的采样估计计划间和计划内的奖励变异性，以进行软模块路由，而采样的平均奖励为自适应课程提供难度估计。在规划器内部，四字段结构化推理输出实现了前缀门控奖励和令牌级优势重加权，将结果级反馈转化为局部监督。在五个基准上的实验表明，DARS优于具有相同主干、数据、奖励模型和采样预算的联合强化学习基线，在推理密集型编辑上提升最大。

## Abstract
Instruction-based image editing uses a planner-renderer pipeline: a vision-language model (VLM) first converts the instruction into an edit plan, and a diffusion model then executes that plan. Training such systems with only final-image rewards is inefficient because a poor edit does not reveal whether additional optimization should place more emphasis on the planner or the renderer, and even planner-dominant cases remain difficult to localize within a free-form reasoning trace. We present DARS, a reinforcement learning framework for dual-level credit assignment in this two-stage setting. Across modules, multi-plan multi-render rollouts estimate between-plan and within-plan reward variability for soft module routing, while rollout mean rewards provide hardness estimates for an adaptive curriculum. Within the planner, a four-field structured reasoning output enables a prefix-gated reward and token-level advantage reweighting, turning outcome-level feedback into localized supervision. Experiments on five benchmarks show that DARS outperforms a Joint~RL baseline with the same backbone, data, reward model, and rollout budget, with the largest gains on reasoning-intensive edits.

## 1. 核心问题与研究动机

- **任务背景**：指令图像编辑采用“规划器-渲染器”两阶段流水线：
  - **规划器（Planner）**：视觉语言模型（VLM）将用户指令解析为结构化的编辑计划；
  - **渲染器（Renderer）**：扩散模型根据编辑计划生成编辑后的图像。
- **核心痛点**：
  - 仅用最终图像奖励训练两阶段系统时，优化信号非常稀疏且模糊；
  - 一旦编辑效果不佳，系统无法判断问题出在**规划环节**（计划不合理）还是**渲染环节**（执行不到位）；
  - 即便问题出在规划器，也难以在**自由形式的推理轨迹**中定位具体错误步骤，导致“结果级反馈”难以转化为“局部优化信号”。
- **研究意义**：如何为两阶段生成系统设计更高效的**信用分配（credit assignment）**机制，使其在有限采样预算下获得更好的训练效果，是该论文要解决的核心问题。

## 2. 方法论：DARS 框架

### 核心思想
DARS 提出**双级信用分配**框架，分别在“模块间”和“规划器内部”两个层面进行奖励归因：

- **跨模块层面**：区分错误来源是规划器还是渲染器；
- **规划器内部层面**：在推理轨迹中定位具体出错位置。

### 关键技术细节

#### 2.1 模块间信用分配：多计划多渲染 Rollout
- 对同一输入指令，同时采样**多个编辑计划**，并对每个计划执行**多次渲染**；
- 通过估计**计划间奖励变异性**与**计划内奖励变异性**，判断当前样本的主要瓶颈：
  - 计划间变异性大 → 规划器是主要制约因素；
  - 计划内变异性大 → 渲染器不确定性主导；
- 利用该信息进行**软模块路由（soft module routing）**，即动态决定当前训练步骤中更应该优化规划器还是渲染器，避免盲目均匀优化。

#### 2.2 自适应课程学习
- 每次 rollout 的平均奖励可视为当前样本的**难度估计**；
- 以此构建**自适应课程（adaptive curriculum）**，让训练从简单样本逐步过渡到困难样本，提高训练稳定性与效率。

#### 2.3 规划器内部信用分配：结构化推理
- 规划器不再生成自由形式的推理文本，而是输出**四字段结构化推理**（four-field structured reasoning），将计划拆解为明确语义字段；
- 利用该结构实现：
  - **前缀门控奖励（prefix-gated reward）**：根据推理前缀的完整性/正确性调整最终奖励的分配；
  - **Token 级优势重加权（token-level advantage reweighting）**：将结果级奖励转化为每个 token 的局部监督信号，使规划器知道“哪一步思考导致了最终失败/成功”。

### 算法流程概述
1. 采样：对每个指令生成多个计划，每个计划多次渲染；
2. 计算各计划内/计划间的奖励分布，估计变异来源；
3. 根据变异性进行软路由，决定优化权重；
4. 在规划器内部，利用四字段结构化输出，逐 token 分配优势值；
5. 同时以平均奖励构建课程难度，进行自适应训练。
