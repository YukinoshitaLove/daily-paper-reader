## 摘要
超高清（UHD）图像恢复必须在空间重复退化线索的聚合与局部图像结构的保持之间取得平衡。紧凑聚合可以减少冗余处理，但可能削弱边缘、纹理及其他精细结构。现有方法通过下采样、窗口划分或基于聚类的令牌缩减来管理UHD恢复成本；然而，其中许多方法并未明确保留那些难以由共享聚合表征的信息。在本研究中，我们提出了一种用于UHD恢复的上下文-细节解耦状态空间模型（CoDe-SSM），该模型在分离的路径中处理聚合上下文和聚类残差。由全局聚类扫描模块（GCSM）实现的上下文建模路径将特征聚合为$K$个依赖于输入的聚类中心，并对生成的固定顺序序列应用选择性SSM推理，从而在将计算成本与空间分辨率解耦的同时，实现跨区域上下文共享。由局部高频模块（LHFM）实现的细节恢复路径利用输入推导的高频掩码和稀疏混合卷积专家处理聚类残差。在五个UHD基准和五种退化类型上的大量实验表明，我们显式的上下文-细节解耦策略在保持理想效率的同时，显著提升了恢复质量。

## Abstract
Ultra-high-definition (UHD) image restoration must balance the aggregation of spatially recurring degradation cues with the preservation of localized image structures. Compact aggregation can reduce redundant processing but may attenuate edges, textures, and other fine structures. Existing approaches manage UHD restoration cost through downsampling, window partitioning, or cluster-based token reduction; yet many of them do not explicitly retain information that is poorly represented by shared aggregation. In this study, we propose a Context-Detail Decoupled State Space Model (CoDe-SSM) for UHD restoration, which processes aggregated context and clustering residuals in separate pathways. The context modeling pathway, implemented by the Global Cluster Scan Module (GCSM), aggregates features into $K$ input-dependent cluster centers and applies selective SSM reasoning over the resulting fixed-order sequence, enabling cross-region context sharing while decoupling computational cost from spatial resolution. The detail recovery pathway, implemented by the Local High-Frequency Module (LHFM), processes the clustering residual with an input-derived high-frequency mask and a sparse mixture of convolutional experts. Extensive experiments on five UHD benchmarks and five degradation types demonstrate that our explicit context-detail decoupling strategy yields substantial gains in restoration quality while maintaining desirable efficiency.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：超高清（UHD，3840×2160）图像分辨率极高，修复时必须同时处理全局退化和局部细节。全局退化（如均匀雾气、全局模糊）具有跨区域规律性，逐像素独立建模是冗余的；而局部结构（边缘、纹理）对压缩敏感，容易在聚合过程中被削弱。
- **现有方法不足**：主流 UHD 修复方法（下采样、窗口划分、聚类令牌缩减）仅从计算成本角度出发，对特征进行均匀压缩，并未显式区分“可共享退化上下文”与“不可共享的局部细节”，导致高频细节丢失。例如 UHDFour、UHDformer、C²SSM 等均属此类。
- **核心思想**：提出“上下文-细节解耦”原则：将可共享的退化上下文与不共享的结构细节分离到两条通路中处理，分别进行聚合和精细恢复。
- **整体含义**：CoDe-SSM 通过显式解耦策略，在控制计算成本的同时保全高质量细节，为 UHD 修复提供了一种新的信息处理范式。

## 2. 方法论：核心思想、关键技术细节与流程

- **总体架构**：采用不对称 U-Net，输入经过 3×3 卷积投影，编码器包含 3 个下采样阶段（通道数 32→64→128），解码器通过像素重排上采样，跳跃连接。每个 U-Net 层级部署多个 CoDeBlock，最终使用可学习残差门控输出 `X + σ(α)·f_θ(X)`。
- **原型软聚类（Prototype Clustering）**：
  - 对输入特征分支计算数值特征 `v_i`，并引入 K 个可学习原型锚点 `p_k`。
  - 经 L2 归一化后，通过带温度 τ 的 softmax 计算软分配矩阵 `A_ik`。
  - 由分配矩阵加权求和得到输入相关的聚类中心 `m_k`。
  - 利用聚类中心重构 `v_i`（`v̂_i = Σ A_ik m_k`），并得到聚类残差 `R_i = v_i - v̂_i`。
  - 该步骤将特征分离为三个输出：紧凑聚类中心、软分配矩阵、聚类残差。
- **上下文路径 GCSM（Global Cluster Scan Module）**：
  - 将 K 个聚类中心（K ≪ N）视为固定长度的序列，应用选择性 SSM 进行跨区域推理：`{m'_k} = SSM({m_k})`。
  - 修改后的聚类中心通过软分配矩阵映射回像素空间：`F_global,i = Σ A_ik m'_k`。
  - 该过程实现全局上下文共享，同时计算复杂度与空间分辨率解耦（取决于 K 而非 N）。
- **细节路径 LHFM（Local High-Frequency Module）**：
  - 针对聚类残差 R，利用输入图像推导的高频能量（HFE）掩码进行门控。HFE 使用固定的拉普拉斯和 Sobel 算子计算单通道灰度图的高频能量图 `E_hf`，经归一化后通过 sigmoid 生成掩码 `M = σ(β(E_hf−1))`，抑制平缓区域伪影，保留真实高频信息。
  - 将门控后的残差送入稀疏混合专家（MoE）模块：包含 4 个可分离卷积专家（3×3、膨胀 3×3、十字形 1×5/5×1、密集 5×5），每个 token 经路由器选择 Top-2 专家，加权融合后经通道注意力调制输出 `F_local`。
  - 还施加负载均衡损失 `L_bal` 防止专家崩溃。
- **融合**：`F_out = F_global + F_local`，随后经 LN 与门控分支 SiLU 逐元素相乘，再经 GDFN 进一步处理。两条路径互补：GCSM 负责共享上下文修复，LHFM 负责残差中的独立细节恢复。
