## 摘要
全模态生成是广泛内容创建和编辑应用的核心。上下文条件化是该范式的基础。它允许扩散 Transformer 在共享注意力序列中处理文本指令和视觉参考。然而，每个参考图像引入数千个标记。因此，计算量随着参考数量迅速增长。现有方法通过结构化稀疏注意力减少计算，这限制了参考标记与目标标记之间的交互。这种结构还使得参考 K 和 V 与去噪目标无关，允许它们被计算一次并在步骤间复用。然而，它阻止了视觉参考注意到文本指令。这显著降低了多参考编辑中的指令遵循和参考保真度。为了解决这一冲突，我们重新设计了标记序列和注意力掩码。我们的超越掩码设计使用静态文本锚点将指令连接到参考分支。它在不增加参数的情况下保留了精确的 K 和 V 复用。然而，这种直接的架构转换降低了生成质量。我们通过教师强制的速度蒸馏来恢复损失的性能，随后进行一个短期的在策略阶段，其中教师监督学生访问的状态。据我们所知，这是扩散模型中首次使用在策略蒸馏进行架构恢复。在三个图像编辑基准上，我们的方法匹配了全注意力生成质量。使用五个参考图像时，它将完整的 40 步去噪过程加速了 3.92 倍，而静态文本锚点引入的运行时间开销可忽略不计；在我们的扩展研究中，十个参考时加速达到 5.47 倍。

## Abstract
Omnimodal generation is central to a wide range of content creation and editing applications. In-context conditioning is essential to this paradigm. It allows diffusion transformers to process text instructions and visual references in a shared attention sequence. However, each reference image introduces thousands of tokens. Computation therefore grows rapidly with the number of references. Existing methods reduce computation through structured sparse attention, which limits interactions between reference and target tokens. This structure also makes the reference K and V independent of the denoising target, allowing them to be computed once and reused across steps. However, it blocks visual references from attending to the text instruction. This substantially degrades instruction following and reference fidelity in multi-reference editing. To resolve this conflict, we jointly redesign the token sequence and attention mask. Our beyond-mask design uses static text anchors to connect the instruction to the reference branch. It preserves exact K and V reuse without adding parameters. However, this direct architectural conversion degrades generation quality. We recover the lost performance through teacher-forced velocity distillation, followed by a short on-policy stage in which the teacher supervises student-visited states. To our knowledge, this is the first use of on-policy distillation for architectural recovery in diffusion models. Across three image-editing benchmarks, our method matches full-attention generation quality. With five reference images, it accelerates the complete 40-step denoising process by 3.92x, while static text anchors introduce negligible runtime overhead; the speedup reaches 5.47x at ten references in our scaling study.

## 一、核心问题与整体含义

- **研究背景**：全模态生成系统（文本、图像、音频、视频）需要同时处理异构输入。在扩散 Transformer 中，上下文条件化（in-context conditioning）允许文本指令、目标图像和参考图像在同一个注意力序列中联合建模，是实现图像编辑等应用的关键范式。
- **核心矛盾**：每个参考图像在 1024×1024 分辨率下约产生 4000 个 token，且参考状态的 K/V 因与去噪目标交互而随去噪步变化，导致计算量随参考数量急剧增长。现有结构化稀疏注意力（如隔离条件分支）虽能实现参考 K/V 的**精确复用**，但会切断参考图像对文本指令的注意力路径，严重损害多参考编辑中的指令跟随和参考保真度。
- **论文目标**：在不引入额外训练参数、不损失生成质量的前提下，实现多参考场景下参考 K/V 的精确缓存，并同时保留文本指令对参考分支的引导。作者称其为“将指令锚定在掩码之外”（Anchoring Instruction Outside Mask），即通过扩展 token 序列而非仅修改掩码来解决冲突。

## 二、论文提出的方法论

### 2.1 核心思想：静态文本锚点（Static Text Anchors）

- **不可行性分析**：论文用依赖图证明，在原始 token 序列 `[LT, Xt, R]` 上，若保留文本–目标双向注意力（`M[X, LT]=1`），任何从更新后的文本状态到参考状态的信息路径都会间接携带目标信息，导致参考 K/V 随步变化，无法精确缓存。因此仅设计掩码不可能同时满足“指令可达”和“精确缓存”。
- **超越掩码设计**：构造新的 token 序列 `[LT, Xt, ST, R]`，其中 `ST` 为静态文本锚点，其时间步固定为 `t=0`。注意力连接方式为：
  - `ST` 与 `R` 双向可见；
  - `ST` 和 `R` 均不接收来自 `LT` 或 `Xt` 的信息；
  - 原始分支 `LT` 与 `Xt` 保持预训练的双向交互，并继续注意到 `R`，但不再注意 `ST`。
- **精确缓存流程**：在缓存构建阶段一次性计算静态子图 `[ST, R]` 中参考分支的 K/V，得到“指令感知但目标无关”的参考缓存；随后丢弃 ST 状态，在 40 步去噪过程中仅复用参考 K/V。由于 ST 复用现有指令嵌入和注意力投影，**不引入任何新参数**。
- **额外开销**：仅缓存构建时增加约 `ΔA = 2·N_R·N_ST + N_ST²` 次注意力交互，由于 `N_ST ≪ N_R`，运行时开销可忽略。

### 2.2 两阶段架构恢复（Two-Stage Recovery）

架构转换（全注意力 → 稀疏缓存注意力）会导致初始质量下降，作者设计两阶段蒸馏恢复：

- **阶段一：教师强制速度蒸馏（Stage 1, Teacher-forced Velocity Distillation）**
  - 使用数据插值状态：`x_t = (1-t)x_0 + t x_1`，其中 `x_0` 为干净样本，`x_1 ~ N(0,I)`。
  - 最小化学生 `v_θ` 与全注意力教师 `v_full` 的速度场差异：`L_TF = E[||v_θ(x_t,c,t) - v_full(x_t,c,t)||²]`。
  - 该阶段在数据分布前缀上对齐，恢复大部分质量，但会因推理时学生轨迹偏移而饱和。
- **阶段二：在策略蒸馏（Stage 2, On-Policy Distillation）**
  - 学生自己 rollout 40 步，收集访问到的状态 `z_t^θ`（使用 stop-gradient），并冻结这些状态。
  - 在相同状态上查询教师速度作为回归目标：`L_OPD = E[||v_θ(z̄_t,c,t) - v_full(z̄_t,c,t)||²]`。
  - 这是**首次将 on-policy distillation 用于扩散模型的架构恢复**。其关键区别在于查询状态来自学生自身的轨迹，而非固定的数据插值分布，可纠正推理时遇到的残差错误。

## 六、主要结论与发现

- 静态文本锚点能在几乎零运行时开销下恢复参考分支对文本指令的访问，使参考 K/V 同时具备“指令感知”和“跨步精确复用”性质。
- 在三个基准上，文本锚点模型匹配或超过全注意力基线：OmniContext Overall 8.185 vs 8.119，ImgEdit-Bench 4.351 vs 4.324，GEdit-Bench 7.540 vs 7.574（差异在评测噪声范围内）。
- 相比隔离缓存（同等 3.93× 加速），文本锚点在 OmniContext Overall 上提高 0.505（7.680 → 8.185），其中 Subject Consistency 提高 0.677。
- 端到端加速：5 个参考图像时 40 步去噪加速 3.92×（370.0s → 94.4s）；10 个参考时加速 5.47×。且该方法是正交于量化、时间缓存、稀疏注意力等技术的，可组合使用。
- 在策略蒸馏（Stage 2）比继续教师强制蒸馏更有效：继续 Stage 1 训练分数饱和在 8.016±0.015，而 Stage 2 在 500 步内达到 8.185，证明监督学生自身轨迹能提供更强的恢复信号。

## 七、优点

- **设计优雅**：通过“掩码外”的静态文本锚点，以小代价绕过不可行性定理，同时保持规则注意力布局，可直接使用 FlashAttention 等优化算子，无需定制 kernel。
- **零额外参数**：ST 复用已有文本嵌入和注意力投影，不增加模型规模。
- **精确复用**：不同于近似缓存（如 TeaCache），参考 K/V 是精确的，不引入近似误差。
- **方法通用性**：与现有加速方法正交，可叠加使用。
- **方法论贡献**：首次在扩散模型架构恢复中使用 on-policy 蒸馏，并给出清晰的动机（查询分布差异导致优化目标改变）和实验验证。
- **诚实评估**：公开评测噪声来源和负面结果，避免过度解读小差异，增强了结果的可信度。
