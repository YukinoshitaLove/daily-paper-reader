## 摘要
我们提出DOME-HDR，一种双输出多曝光HDR重建框架，通过增益图逆色调映射联合生成感知平衡的SDR图像和一致的HDR图像。给定三个包围式LDR输入，DOME-HDR首先使用LoRA适配的潜在扩散模型合成基础SDR。双交叉注意力融合模块注入来自欠曝光和过曝光图像的互补结构和颜色线索，同时锚定中间曝光以保持稳定性。合成的SDR随后指导HPGM（我们的HDR先验引导增益图网络）预测空间变化的增益图，以实现可靠的动态范围扩展。我们在Kalantari、Tel和Challenge123上使用全参考和无参考指标进行评估，DOME-HDR实现了最先进的HDR重建质量；消融研究进一步证实了双交叉注意力和SDR引导增益图估计的有效性。

## Abstract
We propose DOME-HDR, a dual-output multi-exposure HDR reconstruction framework that jointly produces a perceptually balanced SDR image and a consistent HDR image via gain map inverse tone mapping. Given three bracketed LDR inputs, DOME-HDR first synthesizes a base SDR using a LoRA-adapted latent diffusion model. A dual cross-attention fusion module injects complementary structural and color cues from the under- and over-exposed images while anchoring on the mid exposure for stability. The synthesized SDR then guides HPGM, our HDR Prior-guided Gain Map network, to predict a spatially varying gain map for reliable dynamic-range expansion. We evaluate on Kalantari, Tel, and Challenge123 using both full-reference and no-reference metrics, where DOME-HDR achieves state-of-the-art HDR reconstruction quality; ablations further confirm the effectiveness of dual cross-attention and SDR-guided gain map estimation.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：自然场景的亮度动态范围极大，而传统 SDR 成像系统受限于采集与显示能力，无法完整保留真实光照信息。
- **现有方法缺陷**：
  - **多曝光融合（MEF）**：能生成感知上平衡、细节丰富的 SDR 图像，但输出仍受限于 SDR 表示，未显式恢复超出 SDR 范围的场景辐照度。
  - **多曝光 HDR 重建**：旨在恢复高动态范围辐射表示，但通常需要在线性域中建模，且生成式骨干网络（如 VAE、扩散模型）往往在 SDR 域预训练，需额外的 HDR 域适配；此外，重建结果依赖后续选择色调映射算子，最终感知质量随显示设备与算子选择而变化。
  - **增益图逆色调映射（GM-ITM）**：将 SDR 到 HDR 的转换建模为像素级残差（增益图），避免 HDR 域生成建模。但其关键局限在于增益图只能放大已有信号，若输入 SDR 存在过曝或饱和区域，丢失的辐射信息无法恢复，HDR 质量受限于基础 SDR 的质量。
- **核心问题**：如何在一个统一框架中同时生成感知平衡的 SDR 图像和一致的 HDR 图像，避免将 SDR 融合与增益图估计简单级联带来的误差传播问题？
- **整体含义**：DOME-HDR 将 MEF、HDR 重建与增益图逆色调映射这三种原本分离的动态范围扩展范式整合到一个端到端可联合优化的框架中，实现 SDR 与 HDR 的"双输出"，克服了现有方法输出单一或依赖固定 SDR 输入的局限。

## 2. 论文提出的方法论

### 2.1 核心思想

将问题解耦为两个互补阶段：**感知曝光融合**（阶段 1）与 **HDR 动态范围扩展**（阶段 2），并在统一框架中联合优化。合成的基础 SDR 图像同时作为感知输出和增益图估计的引导信号。

### 2.2 阶段 1：基础 SDR 合成（Base SDR Synthesis）

- **骨干模型**：基于 UltraFusion 的潜在扩散模型（LDM），通过 LoRA 适配（作用于交叉注意力投影 to_q、to_v，秩为 8），U-Net 与 VAE 保持冻结。
- **锚定策略**：以中间曝光图像 I_me 作为主要结构参考（query），而非 UltraFusion 中的过曝光图像。
- **双交叉注意力机制（核心创新）**：
  - 从欠曝光 I_ue 和过曝光 I_oe 分别提取结构和颜色线索，经拼接和 1×1 卷积融合为引导特征。
  - 两个**独立**的交叉注意力分支分别将 UE 和 OE 引导特征注入中间曝光潜在表示，而非像 UltraFusion 那样先归一化求和再融合。
  - 公式：`X_out = X_me + Conv₁ₓ₁(softmax(QKᵀ/τ)V)`，其中 Q 来自中间曝光，K、V 来自各曝光分支的引导特征。
  - 优点：保留曝光特定信息，避免平均化造成的互补线索损失。
- **推理**：去噪后的潜在表示经冻结的 VAE 解码器生成基础 SDR 图像 Î_sdr。

### 2.3 阶段 2：增益图估计与逆色调映射（HPGM）

- **HDR 先验构建**：
  - 线性化与曝光归一化：`X_k = I_k^γ / 2^(ev_k)`，γ=2.2。
  - 计算曝光比 R_ue = X_ue/X_me、R_oe = X_oe/X_me。
  - 通过 sigmoid 生成高光/阴影软掩膜 S_hi、S_lo（阈值 0.95/0.05，尖锐度 α=50）。
  - 生成饱和感知的线性 HDR 估计：`Î_prior_hdr = S_hi·X_ue + (1−S_hi−S_lo)·X_me + S_lo·X_oe`。
  - 由 HDR 估计与基础 SDR 之比的 log 域得到增益先验 `G_prior = log(Ĩ_hdr+ε)/log(Î_sdr+ε)`。
- **HPGM 网络结构**：
  - U-Net 编码器输入为 11 通道（基础 SDR、两组曝光比、两个饱和度掩膜）。
  - 瓶颈层注入由轻量卷积编码器提取的 HDR 先验特征（来自 G_prior、S_hi、S_lo 的拼接）。
  - 解码器使用三个 Sobel 边缘引导的上采样块，以边缘图作为空间门控锐化特征边界。
  - 双预测头：增益图头预测残差 `ĝ = G_prior + Δg`；全局尺度头预测 `Q̂_max`（全局平均池化 + 两层 MLP）。
- **最终 HDR 重建公式**：`Î_hdr(x,y) = (Î_sdr(x,y) + ε)^(ĝ(x,y)) · Q̂_max − ε`。

### 2.4 训练损失与策略

- **图像级损失**：μ-law 压缩域 L1 + VGG19 感知损失（加权 λ_perc=10⁻²）。
- **增益级损失**：Charbonnier 损失 + 全局尺度 L1（w_qmax=0.3）。
- **两阶段训练**：
  - 阶段 1：LoRA 扩散模块与 HPGM 联合训练（30k 迭代），学习 SDR 合成与增益预测。
  - 阶段 2：使用阶段 1 生成的 MEF 输出作为基础 SDR 输入，进一步优化 HPGM（30k 迭代），缩小训练与推理间的域差距。

## 6. 论文的主要结论与发现

- **HDR 重建性能最优**：在三个基准合并测试集上，DOME-HDR 在 PU-PSNR（44.63）、PU-SSIM（0.9878）、LPIPS（0.0156）、DISTS（0.0147）等全参考指标上全面超越现有方法，同时在 CLIPIQA（0.4137）、NIQE（3.56）、BRISQUE（22.18）等无参考指标上也有领先或持平表现。
- **双输出优势**：框架直接生成感知平衡的 SDR 图像，避免了 HDR 图像在不同色调映射算子下产生的感知质量波动；在无参考指标上，本方法输出的 SDR 质量优于 AFUNet、SCTNet、SAFNet 在三种色调映射算子下的最佳结果。
- **联合优化优于级联**：将 UltraFusion 与 GMNet 简单级联仅获得 22.96 PU-PSNR，远远低于本方法的 44.63，证明了端到端联合优化的核心价值。
- **双交叉注意力有效**：相比 UltraFusion 的归一化求和特征融合，双分支交叉注意力在所有指标上一致提升。
- **三曝光互补信息关键**：HDR 先验构建使用全部三个曝光时性能大幅优于仅使用单/双曝光（如 PU-PSNR 从约 26 提升至 44.63）。
