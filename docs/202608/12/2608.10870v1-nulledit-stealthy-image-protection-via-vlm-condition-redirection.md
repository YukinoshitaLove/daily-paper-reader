## 摘要
现代图像编辑器将视觉语言模型（VLM）与扩散Transformer主干结合，无需微调即可根据指令修改单个参考图像。这一能力也使得公开图像的未授权篡改成为可能。现有的推理时防御要么通过明显破坏使编辑失效，从而暴露保护，要么允许编辑进行但导致身份或参考内容漂移，从而无法阻止编辑行为本身。我们转而针对一种隐蔽且无害的空操作，其中请求的编辑被抑制，输出保持自然并保留源内容，没有明显的伪影或身份替换，且缺乏恶意指令所请求的有害语义。我们提出NullEdit，该方法针对参考图像和指令联合形成的VLM表示，在该表示条件下调下游DiT主干之前。通过正常编辑和无编辑锚点，NullEdit重定向该表示，同时跨提示梯度平均将保护转移到未见过的指令。在CelebA-HQ和VGGFace2上，使用Step1X-Edit和Qwen-Image-Edit，NullEdit相对于SOTA基线平均降低了EditReward IF分数0.813，同时保留了主体身份和源内容。

## Abstract
Modern image editors combine vision-language models (VLMs) with diffusion transformer backbones to modify a single reference image according to instructions without fine-tuning. This capability also enables unauthorized manipulation of publicly released images. Existing inference-time defenses either invalidate edits through conspicuous corruption, thereby exposing the protection, or allow them to proceed with identity or reference content drift, thereby failing to prevent the editing behavior itself. We instead target a stealthy and harmless no-op in which the requested edit is suppressed, the output remains natural and source-preserving without conspicuous artifacts or identity replacement, and harmful semantics requested by malicious instructions are absent. We propose NullEdit, which targets the VLM representation jointly formed from the reference image and instruction before it conditions the downstream DiT backbone. Using normal-edit and no-edit anchors, NullEdit redirects this representation, while cross-prompt gradient averaging transfers protection to held out instructions. Across Step1X-Edit and Qwen-Image-Edit on CelebA-HQ and VGGFace2, NullEdit reduces the EditReward IF score by 0.813 on average relative to the SOTA baseline while preserving subject identity and source content.

# NullEdit：基于VLM条件重定向的隐蔽图像保护 — 详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：现代图像编辑器（如 Step1X-Edit、Qwen-Image-Edit）结合视觉语言模型（VLM）与扩散 Transformer（DiT）主干，可通过单一参考图像和自然语言指令进行无需微调的图像编辑。这种“上下文编辑”能力带来了隐私与版权风险：攻击者可对公开图像进行表情篡改、身份变更，甚至生成暴力或性化内容、误导性场景。
- **问题**：现有防御手段存在两类不足：
  - **训练时方法**（如 Glaze、Anti-DreamBooth、Nightshade）需要保护图像参与训练/微调，无法约束冻结的推理时编辑器。
  - **推理时方法**（如 PhotoGuard、EditShield、DiffusionGuard）通过破坏 VAE 表示、潜空间或降噪过程使编辑失效，但常引入可见伪影、异常结构，暴露保护意图；而 FaceLock、DeContext 等虽能保护身份，但请求的语义编辑仍可能在漂移后的输出上执行，无法阻止有害内容生成。
- **本文目标**：实现一种“隐蔽且无害的 no-op”（stealthy no-op）防御——在冻结的编辑器上添加有界扰动，使请求的编辑被抑制，输出保持自然、源保留、无身份替换或明显伪影，同时不包含恶意指令所要求的有害语义。
- **核心洞察**：统一上下文编辑模型中，参考图像通过两条路径被利用：VAE 视觉表示负责重建，VLM 条件编码器将参考内容与指令绑定成语义编辑条件。因此，保护应重定向 VLM 编辑条件，同时保留参考重建路径。

## 2. 方法论（核心思想与技术细节）

### 2.1 问题建模

- 参考图像 \(x\) 和编辑指令 \(p\) 被抽象为：
  - 参考表示：\(r_x = E_{ref}(x)\)
  - 联合条件表示：\(h_{x,p} = F_\psi(x,p)\)
  - 完整编辑过程：\(y_p = G_\theta(r_x, \Phi(h_{x,p}); \xi)\)
- 防御方保持编辑器冻结，仅优化有界扰动：\(x_{adv} = x + \delta, \|\delta\|_\infty \le \epsilon\)。
- 目标行为：\(G(x_{adv},p) \not\models p\) 且 \(G(x_{adv},p) \simeq_{src} x\)（编辑失效 + 源内容保留）。

### 2.2 为什么朴素条件目标失败（动机分析）

- **幅度抑制失败**：最小化 VLM 编辑残差范数 \(L_{mag}\) 能大幅降低表示差异，但会破坏图像条件表示，导致部分编辑仍生效或产生可见破坏，无法可靠地产生源保留 no-op。
- **单侧方向约束失败**：
  - 仅“远离正常编辑锚点”：导致严重可见破坏、纹理伪影和结构扭曲。
  - 仅“靠近无编辑锚点”：因正常编辑与无编辑表示共享大量参考条件成分，仍可能保留编辑残差，输出仍是正常编辑样。
- 因此需要**平衡条件重定向**：同时执行“远离正常编辑”和“靠近无编辑”。

### 2.3 平衡条件重定向损失

- 定义 token 级余弦相似度：
  \[
  Sim(A,B) = \frac{1}{M}\sum_{i=1}^M \frac{z_i(A)^\top z_i(B)}{\|z_i(A)\|_2 \|z_i(B)\|_2}
  \]
- 目标损失（最小化）：
  \[
  L_\lambda(x_{adv};p) = Sim(h_{x_{adv},p}, h_{x,p}) - \lambda \, Sim(h_{x_{adv},p}, h_{x,p_0})
  \]
  - 第一项：远离正常编辑锚点 \(h_{x,p}\)；
  - 第二项：靠近共享无编辑锚点 \(h_{x,p_0}\)；
  - 实验发现 \(\lambda \approx 1\) 是实现源保留 no-op 的关键平衡点。
- 机制分析：正常编辑与无编辑的输入梯度高度对齐（共享参考条件成分），对称加权后可抑制共享成分，突出编辑相关残差更新。

### 2.4 跨提示梯度平均（Cross-Prompt Gradient Averaging）

- 不同编辑指令在 VLM 隐藏状态空间中的编辑残差高度对齐（平均 pairwise cosine ≈ 0.940）。
- 因此可使用一组紧凑代表提示 \(P_{rep}=\{p_1,\dots,p_K\}\) 联合优化：
  \[
  \bar{g}^{(k)} = \frac{1}{K}\sum_{j=1}^K g^{(k)}_j = \nabla_{x^{(k)}_{adv}} \left[ \frac{1}{K}\sum_{j=1}^K L_\lambda(x^{(k)}_{adv};p_j) \right]
  \]
- 先对原始梯度平均，再应用符号操作，保留多提示一致支持的更新分量，抑制提示特定变化。
- 优化采用动量引导的投影符号更新（L∞ 约束下），并余弦衰减步长，仅更新图像像素，所有编辑器参数冻结。

## 3. 实验设计

- **指令集合**：共 12 条，覆盖面部表情、局部属性、背景变化。
  - 优化池（Prompts 1–8）：微笑、愤怒、悲伤、惊讶、眼镜、胡须、海滩、森林；
  - 持出集（Prompts 9–12）：担忧表情、帽子、烟熏妆、城市街道，仅用于评估跨提示泛化。

### 3.2 目标模型与基线

- **目标模型**：
  - Step1X-Edit（Liu et al., 2025）
  - Qwen-Image-Edit-2511（Wu et al., 2025）
- **基线方法**：
  - Clean（无保护，正常编辑参考）
  - DiffPGD（基于去噪损失的对抗攻击）
  - VAE（潜空间扰动，代表 PhotoGuard-Encoder / EditShield）
  - DeContext（抑制多模态注意力中的参考传播）

- **编辑抑制**：EditReward-MiMo 指令遵循度（IF，越低越好）

## 6. 主要结论与发现

- **核心结果**：NullEdit 在 Step1X-Edit 和 Qwen-Image-Edit 上均能大幅降低 EditReward IF 分数。摘要指出，相对 SOTA 基线，平均降低 0.813（具体到各设置：Step1X-Edit 上 IF 从约 -0.48 降至 -1.22/-1.18；Qwen-Image-Edit 上从约 -0.03 降至 -0.90）。
- **源保留与身份保持**：在编辑抑制最强的同时，NullEdit 取得了最高的受保护 CLIP-I 和 SSIM，并保持极低 FDFR（Step1X-Edit 上接近零；Qwen-Image-Edit 上略有波动），说明输出自然、身份未被替换。
- **跨提示迁移有效**：held-out 提示保留的抑制增益在 Step1X-Edit 上为 91.2%，在 Qwen-Image-Edit 上为 94.5%，说明保护可泛化到未见过的指令。
- **机制验证**：
  - 幅度抑制（残差范数归零）不足以保证 no-op；
  - 单侧方向约束（仅远离或仅靠近）会导致可见破坏或编辑残存；
  - 平衡重定向（\(\lambda \approx 1\)）是关键；
  - VLM 编辑残差的方向性几何和输入梯度对齐支撑了跨提示梯度平均的设计。

## 7. 优点

- **问题定位精准**：将 VLM 联合表示作为干预面，比破坏 VAE/去噪更具语义针对性；提出“隐蔽 no-op”目标，区分了“保护不失败”与“保护失败但看起来成功”。
- **方法设计优雅**：通过正常/无编辑双锚点和平衡余弦相似度，实现“重定向而非坍缩”；跨提示梯度平均利用 VLM 语义空间的结构，让保护迁移到未见指令。
- **实验较严谨**：两个编辑器、两个数据集、多基线与用户研究结合；消融揭示了超参数敏感性和可行性边界；强调联合指标解读避免误导。
- **计算开销可比**：每图像成本低于前两种推理时基线，接近轻量级方法，有实用性潜力。

## 8. 不足与局限

- **实验覆盖有限**：仅人脸数据集（CelebA-HQ、VGGFace2），未覆盖一般物体、自然场景、艺术风格等更广泛编辑场景；指令池仅 12 条，实际恶意指令空间远大于此。
- **白盒需求**：方法需要访问目标编辑器的 VLM 表示和内部梯度，属于白盒防御；对黑盒 API 或闭源编辑器不适用，也缺乏对自适应攻击者的鲁棒性讨论。
- **保护可绕过性**：未评估当攻击者知晓保护扰动并使用更鲁棒编辑器、多次编辑、或对抗性净化时，保护是否仍然有效。
- **用户研究规模小**：仅 10 名参与者，50 组试次，统计功效有限，结果可能存在选择偏差。
- **指标解读挑战**：某些表格数据显示 FDFR 在 Qwen 上比 SOTA 基线略高（如 0.075 vs 0.062），ISM 增益不明显；论文未充分讨论这些不一致，可能暗示保护有时会轻微影响人脸检测或身份保持。
- **缺乏端到端标准**：论文没有提供统一的“no-op 成功”判定标准（如阈值），使得不同方法间比较可能不够直接。
