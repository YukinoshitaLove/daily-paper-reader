## 摘要
水下图像中的退化信息具有双重作用：其空间和光谱线索可以指导自适应复原，而退化纠缠的特征可能在解码过程中未经明确调控而传播。现有方法在很大程度上忽视了这种双重作用，要么未充分利用退化线索，要么直接通过跳跃连接转发编码器特征。为了解决这个问题，我们提出了PROTEUS，它将退化引导的特征适应与任务导向的潜在控制相结合。PROTEUS从两个互补的视角来解决该问题。在特征层面，引导动态特征调制模块利用空间变化的退化线索来自适应网络各阶段的特征处理。在表示层面，任务导向的潜在控制器在判别性正则化下学习结构化控制码，并将其用于跳跃特征的通道级调制，而无需该控制码形成度量上更干净的嵌入。在五个成对和四个无参考水下基准上的大量实验表明，PROTEUS实现了极具竞争力的复原性能，并在复原质量与计算成本之间取得了有利的平衡。

## Abstract
Degradation information in underwater images plays a dual role: its spatial and spectral cues can guide adaptive restoration, while degradation-entangled features may be propagated without explicit regulation during decoding. Existing methods largely overlook this dual role, either underexploiting degradation cues or directly forwarding encoder features through skip connections. To address this issue, we propose PROTEUS, which couples degradation-guided feature adaptation with task?oriented latent control. PROTEUS tackles this problem from two complementary perspectives. At the feature level, the Guided Dynamic Feature Modulation Block exploits spatially varying degradation cues to adapt feature processing across network stages. At the representation level, the task-oriented latent controller learns a structured control code under discriminative regularisation and uses it for channel-wise modulation of skip features, without requiring the code to form a metrically cleaner embedding. Extensive experiments on five paired and four non-reference underwater benchmarks demonstrate that PROTEUS achieves highly competitive restoration performance, with a favourable balance between restoration quality and computational cost.

## 1. 核心问题与整体含义（研究动机与背景）

水下图像复原是海洋视觉应用（目标检测、分割、3D 重建等）的基础任务。水下环境中存在波长相关的吸收、后向散射、空间变化光照等多种退化因素，它们相互叠加，导致图像出现色偏、低对比度、深度相关的强度衰减等问题。

论文指出现有方法普遍忽视了一个关键问题——**退化信息的双重角色**：

- **积极面**：退化信息中的空间和光谱线索，可以用于指导自适应复原，帮助网络知道"哪里退化、如何退化"；
- **消极面**：退化信息也可能与编码器特征纠缠在一起，若在解码阶段通过跳跃连接不加调控地直接传播，会造成特征污染，损害复原质量。

现有方法大致落入两种极端：要么对退化线索利用不足，要么通过跳跃连接直接转发编码器特征而缺乏显式调控。论文由此提出 **PROTEUS** 框架，试图同时解决这两个互补的问题。

## 2. 方法论

### 2.1 总体框架

PROTEUS 采用对称的三层 U-Net 结构（基础通道数 C=32），在编码器瓶颈处引入任务导向的潜在控制器。整体遵循全局残差公式：

> Ir = D[P(E(Id; ˜Id)); ˜Id] + Id

其中 E 为编码器，P 为瓶颈潜在控制器，D 为解码器，˜Id 为引导图像。全局残差连接使网络只需学习复原残差，降低学习难度。

### 2.2 核心模块

- **Gray-Edge Prior Module（GEPM）**：基于灰度边缘先验，用 Scharr 梯度计算通道增益，纠正全局色偏；通过可学习参数 σ(α) 将白平衡结果与原图混合，作为后续特征调制的引导图像。
- **Guided Dynamic Feature Modulation Block（GDFMB）**：包含两个子模块：
  - **Guided Degradation-Adaptive Block（GDAB）**：将引导图像与特征图投影到共享隐藏空间，采用可变形交叉注意力——以特征图为查询（Q），引导图像为键值（K/V），预测二维偏移场来采样空间变化的退化线索；再通过高斯基展开（Gaussian Basis Expansion）和选择性融合门控生成调制向量，实现逐位置的自适应特征调制。
  - **Gradient Fusion Block（GFB）**：通过通道级 Sobel 算子提取梯度幅度，生成空间掩码，以保持边缘和纹理等高频结构。
- **Task-Oriented Latent Control（任务导向潜在控制）**：
  - **Mapper**：将编码器瓶颈特征 Fl 映射为控制码 Fz 和互补残差 Fres；
  - **Attention Gate**：控制码 Fz 经全局平均池化和两层 MLP 生成通道权重，对跳跃连接特征进行通道级调制后再与解码器特征融合；
  - **正则化**：结合三个损失——参考潜在对齐（Lalign）、正交性正则（Lorth，使 Fz 与 Fres 互补）、对比正则（Lcontrast，与退化阴性样本拉开距离）。作者明确强调这些正则化是优化偏向，而非使 Fz 成为"度量上更干净的嵌入"。

### 2.3 损失函数

总损失包括：Charbonnier 损失、HVI 颜色损失、SSIM 损失、VGG 感知损失、边缘损失，加上潜在控制正则化和自监督一致性损失（对预测结果的弱/强增广视图施加一致性约束）。

### 2.4 训练增强

- 物理动机的**光度增强**：模拟色差（红蓝通道随机偏移）和光谱衰减（通道不对称缩放），训练时启用、推理时关闭；
- **几何增强**：用于自监督一致性损失。
