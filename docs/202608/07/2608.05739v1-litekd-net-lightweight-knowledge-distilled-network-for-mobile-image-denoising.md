## 摘要
移动图像去噪既需要良好的恢复质量，也需要较低的计算成本。此外，收集大规模的低质量-真实干净图像对是令人烦恼的。因此，我们提出了LiteKD-Net，一种用于移动图像去噪的轻量级知识蒸馏网络。首先，与应用于相机的流水线相比，物理引导的噪声模拟流水线通过添加像素串扰来生成成对的训练数据。接下来，我们将Real-ESRGAN适应于恒分辨率去噪，并基于深度可分离卷积使用Lite-RRDB块构建轻量级学生网络。第三，应用特征级知识蒸馏将教师网络的恢复能力转移给学生网络，而不会引入额外的推理成本。在真实世界数据集上的实验表明，我们的模型在保持良好的恢复质量的同时，实现了运行时间的大幅减少和推理速度的提升。与SwinIR相比，我们的模型在所有指标上也达到了最优。这些结果表明，LiteKD-Net在恢复质量和计算效率之间提供了很好的权衡。

## Abstract
Mobile image denoising requires both good restoration quality and low computational cost. In addition, it's annoying to collect large-scale LQ-GT clean pairs. As a result, we propose LiteKD-Net, a lightweight knowledge-distilled network for mobile image denoising. First, a physics-guided noise simulation pipeline generates paired training data by adding pixel crosstalk compared with pipelines applied to cameras. Next, we adapt the Real-ESRGAN to identity-resolution denoising and construct a lightweight Student using Lite-RRDB blocks based on depthwise separable convolutions. Third, feature-level knowledge distillation is applied to transfer the Teacher's restoration capability to the Student without introducing additional inference cost. Experiments on real-world datasets show that our model reaches great reduction in runtime and increase in the inference rate with good restoration quality. Our model also reaches the best in all metrics compared with SwinIR. These results indicate that LiteKD-Net provides a great trade-off between restoration quality and computational efficiency.

## 一、核心问题与整体含义（研究动机与背景）

- **应用场景痛点**：手机已成为最常用的成像设备，但移动传感器面积小、单像素尺寸小，单次曝光捕获的光子少，导致图像信噪比天然较低；单纯提高传感器增益又会放大噪声、色带等退化问题。
- **模型部署困境**：现有高容量去噪网络（含数千万参数、需数十亿浮点运算）部署到移动端会面临高延迟、高能耗和不可接受的内存占用；云端处理虽可缓解本地计算压力，但引入通信延迟、带宽成本和用户隐私问题。
- **数据获取难题**：移动成像的噪声仿真管线研究不足；拍摄同一场景的严格对齐 LQ-GT 图像对极其困难（存在物体运动、光照变化、相机内处理管线造成的空间错位）；纯合成高斯白噪声又无法反映真实 CMOS 传感器的信号相关性与结构化噪声。

**论文目标**：在保证良好去噪质量的同时，显著降低模型体积、计算量和推理延迟，兼顾移动端部署的准确性与效率。

## 二、方法论：核心思想、关键技术细节

### 1. 整体框架
提出 LiteKD-Net，集成三大组件：**噪声模拟流水线（NSP）**、**Lite-RRDB 轻量学生网络**、**特征级知识蒸馏（Noise-KD）**。

### 2. 噪声模拟流水线（NSP）
- 将干净的 sRGB 图像经过伽马展开（γ=2.2）近似线性化，在线性 RGB 域施加传感噪声，再裁剪并逆伽马变换回 sRGB。
- 噪声成分依次为：
  - **光子散粒噪声**：基于泊松分布，信号相关（均值=K·Poisson(y/K)，方差=Ky₀）；
  - **Tukey–Lambda 读取噪声**：采用逆累积分布形式模拟重尾分布的电子读取噪声；
  - **行噪声**：每行采样一个高斯偏移并广播到全行所有通道；
  - **像素串扰（核心贡献）**：通过一个 5×5 权重和恒为 1 的 3×3 核（中心权重 1−5ρ，邻域权重 ρ 或 ρ/4，默认 ρ=0.03）对每个通道做分组卷积，将少量局部信号扩散至邻域，使原本独立的像素噪声变为局部空间相关噪声；
  - **量化噪声**：14-bit 均匀量化噪声。
- 最终公式：x̂_s = Γ⁻¹(clip(C_ρ(K·Poisson(Γ(y_s)/K)+n_read+n_row)+n_q, 0, 1))

### 3. Lite-RRDB 轻量结构
- 移除 Real-ESRGAN 中所有上采样模块，使其适用于 H×W→H×W 恒分辨率去噪，作为 Heavy Teacher。
- 将原 RRDB 块替换为 Lite-RRDB：
  - 去除原 RDB 中的密集拼接路径，五个卷积层顺序执行，特征宽度固定为 64 通道；
  - 每个标准 3×3 卷积替换为深度可分离卷积（DSConv = 1×1 逐点卷积 + 3×3 逐通道卷积）；
  - 参数计算对比：标准卷积 P_std=k²·Cin·Cout，深度可分离卷积 P_DS=k²·Cin+Cin·Cout；
  - 保留块内残差连接与残差缩放（0.2），保留 RRDB 的残差套残差结构。

### 4. Noise-KD 特征级知识蒸馏
- 教师网络（Heavy Teacher）先训练至收敛，之后参数冻结；
- 将同一噪声图像分别输入教师和学生，在 body 特征层面计算均方误差：L_KD = 1/(CHW)·‖F_S(x)−F_T(x)‖₂²；
- 学生总损失：L_total = L₁ + λ_per·L_per + λ_KD·L_KD；
- 教师只在训练阶段存在，推理时完全丢弃，**不引入任何额外推理参数和计算量**。

## 六、主要结论与发现

- LiteKD-Net 与基线（Real-ESRGAN）相比，模型参数从 16.70M 降至 1.67M（约 **10 倍压缩**），MACs 从 1.17T 降至 108.28G、FLOPs 从 2.35T 降至 216.55G（约 **10.8 倍计算量缩减**），推理时间从 148.70ms 降至 83.47ms（约 **1.8 倍加速**），FPS 从 6.72 提升至 11.98；
- 同时图像质量保持接近：PSNR 仅从 38.14 降至 37.91（损失 0.23 dB），SSIM 从 0.9007 降至 0.8975，LPIPS 从 0.0974 升至 0.0987；
- 与 SwinIR 相比，LiteKD-Net 在 **全部质量指标上更优**（PSNR 37.91 vs 34.73，SSIM 0.8975 vs 0.8242 等），且参数量仅为 SwinIR 的约 1/7，推理时间不到其 1/4；
- 噪声知识蒸馏有效恢复了轻量化造成的质量损失（PSNR 从 37.24 提升至 37.91），且不增加推理成本；
- 总体结论：LiteKD-Net 在恢复质量与计算效率之间取得了出色的权衡，适合移动端部署。
