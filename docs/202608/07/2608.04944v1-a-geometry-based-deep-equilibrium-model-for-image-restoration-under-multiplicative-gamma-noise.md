## 摘要
我们提出了一种深度学习框架，用于从受乘性Gamma噪声和模糊双重退化的图像中进行恢复。与依赖隐式神经正则化的传统深度平衡（DEQ）模型不同，所提出的方法学习一个显式且可解释的正则化项，该正则化项由与表面积和平均曲率相关的几何先验参数化。为了最小化所得到的变分模型，我们开发了一种针对常用Gamma噪声保真度项定制的镜像下降算法。利用定义在$o$-最小结构上的函数的Kurdyka-Lojasiewicz性质，我们建立了生成的迭代序列全局收敛到临界点的结论。在灰度图像和彩色图像恢复上的实验结果表明，所提出的方法在一致优于代表性的基于模型的方法的同时，实现了与基于隐式正则化的最先进DEQ模型相当的性能，尽管所需的可训练参数要少得多。

## Abstract
We propose a deep learning framework for image restoration from images degraded by both multiplicative Gamma noise and blur. Unlike conventional deep equilibrium (DEQ) models that rely on implicit neural regularization, the proposed method learns an explicit and interpretable regularizer parameterized by geometric priors associated with surface area and mean curvature. To minimize the resulting variational model, we develop a mirror descent algorithm tailored to the commonly used Gamma-noise fidelity terms. Leveraging the Kurdyka-Lojasiewicz property for functions defined in $o$-minimal structures, we establish the global convergence of the generated iterates to a critical point. Experimental results on both grayscale and color image restoration demonstrate that the proposed method consistently outperforms representative model-based approaches while achieving performance comparable to state-of-the-art DEQ models based on implicit regularization, despite requiring substantially fewer trainable parameters.

## 2. 论文提出的方法论

### 2.1 总体框架：双层优化DEQ模型
- 学习目标为双层级联优化问题：
  \[
  \hat\theta \in \arg\min_{\theta\in\Theta} \frac{1}{N}\sum_{i=1}^N \ell\big(x_i^\infty(\theta; (x_i^0, y_i)), x_i^*\big),\quad \text{s.t. } x_i^\infty \in \mathrm{Fix}(f_\theta(\cdot; y_i))
  \]
- 下层问题：求解固定点，固定点与能量泛函 \(F_\theta(x;y) = D(x;y) + \lambda R_\theta(x) + \iota_{[0,a]^n}(x)\) 的临界点一致。

### 2.2 显式几何正则化器
- 正则化器以 Field-of-Experts（FoE）形式构建，包含：
  - **面积相关项**：使用可学习卷积核 \(k_l\)，经可学习影响函数 \(\psi_a\) 作用后乘以几何量 \(A(x^{(c)}) = \sqrt{(D_h^+x)^2 + (D_v^+x)^2 + \epsilon}\)。
  - **曲率相关项**：使用曲率量 \(K(x^{(c)}) = D_h^- (D_h^+ x / A(x)) + D_v^- (D_v^+ x / A(x))\)，乘以学习的影响函数 \(\psi_c\)。
- 影响函数用高斯RBF展开参数化，卷积核用DCT基参数化（单位范数保证）。
- 该正则化器可退化出多种经典模型：TV、最小曲面、MC-Lp、Euler's elastica、混合几何正则化等，展示了其作为泛化框架的能力。

### 2.3 镜像下降推理算法
- 针对Gamma噪声保真项（KL型与AA型）不满足Lipschitz梯度条件的问题，采用Bregman镜像下降。
- 对AA型保真项，选择Bregman势 \(h_{AA}(x) = \sum_j 1/x_j\)；对KL型，选择Burg熵 \(h_{KL}(x) = -\sum_j \log x_j\)。
- 封闭形式更新：
  - KL型：\(x^{k+1} = \Pi_{[0,a]^n}\left(\frac{x^k}{1 + \tau x^k (\lambda \nabla R_\theta(x^k) + \nabla D_{KL}(x^k;y))}\right)\)
  - AA型：\(x^{k+1} = \Pi_{[0,a]^n}\left(\frac{x^k}{\sqrt{1 + \tau (x^k)^2 (\lambda \nabla R_\theta(x^k) + \nabla D_{AA}(x^k;y))}}\right)\)
- 证明了Bregman近端算子与欧氏投影等价（针对 \(h_{AA}\)）。

### 2.4 收敛性分析
- 通过验证L-smad条件（\(Lh - g\) 凸性），分别对AA型与KL型保真项给出L常数的充分条件。
- 利用o-minimal结构中的可定义性证明目标函数满足Kurdyka-Lojasiewicz (KL) 性质。
- 在步长满足 \(0 < \tau \bar{L} < 1\) 时，证明镜像下降迭代全局收敛到临界点；固定点集合非空。

### 2.5 自适应回溯策略与训练
- 为避免保守的L常数估计和保证迭代良定义，提出回溯算法：动态缩小步长 \(\tau\)，直到满足充分下降条件（Bregman距离形式）和保证投影前参数为正的条件。
- 前向固定点计算采用自动微分求 \(\nabla R_\theta\)，避免手工推导。
- 后向训练使用隐式微分 + Jacobian-free backpropagation (JFB) 近似，避免大规模线性系统求解，节省显存。
