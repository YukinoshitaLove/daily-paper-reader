## 摘要
草图引导的图像修复提供了直观的结构控制，然而真实草图往往混合了可靠的全局意图与局部拥挤、错位、不完整或刻意非常规的笔画。现有方法通常要么在去噪过程中将输入草图保留为固定条件，要么在RGB合成前将其细化为干净结构。前者假设笔画具有均匀可靠性，可能将局部错误传播到整个生成过程；后者则必须在出现外观和语义上下文之前解决模糊结构问题。我们提出了SketchSense，一个通过同步去噪交互的RGB与结构流来解读不完美草图引导的框架。双向注意力融合将外观生成与结构恢复耦合，产生一个暴露模型不断演化的草图解读的精炼结构。短语级目标对齐两个流的语义基础。草图感知空间调节通过调制注意力和融合过程，进一步使草图使用适应局部生成状态，而可选的符号先验将保留与纠正意图注入特征表示和注意力行为中。在自然且结构复杂的图像上的实验表明，在恢复质量和结构保真度方面均显著优于现有方法。

## Abstract
Sketch-guided image inpainting provides intuitive structural control, yet real sketches often mix reliable global intent with locally crowded, displaced, incomplete, or deliberately unconventional strokes. Existing approaches typically either retain the input sketch as a fixed condition throughout denoising or refine it into a clean structure before RGB synthesis. The former assumes uniformly reliable strokes and can propagate local errors throughout generation; the latter must resolve ambiguous structure before emerging appearance and semantic context become available. We propose SketchSense, a framework that interprets imperfect sketch guidance by synchronously denoising interacting RGB and structure streams. Bidirectional Attention Fusion couples appearance generation with structural recovery, producing a refined structure that exposes the model's evolving sketch interpretation. A phrase-level objective aligns the semantic grounding of the two streams. Sketch-Aware Spatial Regulation further adapts sketch use to local generation states by modulating attention and the fusion process, while an optional signed prior injects preserve-versus-correct intent into feature representations and attention behavior. Experiments on natural and structurally complex imagery show substantial gains over existing methods in both restoration quality and structural fidelity.

## 1. 核心问题与整体含义

草图引导的图像修复允许用户通过绘制轮廓、边界等结构信息来控制缺失区域的生成内容。然而，真实用户草图往往**并非均匀可靠**：整体布局可能是可信的，但局部笔画可能拥挤、错位、不完整，甚至含有刻意设计的非常规形状。这种“局部不可靠”是草图引导修复的核心挑战。

现有方法主要分为两类，但各有缺陷：
- **固定条件方法**：将输入草图作为固定条件贯穿整个去噪过程，假设所有笔画同等可靠，容易将局部画错或退化笔画传播到生成结果中。
- **先细化后合成方法**：先将草图细化为“干净结构”，再据此生成 RGB 图像。此类方法要求模型在**外观与语义上下文尚未出现之前**就解决结构歧义，对结构复杂图像（如壁画、艺术品）尤其受限。

SketchSense 的核心动机是：**草图的可信度具有空间异质性，几何形状本身无法区分“错误”与“有意设计”，因此必须结合不断演化的外观、结构、语义信息，动态调整对草图的利用方式。**

## 2. 方法论

SketchSense 提出了一个**同步 RGB–结构双流去噪框架**，核心创新包括四大组成部分：

### 2.1 同步 RGB–结构理解
- 构建两个去噪分支：RGB 分支负责内容恢复，结构分支负责将“不完美草图”逐步细化为“精炼结构”。
- 两分支共享同一去噪时间步，并通过双向信息交换协同演化。
- 初始状态包含图像 token、边缘目标 token、草图 token 和文本 prompt 条件；草图 token 始终作为源证据保留，而边缘目标 token 在结构上下文与外观上下文共同作用下逐层更新。

### 2.2 双向注意力融合（Bidirectional Attention Fusion）
- 在每个 Transformer 块中，复用原有 QKV 投影，同时加入专门的 **joint-attention QKV LoRA** 产生融合用的 ΔQKV。
- 计算两个方向的交叉注意力消息：
  - RGB 查询从结构侧（边缘+草图）检索信息；
  - 边缘目标查询从 RGB 侧检索外观与语义信息。
- 两个方向的消息拼接后经零初始化的投影矩阵，分裂成两个分支的候选残差 ΔHx、ΔHe，再通过门控注入各自分支。
- 该方法同时适用于 FLUX 的 double-block 和 single-block 结构。

### 2.3 短语级跨分支语义一致性（Phrase-Level Cross-Branch Semantic Consistency）
- 利用 LLM 从 prompt 中提取名词短语，并匹配到对应的文本 token。
- 分别聚合 RGB 分支和边缘分支中针对该短语的注意力分布，计算二者的 **Jensen-Shannon 散度**作为差异度量。
- 使用软权重 ωlk 强调“差异大且空间置信度高”的短语对，同时通过 stop-gradient 避免权重干扰梯度。

### 2.4 草图感知空间调节（Sketch-Aware Spatial Regulation）
- **内在调节（Intrinsic）**：
  - 可靠性预测器：结合 token 状态路径（边缘与草图状态差异）和像素几何路径（原始草图 + 掩码 + 乘积），生成每个 token 的可靠性权重 wrel，用于调制草图来源的注意力 logits。实现上采用零初始化，确保训练初期行为不偏离预训练模型。
  - 空间残差门控：对每个分支、每个块预测门控 gi，控制交叉融合残差的注入强度，输入包括当前状态、候选残差、掩码 token 和全局条件。

- **显式符号草图使用建模（Explicit Signed Sketch-Use Modeling）**：
  - 可选输入：符号图 q ∈[−1,1] 表示“保留”或“纠正”意图，支持图 r∈[0,1] 表示该意图成立的区域，组合为 u=q⊙r。
  - 该信号通过三个途径生效：
    - 零初始化的空间编码器将 [u, r, |u|] 转化为分支特定的 token 嵌入，加在初始状态上；
    - 对草图源 key 的注意力 logits 增加带符号偏置 βu，提高或降低特定草图 token 的被关注程度；
    - 使用正/负两条 LoRA 路径对草图 value 表示进行意图相关的变换，分别对应“保留”和“纠正”需求。

### 2.5 训练目标
- 对 RGB 和边缘两个分支分别使用 **flow matching** 目标，预测速度场。
- 损失函数由 RGB 损失、结构损失和短语一致性损失加权组成。
- 空间权重通过对掩码区域和先验支持区域施加额外权重实现（Wb,i = 1 + ηm mb,i + ηr rb,i）。

### 2.6 训练样本构造
- 使用真实边缘图或其抽取结果（MuGE）生成基础草图：通过平滑变形场和线条控制点抖动模拟用户笔触。
- 随机选取局部区域施加三种模式之一：
  - **正模式**：替换为更忠实于目标结构的笔画（u>0，保留）；
  - **负模式**：更强变形、删减笔画或引入无关结构（u<0，纠正）；
  - **中性模式**：保持基础草图（u=0）。
