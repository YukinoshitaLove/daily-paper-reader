## 摘要
自动人像修图技术发展迅速，但其目标本质上是主观的：同一张人像可以产生多个专业上有效的结果，而用户对于哪个结果最佳意见不一。大多数现有方法优化的是群体层面的美学标准，因此无法捕捉个体品味；而为每位用户微调单独的编辑模型则会导致高昂的训练、存储和数据成本。我们提出PALATE，一个共享的奖励进化框架，它保持图像编辑器固定不变，反而对同一源人像的修图候选进行个性化选择。PALATE将每个用户的奖励分解为所有用户共享的全局主干、美学相似用户共享的类别级残差，以及一个轻量级用户适配器，并通过抗坍塌正则化器保持这三个层级互补。一种循环的双层蒸馏方案首先将用户特定偏好蒸馏为类别奖励，然后将所得的类别级知识整合到全局主干中，并在下一轮进化中重新分配以初始化。通过这种方式，共享初始化逐轮改进，使得新用户仅凭少量排序即可被校准。在来自PPR10K的专家修图候选上，针对留出用户和留出图像，PALATE达到了72.83%的成对偏好预测准确率，超越了所有奖励、美学和图像质量基线，其中最强的基线PickScore达到58.06%。每位新用户仅需512字节的用户特定参数和毫秒级评分。

## Abstract
Automatic portrait retouching has advanced rapidly, yet its objective is inherently subjective: the same portrait admits multiple professionally valid results, and users disagree about which one is best. Most existing methods optimize a population-level aesthetic standard and therefore cannot capture individual taste, while fine-tuning a separate editing model for every user incurs prohibitive training, storage, and data costs. We propose PALATE, a shared reward-evolution framework that keeps the image editor fixed and instead personalizes the selection among retouched candidates of the same source portrait. PALATE decomposes the reward for each user into a global backbone shared by all users, category-level residuals shared by aesthetically similar users, and a lightweight user adapter, with anti-collapse regularizers keeping the three levels complementary.A cyclic dual-level distillation scheme first distills user-specific preferences into category rewards and then consolidates the resulting category-level knowledge into the global backbone, which is redistributed to initialize the next evolution round. In this way, the shared initialization improves progressively across rounds, enabling unseen users to be calibrated from only a few rankings. On expert-retouched candidates from PPR10K with held-out users and held-out images, PALATE attains 72.83% pairwise preference-prediction accuracy, surpassing all reward, aesthetic, and image-quality baselines, of which the strongest, PickScore, reaches 58.06%. Each new user costs only 512 bytes of user-specific parameters and millisecond-level scoring.

- **研究背景**：自动人像修图的目标高度主观——同一张人像可以存在多个专业上均合理的修图结果（如肤色冷暖、磨皮强度、色彩表现不同），不同用户对此的偏好差异显著。现有主流方法通常优化群体层面的美学标准，无法适应个体品味；而通过微调编辑模型实现个性化又面临高昂的训练、存储和数据采集成本。
- **核心问题**：如何在**不动图像编辑器**的前提下，以极低的参数和计算代价，为海量用户提供个性化的修图候选选择，并支持新用户从少量偏好排序中快速校准。
- **整体含义**：PALATE 将个性化从编辑模型转移至**奖励模型**，通过共享奖励进化框架，在固定编辑器的情况下，学习并迭代精化一个共享奖励初始化，不断积累历史用户的偏好知识，实现对新用户的高效适配。

## 2. 论文提出的方法论

### 2.1 核心思想
- **奖励分解**：将用户的个性化奖励分解为三个互补层级：
  - **全局骨干（Global Backbone）**：捕获所有用户共享的美学知识。
  - **类别残差（Category Residual）**：建模美学相似用户群体的偏好模式。
  - **用户适配器（User Adapter）**：编码个体差异化口味。
- **抗坍塌正则化**：通过用户级和类别级几何约束，防止用户表征坍缩到少数主导方向，保证层级结构有意义。
- **循环双重蒸馏（Cyclic Dual-Level Distillation）**：
  - 用户→类别：将个体反馈蒸馏为可复用的类别级偏好知识。
  - 类别→全局：将类别知识整合到全局骨干中，再重新分配作为下一轮初始化的基础。
  - 通过多轮循环，共享初始化不断增强，使未见过用户可从极少排序中快速校准。

### 2.2 关键技术细节
- **偏好监督**：使用排序三元组（ranking triplets）作为低负担的用户交互界面，每个排序生成三对一致的两两比较约束，并避免同源比较在训练/测试分裂间泄漏。
- **奖励表示**：全局骨干输出标量奖励和归一化偏好表示，用户奖励为三者之和：  
  \( R_t^u(x,y) = G_t(x,y) + C_t^{c(u)}(x,y) + e_u^\top h_t(x,y) \)
- **损失函数**：采用 Bradley-Terry 排序损失 \( L_{rank} \) 与 margin 蒸馏距离 \( D_\Delta \)，构成统一的蒸馏-锚定目标：  
  \( J = L_{rank} + \lambda D_\Delta + \mu \Omega(f, f^-) \)
- **用户级正则化**：基于 Bootstrap 潜在码的中心化 + SIGReg 的 Epps-Pulley 正态性偏差，鼓励用户表征多样性。
- **类别级正则化**：用固定锚定集上的 margin 签名构造类别表征，推动其指向正则单纯形（regular simplex）方向，保证类别残差不消失且彼此可区分。
- **安全校准（Safe Calibration）**：对新用户，仅优化低维用户残差，并施加 ℓ2 惩罚和预算相关的收缩因子，避免小样本过拟合；若类别未知，则选择支持集损失最小的类别。

## 3. 实验设计

### 3.1 数据集与Benchmark
- 使用 **PPR10K** 数据集中的 1,000 张人像，每张包含 3 个专家修图结果。
- 25 名志愿者在 5 种美学风格下对每个三元组进行排序，生成 25,000 条排序、75,000 对两两比较。
- 评估协议：**用户-图像双重留出（double held-out）**，即训练/验证/测试用户与图像均不重叠。测试集含 1,200 条排序。
- 支持集取自非查询图像区域，测试时预算 K ∈ {0, 1, 5, 10, 20, 50}。

### 3.2 对比方法
- 美学/质量评估：FGAesQ、CLIP-IQA
- 视觉-语言相似度：CLIP image similarity、SigLIP similarity、CLIPScore
- 人类偏好奖励模型：HPS v2、PickScore
- 编辑专用奖励模型：EditReward（通用提示与用户档案条件提示）
- 另设全局模型、错误类别路由、未约束/零初始化的适配器等消融变体。

### 3.3 主要实验结果
- PALATE 在成对准确率上达到 **72.83%**，Top-1 准确率 65.08%，大幅超过最强基线 PickScore（58.06%）。
- 正确路由比仅用全局模型提升约 1.0 个百分点；错误路由下降约 2 个百分点，证明类别残差编码了有效的群体偏好。
- 安全校准在小样本下保持稳定，而普通适配器随 K 增大会退化。
- 存储与计算成本：全局+类别奖励共 7.31 MiB，单个用户仅 512 字节，批量评分每候选 0.488ms。

## 6. 主要结论与发现

- 将个性化从编辑器转移到奖励选择器可行且高效：固定编辑器条件下，通过层级奖励结构即可实现用户个性化。
- 循环双重蒸馏有效：共享初始化逐轮增强，新用户仅需少量排序即可接近甚至超越零样本水平。
- 抗坍塌正则化是保持层级互补的关键：去除两类正则化后准确率下降 1.58 个百分点。
- 偏好类别语义比初始残差值更重要：打乱类别标签造成的性能下降远超重置类别残差。
- 个性化可以以极低成本扩展：单用户状态仅 512 字节，与其复制大量 reward 模型，不如利用字节级状态完成适配。

## 7. 优点
