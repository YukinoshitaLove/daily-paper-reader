## 摘要
屏幕内容图像通常由文本和图形组成。与自然图像相比，这些人工图像包含大量尖锐但重复的结构。然而，现有的屏幕内容超分辨率工作未能充分利用屏幕内容的特殊特性，在提升模型性能和加速方面仍有很大空间。在本文中，我们提出了PixelSR，一种简单而有效的方法，以提高超分辨率性能，同时具有更快的推理速度。为了提升模型性能，我们在训练阶段通过像素分箱对像素进行分类，以计算内容注意力。具体来说，在将像素分入内容相关的组后，内容注意力从每组内的像素特征中聚合，为每个像素引入内容相关且非局部的感受野。在测试阶段，我们利用屏幕内容的自重复性和冗余性来加速推理，而不损失模型性能。我们将目标高分辨率像素分为三类：唯一像素、重复像素和背景像素，针对每个测试图像。我们对唯一像素进行常规网络处理，并在即时查找表中缓存其预测结果。对于已在唯一像素中出现过的重复像素，我们直接从查找表中检索预测结果，而无需网络处理。对于背景像素，我们使用最近邻算法生成高分辨率像素。即时查找表会被清空，并对下一个测试图像重复上述过程。实验表明，我们的PixelSR在屏幕内容超分辨率中实现了最先进的性能，同时具有更短的推理时间。

## Abstract
Screen content images are generally composed of texts and graphics. Compared to natural images, these man-made images contain a large quantity of sharp but repetitive structures. However, existing works in screen content super-resolution underutilize the special characteristics of screen content, leaving a large room to improve model performance and speed up. In this paper, we propose PixelSR, a simple yet effective method to improve super-resolution performance but with faster inference speed. To improve model performance, we classify pixels via pixel binning to compute content attention in the training phase. Specifically, after binning pixels into content-dependent groups, content attention is aggregated from pixel features within each group to introduce a content-dependent and non-local receptive field for every pixel. In the testing phase, we utilize the properties of self-repetitiveness and redundancy in screen content to speed up inference without the loss of model performance. We divide targeted high-resolution pixels into three types, which are unique pixels, repeated pixels, and background pixels for each test image. We conduct conventional network processing on unique pixels and cache their predictions in the on-the-fly lookup table. For repeated pixels which have appeared in unique pixels, we directly retrieve prediction results from the lookup table without network processing. For background pixels, we use the nearest neighbor algorithm to generate high-resolution pixels. The on-the-fly lookup table is cleaned and repeats the procedure above for the next test image. Experiments show our PixelSR achieves state-of-the-art performance with shorter inference time in screen content super-resolution.

- **现有方法的不足**：
  - 自然图像SR方法（如LIIF、LTE、BTC）基于局部隐式图像函数，感受野局限于最近邻3×3网格，无法有效重建屏幕内容的锐利边缘。
  - 已有高效SR方法（如ClassSR、PCSR）采用子图像或像素分类策略，虽然加速了推理，但**不可避免带来性能下降**。
  - 非局部注意力方法（如CiaoSR）虽可扩大感受野，但像素间相关性的计算成本极高，需要窗口划分，严重拖慢推理速度。
- **核心洞察**：屏幕内容图像具有三个独特性质——**异常锐利的边缘**、**高冗余的背景区域**（单一RGB值无波动）、**高自重复性**（同一图像内像素/图案频繁重复出现）。论文通过统计分析证实：SCI1K数据集中背景块占比20.90%（对比DIV2K的2.08%），重复块占比42.25%（对比DIV2K的3.51%）。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 总体框架
PixelSR从**训练**和**推理**两个阶段分别利用屏幕内容的独特性质，实现性能提升和推理加速的兼顾：
- **训练阶段**：通过像素分箱（Pixel Binning）分类像素，聚合分组特征构建内容注意力，为每个像素引入内容相关且非局部的感受野。
- **推理阶段**：将目标HR像素分为唯一像素、重复像素和背景像素三类，分别采用网络处理、即时查找表检索、最近邻算法，实现加速且不损失性能。

### 2.2 训练阶段：像素分箱与内容注意力

**（1）内容提取器（Content Extractor）**：
- 使用轻量级卷积层生成二维归一化内容分数图（Score Map S），公式为：
  `S = Norm(ReLU(Conv(F_LR)))`
- 其中FLR是编码器输出的特征，维度为H×W×C；S为归一化分数图，维度H×W×1。
- **本质**：内容提取器可视为一个可学习的"边缘过滤器"，由于屏幕内容的边缘（如文字、图表边框）异常锐利，这些像素倾向于分入中心值较高的组。

**（2）软分箱（Soft Binning）技术**：
- 直接硬分箱会阻断梯度回传，因此设计**可微分的软分箱**机制。设定N个均匀分布的分箱中心ci，公式为：
  `ci = vmin + (i − 1/2) · Δ`
- 每个像素对每个分箱的软分配权重为：
  `wi(x,y) = exp(−|S′(x,y) − ci|/τ) / Σj exp(−|S′(x,y) − cj|/τ)`
- 其中τ为温度超参数，控制分配的"硬度"。训练中设置较多分箱（10个）以平滑过渡、防止过拟合，再将多个分箱合并为两个内容组（自然内容组和屏幕内容组）。

**（3）内容注意力聚合**：
- 使用**空间平均池化**对组内散布的像素特征进行聚合（池化对随机位置和任意数量像素均适用）：
  - f1 = pooling(FLR ∗ Σᵢ₌₁ᵖ Mi)，第一内容组（低分数组）的平均特征
  - f2 = pooling(FLR ∗ Σᵢ₌ₚ₊₁ᑫ Mi)，第二内容组（高分数组）的平均特征
- 最终内容注意力图：
  `FCA = f1 ∗ Σᵢ₌₁ᵖ Mi + f2 ∗ Σᵢ₌ₚ₊₁ᑫ Mi`
- 将FCA与原始特征FLR拼接后送入解码器，实现每个像素都获得**覆盖整个图像的、内容相关的无限感受野**。

### 2.3 推理阶段：像素划分与即查查找表

**（1）像素三分类**：
- **背景像素**：最近的3×3 LR patch中9个像素RGB值完全相同。
- **唯一像素**：其（3×3 LR patch RGB值 + 相对距离）组合在整图中唯一。
- **重复像素**：其（3×3 LR patch RGB值 + 相对距离）组合已出现在唯一像素中。

**（2）加速策略**：
- **背景像素**：直接用最近邻算法生成HR像素，完全跳过网络。
- **唯一像素**：用网络常规处理，并将预测结果缓存到**即时查找表（On-the-Fly Lookup Table）**。
- **重复像素**：直接从即时查找表检索结果，无需网络处理。
- 每完成一张测试图像的推理后，清空查找表数据，下一张图像重新构建——保证查找表**针对每张测试图像独特定制**。

**（3）即查查找表的创新性**：
- 与传统查找表不同，即时查找表的缓存数据逐图像变化，利用屏幕内容的自重复性实现加速。
- 实验发现3×3感受野足以加速且无PSNR损失。
- 这是**首个可用于任意尺度SR的查找表方法**，可嵌入LIIF、ITSRN、LTE、BTC等现有方法中。
