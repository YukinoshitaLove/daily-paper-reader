## 摘要
高光谱图像超分辨率旨在重建高分辨率图像，同时保留密集的光谱信息。近年来，基于Mamba的模型通过以线性计算复杂度捕获长距离依赖，在该任务中展现出良好潜力。然而，其因果序列建模要求将二维高光谱特征沿预定义的扫描顺序展开，这破坏了空间邻接性，并限制了上下文信息的有效传播。此外，现有模型的状态空间参数化主要源自通用学习表示，未与高光谱图像的固有特征显式对齐。为解决此问题，我们提出了一种基于解混的光谱与结构提示Mamba框架，称为USP-Mamba，通过成分感知的光谱先验和图像相关的结构提示来调整Mamba状态演化。具体而言，一种基于解混的光谱提示捕获输入图像的全局材料组成，并在整个重建过程中提供持续调节。将其注入Mamba序列并在各层间逐步适应，可引导状态演化朝向成分一致的重建。我们引入了包含空间和频率成分的特征级结构提示，以提供图像相关的局部引导。空间提示促进对结构敏感的状态编码，以实现局部细节保留；频率提示则实现同质区域与高频细节之间的区域自适应转换。最后，互补的希尔伯特和语义引导邻域扫描保持了空间连续性，并增强非局部语义依赖建模。在不同数据集上的大量实验表明，所提方法始终优于代表性方法。

## Abstract
Hyperspectral image super-resolution aims to reconstruct high-resolution imagery while preserving dense spectral information. Recently, Mamba-based models have shown promising potential for this task by capturing long-range dependencies with linear computational complexity. Nevertheless, their causal sequence modeling requires two-dimensional hyperspectral features to be unfolded along predefined scanning orders, which disrupts spatial adjacency and restricts the effective propagation of contextual information. Moreover, state-space parameterization of existing models is predominantly derived from generic learned representations, without explicit alignment with the intrinsic characteristics of the hyperspectral image. To address this issue, we propose an Unmixing-derived Spectral and Structural Prompting Mamba framework, termed USP-Mamba, which adapts Mamba state evolution through composition-aware spectral priors and image-dependent structural prompts. Specifically, an unmixing-informed spectral prompt captures the global material composition of the input image and provides persistent conditioning throughout reconstruction. Injected into the Mamba sequence and progressively adapted across layers, it steers state evolution toward composition-consistent reconstruction. We introduce feature-level structural prompts comprising spatial and frequency components to provide image-dependent local guidance. The spatial prompt promotes structure-sensitive state encoding for local detail preservation, while the frequency prompt enables region-adaptive transitions between homogeneous regions and high-frequency details. Finally, complementary Hilbert and Semantic-Guided Neighboring scans preserve spatial continuity and strengthen non-local semantic dependency modeling. Extensive experiments on different datasets demonstrate that the proposed method consistently outperforms representative approaches.

- **单高光谱图像超分辨率（SHSR）** 旨在从单幅低分辨率高光谱图像重建高分辨率图像，同时保持光谱保真度。

1. **空间邻接性破坏**：Mamba 依赖因果序列建模，需要将二维高光谱特征按预定义扫描顺序展开为一维序列，这会破坏像素间的空间邻接关系，削弱局部信息传播，导致边缘与结构细节在重建中被忽视。
2. **状态参数化缺乏高光谱特定指导**：现有 Mamba 模型的状态空间参数主要从通用学习表示中导出，没有显式对齐高光谱图像的固有特征（如物质成分、光谱相关性），导致冗余光谱响应被无差别传播，对平滑区域和高频细节应用相似的状态转换动力学。

**论文定位：**
针对上述问题，论文提出 **USP-Mamba**——一个高光谱特定的状态空间框架，通过全局光谱调节（composition-aware spectral conditioning）与局部结构调制（local structural modulation）来引导 Mamba 状态演化。

## 2. 方法论：核心思想与关键技术

### 2.1 整体架构

USP-Mamba 包含四个主要组件：
1. **解混谱提示生成器（Unmixing-derived Spectral Prompt Generator）**
2. **浅层特征提取模块（Shallow Feature Extraction）**
3. **深度提示条件状态空间骨干（Deep Prompt-conditioned State-space Backbone）**
4. **高分辨率重建模块（High-resolution Reconstruction Module）**

### 2.2 核心思想

> 将高光谱特有的解混先验（物质组成）和图像相关的结构先验（空间/频率特征）注入 Mamba 的状态演化过程，实现**成分一致**与**结构自适应**的重建。

### 2.3 关键技术细节

**(1) 解混谱提示（Unmixing-Derived Spectral Prompt）**
- 利用线性混合模型估计 `K` 个端元（endmembers）`E ∈ R^{K×C}` 和丰度图（abundance maps）`A ∈ R^{H×W×K}`。
- 将丰度图空间聚合后，通过丰度加权端元聚合得到全局光谱先验 `v_s`，经 MLP 获得谱提示 `p_s`。
- 谱提示**逐层适应**：每层通过可学习的深度嵌入和残差缩放，将共享谱提示调整为层级特定的 `p_s^l`。
- 该提示作为"光谱前缀标记"注入扫描序列，建立成分条件的初始状态 `h_0`，在整个重建过程中提供持续调节。

**(2) 图像相关结构提示（Image-Dependent Structural Prompts）**
- **空间提示 `P_spa`**：通过 7×7 卷积从中间特征生成，保留位置相关的几何线索，强调边界与细节。
- **频率提示 `P_fre`**：通过 FFT → 可学习复滤波器加权 → IFFT → 卷积与 Sigmoid 生成，捕捉区域频率变化，区分同质区域与高频细节。
- 两者共同提供图像相关的局部结构引导。

**(3) 提示引导状态空间建模（Prompt-Guided State-Space Modeling, PGSSM）**
- 采用**两种互补扫描策略**：
  - **Hilbert 扫描**：保持空间连续性，促进局部几何信息传播。
  - **语义引导邻域扫描（SGN）**：将语义相似的像素重排到邻近序列位置，捕获非局部语义依赖。
- 层适应谱提示同时前置注入两种扫描序列。
- 状态空间参数（`B`, `C`, `Δ`）由当前特征线性预测，随后被结构提示调制：
  - **空间提示** 调制状态编码参数 `B`（结构自适应状态编码）；
  - **频率提示** 调整转移间隔 `Δ`（区域自适应状态更新率）；
  - **二者联合** 调节状态读出参数 `C`（选择性状态解码）。
- 两条扫描路径的输出经逆序后融合（通道拼接 + 线性投影）。

**(4) 损失函数**
`L = L1 + λ_sam · L_sam + λ_grad · L_grad + λ_unm · L_unm`
- `L1`：重建损失；`L_sam`：光谱角损失；`L_grad`：梯度损失；`L_unm`：解混重建损失（约束解混分支）。

## 6. 主要结论与发现

1. **解混先验有效提升光谱重建**：解混谱提示将物质组成信息注入状态传播，显著降低光谱失真（SAM 大幅下降，Chikusei ×4 从 2.48+ 降至 2.3779）。
2. **结构提示增强细节重建**：空间与频率提示联合调节状态编码与转换，使模型对同质区域和高频细节差异化处理，PSNR 和 SSIM 均获得提升。
3. **互补扫描策略带来增益**：Hilbert 扫描保空间连续性，SGN 扫描增强非局部语义建模，二者组合优于任何单一扫描方式。
4. **整体性能领先**：在 Chikusei 和 Houston2018 上 ×4 与 ×8 四组设置中，USP-Mamba 在 PSNR、SSIM、SAM、CC、ERGAS 五指标上均取得最佳或第二佳（几乎全部最佳）。

**具体关键数据：**
- Chikusei ×4：PSNR 40.2282 dB（比第二名高 0.2485 dB）、SAM 2.3779；
- Chikusei ×8：SAM 4.1261（最低）；
- Houston2018 ×4：PSNR 46.4433 dB；
- Houston2018 ×8：SAM 3.6124（最低）；
- 消融中全体提示联合使用比单独的 USPS 高约 0.2 dB PSNR，比基线高约 0.34 dB。

## 7. 方法优点（亮点）

1. **提出新颖的解混提示范式**：将高光谱经典物理模型（光谱解混）与深度学习状态空间模型结合，将物质组成先验作为持久调节信号注入 Mamba，使状态演化与图像固有属性对齐。这是对现有 Mamba 视觉模型中"通用学习提示"的重要改进。
2. **具有理论解释性**：端元估计与丰度聚合提供了明确的物理意义，谱提示的生成过程可被清晰解释，而不是黑盒的可学习参数。
3. **空间-频率双域结构提示设计精巧**：分别作用于不同状态参数（B、Δ、C），实现"编码-转换-读出"三个层面的结构自适应，分工明确且互补。
4. **Hilbert + SGN 的互补扫描**：针对 Mamba 因果序列建模破坏空间邻接的核心缺陷，从两个维度（局部连续性与非局部语义）展开解决方案，并验证了组合有效性。
5. **消融实验设计清晰**：6 组提示消融 + 3 组扫描消融，逐步验证各组件贡献，说服力较强。
6. **多指标全面评测**：涵盖空间（PSNR/SSIM）与光谱（SAM/CC/ERGAS）5 个指标，并辅以误差图与光谱曲线分析。
