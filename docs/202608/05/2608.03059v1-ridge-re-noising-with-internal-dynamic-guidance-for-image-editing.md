## 摘要
基于无反转流的图像编辑避免了潜在反转，但在每个编辑步骤仍需要目标侧状态。广泛使用的等位移构造在噪声水平间保持带噪源状态与目标侧状态之间的位移不变。这与加噪过程不一致，因为在加噪过程中，两个干净状态在相同噪声水平和噪声样本下加噪后，其位移应随噪声水平增加而收缩。因此，这可能导致在高噪声水平下更新过于激进。我们提出RIDGE：基于内部动态引导的重新加噪图像编辑方法，这是一种无反转且无需训练的方法，将编辑状态保持为对不可得的干净目标状态的演化近似。RIDGE使用与干净源状态相同的噪声水平和噪声样本对该近似重新加噪，使其带噪位移随噪声增加自然减小。由于编辑状态最初包含有限的目标语义，RIDGE在早期高噪声步骤进一步应用内部动态引导。干净目标状态预测通过模型内部导出的软动态掩码引导临时编辑状态，将引导聚焦于需要修改的区域，无需外部分割或检测模型。在两个基准上使用两个主干网络SD3 Medium和FLUX.1-dev的实验表明，RIDGE在源保真、目标对齐和感知质量之间提供了良好的综合权衡。

## Abstract
Inversion-free flow-based image editing avoids latent inversion, but still requires a target-side state at every editing step. The widely used equal-displacement construction keeps the displacement between the noisy source state and the target-side state unchanged across noise levels. This is inconsistent with noising, under which the displacement between two clean states noised with the same noise level and noise sample should contract as the noise level increases. Thus, it can lead to overly aggressive updates at high noise levels. We introduce RIDGE: Re-Noising with Internal Dynamic Guidance for Image Editing, an inversion-free and training-free method that maintains the edited state as an evolving approximation to the unavailable clean target state. RIDGE re-noises this approximation using the same noise level and noise sample as the clean source state, allowing their noisy displacement to decrease naturally with increasing noise. Since the edited state initially contains limited target semantics, RIDGE further applies internal dynamic guidance during the early high-noise steps. A clean target state prediction guides the provisional edited state through a soft dynamic mask derived internally from the model, focusing guidance on regions that require modification without external segmentation or detection models. Experiments on two benchmarks using two backbones, SD3 Medium and FLUX.1-dev, show that RIDGE offers a favorable aggregate trade-off among source preservation, target alignment, and perceptual quality.

- **核心挑战**：早期基于反转（inversion-based）的方法能够将源图像映射到噪声潜在空间，但反转过程耗时且易引入重建误差。免反演（inversion-free）方法虽然绕过了反转，却需要在每个编辑步骤构造一个“目标侧状态”（target-side state）用于计算目标提示速度，而该状态无法从真实目标图像直接获得。
- **现有缺陷**：广泛使用的“等位移构造”（equal-displacement construction）将带噪源状态与目标侧状态之间的位移在不同噪声水平下保持不变。但这一做法与加噪过程的收缩性质相矛盾——两个干净状态在相同噪声水平和噪声样本下被加噪后，它们之间的位移应随噪声水平增加而收缩，并在纯噪声端点趋于零。因此，等位移构造在高噪声步骤会使目标侧状态偏离带噪源状态过远，导致速度差更新过于激进，产生不期望的编辑。

## 2. 方法论

- **核心思想**：RIDGE 将当前编辑状态视为不可得干净目标状态的一个演化近似，并用与干净源状态相同的噪声水平和噪声样本对该近似重新加噪，从而得到目标侧状态。这种方式使带噪位移随噪声增加自然收缩，而非保持恒定。
- **重新加噪构造（Re-noising Construction）**：
  - 编辑窗口设定为 \( t_{\min} < t_i \le t_{\max} \)，初始编辑状态为干净源状态 \( Z^{\text{src}}_0 \)。
  - 在每一步 \( t_i \) 采样共享噪声 \( \eta_{t_i} \sim \mathcal{N}(0, I) \)，分别加噪源状态和当前编辑状态：
    \[
    Z^{\text{src}}_{t_i} = (1-t_i)Z^{\text{src}}_0 + t_i\eta_{t_i},\quad
    Z^{\text{tgt}}_{t_i} = (1-t_i)Z^{\text{edit}}_{t_i} + t_i\eta_{t_i}
    \]
  - 两者的位移满足 \( Z^{\text{tgt}}_{t_i} - Z^{\text{src}}_{t_i} = (1-t_i)(Z^{\text{edit}}_{t_i} - Z^{\text{src}}_0) \)，即位移随噪声水平下降（\( 1-t_i \) 因子）。
  - 计算目标提示速度与源提示速度之差 \( \Delta v_{t_i} \)，并按欧拉步更新得到临时编辑状态 \( \tilde{Z}^{\text{edit}}_{t_{i+1}} \)。
- **内部动态引导（Internal Dynamic Guidance）**：
  - 在早期高噪声步骤，编辑状态包含的目标语义有限，需要对临时编辑状态进一步修正。
  - 首先用目标分支预测干净目标状态：\( \hat{Z}^{\text{tgt}}_0(t_i) = Z^{\text{tgt}}_{t_i} - t_i v_\theta(Z^{\text{tgt}}_{t_i}, c_{\text{tgt}}, t_i) \)。
  - 计算预测与源状态之间的逐通道平均绝对残差得到空间差图 \( D_{t_i} \)，再以 \( q \)-分位数作为自适应阈值，经 sigmoid 生成软动态掩码 \( m_{t_i} \)：
    \[
    m_{t_i} = \sigma\left( \frac{D_{t_i} - \phi_{t_i}}{\tau} \right)
    \]
  - 引导更新为：\( Z^{\text{edit}}_{t_{i+1}} = \tilde{Z}^{\text{edit}}_{t_{i+1}} + \gamma_{t_i} m_{t_i} \odot (\hat{Z}^{\text{tgt}}_0(t_i) - \tilde{Z}^{\text{edit}}_{t_{i+1}}) \)，其中 \( \gamma_{t_i} = \lambda_{\text{guide}}/(1 - \beta_{\text{guide}} t_i) \) 使引导强度随噪声水平递减。
  - 该引导是“内部”的：预测与掩码均由编辑模型自身产生，无需外部分割或检测模型。
- **算法流程（文字描述）**：初始化编辑状态为源状态；在编辑窗口内循环：采样共享噪声 → 构造带噪源状态和目标侧状态 → 计算速度差并更新到临时编辑状态 → 若处于引导窗口则预测干净目标状态并施加软掩码引导，否则直接用临时编辑状态；完成所有编辑步骤后，在目标提示下继续完成剩余去噪步骤，输出最终编辑结果。
- **避免循环依赖**：使用“一步延迟”的预测，即用当前步的干净目标预测引导下一步的临时编辑状态，避免同一步内的循环依赖。

## 6. 主要结论与发现

- 论文从理论上指出等位移构造与加噪过程不一致，并用推导展示带噪位移应随噪声水平收缩。
- 重新加噪 + 内部动态引导的 RIDGE 在两个基准、两个骨干上实现了较好的综合表现：在 SD3 下，RIDGE 的 Avg Score 在 PIE-Bench Official 和 PIE-Bench++ 上均排名第一；DINO 距离和 StructDist 等源保留指标也处于领先。
- 消融实验表明：重新加噪本身偏保守（源保留强但目标对齐较弱）；全局引导能提升目标对齐但明显损害源保留；软动态掩码能在仅小幅降低 CLIP 的情况下恢复源保留，从而验证了其“引导增强编辑强度、掩码聚焦相关区域”的分工。
- 人类偏好研究中，RIDGE 在目标对齐和源一致性两个维度上平均排名最低、Top-1 率最高（分别为 58.0% 和 68

），而全局其余模型的 Top-1 率均在 20% 以下。这进一步佐证了该方法在真实用户感知上的优势。
- 干净目标预测演化诊断显示，RIDGE 的预测轨迹在编辑过程中稳定性更好、相邻预测距离更小，表明重新加噪构造能有效抑制高噪声步骤中的剧烈跳跃，使编辑过程更平滑可控。
- 综上，论文的核心立场是：免反演流式编辑的“目标侧状态”不应由恒定位移构造，而应随噪声水平自然收缩；在此基础之上，结合软掩码引导可以弥补保守性，最终在保持源图结构的同时实现对目标提示的忠实执行。

## 7. 局限性与未解决问题

- **对噪声样本的依赖**：RIDGE 在每一步使用与源状态相同的噪声样本构造目标侧状态，这意味着最终采样结果对初始噪声路径较为敏感；虽然实验显示稳定性优于基线，但理论上的噪声鲁棒性并未被严格刻画。
- **编辑类型不对称**：实验表明 RIDGE 在“删除类”等需要大幅去除源内容的任务上相对保守，可能因目标侧状态与源状态共享大量结构而导致删除不彻底；论文并未给出针对此类任务的特化处理。
- **通用性验证不完整**：FLUX.1-dev 下的实验只覆盖了有限的基线和编辑场景，且未包含多对象、多属性的 PIE-Bench++；因此 RIDGE 对更强骨干的适用性仍有待进一步验证。
- **超参数敏感性**：引导窗口 \( t_{\min}^{g} \)、强度系数 \( \lambda_{\text{guide}} \) 和 \( \beta_{\text{guide}} \) 等超参数需要针对不同骨干或任务微调，论文虽给出扫描实验，但未提供自适应选择机制。
- **计算开销**：由于每个编辑步骤需要同时运行源提示与目标提示两个速度预测分支（部分步骤还需额外预测干净目标状态以计算引导），实际推理成本约为主干模型的两倍左右；论文未与基线进行系统性的时间对比，因此其端到端效率优势（主要是省去反转）尚缺少量化证据。
- **理论深度与范围**：论文对等位移构造的批判建立在线性加噪（time-independent shrinkage）假设之上，但其结论是否对连续时间流匹配、不同调度器或非线性噪声过程仍然成立，未给出一般性理论证明。

## 9. 个人点评与延伸思考

- **方法论贡献的实质**：RIDGE 的贡献并不在于提出新的扩散模型或新的训练目标，而在于对免反演编辑中一个看似“理所当然”的构造（目标侧状态）进行了重新审视。这种“重新加噪”的物理直觉简单且可解释，使其具有很强的推广潜力——任何基于流匹配的免反演编辑框架都可以直接套用这一构造。
- **技巧与本质的权衡**：内部动态引导虽在一定程度上提升了目标对齐，但它引入了多个需要手工调节的超参数（引导窗口、强度、掩码温度），削弱了方法“简洁”的叙事。若能从理论上推导出最优引导强度随噪声水平的闭式表达，该方法的优雅性将更上层楼。
- **与训练式方法的对比**：与近年来出现的训练式编辑模型（如基于指令跟随的端到端编辑）相比，RIDGE 作为免训练方法避免了训练数据偏差和模型特定性问题，但也因此在复杂语义操作（如理解“让这个人看起来像某某名人”）上天然受限。未来工作或可将其重新加噪思想引入训练流程，或作为强正则项提升编辑一致性。
- **替代思路的开放性**：除 RIDGE 的位移收缩方案外，是否也存在其他符合加噪物理的构造？例如对目标侧状态进行动态“去噪-再加噪”循环，或采用随机微分方程的解耦路径；RIDGE 只探索了最直接的一种，相关设计空间仍有大量未开发区域。
- **潜在应用场景**：除图像编辑外，该思想可迁移至视频编辑（多帧间保持位移一致性）、属性可控生成（如类条件流匹配中条件分支的状态构造）以及多模态编辑（文本+图像联合引导）。每个方向的适配都需要重新定义“目标侧状态”的语义，但底层原则（状态随噪声收缩）具有通用性。
- **总体评价**：这是一篇思路清晰、实验扎实、写作规范的论文，核心洞察简洁有力。在免反演编辑这个近年快速发展的方向上，RIDGE 提供了一个立足点清晰、可复现的强基线，也为后续研究指明了改进方向。
