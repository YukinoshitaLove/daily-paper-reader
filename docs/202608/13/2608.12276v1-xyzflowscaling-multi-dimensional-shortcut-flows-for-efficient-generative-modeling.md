## 摘要
高保真图像生成面临速度与质量之间的权衡。扩散模型能产生强大的视觉效果，但需要昂贵的迭代采样。现有的高效方法主要将预训练模型蒸馏为少步采样器，这是一个依赖教师模型质量的困难过程。在本文中，我们引入了XYZFlow，一个通过多维缩放流匹配来重新思考高效生成的框架。与单步映射不同，XYZFlow通过结构化多维条件使概率路径更可识别和可学习，从而增强表达能力。我们将自回归建模视为隐式流拉直，其中更丰富的上下文减少了轨迹模糊性。XYZFlow通过两个正交维度实现这一思想：时间缩放，利用完整去噪历史的非马尔可夫条件；以及空间缩放，由下一步捷径预测实现，该预测使用先前补丁的去噪轨迹作为先验来顺序生成补丁。实验表明，XYZFlow实现了最先进的性能，具有7.2-8.5倍的教师加速和竞争力的FID，而下一步捷径预测在模型缩放或步数减少方面提供了更优的质量-延迟权衡。

## Abstract
High-fidelity image generation faces a trade-off between speed and quality. Diffusion models produce strong visuals but require costly iterative sampling. Existing efficient methods mainly distill pretrained models into few-step samplers, a challenging process that depends heavily on teacher-model quality. In this paper, we introduce XYZFlow, a framework that rethinks efficient generation through multidimensional scaling of flow matching. Unlike single-step mappings, XYZFlow enhances expressivity by making probability paths more identifiable and learnable through structured multidimensional conditioning. We view autoregressive modeling as implicit flow straightening, where richer context reduces trajectory ambiguity. XYZFlow realizes this idea through two orthogonal dimensions: temporal scaling, which uses non-Markovian conditioning on the full denoising history; and spatial scaling, enabled by Next Shortcut Prediction, which sequentially generates patches using preceding patches' denoising trajectories as priors. Experiments show that XYZFlow achieves state-of-the-art performance, with 7.2-8.5X teacher speedups and competitive FID, while Next Shortcut Prediction delivers superior quality-latency trade-offs over model scaling or step reduction.

## 2. 论文提出的方法论

### 2.1 核心思想：多维缩放（Multidimensional Scaling）流匹配
- 与现有“蒸馏算法改进”的 **外在缩放（extensive scaling）** 不同，XYZFlow 采用 **内在缩放（intensive scaling）**，即通过结构化、多维度的条件化来增强概率流表达能力，使去噪轨迹更唯一、更易拟合。

### 2.2 两个正交缩放维度
1. **时间缩放（Temporal Scaling）**：
   - 将去噪过程从 Markovian 变为 non-Markovian，每个时间步都条件于该 patch 从初始状态到当前时刻的完整历史轨迹 \(H_t^p = \{x_\tau^p\}_{\tau=0}^{t-\Delta t}\)。
   - 通过 KV cache 管理历史状态，作为“时间坐标系”锚点，稳定生成路径。
2. **空间缩放（Spatial Scaling）**：
   - 提出 **Next Shortcut Prediction**：将图像划分为 patch 网格（如 \(2 \times 2\) 或 \(4 \times 4\)），逐 patch 生成。
   - 与传统逐 patch 预测只利用之前 patch 的最终输出不同，XYZFlow 显式地将之前 patch 的**完整去噪轨迹** \(T_{<p} = \{\tau^1,\tau^2,\dots,\tau^{p-1}\}\) 作为后续 patch 的条件先验，从而提供更丰富的约束。

### 2.3 关键技术细节与公式
- **条件分布建模**：
  \[
  p(x_0^p | T_{<p}) = p_{\text{prior}}(x_{T(p)}^p) \times \prod_{t=1}^{T(p)} p(x_{t-1}^p | x_{T(p):t}^p, T_{<p})
  \]
  其中 \(x_{T(p):t}^p\) 表示该 patch 的历史去噪轨迹。
- **渐进去噪步数调度**：
  \[
  T(p) = T_{\text{full}} - \Delta T \cdot (p-1), \quad T(p) \ge T_{\min}
  \]
  越早生成的 patch 使用越多去噪步数，越晚的 patch 使用越少步数（“捷径”），从而整体加速。
- **学生网络的单步 Euler 更新**：
  \[
  x_{t-1}^p = G(x_{T(p):t}^p, T_{<p}, t) = x_t^p + (\gamma(t-1)-\gamma(t)) \cdot v_\theta(x_{T(p):t}^p, t, T_{<p})
  \]
- **训练目标（Next Shortcut Prediction Loss）**：
  \[
  \mathcal{L}_{\text{NSP}} = \mathbb{E}_{p \sim [1,P]} \left[ \sum_{t=1}^{T(p)} \left\| G_\theta(x_{T(p):t}^p, t, T_{<p}) - x_{t-1}^p \right\|^2 \right]
  \]
  该损失直接回归教师模型的 ODE 轨迹，同时融合时间和空间条件。
- **注意力掩码**：采用分块因果注意力（block-wise causal attention），使模型能够在一次前向中同时看到全部历史轨迹。
- **对抗微调**：可选地添加判别器损失，基于真实数据监督最终生成 patch，提升高频细节。

- XYZFlow 在 ImageNet 256×256 上取得 SOTA 级别的效率-质量权衡：相比教师模型可实现 **7.2–8.5× 加速**（不同尺度的 Table 中显示 4.0–9.9× 不等的加速比），FID 保持竞争力。

- 多维多条件化（时间+空间）能够有效拉直概率流轨迹，减少去噪路径的模糊性和方差。
- 渐进步数调度（5→4→3→2）相比常数 5 步策略，在保持 FID 不变（1.63 vs. 1.63）的同时减少 30% 的推理步数。
- 对抗损失（GAN）可以在流拉直的基础上进一步提升所有尺度的生成质量（FID 进一步降低约 0.4–0.6）。
- 即使使用弱教师（DiT/XL-2），XYZFlow 的性能仍显著优于普通蒸馏，说明其增益源于提出的时空架构本身，而非教师模型的强度。
- 整体结论：**缩放条件维度（constraint dimensionality）** 而非单纯加大模型或增加蒸馏步数，是高效高保真生成的一条可行且有效的新路径。
