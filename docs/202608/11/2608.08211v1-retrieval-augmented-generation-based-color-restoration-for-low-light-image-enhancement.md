## 摘要
近期低光图像增强（LLIE）方法已将亮度和结构保真度提升至接近正常曝光图像的水平，但其输出仍存在系统性色彩偏移，如天空泛绿、人脸泛黄、白色物体偏暖。我们将其归因于端到端LLIE训练将亮度、结构和颜色耦合在单一网络中，导致颜色通道监督不足。我们将颜色恢复重构为一个独立的子问题，并将其从亮度增强中解耦，实现为一种基于检索增强生成（RAG）的通用后处理模块。该模块不依赖训练期间学习的参数化颜色先验，而是从外部高质量颜色知识库中动态检索参考图像，并将其颜色分布注入颜色恢复网络以纠正残余偏差。该设计包含三个组件：（i）基于中间VGG19特征的双索引FAISS检索器，通过全局均值与方差统计捕捉纹理和结构相似性；（ii）GlobalSPHistAdaIN，将参考图像的空间保持颜色直方图压缩为全局颜色向量，并通过自适应实例归一化调制网络特征，消除对像素级对应的依赖；（iii）残差公式，在前端输出上预测颜色校正。在LOLv1、LOLv2-Real和LOLv2-Synthetic上，该模块持续改善颜色特定指标，且当前端在CPGA-Net++、LLFormer、FLIGHTNet和IAT之间切换时仍保持有效，证实了跨前端通用性。消融实验表明，VGG19双索引优于基于CLIP的检索，说明颜色恢复依赖纹理和结构相似性而非高层语义。

## Abstract
Recent low-light image enhancement (LLIE) methods have driven brightness and structural fidelity close to that of normally-exposed images, yet their outputs still exhibit systematic color shifts such as greenish skies, yellowish faces, and warm-tinted white objects. We attribute this to end-to-end LLIE training coupling brightness, structure, and color within a single network, leaving the color channels weakly supervised. We recast color restoration as an independent sub-problem and decouple it from brightness enhancement, realizing it as a general-purpose post-processing module built on retrieval-augmented generation (RAG). Rather than relying solely on parametric color priors learned during training, the module dynamically retrieves a reference image from an external high-quality color knowledge base and injects its color distribution into a color-restoration network to correct residual bias. The design has three components: (i) a dual-index FAISS retriever built on intermediate VGG19 features, capturing textural and structural similarity through global mean and variance statistics; (ii) GlobalSPHistAdaIN, which reduces the reference spatial-preserving color histogram to a global color vector and modulates network features via adaptive instance normalization, removing dependence on pixel-level correspondence; and (iii) a residual formulation that predicts a color correction over the front-end output. Across LOLv1, LOLv2-Real, and LOLv2-Synthetic, the module consistently improves color-specific metrics, and it remains effective when the front end is swapped among CPGA-Net++, LLFormer, FLIGHTNet, and IAT, confirming cross-front-end generality. Ablations show that a VGG19 dual index outperforms CLIP-based retrieval, indicating that color restoration depends on textural and structural similarity rather than high-level semantics.

# 基于检索增强生成的低光图像增强颜色恢复：论文总结

## 1. 核心问题与研究动机

**问题背景：**
- 现有低光图像增强（LLIE）方法在亮度和结构恢复上已接近正常曝光图像水平，但输出仍存在系统性色偏——天空泛绿、人脸泛黄、白色物体偏暖。
- 作者将这一现象归因于端到端LLIE训练的固有缺陷：亮度、结构和颜色在单一网络中被耦合训练，颜色通道获得的监督信号远弱于亮度通道。
- 像素级损失（L1/L2）对亮度更敏感，感知损失（LPIPS）关注纹理与结构而非色彩精度，导致颜色偏差在整个训练过程中被系统性弱化。

**核心主张：**
- 颜色恢复应被重构为独立于亮度增强的子问题，而非端到端管线中的隐式副产物。
- 借鉴NLP中的检索增强生成（RAG）范式：模型不应仅依赖训练中吸收的参数化颜色先验，而应在推理时从外部高质量图像知识库中动态检索参考图像，并将其颜色分布作为条件先验注入网络，以校正残余色偏。

## 2. 方法论

### 2.1 整体框架：两阶段系统

- **Stage 1 — 亮度增强前端**：使用冻结的预训练LLIE模型（CPGA-Net++为主），将低光图像 `I_low` 增强为亮度恢复图像 `I'`，随后转换到Lab色彩空间，分离出亮度通道 `L` 和色度通道 `ab`。
- **Stage 2 — RAG颜色恢复模块**：由三个子模块组成——参考图像检索、颜色向量提取、颜色残差预测，核心公式如下：
  ```
  ab_hat = ab + Δab_hat         （残差叠加）
  I_hat = Lab2RGB(L, ab_hat)    （最终输出）
  ```

### 2.2 核心组件一：双索引FAISS检索器

- 使用ImageNet预训练的VGG19（冻结权重）提取 relu3_4 层特征（256通道）。
- 对每幅图像计算**全局均值向量** `m_i`（描述纹理风格）和**全局方差向量** `v_i`（描述局部结构与对比度变化），并分别进行L2归一化。

  ```
  m_i = (1/H'W') Σ F_i(·, h, w)
  v_i = (1/H'W') Σ (F_i(·, h, w) − m_i)²
  ```

- 将DIV2K（800张）作为外部知识库，分别构建**纹理索引**（Index m）和**结构索引**（Index v），使用FAISS的IndexFlatIP（精确搜索，内积等价于余弦相似度）。
- 查询时对两个索引分别返回候选集，通过加权重排合并分数：
  ```
  score_j = α · score_m,j + β · score_v,j   （α=β=0.5）
  ```
- 取Top-k=1作为最终参考图像。

### 2.3 核心组件二：GlobalSPHistAdaIN

- **SPHist（空间保持颜色直方图）**：将参考图像的 `a`、`b` 色度通道通过高斯软分配变换为可微分的空间直方图（256个bin/通道），拼接为512维张量，经全局平均池化得到512维颜色向量 `c`。
- **AdaIN注入**：对编码器每层（Dense Block输出）的特征图 `f_i`，由颜色向量通过全连接层生成每通道的缩放参数γ和偏移参数β：
  ```
  AdaIN(f, γ, β) = γ · (f − μ(f))/σ(f) + β
  γ_i = W_γ,i · c + b_γ,i
  β_i = W_β,i · c + b_β,i
  ```
- 关键设计：该模块**完全不需要像素级空间对应**，解决了跨数据集场景中参考图与输入场景不一致时，空间对齐方法可能造成的颜色错误注入问题。

### 2.4 核心组件三：残差学习

- 网络输入为 `cat(L, ab)`（亮度通道+前端初始色度通道），输出为颜色残差 `Δab_hat`，而非直接预测完整颜色。
- 优点：当残差趋近零时，结果接近前端输出，保留前端已有的合理颜色；在跨数据集场景下显著提升泛化稳定性。
- 训练目标函数：
  ```
  L_total = λ_L1·L_L1 + λ_hist·L_hist + λ_SSIM·L_SSIM + λ_perc·L_perc
  ```
  其中直方图损失（EMD，基于CDF的均方误差）同时约束输出接近GT和参考图像的颜色分布。

### 2.5 网络结构

- 编码器：DenseNet-121 U-Net（block配置6/12/24/48，growth rate=32），四个GlobalSPHistAdaIN模块分别注入到四个dense block的输出。
- 解码器：五个Up模块（RDB+双卷积），包含跳跃连接，输出2通道残差。

1. **有效性**：以CPGA-Net++为前端时，LOLv1上PSNR从22.24→22.53 dB，ΔE2000从8.91→8.40，MAE_ab从5.27→4.71，颜色指标改善幅度明显大于亮度指标。

4. **残差学习对跨数据集泛化至关重要**：直接预测在LOLv1上虽然略优（ΔE2000 8.30 vs 8.40），但在LOLv2-Real上崩溃（PSNR降1.69 dB），残差学习则稳定保持增益。

6. **彩色恢复需要动态的外部先验**：去除检索路径的后处理网络（仅靠训练集统计）甚至略差于基线，说明颜色先验无法静态存储于权重中。

## 7. 方法优点

1. **问题解耦视角**：将颜色恢复从端到端LLIE中独立出来，明确识别了现有方法在颜色通道上的系统性缺陷，并用专门的指标和设计来弥补，填补了LLIE评估中颜色维度长期被忽视的空白。
2. **RAG在低层视觉中的成功迁移**：将原本用于NLP的RAG范式扩展到图像颜色恢复，且通过实证证明了"外部知识库+检索+条件注入"的范式在低层视觉任务中的可行性。
3. **无需空间对齐的注入机制**：GlobalSPHistAdaIN将参考图压缩为全局颜色向量，从根本上规避了跨场景参考图与输入不对齐的难题，同时大幅降低了计算开销。
4. **工程上实用**：前端冻结、知识库可随时替换而无需重新训练，知识库替换只需重建索引，具有良好的模块化和可扩展性。
5. **实验严谨**：对检索策略进行了细致比较，直接回应了"用什么相似度度量更合适"的开放问题；用"随机参考"和"无检索"作为对照，证明了检索的实际贡献。

## 8. 不足与局限

1. **合成数据上的表现有限**：在LOLv2-Synthetic上增益很小甚至出现PSNR/SSIM轻微下降，因为合成数据的颜色偏差本身极小，参考库（DIV2K自然图像）与合成分布不匹配时可能引入不必要修正。作者建议此类合成集不适合作为颜色恢复模块的主要评测基准。
2. **知识库分布偏见**：DIV2K偏向风景和建筑，对工业检测、医学影像、夜间城市监控等专业场景覆盖不足，限制了在特定领域中的应用效果。
3. **Top-1检索的脆弱性**：只用单一参考图，结果依赖单次检索质量；若检索到不合适的参考，可能产生错误的颜色引导。
4. **计算开销大**：颜色恢复网络84M参数、853 GFLOPs，远高于轻量前端（如CPGA-Net++的28.94 GFLOPs），距离实时应用尚有差距；参数量和计算量集中在校色网络而非检索，优化方向明确但尚未解决。
5. **无参考数据的NIQE下降**：所有无参考数据集上NIQE均略有上升（平均+0.099），提示颜色校正可能在扰动自然统计特性方面存在代价，需要结合多个指标综合评判。
