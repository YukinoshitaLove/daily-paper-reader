## 摘要
文本引导的扩散图像编辑旨在修改图像的语义属性，同时保持其身份、布局和背景。然而，在采样过程中直接切换文本条件通常会导致全局漂移，因为去噪动态会在令牌间传播变化，并可能破坏未编辑区域。为了解决这个问题，我们提出了异步令牌解码编辑（ATDEdit），这是一种推理时框架，将每个采样步骤视为全局耦合令牌矩阵的并行更新，并支持通过不同化的更新策略进行令牌索引条件切换。ATDEdit不将同步目标条件更新应用于所有令牌，而是使用逐令牌条件意外度估计可编辑位置，并将目标条件修正应用于所选令牌集。它在保持令牌位置提供源键/值记忆，并将选中的保持令牌潜在行投影回其源值；这些操作促进背景保留，但并不构成像素级不变性保证。在PIE-Bench上，ATDEdit实现了最强大的报告保留度量，包括27.44 dB PSNR和0.055 LPIPS，同时保持了有竞争力的语义对齐。

## Abstract
Text-guided diffusion image editing aims to modify semantic attributes of an image while preserving its identity, layout, and background. However, naïvely switching the text condition during sampling often causes global drift, as denoising dynamics propagate changes across tokens and can disrupt unedited regions. To address this issue, we propose \textbf{A}synchronous \textbf{T}oken \textbf{D}ecoding \textbf{Edit} (ATDEdit), an inference-time framework that views each sampler step as a parallel update of a globally coupled token matrix and enables token-indexed condition switching with differentiated update policies. Instead of applying synchronous target-conditioned updates to all tokens, ATDEdit estimates editable locations using token-wise conditional surprisal and applies target-conditioned corrections to the selected token set. It supplies source key/value memory at keep-token positions and projects selected keep-token latent rows back to their source values; these operations promote background preservation but do not constitute a pixel-level invariance guarantee. This approach combines local editing and background preservation without external or user-provided spatial masks and without model fine-tuning. On PIE-Bench, ATDEdit achieves the strongest reported preservation metrics, including 27.44~dB PSNR and 0.055 LPIPS, while retaining competitive semantic alignment.

## 1. 核心问题与整体含义

- **研究背景**：文本引导的图像编辑旨在根据自然语言指令修改图像的语义属性（如类别、颜色、表情），同时保持身份、布局和背景不变。近年来，扩散 Transformer（DiTs）逐渐替代 U-Net，成为高质量图像生成与编辑的主流架构；基于流匹配（Rectified Flow）的编辑方法（如 FlowEdit）将扩散过程视为确定性 ODE 运输，理论上可精确映射源潜在到目标状态。
- **核心问题**：现有轨迹类编辑方法通常将去噪过程视为**整体、同步的变换**——所有潜在 token 在新条件下被统一更新。然而，DiTs 中的 token 通过自注意力机制全局耦合，切换条件（如“狗”→“猫”）会引发跨 token 传播，导致未编辑区域发生**全局漂移**。
- **现有方法局限**：基于掩码的方法（如 DiffEdit）依赖预先计算或外部的静态空间掩码，无法适应去噪过程中动态演变的语义；基于噪声/反演的方法也往往无法精确保留背景。
- **整体含义**：本文提出一种**推理时、无需训练、无需外部掩码**的编辑框架 ATDEdit，通过动态、token 级、异步的更新策略，在局部编辑与背景保持之间取得平衡。

## 2. 方法论

### 2.1 核心思想

- 将扩散采样视为**并行但全局耦合**的 token 矩阵更新过程，将编辑重新表述为**异步 token 解码**：不同 token 在条件切换和状态更新上遵循不同规则。
- 通过 **Token-wise Conditional Surprisal**（逐 token 条件惊异）动态估计哪些位置对目标提示最敏感，只对这些“可编辑 token”施加目标条件更新；对“保持 token”则通过源键/值记忆替换与硬投影来抑制漂移。

### 2.2 关键技术细节与流程

- **符号与设定**：设潜在 token 序列为 \(z_t \in \mathbb{R}^{S \times d}\)，\(S\) 为 token 数，\(d\) 为特征维度；使用整流流参数化，估计干净潜在为 \(\hat{x}_0(z_t, t, c) = z_t - t v_\theta(z_t, t, c)\)。源图像对应的 \(x_0\) 空间潜在记为 \(x_t^{\text{src}}\)，需要维护一个可编辑状态 \(x_t^{\text{edit}}\)。
- **约束集与硬投影**：定义保持集 \(K(t)\) 对应的仿射约束集 \(\mathcal{C}(t) = \{x : x_{K(t)} = (x_t^{\text{src}})_{K(t)}\}\)。通过欧几里得投影 \(\Pi_{\mathcal{C}(t)}(y)\) 实现硬重置：每一时间步后，将保持 token 的潜在行直接恢复为源值（式 15 所示）。这提供的是**潜在状态层的零漂移保证**，而非像素级不变性。
- **公共噪声耦合（Common-Noise Coupling）**：为了降低条件切换对比时随机噪声不匹配带来的方差，源分支使用 \(z_t^{\text{src}} = (1-t)x_t^{\text{src}} + t\varepsilon\)，目标分支通过平行四边形构造 \(z_t^{\text{tar}} = z_t^{\text{src}} + (x_t^{\text{edit}} - x_t^{\text{src}})\)，使两分支共享同一噪声 \(\varepsilon\)。此时耦合差分的方差满足 \(\text{Var}(F-G)=\text{Var}(F)+\text{Var}(G)-2\text{Cov}(F,G)\)；当协方差非负时，方差不高于独立噪声情形。
- **Token-wise Conditional Surprisal**：对同一源潜在 \(z_t^{\text{src}}\) 分别用源/目标条件评估 \(\hat{x}_0\)，计算每个 token 预测差的 \(\ell_1\) 范数并做 \(n_{\text{avg}}\) 次 Monte Carlo 平均，得到敏感性分数 \(s_i(t)\)。分数越高，表示该 token 对条件切换越敏感，越可能需要编辑。
- **掩码选择与平滑**：对 EMA 平滑后的分数取 top-\(\rho(t)\) 分位数作为可编辑掩码；仅在噪声中等区域（\([t_{\text{lo}}, t_{\text{hi}}]\)）更新掩码，且每 \(\kappa\) 步更新一次；可选形态学膨胀以增强空间连续性。
- **注意力记忆边界（Partial Attention Memory Freezing）**：在目标分支自注意力中，对保持 token 的位置，将其 Key/Value 从源分支的 \(K^{\text{src}}, V^{\text{src}}\) 替换到目标分支（式 12）；查询 \(Q^{\text{tar}}\) 仍来自目标分支，注意力权重仍保持条件依赖。该机制通过限制保持 token 向目标条件输出提供记忆，间接抑制背景漂移，但不解耦全局注意力。
- **异步目标条件更新**：计算源/目标速度差 \(\Delta v_t = v_\theta(z_t^{\text{tar}}, t, c^{\text{tar}}) - v_\theta(z_t^{\text{src}}, t, c^{\text{src}})\)（目标分支使用上述混合记忆），将其与可编辑掩码相乘后，仅更新可编辑 token：\(x_{t_{j+1}}^{\text{edit}} \leftarrow x_{t_j}^{\text{edit}} + \Delta t_j [\widehat{\Delta v}_{t_j} \odot m(t_j)]\)，再对保持 token 做硬投影。
- **形式化保证的范围**：论文明确说明——并行更新不等于 token 独立；公共噪声降方差仅在协方差非负时成立；硬投影零漂移是精确算术下对保持 token 潜在行的保证；top-\(B\) 选择只最大化所选集合的分数和，而非最终图像全局最优。

### 3.4 消融实验与组件分析

- **逐组件消融**：论文对以下组件分别进行去除实验：
  1. **Token-wise Surprisal 动态掩码**：改为固定空间掩码或随机掩码后，编辑区域定位能力下降，背景保持与语义对齐均受损；

  3. **硬投影（Hard Projection）**：删除后保持 token 虽仍有软约束，但无法保证零漂移，累积误差导致结构距离上升；

- **超参数敏感性**：对 top-\(B\) 比例 \(\rho(t)\)、更新步长 \(\kappa\)、时间窗口 \([t_{\text{lo}}, t_{\text{hi}}]\) 等进行扫描，结果显示 \(\rho(t)\) 在 0.2–0.4 区间较稳定，过高则背景过编辑，过低则编辑不充分；\(\kappa\) 越大计算越快，但掩码更新滞后会导致局部编辑不完整。整体而言，方法对超参数不特别敏感，具备实用鲁棒性。
- **计算开销**：由于需同时运行源/目标两个分支并计算 Surprisal 估计（\(n_{\text{avg}}\) 次前向），ATDEdit 的推理时间约为单分支采样的 2–3 倍。论文指出可通过减少 \(n_{\text{avg}}\)、延迟掩码更新频率等方式进一步加速。

## 4. 理论分析与跨方法定位

### 4.1 与现有轨迹编辑方法的关系

- **与 FlowEdit 的关系**：FlowEdit 也是基于整流流的两分支耦合（共享噪声），但它的更新对所有 token 同步施加目标条件，不做区分；ATDEdit 在此基础上引入 token 级别的“可编辑/保持”二分，相当于 FlowEdit 的稀疏化版本，但保留了耦合的数学框架。
- **与注意力编辑方法的关系**：MasaCtrl 等通过替换或融合注意力图实现空间控制，但注意力图本身是概率分布，替换后可能导致目标分支缺乏源分支的结构记忆；ATDEdit 的“部分记忆冻结”直接在键/值空间操作，保留源的视觉内容信息，同时允许查询随条件变化，实现更平滑的内容迁移。
- **与掩码编辑的关系**：传统掩码方法（如 DiffEdit）需要提前获得编辑区域，掩码质量高度依赖外部模型；ATDEdit 将掩码从“输入”变为“推理期自动生成并动态更新的内部状态”，从本质上降低了对外部先验的依赖。

### 4.2 核心洞见的总结

- **条件切换的局部性**：文本条件对扩散潜在的影响并非均匀分布，而是集中在与指令语义高度相关的 token 上，这种局部性可在每个时间步被估计。
- **保持不需要“冻结一切”**：保持 token 仍需参与注意力计算以维持全局一致性，但其键/值记忆必须来自源分支，从而在信息流层面阻断目标条件的侵入。
- **异步性与同步性的辨证统一**：更新步长不同（只更新可编辑 token），但每一步都通过全局注意力保持信息交换，因此异步更新并未破坏生成过程的全局协同。

## 5. 局限性

- **依赖源潜在的可获取性**：方法要求对源图像进行精确的潜在编码并沿整流流轨迹维护 \(x_t^{\text{src}}\)。对于与训练数据分布差异较大的真实图像，反演误差可能影响编辑质量。
- **源/目标语义差异过大时的失效**：如果编辑指令导致目标条件与源条件几乎正交（例如“猫”→“狗”但颜色、姿态、场景完全不同），Surprisal 可能覆盖广泛区域，退化为全局编辑，此时背景保持与语义编辑的平衡点难以把握。
- **计算冗余**：双分支推理与 Monte Carlo 平均增加了时间开销，较实时应用仍有距离。未来可探索蒸馏或单分支近似。
- **缺少用户可控的编辑强度旋钮**：目前只能通过超参数 \(\rho(t)\) 间接控制编辑力度，缺少如图像语义编辑中常用的“强度滑块”，交互友好性有限。
- **评估局限**：PIE-Bench 类别有限，且 ground-truth 掩码只覆盖编辑对象，未考虑“背景中不相关语义变化”是否应当被视为编辑结果；方法的背景保持指标可能因评估掩码粒度而偏高或偏低。

## 6. 结论与意义

ATDEdit 提出了“异步令牌解码”这一新视角，将扩散编辑从同时更新所有潜在 token 的范式，转换为按条件敏感性动态区分“可编辑”与“保持” token 的非同步采样策略。通过结合 token 级 Surprisal 掩码、部分注意力记忆冻结、硬投影和公共噪声耦合，方法在无需训练、无需外部掩码的条件下，同时取得了优越的背景保持、结构一致性与语义对齐。其意义不仅在于提供了一个强基线，更在于揭示了一个重要原则：**扩散条件下的内容编辑本质上是局部化、动态化的过程，而有效的编辑模型应当在信息流层级区分“改变的”与“保留的”成分**。

这一思想可能启发后续工作，例如将异步更新扩展到自回归扩散模型、设计可学习的 Surprisal 估计器，或将 token 级条件敏感性与跨帧一致性结合到视频编辑中。
