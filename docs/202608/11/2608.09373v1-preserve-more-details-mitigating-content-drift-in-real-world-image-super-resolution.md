## 摘要
真实世界图像超分辨率（Real-ISR）旨在从遭受多种真实退化影响的低质量（LQ）输入中重建高质量（HQ）图像。近期的研究利用LQ输入以及Stable Diffusion模型学习到的自然图像先验，取得了令人瞩目的成果。然而，现有方法往往忽视了LQ输入清晰度不足不可避免地会导致生成的HQ图像中出现内容漂移。这主要表现为视觉细节退化和文本语义偏移，严重损害了保真度和感知质量。为了解决这一挑战，我们提出了FSP-Diff，一种新颖的一步扩散模型，具有双路径架构。该架构包括一个细节条件路径，用于注入结构化细节以恢复精细结构，以及一个细节调制语义路径，利用结构化细节细化语义引导以缓解语义偏差。在标准Real-ISR基准上的大量实验表明，FSP-Diff在定量和定性指标上均优于现有的一步扩散方法。

## Abstract
Real-world image super-resolution (Real-ISR) aims to reconstruct high-quality (HQ) images from low-quality (LQ) inputs subject to diverse real-world degradations. Recent advances have leveraged the LQ inputs and natural image priors learned by Stable Diffusion models to achieve impressive results. However, existing methods often overlook insufficient clarity of LQ inputs inevitably induce content drift in the generated HQ images. This manifests primarily as visual detail degradation and textual semantic shift, severely compromising both fidelity and perceptual quality. To address this challenge, we propose FSP-Diff, a novel one-step diffusion model featuring a dual-pathway architecture. This architecture comprises a Detail-Conditioned Pathway for injecting structured details to recover fine structures, and a Detail-Modulated Semantic Pathway that refines semantic guidance using structured details to mitigate semantic deviations. Extensive experiments on standard Real-ISR benchmarks demonstrate that FSP-Diff surpasses existing one-step diffusion methods in both quantitative and qualitative metrics.

## 1. 论文的核心问题与整体含义

- 论文关注 **真实世界图像超分辨率（Real-ISR）** ，即从遭受未知、复杂、空间变化的真实退化影响的低质量（LQ）图像中重建高质量（HQ）图像。
- 现有基于 Stable Diffusion 的一步扩散方法（如 OSEDiff）虽然能利用大规模预训练先验，但忽视了 **LQ 输入清晰度不足导致的内容漂移（content drift）** 问题。
- 内容漂移表现为两类：
  1. **视觉细节退化**：VAE 高度压缩的潜在空间丢弃了 LQ 输入中的精细结构，使生成过度依赖先验而非输入本身。
  2. **文本语义偏移**：由 LQ 图像生成的语义文本描述可能错误，导致生成结果出现语义级误重建（如“房屋”被重建为“雪堆”）。
- 整体目标是在一步扩散框架中同时缓解这两种漂移，提升生成结果的保真度和感知质量。

## 2. 论文提出的方法论

### 核心思想
- 提出 **FSP-Diff**（Fine Structure Preserving Diffusion）模型，通过显式提取并利用 LQ 图像中的结构化细节，构建 **双路径架构**：
  - **Detail-Conditioned Pathway（细节条件路径）**：负责注入结构化细节，恢复精细结构。
  - **Detail-Modulated Semantic Pathway（细节调制语义路径）**：利用结构化细节校正文本语义引导，降低语义偏移。

### 关键模块与方法

#### 总体公式
- 现有一步方法直接以 LQ 编码后的潜在表示作为扩散起点：
  - \(\hat{I}_H = G_\theta(Z_L, C_T)\)
- FSP-Diff 引入结构化细节 \(X_S\) 和两个可学习通路 \(P_t\)、\(P_s\)：
  - \(\hat{I}_H = G_\theta(Z_L, P_t(X_S), P_s(C_T, X_S))\)
- 训练目标为重建损失与 VSD 正则化损失的加权组合：
  - \(\theta^* = \arg\min_\theta \mathbb{E}[\mathcal{L}_{rec}(G_\theta(I_L), I_H) + \lambda \mathcal{L}_{reg}(G_\theta(I_L))]\)
  - \(\mathcal{L}_{rec} = L_1 + \lambda_1 LPIPS\)

#### 细节条件路径
1. **结构化细节提取**：使用预训练 ViT 的第一块作为冻结特征提取器 \(E_f\)，从 LQ 图像提取高分辨率（H/8 × W/8）的低层级边缘/边界特征 \(X_S\)。
2. **Detail-Aware Token Compression（DATC）**：初始化少量可学习 query tokens，经多层 Transformer（自注意力 + 交叉注意力）将 \(X_S\) 压缩为紧凑 token 集 \(X_H\)，在保留细节的同时降低序列长度，避免注意力 O(N²) 复杂度过高。
3. **Structured Detail Conditioned Attention（SDCA）**：在 UNet 的每个 block 中、文本交叉注意力（TCA）之后插入 SDCA，以扩散潜在特征为 query、以 \(X_H\) 为 key/value，显式引导精细结构生成。

#### 细节调制语义路径
- 使用 DAPE 从 LQ 生成文本提示，经 CLIP 编码得到语义嵌入 \(X_C\)。
- 提出 **Semantic–Detail Modulator（SDM）**：利用缩放点积注意力计算 \(X_C\) 与 \(X_S\) 的相关性，生成细节调制后的语义条件 \(C_T\)，替代原始文本嵌入。

#### 训练策略
- 沿用 OSEDiff 的 VSD 正则化，通过冻结的预训练 SD 模型与其 LoRA 微调副本之间的预测差异约束生成分布。
- 引入 **timestep-shifted 训练**：通过参数 \(s\) 将采样时间步偏向低噪声区域（默认 \(s=0.9\)），提高训练稳定性与恢复质量。

## 6. 主要结论与发现

- FSP-Diff 在多数指标上优于现有一步扩散方法，尤其在 PSNR、SSIM、LPIPS、DISTS、FID 等有参考指标上表现突出，说明其能更好地保持精细结构和语义一致性。

  - DATC 比固定降采样更有利于细节压缩与保留；
  - SDM 进一步缓解语义偏移，且不会牺牲有参考指标。
- 时间复杂度分析显示，双路径架构仅带来小幅计算开销，仍远低于多步扩散方法。

## 7. 优点

- **问题定义清晰**：首次明确将 Real-ISR 中的内容漂移拆分为“视觉细节退化”和“文本语义偏移”两个可量化问题。
- **方法设计新颖**：通过双路径分别处理细节恢复与语义校正，结构清晰，模块化程度高。
- **轻量高效**：基于一步扩散，无需多步采样，推理速度快（0.15s）。
- **细节保持能力强**：相比 TVT 的 VAE 迁移方案，FSP-Diff 避免了规则化伪影，生成更自然的细节。
- **实验规范**：在公开基准上采用与 OSEDiff 一致的训练设置，便于复现和公平比较。

## 8. 不足与局限

- **对比公平性有限**：部分比较方法使用了更多训练数据或更强的预训练模型（如 TSD-SR 用 SD3），FSP-Diff 的“更好”主要是在同等基础配置下体现，内部消融与主实验不完全一致。
- **无参考指标优势不明显**：在 CLIPIQA、MUSIQ 等指标上，FSP-Diff 低于 TVT/TSD-SR，说明其在某些感知维度未必全面胜出。
- **训练依赖合成退化**：虽在真实数据集上测试，但训练数据仍由合成管道生成，对极端真实退化的鲁棒性可能有限。
- **参数量较大**：2.06B，比 OSEDiff（1.77B）和 TVT（1.72B）更高，虽推理时间仍较快，但对端侧部署不友好。
- **受限于 LQ 语义本身**：SDM 使用 LQ 提取的结构细节来修正文本语义，如果 LQ 中信息过于模糊或结构提取错误，语义校正效果可能受限。
- **未进行更广泛的应用验证**：如真实场景文本图像、人脸、动漫等垂直领域的评估未覆盖。
