## 摘要
基于码本的盲脸恢复（BFR）在严重退化下常常遭受模糊的条件特征和脆弱的预测机制的困扰。为解决这些挑战，我们提出了GeoMAR，一个旨在释放几何对齐特征并采用掩码自回归（MAR）细化以实现稳健人脸恢复的框架。在特征条件化方面，我们引入了一个双输入提取流程，以提取基于组件的几何描述，这些描述具有明确、空间上忠实的锚点。这些文本先验通过一个对齐几何先验注入器与低质量（LQ）特征集成，该注入器采用KV-Q交换策略以生成几何对齐的特征。在预测机制方面，我们将一步映射重新表述为多步MAR过程。这种从粗到细的生成基于越来越可靠的上下文逐步细化复杂的面部区域。在一个人工基准和三个真实世界基准上的实验表明，与现有方法相比，GeoMAR实现了极具竞争力的感知质量和连贯的视觉结构。代码可在https://github.com/BRL-SYSU/GeoMAR.git获取。

## Abstract
Codebook-based blind face restoration (BFR) often suffers from ambiguous conditioning features and a fragile prediction mechanism under severe degradation. To address these challenges, we propose GeoMAR, a framework designed to unleash geometrically aligned features with masked autoregressive (MAR) refinement for robust face restoration. For feature conditioning, we introduce a dual-input extraction pipeline to extract component-based geometric descriptions with explicit, spatially faithful anchors. These textual priors are integrated with low-quality (LQ) features via an Aligned Geometric Priors Injector, which employs a KV-Q exchange strategy to generate geometrically aligned features. For prediction mechanism, we reformulate the one-step mapping into a multi-step MAR process. This coarse-to-fine generation progressively refines complex facial regions based on increasingly reliable context. Experiments on one synthetic and three real-world benchmarks demonstrate that GeoMAR achieves highly competitive perceptual quality and coherent visual structures compared with existing methods. The code is available at https://github.com/BRL-SYSU/GeoMAR.git.

## 1. 核心问题与研究动机

- **研究背景**：盲脸恢复（Blind Face Restoration, BFR）旨在从未知退化（模糊、噪声、低分辨率等）的低质量人脸图像中重建高质量人脸。基于码本（Codebook）的方法近年来成为主流路线之一，通过将人脸先验编码为离散码本，并以低质量特征查询码本实现重建。
- **核心问题**：现有基于码本的方法在**严重退化**条件下存在两大痛点：
  1. **模糊的条件特征（ambiguous conditioning features）**：低质量图像经过编码后，其特征本身已严重受损、空间位置信息模糊，导致查询码本时难以获得准确的语义对应；
  2. **脆弱的预测机制（fragile prediction mechanism）**：现有方法多采用**一步式映射**（one-step mapping），即直接从退化特征一次性预测/重建完整人脸，缺乏逐步修正和利用可靠上下文的能力，在复杂面部区域（如眼睛、嘴唇等细节）上容易产生结构失真。
- **研究意义**：解决这两大问题有助于提升盲脸恢复在真实复杂退化场景下的感知质量与结构连贯性，对监控图像增强、老照片修复、社交媒体人脸美化等应用具有实际价值。

## 2. 方法论

GeoMAR 框架由**两个核心模块**组成，分别对应上述两个痛点：

### 2.1 特征条件化：几何对齐特征（Geometrically Aligned Features）

- **双输入提取流程（Dual-Input Extraction Pipeline）**：
  - 同时接受**低质量（LQ）图像**和对应的**几何/结构信息**作为输入；
  - 提取**基于组件（component-based）的几何描述**，即对人脸各组件（眼、鼻、嘴、轮廓等）分别进行结构特征描述；
  - 这些几何描述具有**明确且空间上忠实的锚点（explicit, spatially faithful anchors）**——即每个描述都对应到人脸图像中确定的空间位置，从而缓解了"模糊条件特征"的问题。
- **对齐几何先验注入器（Aligned Geometric Priors Injector）**：
  - 将上述几何文本/结构先验（textual priors）与低质量特征进行集成；
  - 采用**KV-Q 交换策略（KV-Q exchange）**：在注意力机制中，将低质量特征作为 Query（Q），同时利用一个交换机制在 Key（K）/Value（V）与码本查询之间进行信息的动态交换，使得最终生成的特征是"几何对齐"的——即语义上对应到正确的空间位置，同时融合了先验知识。

### 2.2 预测机制：掩码自回归细化（Masked Autoregressive Refinement）

- **将一步映射重构为多步 MAR 过程**：
  - 不再一次性预测全部人脸 token，而是采用**掩码自回归（Masked Autoregressive, MAR）**方式，分多步生成；
  - 每一步只预测当前被掩码（masked）的一部分面部 token，其余已预测的 token 作为**上下文（context）**参与后续预测；
  - 通过这种 **从粗到细（coarse-to-fine）** 的生成策略，复杂面部区域（如眼睛、嘴巴等）可以基于**越来越可靠的上下文**逐步细化，避免了一步式方法中"一步错步步错"的脆弱性问题。

### 2.3 整体流程概述

1. 输入低质量人脸图像 → 双输入提取流程获得组件级几何描述；
2. 提取的几何先验通过 KV-Q 交换策略与 LQ 特征融合 → 生成几何对齐的条件特征；
3. 以几何对齐特征为条件，执行掩码自回归的多步从粗到细生成；
4. 逐步细化面部各区域，最终输出高感知质量的恢复人脸。
