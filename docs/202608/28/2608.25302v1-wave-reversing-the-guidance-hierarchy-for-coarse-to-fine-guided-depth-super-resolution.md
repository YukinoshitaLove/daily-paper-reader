## 摘要
引导深度超分辨率（GDSR）通常通过卷积层级提取RGB引导特征，继承了其从细到粗的偏差。因此，低层空间线索在早期层中浮现，而深层则抑制那些与真实深度边界不对应的线索，这可能导致伪影和边缘模糊。同样的从细到粗偏差也存在于基于语义的方法中，这些方法早期消耗低层令牌，后期消耗全局令牌。我们提出WAVE，引入多级离散小波变换（ML-DWT）作为显式且可解释的特征控制机制，通过以生成顺序相反的方式消耗子带和语义令牌，实现从粗到细的重建。WAVE进一步利用这些子带分别处理高频和低频内容，从源头过滤误导性的RGB颜色和纹理线索，这些线索通常导致边界模糊和伪影，为不透明网络隐式学习的抑制提供了一种直观的替代方案。WAVE将结构和细节重建分离到专用模块中，这些模块：i) 建模小波子带内部及彼此之间、深度特征和语义先验的交互，ii) 对高频带应用语义门控，以及iii) 通过可逆耦合机制融合模态，防止塌陷到单一模态。跨多个基准的大量实验表明，WAVE匹配或优于现有方法，在高上采样因子下取得最大增益，此时低分辨率深度包含最少的结构信息。

## Abstract
Guided depth super-resolution (GDSR) typically extracts RGB guidance features through convolutional hierarchies, inheriting their fine-to-coarse bias. Thus, low-level spatial cues surface in early layers, leaving the deeper layers to suppress those that do not correspond to true depth boundaries, which risks artifacts and blurred edges. The same fine-to-coarse bias persists in semantics-based methods that consume low-level tokens early and global tokens late. We present WAVE, which introduces a multi-level discrete wavelet transform (ML-DWT) as an explicit and interpretable feature-control mechanism, enabling a coarse-to-fine reconstruction by consuming sub-bands and semantic tokens in reverse of their generation order. WAVE further exploits these sub-bands to treat high- and low-frequency content separately, filtering at its source the misleading RGB color and texture cues that often lead to blurred boundaries and artifacts, offering an intuitive alternative to the suppression learned implicitly by an opaque network. WAVE separates structure and detail reconstruction into dedicated modules that: i) model interactions within and across wavelet sub-bands, depth features, and semantic priors, ii) apply semantic gating to the high-frequency bands, and iii) fuse modalities through an invertible coupling mechanism that prevents collapse onto a single modality. Extensive experiments across multiple benchmarks demonstrate that WAVE matches or outperforms existing methods, with the largest gains at high upsampling factors, where low-resolution depth contains the least structure.

# WAVE：反转引导层级实现从粗到细的引导深度超分辨率——论文总结

## 1. 核心问题与研究动机

- **背景**：引导深度超分辨率（GDSR）利用高分辨率 RGB 图像作为引导，从低分辨率深度图重建高分辨率深度。RGB-D 传感器成本低，但深度分辨率通常低于 RGB，因此 GDSR 具有重要应用价值。
- **核心难题**：RGB 引导中常含有与真实深度边界不一致的纹理、颜色梯度、阴影和光照变化。若不加区分地用于融合，会产生纹理复制伪影、虚假深度边界和模糊的物体轮廓。
- **现有方法的不足**：
  - 基于 CNN 的 GDSR 方法通过卷积层级提取 RGB 特征，天然呈现“由细到粗”（fine-to-coarse）的偏差：早期层输出边缘/纹理等低级线索，深层才形成全局结构。
  - 因而误导性的高频内容先被注入，网络不得不在后期层中隐式地抑制它们，学习过程非单调，易导致伪影和边界模糊。
  - 基于语义先验的方法（如使用 DINO/SAM 蒸馏）通常也沿用“先低层、后全局 token”的次序，并未改变由细到粗的信息流。
- **WAVE 的思路**：反转这一层级顺序，以“先全局结构、再细节”的粗到细方式重建深度，并在信号源头（RGB 引导本身）显式控制频率内容，而非依赖黑盒网络隐式抑制。

## 2. 方法论

### 总体框架
- WAVE 输入低分辨率深度 \(D_{lr}\) 和高分辨率 RGB \(I\)。
- 先对 RGB 进行 **4 级 Haar 多级离散小波变换（ML-DWT）**，生成金字塔式子带：每级有 1 个近似带 \(LL_l\) 和 3 个细节带 \(LH_l, HL_l, HH_l\)。
- 同时用冻结的 **DINOv3**（ViT-B/16）提取 4 层 patch tokens（层级 2、5、9、11），并通过轻量适配模块 **SToRA** 使其任务化。
- 深度图先经 **Depth Preprocessor** 编码。
- 四个 **HUMMA 重建块**以“逆序”方式消费 DWT 子带与 DINO 语义 token——先消费最粗糙的层级，再逐步向高分辨率细节推进，每个块完成 2× 上采样。

### 关键技术细节

1. **SToRA（语义 token 残差适配器）**
   - 保留冻结 DINOv3，仅对 token 施加低秩残差：
     \[
     \tau_l^* = \tau_l + \varsigma W_u(W_d\tau_l)
     \]
   - \(W_u, W_d\) 为低秩矩阵，\(W_u\) 零初始化，使训练从原始预训练表示开始逐步调整。
   - 相比完整变换仅需 \(2Cr\) 参数，轻量且不破坏语义。

2. **HUMMA 块**：分为细节分支与结构分支。

   - **细节分支（Detail Branch）**
     - 处理高频子带：
       - 边缘路径：将 \(LH\) 与 \(HL\) 拼接后输入边缘编码器 \(\varepsilon_{edge}\)，得到 \(F_{edge}\)。
       - 纹理路径：将 \(LH, HL, HH\) 拼接后输入纹理编码器 \(\varepsilon_{text}\)，得到 \(F_{text}\)。
     - 语义门控：将对应层 SToRA token 投影为引导向量，用线性交叉注意力对每个高频特征做全局选择：
       \[
       \tilde{F}_{edge} = Attn(E_{guide}, F_{edge}, F_{edge}),\quad
       \tilde{F}_{text} = Attn(T_{guide}, F_{text}, F_{text})
       \]
     - 可学习门控混合（γ 初始化为 0）逐步引入语义调制：
       \[
       F_{edge}^* = (1-\gamma_{edge})F_{edge} + \gamma_{edge}\tilde{F}_{edge}
       \]
       \[
       F_{text}^* = (1-\gamma_{text})F_{text} + \gamma_{text}\tilde{F}_{text}
       \]
     - 合并两条路径并经投影得到高频细节图 \(F_{details}\)。

   - **结构分支（Structure Branch）**
     - 输入：低分辨率深度特征 \(D\)、LL 近似带 \(E_l\)、语义特征 \(S_{guide}\)，各自投影到共同潜空间。
     - 用深度特征作为查询，对语义特征做交叉注意力（与细节分支的查询/键设置相反），拉取与深度结构相关的内容：
       \[
       S_{dep} = Attn(Q=D, K=V=S_{guide})
       \]
       \[
       E_d^* = E_d + \mu S_{dep}
       \]
       \(\mu\) 初始化为零，语义修正随训练逐步引入。
     - **可逆融合（IRN 风格）**：将 \(E_d^*\) 与 \(E_l\) 拼接，经 LU 参数化的可逆 1×1 卷积混合后分成两半 \(Z_1, Z_2\)，再用仿射耦合：
       \[
       Y_1 = Z_1 + F(Z_2),\quad S = 2\sigma(H(Y_1))-1
       \]
       \[
       Y_2 = Z_2 \odot \exp(S) + G(Y_1)
       \]
       可逆性迫使两种模态都保持可恢复，避免融合塌缩到单一模态。
     - 拼接投影后得到结构特征 \(E_{struct}\)。

   - **重建与上采样**
     - 细节特征经投影后以残差形式加到结构特征上，系数 \(\rho\) 初始化为零：
       \[
       \tilde{D} = \Gamma(E_{struct} + \rho\tilde{F}_{details})
       \]
     - 用 DBP 式反投影实现 2× 上采样，包含降采样再上采样的误差修正：
       \[
       H_0 = SiLU(\uparrow\tilde{D}),\quad L_0 = SiLU(\downarrow H_0)
       \]
       \[
       E_{err} = L_0 - \tilde{D},\quad H_1 = \uparrow E_{err},\quad \tilde{D}_\uparrow = H_0 + H_1
       \]

3. **边界细化与优化**
   - 利用 DINOv3 最后一层 patch token 的局部余弦相似度计算语义边界强度：
     \[
     c_x = \langle \omega_{i,j}, \omega_{i,j-1}\rangle,\quad
     c_y = \langle \omega_{i,j}, \omega_{i-1,j}\rangle
     \]
     \[
     B = \sqrt{(1-c_x)^2 + (1-c_y)^2}
     \]
     经高斯平滑和均值归一化得到软边界图 \(\tilde{B}\)。
   - 将软边界、投影 RGB 与最后 HUMMA 块的深度特征一起送入融合网络，得到最终高分辨率深度。
   - 使用改进的 L1 loss 进行优化。

## 6. 主要结论与发现

- WAVE 通过**多级小波分解 + 逆序消费层级语义 token**，实现了真正的“先结构后细节”的粗到细重建，克服了传统 CNN 引导提取器的由细到粗偏差。
- 在高上采样倍数（尤其 32×）下获益最大，因为此时低分辨率深度保留的结构信息最少，粗到细策略能最有效地恢复全局几何。
- 实验表明：
  - 可逆跨模态耦合比普通拼接更有利于保持双模态信息。
  - 语义门控高频子带能有效抑制纹理复制伪影。
  - SToRA 轻量适配 DINO token 带来稳定增益。
  - 该方法对
