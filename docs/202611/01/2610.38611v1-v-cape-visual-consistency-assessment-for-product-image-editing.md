## 摘要
生成式图像编辑的最新进展使得基于自然语言指令的复杂变换成为可能，例如背景替换、物体操控和姿态调整。然而，验证这些变换是否保持视觉一致性仍是一个很大程度上尚未解决的问题；视觉一致性被定义为对象固有视觉属性的保持，包括几何形状、纹理、颜色和细粒度细节。这一挑战在大规模场景下尤为突出，此时人工检查不可行，自动化质量评估（AutoQA）可能变得至关重要。在本工作中，我们提出了面向产品图像编辑的视觉一致性评估（V-CAPE），这是一个用于评估生成式图像编辑中视觉一致性的大规模数据集。该数据集包含 4 万对独特的源-目标产品图像，每对图像均标注有二元接受/拒绝标签以及结构化失败模式，用于捕捉几何畸变、姿态错误和身份不匹配等细粒度不一致。V-CAPE 将真实世界编辑图像与由 3D 资产构建的合成子集相结合，从而同时支持真实感评估和受控分析。在 AutoQA 上，所有被评估规模类别的视觉语言模型（VLM）准确率均低于 65%，表明无论模型规模如何，该数据集都构成了重大挑战。我们的结果凸显了当前模型在验证变换下视觉一致性方面的根本局限性，并将 V-CAPE 定位为推进细粒度图像编辑评估的基准。

## Abstract
Recent advances in generative image editing enable complex transformations such as background replacement, object manipulation, and pose adjustment from natural language instructions. However, verifying that these transformations preserve visual consistency, defined as the preservation of an object's intrinsic visual attributes, including geometry, texture, color, and fine-grained details, remains a largely unsolved problem. This challenge is particularly pronounced at scale, where manual inspection is infeasible and automated quality assessment (AutoQA) could become essential. In this work, we introduce Visual Consistency Assessment for Product Image Editing (V-CAPE), a large-scale dataset for evaluating visual consistency in generative image editing. The dataset consists of 40K unique source-target product image pairs, each annotated with binary accept/reject labels and structured failure modes capturing fine-grained inconsistencies such as geometric distortions, pose errors, and identity mismatches. V-CAPE combines real-world edited images with a synthetic subset constructed from 3D assets, enabling both realistic evaluation and controlled analysis. Vision-language models (VLMs) across all evaluated size categories on AutoQA achieve accuracy below 65%, indicating that the dataset poses a substantial challenge regardless of model scale. Our results highlight fundamental limitations of current models in verifying visual consistency under transformation, positioning V-CAPE as a benchmark for advancing fine-grained image editing evaluation.

## 1. 核心问题与研究动机

- **核心问题**：生成式图像编辑（如背景替换、物体移除、姿态调整、虚拟试穿）已能完成复杂变换，但如何**验证编辑后的图像仍保持原始物体的视觉一致性**（几何、纹理、颜色、细粒度细节）仍基本未解决。
- **背景与动机**：
  - 即使细微的几何畸变、姿态错误或细节丢失，也会损害编辑图像的语义保真度。
  - 在大规模电商场景中，人工逐张检查不可行，亟需**自动化质量评估（AutoQA）**。
  - 现有数据集（InstructPix2Pix、Emu Edit、HQ-Edit 等）主要面向“如何生成编辑”，而非“如何判定编辑是否正确”；细粒度感知基准（SEED-Bench、MMBench、POPE）也缺乏源-目标对应关系、人类保真度标注和结构化失败模式。
  - 已有证据表明 VLM 在细粒度视觉感知、实例级区分和 3D 空间关系上存在明显短板。
- **整体含义**：论文将“编辑一致性验证”形式化为二分类 AutoQA 任务，并构建大规模基准，揭示当前多模态模型在细粒度视觉保真度验证上的根本局限。

## 2. 方法论

### 2.1 核心思想
- 构建 **V-CAPE 数据集**：40K 源-目标产品图像对（27K 唯一图像），每对含二值接受/拒绝标签 + 结构化拒绝原因，覆盖真实编辑输出与可控合成渲染两类场景。
- 任务形式化：给定源图 \(I^\star\) 与编辑图 \(\hat{I}\)，判定变换是否保持物体语义身份与细粒度属性，输出 \(y \in \{0,1\}\)。

### 2.2 两个互补子集
- **V-CAPE-R（真实子集，20K 对，沙发品类）**
  - 流程：图像 sourcing → 生成编辑 → 质量评估。
  - **候选选择** \(I^\star = S(I, c)\)：用冻结 DINOv2 嵌入 + 两层 MLP 的**姿态分类器**（left/right/frontal/corner/other）与**对称性分类器**（各 7,000 张人工标注训练），再按经验接受率规则排序：左朝向 > 右朝向对称 > 正面 > 右朝向非对称 > 其他。
  - **生成编辑** \(\hat{I} = G(I^\star, p(c))\)：先用 Gemini 2.5 Flash 做背景清理（固定 prompt），再按姿态条件决定是否用 Qwen-Edit-2509-Multiple-angles 做生成式旋转（正面 −20°、右向 −40°）；右向对称沙发改用确定性水平镜像，避免生成伪影。
  - **质量评估** \(y = Q(\hat{I}, r)\)：人工标注 + 结构化拒绝原因。
- **V-CAPE-S（合成子集，20K 对，19+ 品类）**
  - 基于 ABO 3D 资产，用 Blender API 渲染 1024×1024 目标图（front/left/right 多视角，随机方位角/仰角）。
  - 两级过滤：产品级（排除透明/高反光等难渲染品类）+ 图像级（CLIP 嵌入分类器筛选 lifestyle 图，90% 精度 / 82% 召回）。
  - 负样本构造：错误姿态、同品类错误实例、品类不匹配，要求模型具备几何、语义与身份推理能力。

### 2.3 标注协议
- 每样本由 **3 名训练有素标注员**独立评估，多数投票定标签；经 5 轮对齐，**Fleiss Kappa = 0.77**。
- 标签体系：
  - V-CAPE-R：接受 10,000；几何伪影 6,000；错误朝向 1,804；无关物体 989；纹理/光照/颜色 802；背景问题 306；颜色/材质/图案不匹配 99。
  - V-CAPE-S：接受 10,843；错误朝向 4,303；同品类错误实例 4,096；品类不匹配 758。

## 6. 主要结论与发现

- **AutoQA 远未解决**：所有被评估 VLM（含专有最强模型）在两个子集上准确率均**低于 65%**（基线约 50%–63.5%，F1 55%–67%），部分模型出现“近乎全接受/全拒绝”的退化行为。
- **自动 prompt 收益有限**：IPC 带来 +3–5pp 的稳定但中等提升，对最强模型收益递减，部分情况无提升，说明瓶颈在于模型感知能力而非指令设计。
- **清晰的难度梯度**：粗粒度违规（几何、品类、实例不匹配）召回尚可；细粒度违规（纹理、光照、背景、颜色/材质不匹配）接近随机水平。
- **零样本方向分类仍具挑战**：对比式 VLM 在 V-CAPE-S 仅 33–47%（强偏向预测正面）；自监督编码器达 56.8% 且类别更均衡；方向专用模型在 V-CAPE-R 达 91.1%、V-CAPE-S 约 59%，但依赖数据集特定的方位角阈值校准。
- **少样本微调有效但有限**：LoRA 微调将 V-CAPE-S 的 F1 从 6.7% 提升至 62.4–68.3%，最佳配置为 N=5（55 个训练样本）；N 从 5 增至 10 反而轻微下降，说明简单扩样本不能单调提升，任务需要内化类别特定的细粒度判据。
- **合成 vs 真实差异**：V-CAPE-S 上性能普遍高于 V-CAPE-R，表明合成缺陷模式更系统、更易从少量样本学习，真实缺陷更多样、更依赖上下文。

## 7. 优点

- **任务定义清晰且实用**：将“编辑一致性验证”明确形式化为 AutoQA，贴合电商大规模质检的真实需求。
- **数据集设计有层次**：真实 + 合成双轨互补，兼顾真实感与可控性；不仅给二值标签，还提供**结构化失败模式**，支持细粒度诊断而非仅粗分类。
- **标注质量较高**：3 人独立标注 + 多数投票 + 5 轮对齐，Fleiss Kappa 0.77，标注协议与伦理规范（薪酬、工时、现代奴隶制合规）披露完整。
- **生成管线工程细致**：姿态/对称分类器 + 规则排序选择源图、条件式生成编辑（能镜像就不生成）、固定清理 prompt，显著降低伪影，体现对生成模型缺陷的深刻理解。
- **实验分析多维**：主实验 + 逐拒绝原因分解 + 零样本方向解耦 + 少样本微调 + VQA 逐题分析，层层递进地定位失败来源。
- **统计报告规范**：bootstrap 置信区间、标准差、退化行为诊断均有报告；计算资源、超参数、prompt 全文附录化，可复现性强。

## 8. 不足与局限

- **品类覆盖偏窄**：V-CAPE-R 仅限沙发品类，真实场景的跨品类泛化性未验证；V-CAPE-S 虽扩展至 19+ 品类，但均为 ABO 3D 资产可渲染品类，排除了透明/高反光等难渲染物体。
- **真实缺陷分布的代表性有限**：V-CAPE-R 的编辑由特定管线（Gemini 2.5 Flash + QEM）生成，缺陷模式可能带有该管线的系统性偏差，未必覆盖其他生成模型的失败模式。
- **合成与真实存在分布差距**：V-CAPE-S 性能系统性高于 V-CAPE-R，说明合成负样本可能偏“简单”或模式化，存在高估模型能力的风险。
- **标注粒度仍为图像级**：缺少区域级或对应点级标注，无法定位“具体哪个部件出错”，限制更细粒度的诊断与训练监督。
- **少样本微调实验有限**：仅微调单一模型（Qwen3-VL-8B）、单一 LoRA 配置，未探索全参数微调、更大模型或更复杂训练策略；N=10 性能下降的原因分析偏定性。
- **自动 prompt 存在调参偏差风险**：IPC 使用标注样本优化 prompt，虽与基线对照，但仍可能轻微高估“prompt 工程”的可迁移收益。
- **方向分类专用模型依赖校准**：OrientAnything 在 V-CAPE-R 的 91.1% 依赖数据集特定方位角阈值映射，零样本泛化结论需谨慎解读。
- **应用限制**：论文聚焦产品图像 lifestyle→studio 这一特定变换，结论向其他编辑类型（如虚拟试穿

（如虚拟试穿、物体移除、姿态重定向）的推广需重新验证，当前结论不宜直接外推。

- **评价指标较单一**：主指标为二分类 Accuracy 与 F1，未引入对“拒绝原因分类”的定量评估（如原因预测的混淆矩阵、层级一致性），结构化标签的诊断价值未被充分利用。
- **缺少与人类上限/下限的对照分析**：虽报告标注者间 Kappa，但未系统比较模型与单标注员、多数投票标注员的一致性差异，难以判断模型差距相对于人类噪声的绝对量级。
- **误差分析以聚合为主**：逐拒绝原因召回率分解已较细，但缺少对典型失败案例的定性可视化与错误归因（如“因背景残留而误拒”“因视角近似而误受”），对后续改进的指导性可进一步加强。
- **成本与延迟未讨论**：作为 AutoQA 方案，论文未报告各模型在实际质检吞吐下的推理成本、延迟与部署可行性，削弱了“可落地性”的说服力。

## 9. 对领域的启示与可延伸方向

- **“生成能力”与“验证能力”严重不对称**：当前生成模型已能产出视觉上逼真的编辑结果，但即便是最强专有 VLM 也无法可靠判定其保真度。这提示社区应将**编辑验证**视为独立且更难的研究问题，而非生成模型的附属能力。
- **细粒度感知是共同瓶颈**：粗粒度语义违规（品类、实例、明显朝向错误）可被较好识别，而纹理、光照、颜色、材质、背景残留等细粒度判据接近随机。这与已有关于 VLM 细粒度感知短板的证据一致，说明 AutoQA 的突破可能依赖**区域级/对应点级的感知增强**，而非单纯扩大模型规模或优化 prompt。
- **数据设计层面的可复用经验**：
  - “真实 + 合成”双轨互补是一种务实的折中：合成提供可控、可扩展、缺陷模式明确的监督信号，真实数据保证分布贴近应用；但需警惕合成子集系统性偏简单所导致的能力高估。
  - 结构化拒绝原因标签比二值标签信息量更高，既可支撑诊断式评测，也可作为**原因感知训练**（多任务/层级分类）的监督信号。
  - 生成管线中“能确定性变换就不调用生成模型”（如对称沙发用镜像替代生成旋转）是降低伪影、保证标签可信度的有效工程原则。
- **少样本微调的价值与边界**：LoRA 在极少样本（N=5，55 条）下即可将 F1 从 6.7% 提升至 62–68%，说明任务本身可学，瓶颈在于**类别特定判据的内化**；但 N=10 的性能回落提示简单扩充样本并非单调有效，未来可探索难例挖掘、原因分层监督、对比式训练等更高效的监督方式。
- **潜在延伸方向**：
  1. 扩展到更多品类与更多编辑类型（试穿、移除、重打光），验证结论的跨任务泛化性；
  2. 引入区域级标注与部件级对应关系，实现“定位哪一处出错”的可解释质检；
  3. 将方向/姿态理解与保真度判定解耦建模，或引入 3D 先验、几何一致性约束作为外部工具增强；
  4. 探索“生成—验证”闭环，用验证器反馈指导生成模型筛选与重生成；
  5. 建立人机一致性分析与成本—精度权衡曲线，推动从 benchmark 走向生产级 AutoQA。

## 10. 总体评价

- **贡献定位**：论文的核心贡献不在于提出新模型，而在于**提出一个被忽视且具产业价值的问题（编辑一致性验证）、构建一个规模可观且标注规范的双轨基准、并给出系统性的负面结论**——即当前 VLM 在该任务上普遍不可用。这类“揭示局限”的工作对领域方向具有实际引导价值。
- **方法严谨性**：数据构建流程工程细致（姿态/对称分类器筛选、条件式生成、固定清理 prompt、两级过滤、三人标注 + 多数投票 + Kappa 校验），实验设计层次清晰（主实验 → 原因分解 → 解耦方向分类 → 少样本微调 → VQA 逐题分析），统计报告规范（bootstrap 置信区间、标准差），整体可信度较高。
- **主要短板**：真实子集仅覆盖沙发单品类、编辑管线单一，跨品类与跨生成器的泛化性证据不足；合成子集缺陷模式偏系统化，可能高估模型能力；缺少区域级标注、原因分类的定量评估与推理成本分析。
- **适用读者与使用建议**：适合关注多模态评测、细粒度视觉感知、电商视觉质检与生成式编辑质量控制的读者。引用其结论时，建议明确限定在“产品图 lifestyle→studio 变换 + 沙发品类真实场景 + ABO 合成场景”范围内，避免过度外推至所有图像编辑任务。
