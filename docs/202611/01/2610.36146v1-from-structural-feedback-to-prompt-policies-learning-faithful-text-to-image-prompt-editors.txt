## Abstract 

Prompt optimization should improve the image a user receives without changing the scene the user requested. Yet stylistic rewriting can weaken object attributes and relations even when global text–image similarity remains high. We propose StruPO, a structure-aware prompt editor that uses a calibrated scene graph as a shared representation for policy conditioning and image-grounded supervision. The graph exposes what should be preserved, while deletion, reordering, and in-sertion provide a token-aligned way to modify the prompt. This turns structural feedback from an external critique into a training signal for a reusable editing policy. Learning from that signal requires handling both uncertain grounding and stochastic image generation. StruPO retains grounding confidence through smooth reward shaping and averages multiple images for each edit before computing group-relative advantages. Experiments span three disjoint 2K-prompt test sets and four frozen generation backbones, with comparisons to learned prompt optimizers, iter-ative structural feedback, diffusion-model fine-tuning, and inference-time attention control. StruPO improves the faithfulness–aesthetics trade-off, with consistent gains in relational fidelity. Independent automatic evaluators and a 15-annotator study provide complementary evidence, and human preference margins increase with relation complexity. Controlled ablations connect these gains to graph condi-tioning, local editing, and image-grounded learning. The resulting policy produces reusable optimized text in one pass after graph calibration, without an iterative critique–rewrite loop. 

## 1 Introduction 

Text-to-image (T2I) models such as Stable Diffusion [1] and DALL-E [2] have made visual content creation widely accessible, but the quality of their outputs still depends strongly on prompt formula-tion. Users describe what they want to see; generators also respond to how that intent is expressed through composition, lighting, and stylistic detail. Automatic prompt optimization bridges this gap by transforming a user prompt x into a generator-effective prompt y. Its objective is twofold: improve the resulting image’s perceptual quality and preserve the scene specified by the user. These goals need not move together. A rewriter can make a prompt more vivid while changing which objects appear, which attributes belong to them, or how they relate. Style-oriented optimizers [3, 4] and embedding-level relevance constraints [5] address important parts of the task, but a high global text–image score can conceal local semantic failures [6, 7]. Scene graphs (SGs) express this intent through ob-ject phrases and relations. Complete phrases such as “gold crown” retain attributes, while edges spec-ify how the objects are connected. Prior methods already exploit such structure: OPT2I optimizes consistency scores through iterative prompting [8], and VisualPrompter uses atomic visual feedback to target missing concepts [9]. These methods establish the value of structural diagnosis. The next question is how to turn that diagnosis into a 

learned editing behavior that generalizes across prompts, rather than repeatedly asking an external rewriter to interpret feedback at test time. Our central idea is to use the same structured intent to condition the editor and to evaluate its consequences . This connects the information available when choosing an edit to the object–attribute– relation constraints checked in the generated image. A graph-conditioned policy can then learn which textual changes improve rendering while retaining semantic anchors. Expressing those changes as deletion, reordering, and insertion further biases the policy toward modifying the input rather than replacing it wholesale. The benefit is not only fewer test-time revisions: it is a closer alignment between the representation of user intent, the granularity of prompt changes, and the feedback used to learn them. Making this alignment learnable presents two challenges. First, text parsers may confuse style or camera descriptions with visible content, while grounding models provide uncertain evidence about genuine constraints. Second, image generation is stochastic: two renders of the same edited prompt can receive different scores. A policy trained on thresholded, single-image feedback can therefore react to evaluator discontinuities or rendering noise instead of the quality of an edit. Graph calibration, confidence-preserving rewards, and environment-sample averaging address these distinct sources of uncertainty. We instantiate this approach as StruPO (Stru ctured Prompt Optimization). A scene-graph extractor calibrates the input structure, a hybrid encoder exposes text and graph features to the policy, and an edit-action generator produces the optimized prompt. Supervised fine-tuning provides an initial editing behavior; image-grounded reinforcement learning then improves its downstream consequences. Smooth structural rewards retain grounding confidence, and environment-aware GRPO compares edits after averaging multiple renders of each candidate. At inference time, one policy pass follows graph calibration and returns reusable text; the T2I generator stays frozen. Our contributions are threefold. First, we develop a structure-aware editing policy in which calibrated intent is shared between policy conditioning and image-grounded supervision. Second, we pair confidence-preserving reward shaping with environment-aware group-relative optimization, sup-ported by a reward-stability analysis. Third, we establish the approach’s relation-sensitive benefits through controlled ablations, cross-backbone transfer, independent evaluators, and human judgments. The experiments connect improvements to graph access, local edits, and image feedback, while comparisons with learned and iterative optimizers characterize the resulting quality–cost trade-off. Additional evaluator and baseline results are provided in the appendix. 

## 2 Related Work 

Prompt optimization for T2I generation. Early work studies how users construct T2I prompts and derives practical design guidelines [10, 11]. Automatic methods optimize prompt tokens or embeddings through generator gradients in white-box settings [12, 13], or learn textual reformulations with supervised fine-tuning [4, 14], multimodal supervision [15, 16], reinforcement learning [5], and LLM prompting [17]. Recent learned optimizers broaden the objective beyond style: PAE learns modifiers together with token weights and denoising-time ranges [18], while RePrompt uses GRPO to train reasoning-augmented reprompting from image-level feedback [19]. StruPO focuses on a complementary design choice: sharing a calibrated scene graph between the editor’s input and 2its atomic grounding reward, then learning token-aligned edits from that feedback. Appendix G.3 compares PAE and RePrompt under matched SD v1.5/Lexica evaluation. 

Structure-aware feedback for prompt optimization. OPT2I iteratively revises prompts to maxi-mize consistency, including Davidsonian scene-graph (DSG) scores [8]. VisualPrompter decomposes prompts into atomic concepts, identifies missing content through visual feedback, and performs targeted refinement without training [9]. Both demonstrate that structural feedback can improve prompt–image alignment. StruPO learns a reusable editor from this type of feedback: the graph conditions its decisions, and image-grounded rewards evaluate the edited prompt against the same constraints. The distinction is thus learned graph-conditioned editing versus test-time feedback-driven revision. Appendix G.7 compares the resulting policy with a three-round GPT-4o structural-feedback system on the full 2K-prompt Lexica test set. 

Scene graphs and fine-grained T2I evaluation. Scene graphs represent objects and pairwise relations [20, 21]. Image scene-graph generation combines object detection with contextual relation reasoning [22–25]; language-supervised systems extend grounding to open-vocabulary concepts [26, 27]. For T2I evaluation, DSG [6] decomposes semantic correctness into dependent atomic questions, exposing failures that global similarity can miss. StruPO uses object and relation grounding for policy learning while retaining attribute-bearing phrases in both graph features and grounding queries. We assess this learned objective with held-out OR/RR, and complement it with Gemini-VQA, human judgments, and independent evaluators (Appendix G.2). 

Text editing and broader faithfulness interventions. Explicit text editors decompose rewriting into deletion, reordering, and insertion [28, 29], providing a token-level link between an input and its revision. StruPO adapts this action representation to graph-conditioned, image-grounded prompt optimization. Related approaches intervene elsewhere in the generation process: DPOK updates diffusion-model parameters [30], and Attend-and-Excite adjusts the latent trajectory using attention-based guidance [31]. These approaches expose different control and access requirements. Appendix G.6 compares their quality, offline cost, and per-image interventions with the reusable-text interface of StruPO.

Scene-graph extraction and calibration (DSE). DSE constructs a calibrated scene graph Gx =(Ox, V x) from the input prompt x. A language parser first produces a coarse graph ˜Gx = ( ˜Ox, ˜Vx),but text-only parsing can introduce artifacts. For example, in “ a girl photographed with a Leica lens ,” the phrase “ Leica lens ” may be misinterpreted as a visible object rather than a photographic condition. DSE uses one image ix ∼ g(x) to help identify ambiguous parser outputs. Parsed elements are partitioned into text-core elements and auxiliary elements. Text-core objects are explicit syntactic heads or entities participating in relations; auxiliary elements are ambiguous noun phrases that often describe style, camera, or medium. Visual evidence filters auxiliary elements, while text-core elements are retained even when the initial image fails to render them. Thus, a missing requested object remains a constraint for subsequent optimization; an ambiguous camera or style phrase can be removed from the graph. Object grounding uses GLIP [26]. Multimodal hybrid encoder (MHE). MHE maps the prompt and SG into a shared representation. A frozen CLIP text encoder [34] produces token-level features ftext (x) ∈ Rl×d. Each object phrase and serialized relation query qv is encoded by the same text encoder, with the [EOS] embedding used as the initial representation of a graph element. A two-layer GCN propagates information over the topology induced by Vx, producing fgraph (Gx) ∈ Rn×d for n = |Ox| + |Vx|. The editor receives the concatenated representation f (x, G x) = ftext (x) ⊕ fgraph (Gx). This representation supplies token detail and graph context to the same editor. ## 4 Experiments 

4.1 Experimental Settings Data collection. For SFT, we collect 72K optimized prompts from Lexica as targets. Following Promptist [5], each optimized prompt is converted into two input variants: (i) a semantic skeleton obtained by removing stylistic modifiers and (ii) a GPT-4o rewrite of that skeleton. This procedure yields 144K input–target pairs. SFT uses the full paired set, whereas RL uses 24K input prompts sampled from the training split without access to their targets. Evaluation uses three disjoint test sets: Lexica and DiffusionDB [36] as in-domain prompt-optimization distributions, and COCO captions [37] as an out-of-domain distribution. Each test set contains 2K prompts and is disjoint from training, validation, and hyperparameter selection. 

Implementation details. Unless stated otherwise, we use GLIP-T [26] for object grounding, BLIP-base [33] for relation verification, Stable Diffusion v1.5 [1] as the default generator, and CLIP ViT-L/14 [34] as the frozen text encoder. The edit policy is initialized from BART-base [38]; the graph encoder is a two-layer GCN with hidden size 768. Grounding models, CLIP, and the T2I generator remain frozen, and only the GCN and editing policy are updated. We use AdamW [39] with learning rate 2 × 10 −5. SFT runs for approximately 50 epochs, followed by 24K RL prompts organized into 6K updates. Each RL context samples N = 4 policy rollouts and M = 3 images per rollout. Hyperparameters are selected once on a held-out Lexica validation split and then fixed across all test distributions and generation backbones. Appendix C provides model versions, the aesthetic-predictor checkpoint and architecture, optimization settings, and compute accounting. 

Evaluation protocol. We evaluate perceptual quality and semantic faithfulness. AES ∆ denotes the change in the frozen aesthetic score relative to the raw prompt. For structured consistency, we evaluate held-out images with thresholded grounding rather than the smoothed training reward, reporting object recall (OR), relation recall (RR), and SGR = (OR + RR) /2. Unless noted, each score averages three matched-seed generations per prompt. We compare StruPO with template prompting [40], learned LM optimizers (Promptist [5], MagicPrompt [3], and BeautifulPrompt [4]), structure-aware feedback prompting (VisualPrompter [9]), GPT rephrasing and few-shot prompting, and human-crafted target prompts when available. The Template baseline appends a universal style-only suffix while leaving semantic content unchanged, so it serves as a near-original-prompt reference. OR/RR measure generalization on the trained structural objective; Gemini-VQA and human judgments assess faithfulness through separate evaluators. TIFA, VQAScore, ImageReward, HPSv2.1, and further evaluation details appear in Appendix G.2.

Human evaluation. We conduct a pairwise study with 15 annotators over all 2K Lexica prompts. ## 5 Conclusions and Limitations 

StruPO learns faithful prompt editing by sharing calibrated structural intent between policy condi-tioning and image-grounded supervision. Local edit actions preserve a token-level connection to the user’s description, while confidence-preserving rewards and environment-aware GRPO make noisy structural feedback usable for optimization. Across prompt distributions and frozen T2I backbones, the resulting policy improves the faithfulness–aesthetics trade-off, with the most consistent gains in relations. Controlled ablations connect these gains to the graph, action representation, and image feedback; independent evaluators and human judgments provide complementary evidence. The broader lesson is that structural feedback can shape how a prompt policy learns, not merely how its outputs are scored. After graph calibration, the editor returns reusable optimized text in one pass, linking relation-sensitive quality to a practical frozen-generator interface. 

Limitations. The approach depends on parser, grounding, and generator quality. Attribute-bearing phrases capture local modifiers, but object–relation graphs are less expressive for counting, occlusion, negation, emotion, metaphor, and other abstract intent. Conservative editing can also be too restrictive when a prompt needs global reformulation; the long-input and dense-scene analyses expose these limits. Multi-image averaging increases offline training cost, and inference includes an initial calibration render in addition to the final image. Transfer does not remove the capabilities or biases of the underlying generator, and the studied English prompt distributions do not establish multilingual coverage. Richer constraint representations and adaptive editing strategies are promising next steps, alongside broader human evaluation of which semantic differences matter in practice. 9Acknowledgments and Disclosure of Funding

A.2 Supervised Fine-Tuning 

For supervised fine-tuning, we derive edit-action targets from each mapping x → y with a greedy token alignment that favors a long shared subsequence. The target action sequence is then constructed in three ordered steps: 1. Deletion : Iterate through the token list of the raw prompt x and mark the tokens that do not appear in the alignment result to identify the deletion actions. 2. Reordering : Record the mapping of tokens between their original positions and target positions during the alignment process to parse the reordering actions. 3. Insertion : Compare the token list of the optimized prompt to identify tokens that do not appear in the alignment result, and determine their target insertion positions to parse the insertion actions.

## C Implementation Details 

C.1 Models and Frozen Evaluators 

Unless stated otherwise, the default generator is Stable Diffusion v1.5, object grounding uses GLIP-T, relation verification uses BLIP-base, and the prompt editor is initialized from BART-base. The frozen 19 MHE encoder is OpenAI CLIP ViT-L/14 and the graph encoder is a two-layer GCN with hidden size 768. During training, the T2I generator, GLIP, BLIP, CLIP, and all reward models are frozen; only the GCN and prompt editor are updated. The aesthetic term uses the released christophschuhmann/improved-aesthetic-predictor 

implementation 4 with checkpoint sac+logos+ava1-l14-linearMSE.pth . It consumes a normal-ized 768-dimensional OpenAI CLIP ViT-L/14 image embedding and applies an MLP with widths 

768 → 1024 → 128 → 64 → 16 → 1, totaling 927,969 parameters. The released model uses dropout rates 0.2/0.2/0.1 and was trained by mean-squared error on SAC+Logos+AVA1 ratings. The predictor is frozen in both training and evaluation. 

C.2 Optimization Hyperparameters 

All hyperparameters are selected once on a reserved Lexica validation split and then fixed for every test set and generation backbone. SFT uses the 144K paired examples for 56K updates (approximately 50 epochs). The RL pool contains 24K prompts and training uses 6K optimizer updates, with four policy rollouts and three independently sampled images per rollout for environment-aware averaging. MagicPrompt. MagicPrompt uses the released GPT-2 117M continuation checkpoint, trained for 150K steps on roughly 80K diffusion prompts [3]. D.3 Error Bars and Statistical Stability 

For automatic metrics, each prompt-level score is first averaged over three generated images. We then resample prompts with replacement for 1,000 bootstrap trials. Across Lexica, DiffusionDB, and COCO, the average 95% half-widths are approximately ±0.02 for AES ∆, ±0.6 for OR, ±1.1

for RR, and ±0.8 for SGR. The pairwise ranking between StruPO and the strongest non-StruPO baseline remains unchanged in 91.2% of bootstrap trials for SGR and 90.6% for AES ∆. These intervals quantify prompt-sampling uncertainty; they do not account for uncertainty in the pretrained evaluators themselves.

## H Structural Feedback in Learned Prompt Editing 

Structural feedback can enter prompt optimization in different places: it can score candidates in an external search loop, inform a learned policy, or supervise that policy’s image outcomes. The graph supplies the semantic anchors available to the editor, and its grounded elements determine which rendered outcomes receive higher reward. The components serve complementary roles in this learning problem. DSE calibrates the structural context; MHE exposes it to the editor; EAG links candidate changes to input tokens; and confidence-preserving, environment-aware optimization handles noisy image feedback. Table 4 tests these roles through separate interventions. In particular, replacing local edits with free-form generation retains the graph, reward, and RL procedure but lowers SGR by 7.06 points. Conversely, retaining the editing architecture without structural reward lowers SGR by 5.60 points. The evidence therefore supports both the editing parameterization and the supervision it receives. This design also yields a practical distinction from iterative feedback: after calibration, a single policy pass returns text that can be reused across generations. The full comparison in Table 23 measures that online trade-off, while Table 2 evaluates reuse across frozen backbones. The contribution is a learned connection between structured intent and image-effective edits, with amortized inference as a consequence of that formulation. 

Broader impact. Faithful prompt editing can reduce manual prompt-engineering effort and unin-tended changes to a user’s requested scene. More controllable, visually convincing generation can also 35 facilitate misleading synthetic content or reproduce biases in the underlying generator and feedback models. Deployment should retain the generator’s safety filters and usage restrictions, communicate the synthetic origin of outputs, and respect privacy and copyright constraints on prompts, training assets, and generated content. The editor improves how intent is expressed to a generator; it does not itself establish that a requested use is appropriate.
