## 摘要
我们提出了DiT读出（ReaDiT）引导，这是一种轻量级框架，通过扩散Transformer（DiT）模型的内部特征表示来控制生成。ReaDiT引导使用来自单个DiT块的特征，根据测试时提供的空间目标（如深度、姿态或边缘图）来引导生成过程。此外，由于现代文本到视频模型大多基于DiT骨干架构，ReaDiT引导自然扩展到视频生成，实现相机和运动控制。实验结果表明，与现有的基于特征的方法和现成的基于适配器的方法相比，我们的方法在需要更少参数的情况下达到了具有竞争力或更好的结果。

## Abstract
We present DiT Readout (ReaDiT) Guidance, a lightweight framework for controlling generation with Diffusion Transformer (DiT) models via their internal feature representations. ReaDiT Guidance uses features from a single DiT block to steer the generative process according to spatial targets - like depth, pose, or edge maps - provided at test time. Furthermore, since modern text-to-video models are largely built on DiT backbones, ReaDiT Guidance naturally extends to video generation, enabling camera and motion control. Experimental results demonstrate that our approach achieves competitive or improved results compared to existing feature-based and off-the-shelf adapter-based approaches while requiring fewer parameters.

- **核心问题**：扩散模型虽能根据文本提示生成高质量图像和视频，但仅靠文本难以精确控制生成结果的空间属性，例如指定深度图、姿态骨架图或边缘图。现有控制手段主要存在两类瓶颈：
  - **适配器类方法（如 ControlNet）**：控制效果好，但需要大规模成对训练数据，且引入大量额外参数；迁移到视频生成时计算和训练成本急剧上升。
  - **基于特征的轻量方法（如 Readout Guidance, RG）**：只需少量训练数据和参数，但 RG 专为 U-Net 架构设计，难以直接适应当前主流的 Diffusion Transformer（DiT）架构。
- **整体含义**：论文旨在探索是否可以利用 DiT 自身内部特征，以轻量、统一的方式同时实现图像与视频的细粒度空间控制（深度、姿态、边缘）以及视频的运动/相机控制，并避免重适配器和昂贵的训练。
- **关键观察**：与 U-Net 中不同层特征差异显著不同，DiT 各 block 的特征高度相似（PCA 分析和线性拟合 R²=0.7 证实冗余性）。因此，**单个 DiT block 的特征足以预测并引导空间属性**，这为设计极简的“读出”模块提供了依据。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：训练一个轻量“读出”网络 gθ，从冻结的 DiT 中提取**单一 block** 的特征 f_l^t，预测目标任务的空间输出（深度/姿态/边缘/光流）；推理时，通过反向传播梯度更新潜变量 z_t，使预测结果逼近用户给定的控制目标，从而引导生成过程，不修改任何基础模型参数。
- **ReaDiT 架构**（图 2），由三部分组成：
  1. **编码器（Encoder）**：先对输入特征施加时间条件化的 AdaLN（抑制 DiT 中常见的异常大激活值并适配不同去噪时间步的分布），再通过线性层压缩通道维度。
  2. **多尺度 Rescale blocks**：将 token 序列重组为 2D 空间网格，生成 0.5×、1×、2×、4× 四个分辨率的特征分支，各自映射至统一通道数。
  3. **Fusion blocks**：对多尺度特征再次施加 AdaLN（t 条件），从粗到细逐级融合（卷积细化+上采样+残差连接），最终得到高分辨率特征图。
  之后接**任务特定 head**（对于稠密预测为小型卷积网络；对于光流任务，直接比较描述子计算期望位置）。
- **训练策略**：
  - 目标函数式 (1)：min_θ E_{t∼[t_min,t_max],x} L(gθ(f_l^t(x), t), y(x))。
  - **时间步采样**采用对数均匀采样 `log t ~ U(log t_min, log t_max)`，兼顾中低噪声步（信息更丰富）与高噪声步。

  - **稀疏对应/光流任务**：对两帧特征分别得到描述子，计算归一化余弦相似度矩阵 S，经行 softmax 得概率分布 P，用期望坐标计算光流；损失为 L1。
- **图像引导算法**（Algorithm 1）：
  1. 初始化 z_T ~ N(0, I)。
  2. 在每一步去噪中，迭代 M 次：提取特征 f_l^t → 预测 ŷ → 计算 L(ŷ, y) → 用梯度更新 z_t（DiT 与 ReaDiT 均冻结）。
  3. 执行 flow-matching 去噪步。
- **视频扩展**：
  - **空间引导**：逐帧预测与每帧目标比对；若视频模型在时间上下采样 s 倍，则用第 k 个隐帧预测与第 k·s 个目标帧计算损失。

## 6. 论文的主要结论与发现
- DiT 特征存在跨层高度线性冗余，**单一 DiT block 特征足以支撑高质量的空间预测与引导**，甚至优于多个 block 的组合特征（多块冗余信息反而可能损伤泛化）。
- ReaDiT 在图像深度、姿态、边缘引导上均明显优于 U-Net 时代的 RG，并与参数量远大于它的 ControlNet/OminiControl 达到相当或更优精度；且可与 ControlNet 等适配器方法叠加进一步提升性能。

- ReaDiT 不修改基础模型，不依赖大规模配对训练数据，具有统一的图像/视频、空间/运动控制能力，并可自然地支持多任务组合引导。

## 7. 优点
- **轻量且统一**：约 53M 参数，比 ControlNet（~1487M）少一个数量级，却以同一框架覆盖图像/视频、稠密空间控制与稀疏运动控制，无需为每个任务单独设计适配器。
- **免适配器、不修改基座模型**：作为一种“即插即用”推理时引导方法，可与 ControlNet 等兼容使用，且更可解释。
- **“单 block 特征足够”这一洞察具有方法论价值**：提供 PCA、线性冗余分析、逐 block 深度预测 RMSE 等证据链，而非仅凭直觉。
- **训练效率高**：仅需小型数据集和单块 A40 即可完成训练，代码路径清晰，具备较低重现门槛。
- **具备扩展性与灵活性**：支持多目标双引导、利用掩码处理不一致控制图、自然迁移至视频的时空特性。

## 8. 不足与局限
- **推理速度慢**：每个去噪时间步内需多次梯度回传，引导过程导致显著额外计算开销（图像生成慢约一倍，视频生成慢约 6–7 倍）。
- **运动控制短板**：快速动态场景效果不佳，EPE 明显高于专有方法（29.6 vs. 16.1），论文也承认缺少时间上采样处理或可学习的时间先验是未来方向。
- **实验覆盖的限制**：
  - 评测主要在 512 分辨率、少数基础模型（SD3/FLUX/CogVideoX）上完成，未覆盖更高分辨率或更多样骨干；
  - 视频 ControlNet/大规模适配器因算力未参与公平对比；
  - 单 block 有效性的详细消融在深度任务上进行，未系统展示不同 DiT 层的姿态/边缘/光流结果；
  - 运动控制只使用少量参考运动类别（6 个相机动作 × 20 prompts），多样性不足。
- **依赖现成标注模型的质量**：训练标签（深度、姿态、边缘）来自外部模型，其噪声与偏差会传入引导训练。
- **引导精度仍受优化策略影响**：学习率、迭代步数等超参变化较大，未讨论其对极端控制目标（如姿态极小面积或严重遮挡）的鲁棒性。
- **可扩展性问题未解决**：对于超长视频生成，每帧逐步梯度更新的计算与显存代价可能快速增加。
- **无理论保证**：虽然实验上单 block 足够，但并未给出数学解释为什么冗余特征反而会降低预测性能。
