## 摘要
个性化模型通过几个主题参考生成新图像，而风格迁移方法旨在产生与从参考图像衍生的全局风格对齐的图像。当参考图像包含单个对象时，近期方法表现良好，能有效捕捉涵盖所有隐式属性的全局风格。然而，当应用于包含多个具有不同属性特征的对象的复杂真实场景时，这些方法由于其实行全局级引导，无法定位参考图像中的相关元素。全局引导限制了它们基于参考图像中局部属性生成新图像的能力。此外，现有方法通常采用单个标识符令牌来捕获参考中的全部细节，导致缺乏个体属性级控制。受这些局限性的驱动，我们提出了RefDiT，一种用于参考引导图像生成的新框架。RefDiT输入参考图像、文本提示及可选的用户提供的引导上下文，利用局部元素的属性进行局部区域引导。通过执行标识符令牌的属性级分解，从参考图像构建属性感知的条件信号，并在推理提示中进行上下文调整，以训练基于扩散变压器（DiT）的生成模型的低秩适配器（LoRA）块。RefDiT学习标识符令牌与参考图像中局部区域之间的对应关系，从而能够实现更有效的局部引导。

## Abstract
Personalization models generate new images guided by a few subject references, while style transfer methods aim to produce images aligned with a global style derived from a reference image. Recent approaches perform well when the reference image contains a single object, effectively capturing a global style that encompasses all implicit attributes. However, when applied to complex real-world scenes containing multiple objects with distinct attribute characteristics, these methods, due to their global-level guidance, fail to localize relevant elements in the reference image. The global guidance restricts their ability to generate new images based on the local attributes in the reference image. Moreover, existing methods typically employ a single identifier token to capture all details from the reference, resulting in a lack of individual, attribute-level control. Motivated by these limitations, we propose RefDiT, a novel framework for reference-guided image generation. RefDiT takes as input a reference image, a text prompt, and an optional user-provided guidance context. RefDiT employs local region guidance using the attributes of local elements. It constructs an attribute-aware conditioning signal from the reference image by performing attribute-level decomposition of the identifier token and performs context adjustment in the inference prompt to train low-rank adapter (LoRA) blocks of a diffusion transformer (DiT)-based generative model. RefDiT learns the correspondence between identifier tokens and local regions in the reference image, enabling more effective local guidance.

## 1. 核心问题与研究动机

- **背景**：参考图像引导（reference-guided）的图像生成是当前生成模型的重要能力方向，包含两个密切相关但侧重不同的任务：
  - **个性化生成**：利用少量特定主体的参考图像，在新场景中生成该主体。
  - **风格迁移/引导**：使生成图像在整体风格上与参考图像保持一致。
- **现有方法的局限**：主流方法（如基于单一标识符 token 的个性化模型）在参考图像为**单一对象**时表现良好，可以隐式捕捉对象的所有属性，形成所谓的“全局风格”。但当参考图像为**复杂的真实场景**、其中包含**多个具有不同属性特征的对象**时，现有方法存在两大不足：
  1. **全局级引导失效**：方法仅能做整图的全局引导，无法在参考图中精准定位与文本提示相关的局部元素，因此无法基于“局部属性”控制生成。
  2. **单一标识符 token 控制粒度不足**：单个 token 承载了参考图的全部细节，无法对不同对象/不同属性进行独立、细粒度的控制。
- **本文提出问题的本质**：如何在多对象复杂参考场景中，基于参考图像的**局部属性**（而非全局风格）进行条件引导，使生成图像能够在文本提示的指引下从参考图中的不同区域提取相应属性，分别作用于要生成的不同对象。

## 2. 方法论：RefDiT

- **核心思想**：对现有架构的标识符 token 做**属性级分解**，将单一全局 token 拆解为多个**属性感知 token**；每个 token 不与整张参考图关联，而是与参考图中的某个**局部区域/对象**形成对应关系，从而在扩散 Transformer（DiT）的注意力机制中实现局部属性的条件化引导。
- **输入构成**：
  - 参考图像（reference image）
  - 文本提示（text prompt）
  - 可选的用户提供引导上下文（guidance context）
- **关键环节**：
  1. **属性级分解（Attribute-level Decomposition）**：从参考图中构造属性感知条件信号。具体而言，将原来代表整个参考图的标识符 token 扩展为多个子 token，每个子 token 绑定参考图像中的局部区域（例如不同对象的属性）。
  2. **上下文调整（Context Adjustment）**：在推理提示（inference prompt）中对分解出的 token 所关联的上下文文本进行组织与调整，使得模型能够统一理解“哪个文本描述对应哪个 token、对应哪个局部区域”。
  3. **LoRA 适配块训练**：基于上述两类调整后的条件，对基于 DiT 的图像生成模型的**低秩适配器（LoRA）**块进行训练，使模型学会标识符 token 与参考图像局部区域之间的对应关系，从而将参考属性从局部区域“迁移”到生成图像中的对应新对象上。
- **流程本质**：该方法不是直接在像素级或特征级施加 cross-attention 图约束，而是通过**重新设计条件语义空间中的 token 分配**，利用 DiT 天然的 attention 机制隐式实现“局部区域属性 → 文本语义位置 → 生成对象”的对齐。
