## 摘要
即插即用（PnP）方法通过将深度去噪器融入迭代优化算法来求解成像逆问题。尽管实际实现通常会在迭代过程中降低去噪器噪声水平 $σ$，但大多数现有收敛分析都假设去噪器固定不变。在这项工作中，我们为一类广泛的具有退火噪声水平的即插即用算法建立了收敛保证，涵盖确定性方法（RED--GD 和 PnP--PGD）与随机方法（SNORE、等变 RED 以及 PnP--Flow 的一个变体）。对于每种方法，我们识别出一个与终端去噪水平相关的显式非凸目标函数，并证明迭代点相对于该目标函数的渐近驻点性。我们的分析不对噪声调度规定任何衰减速率，并且我们的假设同时涵盖学习到的梯度步去噪器和精确 MMSE 去噪器。总体而言，我们的理论结果弥合了现有 PnP 收敛理论与当前最先进图像复原方法所采用的递减去噪实践之间的差距。我们通过实验证明了此类调度的优势，并在若干成像逆问题上展示了所预测的收敛行为，包括图像修补、超分辨率、去马赛克和断层成像。

## Abstract
Plug-and-Play (PnP) methods solve imaging inverse problems by incorporating deep denoisers into iterative optimization algorithms. Although practical implementations often decrease the denoiser noise level $σ$ along iterations, most existing convergence analyses assume a fixed denoiser. In this work, we establish convergence guarantees for a broad family of Plug-and-Play algorithms with annealed noise level, spanning deterministic methods (RED--GD and PnP--PGD) and stochastic methods (SNORE, equivariant RED, and a variant of PnP--Flow). For each method, we identify an explicit, nonconvex objective associated with the terminal denoising level and prove asymptotic stationarity of the iterates with respect to this objective. Our analysis does not prescribe any decay rate for the noise schedule, and our assumptions cover both learned gradient-step denoisers and exact MMSE denoisers. Overall, our theoretical results bridge the gap between existing PnP convergence theory and the decreasing-denoising practices used by state-of-the-art image restoration methods. We empirically demonstrate the benefits of such schedules and illustrate the predicted convergence behavior on several imaging inverse problems, including inpainting, super-resolution, demosaicing and tomography.

- **整体含义**：本文为一类广泛的退火噪声 PnP 算法建立收敛保证，首次将固定去噪器 PnP 收敛理论与现代 SOTA 图像复原实践中广泛使用的递减噪声调度统一起来。

## 2. 方法论

### 2.1 核心思想

- 对每种算法，识别出一个与**终端去噪水平 ε** 相关联的**显式非凸目标函数** F_ε，并证明迭代点渐近驻点（梯度趋于零），且无需规定噪声衰减速率、无需凸性假设。
- 为保持变分解释，要求去噪器是**精确梯度映射**或**近端映射**。

### 2.2 算法族（涵盖 5 类）

| 类型 | 算法 | 更新形式 |
|---|---|---|
| 确定性 RED | RED–GD | x_{k+1} = x_k − γ[∇f(x_k) + λ(x_k − D_{σ_k}(x_k))] |
| 随机 RED | SNORE | 在去噪器输入注入 σ_k Z_{k+1} 高斯噪声 |
| 随机 RED | ERED（等变 RED） | 注入随机正交变换 Q（旋转/翻转/置换） |
| 确定性 PnP | PnP–PGD | x_{k+1} = D_{σ_k}(x_k − γ∇f(x_k)) |
| 随机 PnP | SNOPnP / PnP–Flow | 在近端步前注入独立噪声 τ_k Z_{k+1} |

### 2.3 关键技术细节

- **去噪器假设**：
  - 保守去噪器 D_σ = Id − ∇g_σ（Tweedie 公式下精确 MMSE 去噪器满足；GS 去噪器按此参数化训练）。
  - 近端去噪器 D_σ = Prox_{φ_σ}（精确 MMSE 去噪器满足式(7)势函数；∇g_σ 收缩的 GS 去噪器也满足）。
- **噪声调度假设（Assumption 3.1）**：σ_{k+1} ≤ σ_k 且 σ_k → ε > 0（非增、收敛到正下限，避免 σ→0 时正则性退化）。
- **数据项假设（Assumption 3.2）**：f ∈ C¹、下有界、次解析（subanalytic）、梯度全局 Lipschitz。
- **证明策略**：在移动目标 F_{σ_k} 上做下降引理；噪声水平变化引入的误差项因 σ_k 单调收敛而可和（总变差有限），从而得到对 F_ε 的渐近驻点性。确定性算法在 |σ_k − ε| = O(k^{−α}), α>1 时用非精确 KL 定理（Ochs）证明全序列收敛。

### 2.4 主要理论结果（表 1）

- **RED–GD**：步长 γ(L_f + λL_g) < 2；驻点 + 点收敛；速率 O(1/K)。
- **SNORE / ERED**：步长 γ_k(L_f + λL_g) < 2，Σγ_k = ∞、Σγ_k² < ∞；几乎必然驻点。
- **PnP–PGD**：步长 γL_f < 1；驻点 + 点收敛。
- **SNOPnP / PnP–Flow**：γL_f < 1，Στ_k² < ∞；几乎必然驻点（需将注入噪声幅度 τ_k 与去噪水平 σ_k 解耦，因为 σ_k → ε > 0 时噪声方差不可和）。

## 6. 主要结论与发现

- **理论结论**：退火噪声 PnP/RED 算法（确定性 + 随机）在单调 σ_k ↓ ε > 0 下，迭代点渐近收敛到显式非凸目标 F_ε 的驻点，且**不需要噪声衰减速率条件、不需要凸性**；假设同时覆盖学习到的梯度步去噪器与精确 MMSE 去噪器。
- **实验结论**：
  - 退火在所有任务上均提升 PSNR，**修补与去马赛克增益最大**，超分增益较小（无大范围缺失区域时固定小 σ 已足够）。
  - 退火对 **PnP 算法（PnP–PGD、SNOPnP）尤为关键**，因为 PnP–PGD 的步长 γ 同时决定有效正则权重，受 γL_f < 1 约束限制；退火用大 σ 早期填洞、小 σ 后期避免过正则化，缓解该矛盾。
  - 收敛曲线显示目标值稳定、残差趋零，与理论预测一致；退火初期 PSNR 可能低于固定 σ，但随噪声下降最终反超。

## 8. 不足与局限

- **未解释"为何退火更好"**：退火与固定噪声算法满足相同的驻点保证，理论不排除退火收敛到差的临界点；**退火对驻点选择的影响仍是开放问题**。
- **去噪器假设偏强**：要求保守性（D_σ = Id − ∇g_σ）和/或收缩性（近端性）；标准学习去噪器即使逼近 MMSE，也仅近似满足，有限容量与训练不完美带来的近似误差对收敛的影响未量化。
- **近端性仅为软约束**：Prox 去噪器的收缩条件由软惩罚促进，验证集上谱范数略超 1，靠 ρ = 0.7 松弛提供经验安全边际，**非全局保证**。
- **步长条件限制**：PnP–PGD 要求 γL_f < 1，对有效正则权重构成下界约束；SNORE/ERED 需消失步长（Σγ_k² < ∞），实际实现需延迟衰减以避免早期步长过小。
- **算力信息缺失**：未报告 GPU 型号、数量与训练总时长，不利于复现与成本评估。
- **实验覆盖局限**：未测试非保守标准去噪器（如直接使用预训练扩散模型）、未与更多 SOTA 扩散类求解器（如 DPS、DiffPIR）对比；断层成像仅在 CBSD68 上测试。
- **应用限制**：终端 ε > 0 意味着算法不会收敛到 σ = 0 的理想 MAP 解，而是收敛到与 ε 相关的正则化解，ε 的选取需依赖验证集调参。
