## 摘要
任务驱动的图像复原旨在同时提升图像质量和下游任务性能。然而，现有方法大多聚焦于单一退化类型，难以应对真实场景中遇到的各种退化。不同退化对复原提出不同需求，而复原不足可能残留退化和伪影，损害目标边界与语义线索，从而影响下游任务性能。为应对这些挑战，我们提出 TaskIR，一种两阶段的任务驱动统一图像复原框架，将退化自适应复原与任务反馈精炼相结合。在第一阶段，退化表示模块（DRM）提取退化表示，使退化引导 Transformer 块（DGTB）能够动态调制特征变换以实现自适应复原。在第二阶段，任务到复原反馈生成模块（TRFG）通过建模与当前复原相关的任务-表示差异，将异构任务特征转化为复原反馈。随后，选择性任务反馈精炼模块（STFR）评估反馈相关性，并有选择地精炼中间复原特征，以减轻对已复原良好内容的干扰。大量实验表明，TaskIR 在多种退化和任务上均取得了具有竞争力的复原质量和下游任务性能。

## Abstract
Task-driven image restoration aims to improve both image quality and downstream task performance. However, existing methods predominantly focus on single degradation type and struggle to handle the diverse degradations encountered in real-world scenarios. Different degradations impose distinct restoration demands, and insufficient restoration may leave residual degradations and artifacts that impair object boundaries and semantic cues, thereby compromising downstream task performance. To address these challenges, we propose TaskIR, a two-stage task-driven unified image restoration framework that integrates degradation-adaptive restoration with task feedback refinement. In Stage I, a Degradation Representation Module (DRM) extracts degradation representations, enabling a Degradation-Guided Transformer Block (DGTB) to dynamically modulate feature transformations for adaptive restoration. In Stage II, a Task-to-Restoration Feedback Generation module (TRFG) transforms heterogeneous task features into restoration feedback by modeling task-representation discrepancies associated with the current restoration. Subsequently, a Selective Task Feedback Refinement module (STFR) assesses feedback relevance and selectively refines intermediate restoration features to mitigate interference with well-restored content. Extensive experiments demonstrate that TaskIR achieves competitive restoration quality and downstream task performance across diverse degradations and tasks.

## 1. 核心问题与研究背景

- **研究动机**：图像复原的目标不仅是提升视觉质量，还要为分类、语义分割、目标检测等下游视觉任务提供可靠输入。真实场景中的退化（噪声、模糊、雾、低照度等）多样且往往并存。
- **现有方法的局限**：
  - **任务驱动图像复原（TDIR）** 大多针对**单一退化**设计（如超分、去雾、水下增强），网络结构与任务引导机制高度专用，难以直接迁移到多退化场景。
  - **一体化图像复原（AiOIR）** 虽能处理多退化，但主要优化像素保真度与视觉质量，**提升复原质量并不必然带来下游任务性能提升**。
  - 下游任务特征偏向高层语义与判别信息，与复原所需的纹理/结构信息不一致，**直接使用任务特征会引入干扰**；且不同任务反馈的贡献不同，**不加区分地精炼会破坏已复原良好的内容**。
- **整体含义**：论文将任务驱动复原从"单一退化"扩展到"统一多退化"场景，试图在**退化自适应复原**与**任务反馈精炼**之间取得平衡，兼顾图像质量与下游任务性能。

## 2. 方法论

### 2.1 核心思想
两阶段框架 **TaskIR**：
- **Stage I（退化引导复原）**：先做退化自适应的初步复原，得到 $I_0$。
- **Stage II（任务驱动反馈建模）**：加载 Stage I 权重，冻结复原主干与任务网络，仅训练反馈模块，用任务反馈选择性精炼中间复原特征，得到 $I_{out}$。

### 2.2 Stage I：退化引导复原
- **退化表示模块（DRM）**：
  - 3×3 卷积得到浅层特征 $X$；**多尺度退化提取（MDE）** 用不同感受野的并行深度可分离卷积分支 + 特征融合 + 残差连接得到退化特征 $X_d$。
  - 对 $X_d$ 施加 **GAP + 全局标准差池化（GSP）**，拼接后经 MLP 得到**全局退化表示** $z_d \in \mathbb{R}^{B\times D}$。
  - 用空间映射器 $P_s(\cdot)$ 预测**空间退化响应** $S_d$，再按各复原阶段分辨率 Resize 并用 Sigmoid 映射，得到空间退化图 $M_d^{(k)} = 2\sigma(\text{Resize}_k(S_d))$。
- **退化引导 Transformer 块（DGTB）**：
  - **退化条件参数生成器（DPG）** 从 $z_d$ 生成两组调制参数：通道尺度 $\lambda_i^{(k)}$、通道偏置 $\beta_i^{(k)}$、残差尺度 $\rho_i^{(k)}$（$i\in\{1,2\}$）。
  - 第一组参数调制 MDTA 分支：$F_1 = F + \rho_1^{(k)}\odot M_d^{(k)}\odot \text{MDTA}(\lambda_1^{(k)}\odot \text{LN}(F)+\beta_1^{(k)})$。
  - 第二组参数调制 GDFN 分支得到输出 $F_2$。
  - 即：**通道响应、残差更新强度、空间更新幅度**三者均随退化状态动态调整；DGTB 部署在 latent 与 decoder 阶段。

### 2.3 Stage II：任务驱动反馈建模
- **任务到复原反馈生成（TRFG）**：
  - **投影库（Projection Bank）**：对每个任务 $t$、位置 $l$ 的特征 $F_{t,l}$ 做通道映射与空间对齐，得到 $Q_{t,l}$。
  - **任务条件动态适配器（TCDA）**：用膨胀率 $r_j\in\{1,2,3\}$ 的三路深度可分离卷积提取多尺度信息，依据全局统计与可学习条件嵌入 $e_{t,l}$ 预测分支权重 $\omega_j^{t,l}=\text{Softmax}_j(\text{MLP}([\text{GAP}(Q_{t,l});e_{t,l}]))$，加权聚合 + 轻量映射 + 残差连接得 $\hat{F}_{t,l}$。
  - **任务差距预测器（TGP）**：$\Delta\hat{F}_{t,l}=\tanh(\Phi_l(\hat{F}_{t,l}))$ 预测当前复原结果的任务表示差异；训练时用 **EMA 教师** 以 $I_0$ 与 $I_{GT}$ 的任务表示差异构造监督目标，**推理时不需要参考图**。
  - 最终反馈：$T_{t,l}=\hat{F}_{t,l}+\sigma(\Psi_l(\hat{F}_{t,l}))\odot\Delta\hat{F}_{t,l}$。
- **选择性任务反馈精炼（STFR）**：
  - **任务相关反馈（TRF）**：将复原特征 $F_k$ 与三路任务反馈投影到统一 $d$ 维空间并展平；引入**共享可学习原型库** $C=\{C_m\}_{m=1}^M$，用余弦相似度计算软分配 $A_{n,m}$，加权聚合成原型表示；再计算原型间余弦相似度矩阵 $S_{k,i}$，用**对数域 Sinkhorn 迭代**近似熵正则最优传输计划 $\Pi_{k,i}$，得到相关性得分 $\rho_{k,i}=\sum_{m,n}\Pi^{m,n}_{k,i}S^{m,n}_{k,i}$ 与权重 $w_{k,i}=\text{Softmax}_i(\rho_{k,i}/\tau_r)$；对齐后按权重融合得 $T_k^{TRF}=\sum_i w_{k,i}\tilde{T}_{k,i}$。
  - **条件复原精炼（CRR）**：用通道级交叉注意力（Q 来自 $F_k$，K/V 来自 $T_k^{TRF}$）产生候选修正 $\Delta F_k=\eta_k\tanh(H_k(\text{CA}_k(F_k,T_k^{TRF})))$；构造"保持态"$F_k^K=F_k$ 与"更新态"$F_k^U=F_k+\Delta F_k$，共享 Scorer 依据与融合反馈的条件关系（含拼接、点乘、绝对差）计算响应 $R_s^k$；由响应差生成更新门 $\Omega_k=\sigma(G_k(R_U^k-R_K^k))$；最终 $F'_k=(1-\Omega_k)\odot F_k^K+\Omega_k\odot F_k^U=F_k+\Omega_k\odot\Delta F_k$。

## 6. 主要结论与发现

- TaskIR 在 **8 种退化类型**下均取得有竞争力的复原质量（ImageNet-1K PSNR 28.31/SSIM 0.8491；Cityscapes 35.31/0.9481；VOC2012 28.28/0.8484），优于所有对比方法。
- 下游任务性能同样领先：分类 Top-1 73.00 / Top-5 90.65，分割 mIoU 74.69 / Dice 84.77，检测 mAP@0.5 82.46 / mAP@0.5:0.95 63.98。
- **引入任务反馈不会明显损害复原质量**（与 C3 相比复原指标接近），但能显著提升任务性能（如 Top-1 +0.28、mIoU +0.40），说明两阶段设计有效平衡了两者。
- **空间退化图 $M_d$** 的引入可提升复原质量（C2 vs C1）；**TRF 与 CRR 二者结合**比单独使用效果更好，说明反馈融合与选择性精炼均不可或缺。
- 定性结果显示 TaskIR 能更好恢复目标边界与结构细节（如车灯轮廓），分割边界更连续、检测框更贴合目标。

## 7. 优点（亮点）

- **问题定位准确**：明确指出"多退化统一 + 任务驱动"这一交叉空白，并指出"复原质量↑ ≠ 任务性能↑"与"任务特征直接用于复原会带来干扰"两个关键痛点。
- **退化自适应设计细致**：同时建模**全局退化统计**（GAP+GSP→$z_d$）与**空间退化分布**（$S_d$→$M_d$），并通过 DPG 将退化条件注入通道尺度、偏置、残差尺度与空间更新幅度四个维度，调制粒度较细。
- **任务反馈机制新颖**：
  - 用 **EMA 教师 + 任务表示差异预测** 生成反馈，推理阶段无需参考图，实用性较好。
  - 用 **原型库 + Sinkhorn 最优传输** 度量任务反馈与当前复原状态的相关性，比简单注意力/拼接更具可解释性与判别性。
  - **CRR 的 keep/update 双状态 + 更新门** 设计直接回应"避免破坏已复原内容"的动机，逻辑自洽。
- **工程上克制**：Stage II 冻结主干与任务网络、只训练轻量反馈模块，训练成本较低，便于即插即用。
- **实验报告规范**：主表与消融表同时给出复原与任务双指标，便于判断权衡；定性对比覆盖三类任务。

## 8. 不足与局限

- **对比公平性存疑**：
  - 未与任务驱动复原（TDIR）专门方法对比，"任务驱动"定位的实验支撑不足。

- **实验覆盖有限**：
  - 退化类型虽称 8 种，但未说明是否为合成退化及是否包含真实退化组合；未验证**未见退化组合**的泛化能力。
  - 仅覆盖分类、分割、检测三类任务，未涉及深度估计、超分、视频任务等。
  - 未报告失败案例或退化极严重/极轻微时的行为。
- **效率与部署信息缺失**：无参数量、FLOPs、推理延迟、显存占用；原型库 + Sinkhorn 迭代 + 交叉注意力的额外开销未知，可能影响实时性场景的适用

性。

- **可复现性与实现细节缺失**：未说明下游任务网络的具体骨干、预训练权重来源及是否参与训练；Stage II 中任务反馈的层位置 \(l\) 如何选取、任务特征维度如何对齐、损失权重如何设置均未给出细节。
- **任务反馈的通用性未验证**：Stage II 依赖特定下游任务网络的中间特征，若更换任务网络、任务头或任务类型，反馈模块是否需要重新训练或适配尚未讨论，跨任务迁移能力不明确。
- **退化设定不够透明**：8 种退化是分别独立测试还是混合退化？是否包含真实退化组合？任意退化组合、未见退化组合下的泛化能力未评估，影响“统一多退化”结论的强度。
- **训练成本与性价比未讨论**：Stage I 200K + Stage II 100K 迭代、4×A100 的训练开销不低，但未与基线方法对比训练成本或推理成本，难以判断其实际部署价值。

## 9. 总体评价与启示

TaskIR 针对“多退化统一复原 + 下游任务驱动”这一交叉问题，提出了逻辑清晰的两阶段框架：Stage I 通过全局/空间退化表示与退化条件调制实现退化自适应复原；Stage II 通过任务反馈预测、原型-Sinkhorn 相关性融合与 keep/update 门控实现选择性精炼。其核心设计将任务反馈从“直接使用任务特征”转变为“预测任务表示差距并选择性注入”，并借助最优传输度量反馈与当前复原状态的相关性，在动机与机制上较为自洽，兼顾了任务性能与复原质量。

实验层面，论文覆盖 3 个数据集、8 种退化、3 类下游任务与 10 个较新基线，主表与消融均报告复原与任务双指标，整体较规范。但论文的核心定位“任务驱动”在对比实验中未与 TDIR 专门方法直接比较，性能提升幅度有限且缺少方差/显著性检验，Stage I 关键组件缺乏消融，效率与部署信息缺失，任务反馈的通用性与超参敏感性也未充分讨论。因此，TaskIR 可视为一个设计精巧、工程可行的多退化任务驱动复原框架，但其相对现有 AiOIR 方法的实际优势仍需更严格的公平对比与更全面的消融来支撑。
