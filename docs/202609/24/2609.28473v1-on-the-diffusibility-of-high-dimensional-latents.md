## 摘要
表示自编码器（RAEs）使扩散模型能够在预训练视觉编码器的特征空间中运行。然而，许多现成的编码器并未针对忠实的重建进行优化，会丢弃细粒度的视觉细节。正如预期，针对图像重建对这些编码器进行微调可以恢复此类细节。然而，或许与直觉相反，这一过程会降低所得表示的有效维度，并且改变后的几何结构会对生成产生下游影响。具体而言，我们表明，在这种高维空间中使用流匹配中的标准速度预测，会要求模型拟合低维信号流形之外的正交噪声方向，从而使优化效率低下。这促使我们改用干净数据参数化（\boldsymbol{x}_{0}-预测），它将学习集中在潜在信号流形上。在使用多个强重建编码器的实验中，我们表明 \boldsymbol{x}_{0}-预测能够持续提升文本到图像生成性能。

## Abstract
Representation Autoencoders (RAEs) enable diffusion models to operate in the feature spaces of pretrained visual encoders. However, many off-the-shelf encoders are not optimized for faithful reconstruction, discarding fine-grained visual details. As expected, finetuning these encoders for image reconstruction recovers such details. However, perhaps counterintuitively, this procedure reduces the effective dimensionality of the resulting representation, and the altered geometry has downstream effects on generation. Specifically, we show that using the standard velocity prediction in flow matching in this high-dimensional space requires the model to fit orthogonal noise directions outside the low-dimensional signal manifold, making optimization inefficient. This motivates using the clean data parameterization ($\boldsymbol{x}_{0}$-prediction) instead, which focuses learning on the underlying signal manifold. Across experiments with multiple strong-reconstruction encoders, we show that $\boldsymbol{x}_{0}$-prediction consistently improves text-to-image generation performance.

# 论文总结：On the Diffusibility of High-Dimensional Latents（论高维潜表示的可扩散性）

## 1. 核心问题与整体含义

- **背景**：扩散模型与流匹配已成为高保真视觉生成（含文生图）的主流范式。为提升计算效率，生成通常在潜空间中进行：早期工作使用 VAE 潜空间，但其维度低、常丢弃感知重要信息；近期兴起的**表征自编码器（Representation Autoencoders, RAE）** 则尝试直接在预训练语义视觉编码器（如 DINOv2、SigLIP2、MAE）的特征空间中生成。
- **矛盾点**：这些语义编码器并非为重建而训练，无法保证保留图像全部信息，会丢失高频细节（文字、纹理、小物体）。直观的补救方式是**用重建目标微调编码器**以恢复细节。
- **反直觉发现**：论文发现，重建微调虽提升重建保真度（PSNR 从 17.34 → 29.12），却**显著压缩了表征的有效维度**（DINOv2-L 的 R₉₀ 从 672 降至 129）。在这一几何结构下，流匹配的**标准速度预测（v-prediction）** 需要模型去拟合位于低维信号流形之外的**正交噪声方向**，导致优化效率低下——即使在单图过拟合这样的简单任务中也收敛缓慢。
- **整体含义**：高维潜空间"可扩散性"（diffusibility）并非仅由重建保真度决定，而由表征的几何结构主导；本文据此提出用**干净数据参数化（x₀-prediction）** 替代 v-prediction，从而在强重建、高维表征空间中高效训练文生图模型。

## 2. 方法论

### 2.1 核心思想
- 不使用 v-prediction，而让模型**直接预测干净表征 x₀**，把学习容量集中在低维信号流形上，从而绕开正交噪声分量。

### 2.2 技术细节与公式流程

- **流匹配基础**：`z_t = (1-t)x₀ + tε`，速度目标 `v = ε - x₀`，损失 `L = E‖v_θ(z_t,t) - v‖²`。
- **x₀-prediction**（受 JiT 启发）：令 `v_θ = (z_t - x_θ)/t`，损失等价于 `L = E‖(x₀ - x_θ)/t‖²`；实践中将 t 下限截断为 0.05 以保证数值稳定。
- **强重建 RAE 的训练**：采用三阶段微调 DINOv2-L，损失为
  `L_FT = ω_sp‖g(I) - g'(I)‖² + L_L1 + ω_p L_perceptual + ω_g L_GAN`，
  其中 `ω_sp = 1, ω_p = 1, ω_g = 0.5`。语义保持项用于防止表征崩塌。
- **有效维度度量**：对 200k 个 ImageNet patch 的 L2 归一化特征中心化后做 SVD，能量占比 `f_i = σ_i²/E`，累积能量 `C(k)`，定义 `R_τ = min{k | C(k) ≥ τ/100}`，τ ∈ {90, 95, 99}。
- **几何分析（子空间模型）**：设 `x₀ = Qc₀`，Q 的列为正交基。前向过程分解为
  `z_t^h = Q((1-t)c₀ + tε_l) + tε_⊥`，且 `P_⊥ z_t^h = t ε_⊥`。
  - v-prediction 的贝叶斯最优解为：
    `v_θ^h(z_t^h,t) = Q v_θ^l(Q^T z_t^h, t) + (1/t)(I - QQ^T) z_t^h`。
    第二项是 (h−l) 维、与数据子空间正交、对 c₀ 无信息量的确定性项。当 h ≫ l 时，该正交项能量 `tr(P_⊥) = h - l` 会主导目标，迫使模型浪费容量。
  - x₀-prediction 的贝叶斯最优解为：
    `x_θ^h(z_t^h,t) = E[Qc₀ | Q z_t^l] = Q x_θ^l(z_t^l, t)`，
    由于 c₀ ⊥⊥ ε_⊥ | z_t^l，正交噪声不带来额外信息，输出完全落在信号子空间内，因此更高效。
- **生成架构**：冻结的 Qwen3-VL-2B-Instruct 作为自回归模型，用 64 个可学习 query token 提取文本条件；随机初始化的 DiT（Lumina-Next 1B，24 层、24 头、隐层 1536）在 1024×16×16（DINOv2）或 768×16×16（MAE）的高维潜上做扩散；采用带 shift 的均匀时间调度（n = 4096）。

## 6. 主要结论与发现

1. **有效维度崩塌**：以重建为目标（预训练或微调）的编码器，其表征会急剧集中到低维子空间（如 MAE-B 的 R₉₀ = 103 vs DINOv2-B 的 507；微调 DINOv2-L 的 R₉₀ = 129 vs 原始的 672），即便在 Instagram-3B 等大规模数据上预训练也无法避免。
2. **v-prediction 在高维强重建空间中失效**：微调 DINOv2-L + v-prediction 相比原始 DINOv2-L 全面退化（GenEval 37.63 → 30.96，DPG 70.21 → 67.47，FID 18.34 → 29.97）。
3. **x₀-prediction 是一致有效的补救**：微调 DINOv2-L + x₀ 达到 GenEval 39.48、DPG 71.83、FID 16.80，反超原始 DINOv2-L；MAE-RAE 上从 36.17/67.54/22.20 提升至 40.89/73.90/17.24。
4. **重建仍然重要**：强重建 + x₀ 的组合在结构完整性和颜色对齐上优于纯语义冻结基线（定性可见）。
5. **高维并不必然劣于低维**：32 维瓶颈变体文本对齐更好（GenEval 40.99、DPG 73.04）但 FID 更差（17.64 vs 16.80），说明不降维、保留细粒度信息可换来更好的视觉保真度。
6. **可扩展性**：在 90M 数据 + SFT 后达到 GenEval 78.62 / DPG

+ SFT 后达到 GenEval 78.62 / DPG-Bench 84.30（512 分辨率），在 2.4B DiT、1152 维、224 分辨率的 Scale-RAE 对照下仍具竞争力；说明该参数化在高维潜空间下可随数据与模型规模平滑扩展。

7. **微调语义编码器存在"语义—重建"权衡**：以重建目标微调 DINOv2-L 虽恢复细节，却削弱了其原始语义判别力——线性探测准确率从 84.5% 降至 63.9%；冻结 VLM 主干在 7 个多模态理解基准上的评估（Tab. 7）亦显示，一旦让编码器承担重建职责，其作为通用视觉表征的能力会部分退化。这提示"强重建 tokenizer"与"强语义编码器"两种角色存在内在张力。

8. **预测目标与潜空间几何的匹配是核心变量**：论文反复强调，v-prediction 与 x₀-prediction 的差异并非简单的损失重参数化，而是对"噪声方向是否携带信号"这一几何事实的利用与否。当有效维度接近名义维度时（如冻结语义编码器），两者差距不大；一旦有效维度远低于名义维度（强重建 tokenizer），x₀-prediction 的优势被急剧放大。

## 7. 局限性与可讨论之处

- **规模边界未完全探明**：主实验的 DiT 仅 1B、分辨率 256（SFT 512），虽给出 2.4B / 1152 维 / 224 的 Scale-RAE 参考，但并未在同一框架下做完整的"模型规模 × 潜维度 × 预测目标"三维扫描，x₀-prediction 在更大规模下的收益曲线尚不明确。
- **几何分析基于线性子空间假设**：子空间模型假设 x₀ 落在固定 l 维线性子空间、且 ε_⊥ 与 c₀ 条件独立，真实表征流形可能非线性、有效维度随 t 变化，理论结论是理想化近似。
- **混淆因素未完全隔离**：如第 5 节所述，"原始 DINOv2 + v" 与 "微调 DINOv2 + x₀" 同时改变了 tokenizer 与预测目标；低维瓶颈对照的解码器亦为单独训练。更严格的 2×2 因子设计（冻结/微调 × v/x₀）能更干净地分离两个变量的贡献。
- **超参与训练细节缺少消融**：t 截断下限（0.05）、时间调度 shift（n = 4096）、语义保持损失权重 ω_sp 等关键选择未做敏感性分析。
- **语义退化的缓解手段未展开**：论文指出微调损害语义能力，但未系统比较"部分层微调 / 适配器 / 多任务联合"等可能兼顾两者的方案。
- **评测维度**：以 GenEval、DPG-Bench、COCO FID 为主，缺少人类偏好或美学类评测；文本渲染、计数等细粒度能力未单独拆解。
