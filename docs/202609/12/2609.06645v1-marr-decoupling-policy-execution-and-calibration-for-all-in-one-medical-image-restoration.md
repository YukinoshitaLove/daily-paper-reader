## 摘要
一体化医学图像复原旨在用单一模型恢复异构临床图像，但 PET、CT 和 MRI 在退化统计、解剖对比度和输出空间偏差方面存在显著差异。完全共享的网络会纠缠模态特定的残差误差，而独立的模态特定网络则牺牲了统一部署的实际优势。因此，我们将一体化复原重新表述为有限适应应置于何处的问题：策略选择、特征执行还是输出校准。我们提出 MARR，一个紧凑的复原框架，将多模态适应约束为退化感知的策略路由、模态私有残差执行和图像域残差校正，且无需退化标签或独立的模态特定模型。策略分支根据输入统计量、潜在内容和模态身份形成路由提示，并仅将其用作控制信号。随后，提示门控的模态私有适配器在解码器中间阶段执行轻量级残差细化，而零初始化的模态特定输出头校准最终图像域残差，且不扰动初始共享预测。在一体化 PET、CT 和 MRI 复原基准上，MARR 优于在相同协议下重新训练的十三种方法，在 PET、CT 和 MRI 上分别达到 37.34 dB、33.85 dB 和 32.09 dB 的 PSNR，并取得最佳模态平均 PSNR 34.43 dB。代码公开于 https://github.com/CHB-learner/MARR。

## Abstract
All-in-one medical image restoration seeks to recover heterogeneous clinical images with a single model, but PET, CT, and MRI differ substantially in degradation statistics, anatomical contrast, and output-space bias. A fully shared network can entangle modality-specific residual errors, whereas separate modality-specific networks sacrifice the practical advantages of unified deployment. We therefore recast all-in-one restoration as a question of where limited adaptation should be placed: policy selection, feature execution, or output calibration. We propose MARR, a compact restoration framework that constrains multi-modality adaptation into degradation-aware policy routing, modality-private residual execution, and image-domain residual correction without requiring degradation labels or separate modality-specific models. The policy branch forms a routing prompt from input statistics, latent content, and modality identity, and uses it only as a control signal. Prompt-gated modality-private adapters then perform lightweight residual refinement at intermediate decoder stages, while zero-initialized modality-specific output heads calibrate the final image-domain residual without perturbing the initial shared prediction. On an all-in-one PET, CT, and MRI restoration benchmark, MARR outperforms thirteen methods re-trained under the same protocol, achieving PSNR values of 37.34 dB, 33.85 dB, and 32.09 dB on PET, CT, and MRI, respectively, and the best modality-average PSNR of 34.43 dB. The code is publicly available at https://github.com/CHB-learner/MARR.

## 1. 核心问题与研究动机

- **背景**：医学图像复原（restoration）是下游诊断、定量分析和图像引导介入的核心预处理步骤。不同成像模态呈现截然不同的复原失败模式：
  - **PET**：需抑制低计数噪声，同时不抹除微弱的功能性摄取信号；
  - **低剂量 CT**：需去除结构化伪影，同时保持标定的强度值；
  - **MRI**：超分辨率需恢复解剖边缘与组织对比度。
- **核心矛盾**：
  - 为每个模态单独训练模型在技术上可行，但会**增加验证成本、碎片化维护、复杂化多模态临床部署**；
  - 一体化（all-in-one）复原用单模型处理多模态，但 PET、CT、MRI 在**退化统计、解剖对比度、输出空间偏差**上差异显著——完全共享的网络会**纠缠模态特定的残差误差**，而分模态网络又丧失统一部署优势。
- **重新表述**：作者将一体化复原重构为“**有限适配应放在哪里**”的设计问题，即：策略选择（policy selection）、特征执行（feature execution）、输出校准（output calibration）三个位置。
- **现有方法的不足**：已有的一体化方法（如 AMIR、RAT、TAT、DaPT）引入了任务路由、任务自适应注意力和退化感知提示，但往往**未明确提示的功能角色**——同一个提示可能被同时期望用于选择复原行为、调制中间特征、修正最终重建，导致单一提示分支吸收不兼容的职责。

## 2. 方法论

### 2.1 核心思想
- 提出 **MARR（Modality-aware Residual Recalibration）**，将多模态适配**约束**为三个明确角色，形成“**决策—执行—校正**”（decision-execution-correction）分解：
  1. **策略路径**：估计退化感知提示，仅作控制信号；
  2. **执行路径**：提示门控的模态私有适配器，在解码器中间层做轻量残差细化；
  3. **校正路径**：零初始化模态特定输出头，做图像域残差校正。
- 整体为单一可部署模型（基于 MA-DASUR 网络），**无需退化标签**，也无需独立模态模型。

### 2.2 关键技术细节

**（1）退化感知提示策略（决策）**
- 从输入图像计算简单统计向量：
  `s(x) = [μ(x), σ(x), r(x), e_g(x), ρ_f(x)]`
  其中 μ、σ 为均值与标准差，r 为强度范围，e_g 为平均梯度能量（强调局部结构损坏），ρ_f 为高低频能量比（区分高频噪声/纹理丢失与低频强度漂移）。
- 从瓶颈特征经全局池化得潜在内容描述子 c，并从元数据获取可学习模态嵌入 e_m。
- 三者拼接形成查询：`q = φ_q([e_m, z_d, φ_c(c)])`。
- 查询在**模态提示池 P_m** 与**退化提示池 P_d**上做 softmax 软选择：
  `a_m = softmax(P_m q / √d)`，`a_d = softmax(P_d q / √d)`。
- 选中提示与查询上下文融合为策略提示 z_p，**仅作为控制信号**，不注入图像特征或合成图像细节。
- 使用轻量策略正则器 `L_p = L_div + λ_e L_ent`，多样性项防提示冗余，熵项防路由过早尖峰（防提示坍缩）。

**（2）提示门控模态私有残差适配（执行）**
- 对解码器第 l 层特征 F_l：
  `F̃_l = F_l + α · g_lm(z_p) · A_lm(F_l)`
- 每个模态拥有一个 **DWConv-GELU-PWConv** 轻量深度可分离残差分支；策略提示经小型 MLP 投影 + sigmoid 生成模态门控。
- 最后一个逐点卷积**零初始化**，残差缩放 α 保持较小，使分支初始为**恒等扰动**而非不受控的模态变换。
- 适配器放置在**两个解码器中间阶段**：过早会过拟合模态特定强度统计，过晚则不足以恢复模态细节。

**（3）零初始化输出校准（校正）**
- 给定最终解码器特征 F_o 与基础预测 ŷ_0：
  `ŷ = ŷ_0 + β · C_m(F_o)`
- 所有输出头权重与偏置**零初始化**，初始时模型预测恰为 ŷ_0，校准分支仅学习残差修正，避免早期训练扰动共享表示。
- 该分支只处理共享预测与私有适配器之后残留的**图像域强度/纹理偏差**，不替代特征级适配。

**（4）训练目标**
- `L = Σ_m w_m E_(x,y)∈D_m [||ŷ − y||_1] + λ_p L_p`
- 模态权重补偿 PET/CT/MRI 样本不平衡；策略正则权重较小，重建目标占主导。
- **模型选择**采用跨所有模态的验证分数，而非仅样本加权平均（因测试集被 MRI 切片主导）。

## 6. 主要结论与发现

- MARR 在复现协议下取得**三模态全部最优**：PET 37.34 dB、CT 33.85 dB、MRI 32.09 dB，**模态平均 PSNR 34.43 dB**（对比最强基线 TAT 的 34.36 dB）。
- 平均 SSIM 从 0.9357 提升至 0.9361，平均 RMSE 从 12.4940 降至 12.4811。
- **机制诊断发现**：
  - 策略提示嵌入在 t-SNE 中形成清晰的**模态感知聚类**（轮廓系数 0.83），支持提示作为模态结构化控制表示；
  - 适配器残差在 CT 和 MRI 的**解码器第 2 层最活跃**，表明私有适配主要修正中间结构特征；
  - 输出校准偏移 **PET 最大、MRI 中等、CT 最小**，说明 PET 更受益于最终图像域残差校准。
- **消融结论**：不存在跨模态单一主导机制——校准解释了 PET/CT 的大部分改进，特征级适配对 MRI 更相关；紧凑的 MARR 设计优于堆叠更多特化模块的扩展变体，说明价值在于**将有限适配容量分配到互补的决策、特征、输出角色**，而非模块堆叠。

## 7. 优点

- **方法论亮点**：
  - 将“适配位置”问题显式化，提出**角色约束**而非无约束模块堆叠，使每个路径只承担有限错误类型，模型更**可审计**；
  - 无需退化标签，统计线索简单且不依赖外部质量估计器；
  - 零初始化输出头 + 小残差缩放 + 零初始化逐点卷积，保证训练初期**恒等残差路径**，优化稳定；
  - 适配器置于中间解码器层，兼顾语义上下文与空间分辨率，避免过早过拟合或过晚不足。
- **实验设计亮点**：
  - 严格的复现协议（同划分重训、双 checkpoint 取优、全测试集、统一指标脚本）；
  - 采用模态均衡平均而非样本加权，契合一体化目标；
  - 结合 t-SNE、残差范数、校准偏移的机制诊断，提供一定的可解释性；
  - 消融不仅验证核心模块，还测试多种扩展设计，证明紧凑设计的必要性。

## 8. 不足与局限

- **评估指标局限**：仅使用全参考指标（PSNR/SSIM/RMSE），**未直接衡量下游临床效用**（分割、定量分析、诊断），而配对指标与临床价值并不等价。
- **依赖模态标签**：训练与测试均使用模态标签，虽然临床数据通常可获得，但**缺乏全自动模态推断**会使框架在元数据不完整时不够鲁棒。
- **理论支撑不足**：所提分解仅由消融和诊断支持，**没有正式的域偏移界（domain-shift bound）**；使用的是轻量统计线索而非学习式不确定性估计器。
