## 摘要
由恶劣天气导致的图像退化因其空间异质性退化而仍然具有挑战性。许多现有的天气专用复原模型依赖于与天气无关的全局聚合、朴素的跨尺度融合和确定性目标，难以处理一体化恶劣天气设置中的异质性退化。为解决这些局限性，我们提出了一种不确定性引导的恶劣天气复原网络（UAR-Net），这是一种天气专用的一体化框架，集成了带有平衡多尺度跳跃连接的门控Transformer。具体而言，我们采用门控双尺度Transformer块（GDTB）来联合建模选择性全局交互和多尺度局部结构，采用渐进式平衡多尺度跳跃连接（BMSC）实现平衡的多尺度特征融合，以及采用不确定性感知细化头（URH）进行伪影去除、细节增强和预测不确定性估计。该模型由亮度感知能量损失（BAE-Loss）监督，以鼓励具有良好校准不确定性的准确重建。大量实验表明，我们的方法在多个恶劣天气基准上达到了最先进的性能。代码将在录用后开源。

## Abstract
Restoring images degraded by adverse weather remains challenging due to spatially heterogeneous degradations. Many existing weather-specific restoration models rely on weather-agnostic global aggregation, naive cross-scale fusion, and deterministic objectives, which struggle to handle heterogeneous degradations in all-in-one adverse-weather settings. To address these limitations, we propose an Uncertainty-guided Adverse-weather Restoration Network (UAR-Net), a weather-specific AiO framework that integrates a gated transformer with balanced multi-scale skip connections. Specifically, we employ Gated Dual-scale Transformer Blocks (GDTB) to jointly model selective global interactions and multi-scale local structures, a progressive Balanced Multi-scale Skip Connection (BMSC) for balanced multi-scale feature integration, and an Uncertainty-Aware Refinement Head (URH) that performs artifact removal, detail enhancement, and predictive uncertainty estimation. The model is supervised by a Brightness-Aware Energy Loss (BAE-Loss) to encourage accurate reconstruction with well-calibrated uncertainty. Extensive experiments demonstrate that our method achieves state-of-the-art performance across multiple adverse-weather benchmarks. The codes will open source upon acceptance.

## 1. 核心问题与整体含义（研究动机与背景）

- 恶劣天气（雨、雪、雾、水滴等）会造成图像空间异质性退化，模糊结构边界、降低能见度，并严重影响自动驾驶、智能监控等安全关键应用的下游任务。
- 已有方法分为两类：
  - **任务特定方法**：如去雨、去雪、去雾，仅面向单一退化类型，需要分别训练多个模型，难以扩展到真实复杂场景。
  - **一体化 All-in-One（AiO）方法**：用单一网络恢复多种天气退化，但已有模型仍存在三大问题：
    - 在全局上下文聚合上采用天气无关的**均匀聚合**，未针对不同退化进行选择性调节；
    - 简单拼接或相加的**跨尺度跳跃连接**，容易传播被污染的浅层特征，干扰解码；
    - 采用**确定性目标函数**，忽略像素级预测不确定性，导致在严重退化区域产生过度自信和不稳定的恢复结果。

- 论文目标：构建一个能够在统一框架中处理多种恶劣天气退化、同时实现伪影去除、细节增强与不确定性估计的鲁棒恢复模型，即 **UAR-Net**。

## 2. 方法论：UAR-Net 核心思想与关键技术

整体结构为 U-Net 风格编码器-解码器，基于堆叠的 **GDTB** 构建，并集成 **BMSC**、**URH** 和新的 **BAE-Loss**，形成端到端的天气专用 AiO 复原框架。

### 2.1 Gated Dual-scale Transformer Blocks（GDTB）
- 每个 GDTB 包含核心注意力模块 **Selective Gated Attention (SGA)** 和 **双尺度门控前馈（DGFF）**。

- **SGA 设计要点**：  
  - 基于线性注意力（linear attention）以保持线性复杂度，避免 softmax attention 的 O(N²) 复杂度。  
  - 引入正弦位置重加权：用 ReLU 约束 Q、K，并将 cos(π(i−j)/2M) 分解为正弦/余弦形式的核特征，使相似 token 获得更高响应，保留局部结构并避免无关远距离区域干扰。  
  - 加入数据依赖门控机制：将 Query 投影通道分为“注意查询”与“门控分支”，通过 sigmoid 产生门控值，对线性注意力输出进行逐元素调制，实现对不同天气退化相关信息的**选择性过滤与强调**。  
  - 逐步同时保持 O(N) 复杂度和更强的表达力。

- **DGFF 模块**：  
  - 使用两个并行深度卷积分支（3×3 和 5×5 感受野）捕获多尺度局部模式，并通过门控自适应融合，弥补全局注意力在局部细节建模上的不足。

### 2.2 Balanced Multi-scale Skip Connection（BMSC）
- 动机：不同天气条件下浅层特征被破坏程度不同，直接加和或拼接会造成噪声放大和误导解码。
- 方法：采用从深到浅、逐步融合编码器多层特征的**预测-校正（P–C）积分机制**，灵感来自多步数值积分方法（Adams–Bashforth / Adams–Moulton）。
  - 第一步用显式 Euler 预测；第二步用二阶 Adams–Moulton 校正。  
  - 统一表示为线性多步积分形式 y_{n+1} = y_n + δ/ K Σ β_j F(y_{n−j}, x_{n−j})。  
  - 平衡特征在中间层分辨率（H/4×W/4）构建，并通过轻量级细化模块（采用受热传导启发的高效注意力 vHeat，以 O(N^1.5) 复杂度实现全局扩散式建模）进一步净化，然后作为共享的跨尺度跳层指导注入所有解码器阶段。
- 优点：减轻被污染浅层特征的影响，形成更干净、平衡的跨尺度信息，有利于多天气条件下的稳定恢复。

### 2.3 Uncertainty-Aware Refinement Head（URH）
- 在粗预测基础上进一步细化，采用紧凑四阶段 U-Net，块内使用 GDTB。
- 细化头通过两个并行预测头输出：
  - 均值 μ(x)：最终恢复图；
  - 方差 σ²(x)：像素级不确定性图。
- 方差不是严格校准的不确定性量，而是“任务驱动的困难度信号”：严重退化区域预测方差更高，从而抑制过度自信、增强弱区域稳定性。

### 2.4 Brightness-Aware Energy Loss（BAE-Loss）
- 由两部分组成：
  - **能量评分项（Energy Score）**：将 URH 输出视为逐像素高斯分布，通过蒙特卡洛抽样估计能量分数，鼓励把概率质量放在真实值附近，而不仅是单点匹配，利于稳健不确定性估计。
  - **亮度感知回归项**：引入基于 Bhattacharyya 距离的自适应权重 W，对预测与真值之间的整体亮度漂移进行修正。
- 总损失函数：  
  L = L_BAE + L_corr  
  其中 L_corr 为皮尔逊相关系数损失，用于保持全局结构一致性。

## 3. 实验设计：数据集、Benchmark 与对比方法

### 3.3 对比方法

## 6. 主要结论与发现
- UAR-Net 在多个恶劣天气基准上均达到 SOTA，同时提升像素级准确性和感知质量。
- 门控与选择性全局建模：门控机制带来的平均增益较大（≈+0.27 dB），说明“按内容门控”的上下文聚合对天气多样性很关键。
- BMSC 的渐进整合优于简单平均，且低分辨率平衡特征（H/4）兼具性能与效率。
- 在轻量条件下先进行亮度感知回归、再逐步引入概率能量损失（退火至 300k）最有利于整体效果。
- t-SNE 验证：UAR-Net 可生成天气条件更分离开、内部更紧凑的特征表达，有利于下游统一恢复。
- 代码已承诺在论文接收后开源。

## 7. 优点
- **方法全面**：针对 AiO 复原的三个核心痛点（均匀全局聚合、朴素跳连、确定性损失）一一给出对应解决模块，而且部件之间互洽。
- **理论依据较强**：  
  - 将线性注意力模块化为核方法，并引入位置感知的正弦分解，具有数值上可解释性；  
  - BMSC 借用线性多步数值积分形成预测-校正融合，说明“如何把跨尺度特征逐步稳定整合”。
- **不确定性建模**：将方差作为任务难度信号，与 loss 联合训练，避免过度自信，且不要求在测试时重采样。
- **评估全面**：既比较了传统 PSNR/SSIM，又测评了 LPIPS、Q-Align、MUSIQ 等更贴近人眼的指标。
- **细节工程化**：渐进训练策略、平衡计算复杂度、退火调度等实验设置比较完整，提高了实用可信度。

## 8. 不足与局限
- **真实场景验证缺失**：虽然数据集章节提到 Snow100K-Real 等真实雪景，但实验结果表并未报告该真实子集上的表现，无法确认模型在真实退化数据上的泛化性。
- **天气覆盖场景有限**：训练/测试集中在雪、雨、雨滴（以及雨雾混合），并未覆盖如雾天弱光、夜间雨雪、路面反光等更具有实际驾驶挑战性的场景。
- **不确定性未见定量评估**：论文声明方差作为任务驱动信号，但只可视化一般不确定图，并未对不确定性的校准性、区域相关性做定量验证（如 ECE、相关性分析等）。
- **损失权重复杂性**：BAE-Loss 引入较多超参数（能量分数、退火时机、相关损失等），实际训练中调参负担较重，该方法的鲁棒性依赖于训练调度。
- **计算开销偏高**：模型 FLOPs 高于多个对比方法（如 Histoformer、MODEM），对高分辨率实际部署存在效率瓶颈。
- **部分消融非最终配置**：部分消融（如平衡特征分辨率、BMSC 内部分析）在不含 URH/BAE 的简化设置下进行，可能使对比结果无法完全反映最终模型行为。
- **任务间公平性**：与某些任务特定方法比较较小，且没有做同批次、同优化超参的严格复现对比，存在轻微“基准不可控”风险。
