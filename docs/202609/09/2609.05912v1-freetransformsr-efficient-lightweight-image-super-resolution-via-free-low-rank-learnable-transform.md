## 摘要
单图像超分辨率旨在从低分辨率输入重建高分辨率图像。本文提出FreeTransformSR，一种基于通道级自由低秩可学习变换的新型轻量级超分辨率网络。该变换以数据驱动的方式学习任务自适应基函数，能够以最小的参数开销实现自适应特征调制。为进一步增强高频细节恢复，我们引入局部特征调制分支，通过深度卷积补充变换域处理。此外，软复杂度自适应模块通过轻量级门控网络动态融合局部卷积和窗口自注意力分支的输出，根据区域纹理特征自适应调整融合比例。还纳入自适应强度调制策略，在样本级别调整变换域响应强度，使网络能够根据输入特征动态调整处理强度。在五个基准数据集上的大量实验表明，FreeTransformSR以显著更少的参数和FLOPs实现了具有竞争力的PSNR/SSIM性能。具体而言，FreeTransformSR在仅595K参数的情况下，在BSD100 x2上达到32.41 dB，在Urban100 x4上达到27.00 dB，同时推理速度优于现有方法，非常适合资源受限场景中的部署。源代码可在以下网址获取：https://github.com/HJiLi/FreeTransformSR。

## Abstract
Single image super-resolution aims to reconstruct high-resolution images from low-resolution inputs. This paper proposes FreeTransformSR, a novel lightweight super-resolution network based on a channel-wise free low-rank learnable transform. The transform learns task-adaptive basis functions in a data-driven manner, enabling adaptive feature modulation with minimal parameter overhead. To further enhance high-frequency detail recovery, we introduce a local feature modulation branch that complements transform-domain processing with depthwise convolution. In addition, a soft complexity adaptive module dynamically fuses the outputs of local convolution and window self-attention branches through a lightweight gating network, adaptively adjusting the fusion ratio based on regional texture characteristics. An adaptive intensity modulation strategy is also incorporated to adjust transform-domain response strength at the sample level, enabling the network to dynamically adjust processing intensity according to input features. Extensive experiments on five benchmark datasets demonstrate that FreeTransformSR achieves competitive PSNR/SSIM performance with significantly fewer parameters and FLOPs. Specifically, FreeTransformSR achieves 32.41 dB on BSD100 x2 and 27.00 dB on Urban100 x4 with only 595K parameters, while delivering faster inference speed than competing methods, making it well-suited for deployment in resource-constrained scenarios. Source code is available at: https://github.com/HJiLi/FreeTransformSR.

# FreeTransformSR 论文结构化总结

## 1. 核心问题与研究动机
- **背景挑战**：单图像超分辨率（SISR）需从低分辨率输入重建高分辨率图像。轻量级超分网络面临三大矛盾：
  - CNN 受限于局部感受野，难以捕捉全局依赖；为扩大感受野而加深网络会带来高计算成本。
  - Transformer/自注意力虽能捕获长程依赖，但复杂度高、推理慢（需大量 reshape 和 mask 操作），实际部署效率差。
  - 现有频域方法（如 WavTrans、CiaoSR）依赖预定义的固定基函数（DWT、DCT），缺乏数据自适应能力；基于聚类/哈希的 token 聚合方法（SPIN、BOAT）则增加推理延迟或损失细节。
- **本文目标**：设计一种在**参数、FLOPs、推理速度、重建质量**之间更均衡的轻量级超分网络，以数据驱动方式实现自适应特征变换与调制。

## 2. 方法论
### 2.1 总体架构
- 输入 LR 图像 → 3×3 卷积浅层提取（通道数 C=60）→ 堆叠 N 个残差组（RG）→ 1×1 卷积精炼 → 3×3 卷积 + PixelShuffle 上采样 + 双线性全局残差。
- 每个残差组包含 4 个基本块：前 2 个为**可学习变换块（LTB）**，后 2 个为**软复杂度自适应块（SCAB）**；组尾接 1×1 卷积 + ECA 通道注意力，并使用残差连接。

### 2.2 可学习变换块（LTB）
- **通道级自由低秩变换**：
  - 对每个通道独立学习一对（行/列）变换矩阵 \(T_h^{(c)}, T_w^{(c)} \in \mathbb{R}^{p \times p}\)（窗口 p=8）。
  - 参数化为“恒等映射 + 低秩残差”：\(T = I + \Delta\)，其中 \(\Delta = A B\)，\(r=1\)；A、B 初始化为零，确保起始为恒等映射。
  - 前向变换：\(Y = T_h X_{win} T_w^T\)；在变换域通过系数矩阵 \(W\)（固定模板）和样本级强度系数 \(S\) 进行逐元素调制：\(\tilde{Y} = Y \odot W \odot S\)。
  - 反向映射采用**转置近似**而非严格求逆：\(\hat{X} = T_h^T \tilde{Y} T_w\)，避免正交约束，降低复杂度，且误差可被后续层补偿。
- **局部特征调制分支**：
  - 输入经 1×1 卷积扩维后 split 成 \(X_1, X_2\)；\(X_1\) 走变换域路线，\(X_2\) 走深度卷积路线得到 \(X_{local}\)，再与变换域输出逐元素相乘：\(X_{mod} = \hat{X}_1 \odot X_{local}\)，以补充高频细节。
- **ConvFFN（MLP）**：采用类似 GDFN 的通道扩展、深度卷积、门控（GELU）和 1×1 压缩并含残差连接。

### 2.3 软复杂度自适应模块（SCAB）
- 融合两个分支：
  - 局部卷积分支 \(L(X)\)：LayerNorm + 3×3 深度可分离卷积 + 1×1 卷积 + 残差。
  - 窗口自注意力分支 \(H(X)\)：Swin 移位窗口注意力，窗口 16×16，3 头 + 残差。
- 门控网络 \(R(X)\) 输出连续系数，范围限制在 [0.1, 0.9] 以防分支完全失活：
  - \(R(X) = 0.1 + 0.8\cdot\sigma(Conv_{1\times1}(GELU(Conv_{1\times1}(DWConv_{3\times3}(X)))))\)
  - 最终输出：\(X_{out} = L(X) + R(X) \odot (H(X)-L(X))\)。
- 门控根据区域纹理特征平滑选择局部或全局处理，允许两个分支梯度同时流动。

### 2.4 自适应强度调制（Scale Gate）
- 通过全局平均池化 + 1×1 卷积 + Sigmoid 生成样本级标量：\(S = 0.8 + 0.6\sigma(Conv_{1\times1}(AvgPool(X)))\)
- 对所有通道施加统一缩放，动态调节变换域响应强度，由损失函数自动学习，无需显式规则。

### 2.5 损失函数
- 总损失：\(\mathcal{L}_{total} = \mathcal{L}_{L1} + 0.1 \cdot \mathcal{L}_{FFT}\)
- L1 约束空间域逐像素精度；傅里叶空间损失约束频域一致性，增强高频恢复。

## 6. 主要结论与发现
- 通道级可学习变换（以“恒等+低秩残差”参数化）在极低参数开销下优于固定基函数（如 DCT），Urban100 ×2 上提高 0.12 dB。
- 低秩约束几乎不损失性能（Full Rank vs Single Rank 差异<0.02 dB），却能减少参数，说明低秩分解是有效的参数效率策略。
- 通道独立学习优于共享变换（Set14 提高 0.06 dB），采用通道独立设计合理。
- 局部特征调制分支与自适应强度调制（scale gate）均带来增益：后者在参数量几乎不变的情况下将 Set14 提升 0.12 dB。
- 仅通过增加通道数不能有效提升性能（“Balanced”对照），证实性能提升来自结构设计而非参数规模。
- 最终模型以最小或近最小的参数量/FLOPs，在多数数据集上取得最优 PSNR/SSIM，并在 ×2 和 ×4 上推理速度均快于对比方法（×2 比 CAMixerSR 快约 1.06×，比 MambaIRv2-light 快约 2.16×）。

## 7. 优点
- **强数据自适应性**：用可学习低秩变换替代固定变换，摆脱预定义基函数的限制。
- **极高参数效率**：低秩 + 恒等初始化使每通道仅需极少参数即可实现复杂变换；r=1 带来的收益验证了“free low-rank”设计的有效性。
- **多粒度动态机制**：门控软融合实现“区域级”分支选择；scale gate 实现“样本级”强度调制，两者结合使模型对内容/退化程度更具适应性。
