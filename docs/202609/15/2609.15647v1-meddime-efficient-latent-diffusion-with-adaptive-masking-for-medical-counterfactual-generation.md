## 摘要
医学反事实生成通过修改图像来改变模型预测，以提升可解释性。然而，现有基于扩散的方法通常速度极慢且内存消耗巨大，使其难以应用于高分辨率场景。此外，现有掩码策略与像素空间表示紧密耦合，导致其与潜在空间扩散编辑不兼容。为解决这些挑战，我们提出 MedDiME，一种潜在空间分类器引导的扩散框架，在降低计算和内存开销的同时，引入与潜在空间兼容、由梯度驱动的自适应掩码机制，用于空间精确的医学反事实生成。大量实验表明，与先前分类器引导的扩散基线相比，MedDiME 实现了高质量反事实生成，并取得显著效率提升，推理速度最高快 40 倍，峰值 GPU 内存使用降低至 1/13。

## Abstract
Medical counterfactual generation modifies images to change model predictions for interpretability. However, existing diffusion-based approaches are often prohibitively slow and memory-intensive, making them difficult to apply in high-resolution settings. Moreover, existing masking strategies are tightly coupled with pixel-space representations, making them incompatible with latent-space diffusion editing. To address these challenges, we propose MedDiME, a latent-space classifier-guided diffusion framework that reduces computational and memory overhead while introducing a latent-compatible, gradient-driven adaptive masking mechanism for spatially precise medical counterfactual generation. Extensive experiments demonstrate that MedDiME achieves high-quality counterfactual generation with significant efficiency gains compared to prior classifier-guided diffusion baselines, achieving up to 40 times faster inference and 13 times lower peak GPU memory usage.

## 1. 核心问题与研究动机

- **背景**：深度学习模型在医学影像中常被视为"黑箱"，限制临床信任与部署。反事实生成通过修改与模型决策相关的区域来改变预测，从而提升可解释性，其本质是**决策驱动的语义反转**，而非像素级精确重建。
- **核心痛点**：
  - **效率瓶颈**：现有基于扩散的反事实方法（如 DiME）需要完整去噪展开并在像素空间进行全局引导，计算与内存开销极高，难以应用于高分辨率（如 512×512 及以上）医学图像。
  - **掩码不兼容**：现有掩码策略（FastDiME 基于像素差异、MaskDiME 基于像素空间梯度）与像素空间表示紧密耦合，无法直接迁移到潜在空间编辑。
  - **潜空间迁移的挑战**：潜表示缺乏显式空间对应关系，基于像素差异或图像空间线索的掩码策略在概念上不兼容。
- **整体含义**：作者提出 MedDiME，将分类器引导的扩散反事实生成完全迁移至潜在空间，并设计潜空间兼容的梯度驱动自适应掩码，旨在兼顾高分辨率下的生成质量、空间精度与计算效率。

## 2. 方法论

### 核心思想
构建一个**全潜空间分类器引导扩散框架**，利用预训练 VAE 将高分辨率图像压缩为低维潜表示，在潜空间中完成前向加噪、反向去噪与梯度引导，并基于潜空间分类器梯度构建自适应掩码，实现空间精确的反事实编辑。

### 关键流程（算法步骤）
1. **编码与加噪**：输入图像 X 经冻结的 VAE 编码器得到潜表示 x，前向扩散至预定义时间步 τ，得到噪声潜变量 ẑ_τ，并以其初始化反向过程 z_τ。
2. **反向去噪（公式1）**：每一步按
   `z_{t-1} = M_t ⊙ N(μ_θ(z_t) − Σ_θ(z_t)∇z_t, Σ_θ(z_t)) + (1 − M_t) ⊙ ẑ_{t-1}`
   更新，即**仅在自适应掩码 M_t 指示的区域内执行分类器引导去噪**，掩码外保持原始扩散轨迹。
3. **一步估计干净潜变量（公式2）**：基于 Tweedie 公式，仿照 FastDiME 用一步去噪估计
   `x̂_0^{(t-1)} = (z_{t-1} − √(1−ᾱ_{t-1}) ε_θ(z_{t-1})) / √ᾱ_{t-1}`
   避免完整反向去噪，降低计算量。
4. **构建下一潜状态（公式3）**：`x_{t-1} = M_t ⊙ x̂_0^{(t-1)} + (1 − M_t) ⊙ x`，掩码外保留原潜表示，用于下一步梯度计算与掩码构建。
5. **循环迭代**：重复上述过程直至得到最终潜状态 z_0，经 VAE 解码器输出反事实图像 X_cf。

### 潜空间梯度引导（公式4–5）
- 优化联合损失：`L = λ_c L_class(C(y|x_t)) + λ_p L_perc(x_t, x) + λ_l L_L1(x_t, x)`，固定 λ_c=5、λ_p=50、λ_l=1。
- 为避免通过 U-Net 反向传播，近似梯度为 `∇z_t = (s/√ᾱ_t) ∇x_t L`，默认 s=200。

### 潜空间自适应掩码（公式6–7）
- 在潜表示上直接训练分类器 C，计算分类损失对噪声潜变量的梯度 `∇^{class}_{z_t} = (1/√ᾱ_t) ∇x_t L_class`。
- 取绝对值并在通道维平均，得到标量显著性图 `G_t ∈ R^{1×H×W}`。
- **自适应掩码 M_t**：选取 G_t 中 top-k% 的空间位置置 1，其余置 0。ISIC2018 任务取 k=20%，CheXpert 取 k=30%。
- 为增强空间连贯性，施加核大小为 5 的形态学膨胀。

## 6. 主要结论与发现

- **效率显著提升**：反事实生成推理时间相比 MaskDiME、FastDiME、DiME 分别降低 2.5×、4×、**超过 40×**；峰值 GPU 显存分别降低 7×、13×、10×。
- **质量不降反升**：MedDiME 取得最低或接近最低的 FID；S³ 相似度最高；Flip Rate 与 MAD 表现最佳或接近最佳。整体呈现"效率—质量—显存"三者兼顾的最优权衡（图1左下区域）。
- **潜空间训练更快**：分类器与扩散模型的训练收敛速度分别提升 3.0×–6.8× 与 4.2×–10.2×，并达到更低的 FID。
- **编辑更精准**：梯度驱动自适应掩码将修改限制在决策相关区域（病灶、标尺、起搏器），周围非诊断区域基本不变；而基线方法（DiME、FastDiME）倾向于产生分散编辑与背景改动。
- **消融结论**：无掩码会全局扰动并全面劣化指标；像素差异掩码定位不准；固定掩码虽改善 FID/L1 但无法随扩散步自适应梯度方向；MedDiME 的动态梯度对齐掩码综合表现最优。

## 7. 优点
