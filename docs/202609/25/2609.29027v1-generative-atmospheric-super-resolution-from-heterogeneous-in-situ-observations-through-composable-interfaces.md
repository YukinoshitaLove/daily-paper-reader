## 摘要
大气观测稀疏、异构且分布不均，而许多生成式大气模型学习的是规则网格化多变量状态的分布。一旦预训练完成，扩散模型可以提供大气先验，并可在贝叶斯框架中与由观测导出的似然因子相结合。然而，这些观测源在几何结构和采样密度上差异显著，使得在统一推断框架中一致地使用其观测变得复杂。在这里，我们将该重建问题表述为生成式大气超分辨率，并引入可组合观测接口，用于对单个预训练的13变量大气扩散模型进行条件化。这些接口将稀疏的无线电探空仪（R）、聚集的飞机（A）以及密集但不规则的地面站（S）观测转换为特定于来源的似然因子，这些因子规定了观测在何处约束网格化状态、在不均匀采样下如何计算残差，以及每个来源对后验采样的引导强度。我们使用2019年观测开发了飞机和地面观测接口，并在2020年全年评估了所选接口，未进行进一步调优。与仅以无线电探空仪观测为条件的重建相比，组合的R+A+S接口在CONUS区域的所有13个状态变量上，将针对ERA5评估的RMSE降低了9.24%。飞机和地面因子在高空变量和地面变量上提供了互补的改进。R+A+S组合还降低了连续分级概率评分（CRPS），同时在留出的飞机和地面站观测上的评估显示预测误差减小。总之，这些结果展示了一条模块化路径，可在不重新训练底层模型的情况下，将预训练的大气生成先验条件化于异构原位观测。

## Abstract
Atmospheric observations are sparse, heterogeneous, and unevenly distributed, whereas many generative atmospheric models learn distributions over regularly gridded multivariate states. Once pretrained, diffusion models can supply atmospheric priors that can be combined with observation-derived likelihood factors in a Bayesian formulation. However, these observation sources differ substantially in geometry and sampling density, complicating the consistent use of their observations within a common inference framework. Here, we formulate this reconstruction problem as generative atmospheric super-resolution and introduce composable observation interfaces for conditioning a single pretrained 13-variable atmospheric diffusion model. The interfaces convert sparse radiosonde (R), clustered aircraft (A), and dense irregular surface-station (S) observations into source-specific likelihood factors that specify where observations constrain the gridded state, how residuals are counted under uneven sampling, and how strongly each source guides posterior sampling. We developed the aircraft and surface observation interfaces using 2019 observations and evaluated the selected interfaces throughout 2020 without further tuning. Compared with reconstructions conditioned only on radiosonde observations, the composed R+A+S interface reduces RMSE evaluated against ERA5 by $9.24\%$ across all 13 state variables over the CONUS domain. The aircraft and surface factors provide complementary improvements in upper-air and surface variables. The R+A+S combination also lowers the Continuous Ranked Probability Score (CRPS), while evaluations at held-out aircraft and surface-station observations show reduced prediction errors. Together, these results demonstrate a modular route for conditioning a pretrained atmospheric generative prior on heterogeneous in situ observations without retraining the underlying model.

## 1. 核心问题与研究动机

- **背景矛盾**：大气状态是高维、多尺度且仅被部分观测的系统。真实原位观测（无线电探空仪、飞机报、地面站）在**测量变量、空间/垂直支撑、采样几何与密度**上高度异构；而当前主流生成式大气模型（如基于 ERA5 的扩散模型）学习的却是**规则网格化、多变量**的联合分布，二者之间存在结构性错配。
- **核心问题**：如何在**不重新训练**预训练大气扩散先验的前提下，把几何与采样密度差异极大的多种原位观测，**一致地、可审计地**组织进同一个贝叶斯推断框架，用观测似然对网格化状态进行条件化？
- **问题定位**：作者将"从稀疏、异构、不规则观测重建规则网格大气状态"形式化为**生成式大气超分辨率（Generative Atmospheric Super-Resolution）**。在贝叶斯框架下，预训练扩散模型提供先验 $p_\theta(x_0|s)$，各观测源提供似然因子，重建即后验采样。
- **关键缺口**：预训练先验本身建模了状态内部的空间与跨变量统计关系，但**不规定**不同几何/采样密度的观测应如何进入似然——"如何为每个观测源定义并组合似然因子"正是本文要解决的贝叶斯问题。
- **贡献定位**：本文的贡献不在于单一观测算子或平均规则（这些在经典资料同化中已有先例），而在于将其组织为**可组合的观测接口**，使一个预训练先验可在多种异构原位观测源间复用。

## 2. 方法论

### 2.1 核心思想：可组合观测接口 + 推理时条件化

- 保持**固定的 13 变量 ERA5 扩散先验**（EDM 框架）及其采样器不变，把每个观测源封装为一个"接口"。每个接口由四要素规定：
  1. **保留观测的构造** $y_m$：源选择、质控、时间/垂直匹配、聚合；
  2. **状态映射** $H_m$：把观测目标映射到网格状态的位置、层次与变量；
  3. **残差计数** $W_m$：如何统计残差（各活跃通道等权、通道内目标等权）；
  4. **似然加权** $\lambda_m / v_m(\sigma)$：噪声相关的引导强度。
- 三个观测源分别为：探空仪 **R**（IGRA）、飞机 **A**（MADIS ABO）、地面站 **S**（MADIS METAR）。

### 2.2 关键技术细节

- **状态与先验**：状态 $x_0 \in \mathbb{R}^{C\times N_\phi\times N_\ell}$，$C=13$，$N_\phi=128$，$N_\ell=256$。通道集为 $\{t2m, u10, v10, t500, u500, v500, z500, q500, t850, u850, v850, z850, q850\}$。所有变量与观测用 ERA5 训练集的通道均值/标准差标准化。
- **先验分数**：EDM 框架下 $x_\sigma = x_0 + \sigma\epsilon$，去噪器 $\hat x_0 = D_\theta(x_\sigma,\sigma,s)$，先验分数 $s_\theta = (D_\theta - x_\sigma)/\sigma^2$。

- **似然因子**（各源残差能量）：
  $$E_m(x_0) = \frac{1}{|K_m^+|}\sum_{k\in K_m^+}\frac{1}{|I_{mk}|}\sum_{r\in I_{mk}}(H_{mk}(x_0)_r - y_{mkr})^2$$
  即**每个活跃通道等总权、通道内每个保留目标/占据格等权**。
- **噪声相关方差**：$v_m(\sigma) = \text{std}_m^2 + \gamma_m\sigma^2$；高斯平方残差对数似然 $\log q_{m,\sigma} \propto -E_m(z)/(2v_m(\sigma))$；源负对数似然 $L_m = \frac{\lambda_m}{2v_m(\sigma)}E_m$。
- **组合后验（清洁状态坐标下）**：$\tilde p_\sigma(x_0|\{y_m\},s) \propto p_\theta(x_0|s)\exp[-L_{obs}(x_0;\sigma)]$，其中 $L_{obs}=\sum_m L_m$（条件独立假设）。

- **几何特定映射**：
  - **R**：双线性插值到探空站位置，每个站点目标保留一个残差（保留稀疏位置信息）。
  - **A / S**：**先按模型格胞内对同变量报告取均值**，每个占据格只贡献一个残差（等格胞构造），避免密集航线/机场/站点簇因报告数量多而获得不成比例的似然影响。
  - A 约束 500/850 hPa 的温度与水平风；S 约束 t2m、u10、v10；R 可约束全部 13 变量。

- **推理时 DPS 引导流程**（Section 5.4）：
  1. 在当前噪声状态 $x_i$ 上求去噪估计 $\hat x_{0,i}=D_\theta(x_i,\sigma_i,s)$；
  2. 计算各源清洁状态似然梯度 $d_m = -\frac{\lambda_m}{v_m}J_{H_m}^\top W_m(H_m(\hat x_0)-y_m)$；
  3. 通过**去噪器雅可比回拉**到噪声状态：$g^{raw}_{m,i}=J_{D,i}^\top d_m$；
  4. 求和 → **逐元素裁剪到 [-1,1]** → 乘 $\sigma_i$ 得修正量 $c_i$；
  5. 从 Heun 平均的先验斜率中减去 $c_i$，更新到 $x_{i+1}$。

## 6. 主要结论与发现

- **CONUS 域显著改进**：相对 R-only，R+A+S 使全部 13 变量 RMSE 平均降 **9.24%**，地面目标组降 **14.17%**，高空温度风组降 **9.30%**；R+A 对高空组降 6.74%，R+S 对地面组降 13.31%，体现**互补性**。相对各自更强的单项，R+A+S 额外多降 3.89 / 0.86 / 2.56 个百分点。
- **时间稳健**：14 天块 bootstrap 的 95% 区间对三组及**全部 13 个变量**均低于零（如全部变量 [−9.57%, −8.92%]）。
- **概率技能提升**：R+A+S 使 CRPS 降 9.98%（全部变量），地面组 15.01%，高空组 10.45%，区间均低于零；fair-CRPS 结论一致。
- **留出观测改进**：在被剔除的 S 观测上 RMSE 降 13.50%（24/24 时次），A 观测上降 11.71%（23/24 时次）。
- **地理局限**：全球排除 CONUS 域的均值变化接近零（区间含零），说明改进**集中在 A/S 直接约束的区域**，非全球普适提升。
- **机制发现**：A 与 S 在清洁状态梯度上作用于**互不相交**的变量（A 100% 在高空温度风，S 100% 在地面），但经共享去噪器回拉后，二者的噪声状态引导方向在高噪声阶段**余弦相似度最高达 0.93**，说明预训练多变量先验提供了跨变量耦合通道；接近末步时 S 占三源引导范数之和的 90.80%。
- **设计教训**：报告数量多不等于更好——加入 TAMDAR 反而增大误差；**等格胞残差表示**优于逐报告残差。

## 7. 优点

- **模块化与可审计性**：把"保留哪些观测、如何映射、如何计数残差、如何加权"四要素显式分离，新观测源可通过定义接口并标定参数接入，**无需重训先验**。
- **方法学严谨**：开发年（2019）与评估年（2020）严格分离，参数选择使用配对月 bootstrap 并采用"区间含零则视为不可区分 → 选参数范围中心 → 权重更小"的稳健选择规则，避免挑选极端设置。
- **不确定性处理得当**：识别并处理了 12 小时时次间的序列相关，采用 14 天移动块 bootstrap 保留真实缺失时次。
- **多维评估闭环**：确定性 RMSE + 概率 CRPS + 留出观测 + 空间谱形状诊断（排除"整体平滑化"假象）+ 机制诊断，层层递进。
- **机制可解释**：用清洁状态梯度余弦相似度与范数占比，定量刻画了"变量不相交 → 经共享去噪器耦合"的路径。
- **理论形式清晰**：给出从似然因子 → 清洁状态梯度 → 雅可比回拉 → 裁剪求和 → 反解器更新的完整链条。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号/数量/机时，难以评估方法实际计算成本与可复现性（尤其是雅可比回拉的开销）。
- **缺乏外部基线对比**：仅与自身配置对比，**未与经典资料同化系统或其他扩散式同化方法比较**，无法确立相对优越性。
- **参考真值偏差风险**：所有确定性/概率性/空间结果均以 **ERA5 为参考**，结论是"相对于再分析"的，非相对于独立真值。
- **泛化性有限**：
  - A/S 仅覆盖 CONUS，全球排除 CONUS 域无显著改进；
  - 留出评估是同系统内 80/20 插值，非跨观测系统迁移；
  - 仅使用 500/850 hPa 两个层次（固定 ±25 hPa 窗），未测试更多垂直层。
- **似然建模简化**：使用加权平方残差，**未显式建模观测源间及近邻观测间的相关误差**（仅靠格胞内平均缓解）；组合后**求和再裁剪**使修正量在饱和时呈非线性，各源贡献无法在裁剪后分解。
- **机制诊断的统计代表性不足**：Section 8 的梯度对齐、范数占比、空间分布仅基于**单个分析时次、单条反演轨迹**，作者本人也声明不能外推为年度机制统计。
- **集合欠离散**：spread–skill 比始终小于 1，秩频率在边缘秩偏高，说明集合仍然**欠离散（underdispersed）**，尽管 CRPS 与 RMSE 均有改善；覆盖率低于 0.90 大集合参考值。
- **接口设计依赖人工选择**：报告流筛选、压力窗、残差表示等均为人工比较选定，参数范围与候选集合的选择可能引入隐含偏置。
