## 摘要
数据在许多基于深度学习的逆问题求解器中非常重要。然而，在许多场景中获取足够的配对数据仍然极具挑战性，而未配对数据成本低廉。为了最大化数据利用率，本文提出LUD-DIF，一种基于扩散的未配对数据逆问题求解方法。从联合分布的证据下界（ELBO）出发，我们在弱耦合假设下将其解耦为两个独立的扩散过程。该方法从变分推断角度提供理论支持，推导出损失函数，定量分析了假设引入的误差界，并为超参数选择提供了定理驱动的启发式方法。实验结果表明，LUD-DIF在多个图像逆问题上取得了优异性能，验证了其在未配对逆问题设置中的有效性和泛化能力。

## Abstract
Data is important in many deep learning-based inverse problem solvers. However, obtaining sufficient paired data in many scenarios remains highly challenging, while unpaired data is cheap. To maximize data utilization, this paper proposes LUD-DIF, a diffusion-based approach for solving inverse problems with unpaired data. Starting from the evidence lower bound (ELBO) of the joint distribution, we decouple it into two independent diffusion processes under the weak-coupling assumption. The method provides theoretical support from a variational inference perspective, derives the loss function, quantitatively analyzes the error bound introduced by the assumption, and offers a theorem-motivated heuristic for hyperparameter selection. Experimental results demonstrate that LUD-DIF achieves outstanding performance on multiple image inverse problems, validating its effectiveness and generalization capability in unpaired inverse problem settings.

## 1. 核心问题与研究动机

- **背景问题**：逆问题（inverse problems）广泛存在于计算机视觉、地球物理勘探和生物医学成像等领域，其目标是从观测数据 y 中恢复未知状态 x。深度学习已在其中取得显著成果，但通常依赖大量配对数据（clean–noisy 对）进行监督学习。
- **现实瓶颈**：在许多实际场景（如医学影像、天文观测）中，获取配对数据成本极其高昂甚至不可能；相反，未配对数据（仅独立的 clean 样本和独立的 noisy 样本）往往廉价且充足。如何在只有边缘分布 p(x)、p(y) 而没有配对样本的条件下学习联合分布 p(x, y)，成为限制深度学习方法落地的主要瓶颈。
- **现有方法的不足**：
  - GAN 类方法（如 CycleGAN 等）可用于未配对跨域生成，但面临模式坍塌和训练不稳定等问题，且缺乏严格的概率解释；
  - VAE 类方法可解释性更强，但受限于潜在空间分布的强假设，生成质量大打折扣；
  - 已有的扩散模型方法（如 OTCS、Diffusion Distribution Matching 等）虽有一定进展，但缺乏一个从完全未配对边缘分布出发、以似然为基础的**条件扩散目标函数的原理性推导框架**，也缺少对代理耦合引入偏差的**量化分析**。
- **本文目标**：提出一种称为 **LUD-DIF（Learning from Unpaired Data via Diffusion Model）** 的方法，用变分推断视角从理论上支撑未配对数据下的扩散模型训练，同时定量刻画近似假设带来的误差界。

## 2. 方法论

**核心思想**：将逆问题统一转化为"噪声建模"问题。假设观测模型可归约为 Y = X + Ξ（通过信号变量重标定或吸收未知算子误差于有效噪声中），则学习联合分布的核心被归结为估计条件噪声分布。

具体技术路线可以拆解为如下五个部分：

1. **数据预处理与归一化**：计算边缘分布的方差 σ²_X 与 σ²_Y，将数据进行标准化缩放，使两个域量纲可比，以便构建联合扩散过程。

2. **构造联合扩散过程**：对联合变量 Z_t = (X_t, Y_t) 定义独立的边缘前向扩散过程；证明前向过程与后验转移概率在 X 与 Y 之间具有**因子分解性质**（Proposition 3.2）。

3. **设计受限变分反向过程**：在未配对条件下，难以直接学习完整的联合反向核。作者将反向过程限制为如下带自回归排序的**因子化高斯族**：
   - X-分支：pθ(X_{t−1}|X_t)，用于建模干净结构边缘；
   - Y-分支：pθ(Y_{t−1}|X_{t−1}, Y_t)，以较少扩散的结构状态 X_{t−1} 为条件，再结合噪声观测 Y_t 进行去噪；
   - 该限制被解释为变分流形的限制而非对真实反向过程的独立假设。

4. **ELBO 解耦与损失函数**：基于上述反向参数化，联合 ELBO 可分解为两部分（Proposition 3.3）：
   - **边缘损失** L_marg：仅依赖边缘分布 p(X_0)，可用未配对 clean 样本估计；
   - **条件损失** L_cond：依赖于联合分布 p(X_{t−1}, Y_t, Y_0)，仍需配对信息。
5. **弱耦合假设与代理条件分布**：由于条件分布 p(X_0|Y_0) 无法从边缘分布唯一确定，作者引入**弱耦合假设（Assumption 3.4）**：
   - 用 p(X_0|X_V)（给定 XV = 某扩散后的观测 Y_S）来近似真实的 p(X_0|Y_0)；
   - 具体来说，给定一个观测 y₀，先将其扩散到 Y_S，再将该带噪状态与 X_V 对齐（即视为同一随机变量），然后用干净域扩散模型的反向过程重建 X_0^weak ——即"代理配对样本"。
   - 该假设依赖两个近似：将对齐近似和扰动近似结合，在实际中形成 S、V 时步选取的权衡。

由此获得可计算的弱耦合目标函数 L_weak = L_marg + L_weak_cond，并在弱耦合假设成立时证明其与理想配对目标一致（Theorem 3.7）。训练时，两条扩散模型的路径可以分别训练，提升效率。

### 核心公式（文字描述）

- 前向扩散过程：X_t、Y_t 各自执行标准的 DDPM 型加噪 X_t = √α_t X_{t−1} + √(1−α_t) ε；
- 反向参数化：X 分支为独立高斯 N(μ_X,t(x_t), σ²_t I)，Y 分支为条件高斯 N(μ_Y|X,t(y_t, x_{t−1}), σ²_t I)；
- 总损失：L_weak(θ) = Σ_t (1/(2σ²_t)) E‖μ_X,t(X_t) − μ̃(X_t, X_0)‖² + Σ_t (1/(2σ²_t)) E‖μ_Y|X,t(Y_t, X^weak_{t−1}) − μ̃(Y_t, Y_0)‖²；
- 当弱耦合假设不满足时，作者给出了误差上界（Theorem 4.5）——即损失函数误差受**扰动误差**（来自 Y_S 相对 Y_0 的信息损失）、**对齐误差**（来自 XV 与 YS 分布失配）控制，后者又依赖于均值/方差匹配项与噪声的非高斯性 KL 散度。

### 超参数选择

- 基于定理 4.5 的启发式规则：建议在方差对齐条件 ᾱ_V σ²_Y = ᾱ_S σ²_X 下选取 τ_S，再依 τ²_V = τ²_S + σ² 求 V；
- 对实际噪声，论文推导出近似最优 τ_S 的闭式解，其核心依赖为噪声与信号的**超额峰度差异**与数据集规模相关的常数 λ。

## 6. 主要结论

- **核心结论**：在未配对数据条件下，可通过"弱耦合假设 + 双路径扩散解耦"近似学习联合分布；LUD-DIF 从变分推断 ELBO 出发推导的损失可分解为独立边缘损失与条件损失，且在假设成立时与理想配对目标一致。
- **理论贡献**：当假设不严格成立时，LUD-DIF 的误差可以被扰动误差、对齐误差及噪声非高斯性 KL 散度上界所控制；基于该上界，可推导出带理论指导意义的超参数启发式选择规则。
- **实验结论**：LUD-DIF 在模拟噪声、SIDD 真实去噪和真实超分数据上显著优于现有未配对方法，具备较强的实际应用价值。

- **无法处理非加性/非局部噪声**：方法核心框架是加性噪声建模（尽管可松驰为信号相关条件噪声），对于空间相关的结构化噪声（如条纹噪声、传感器坏点）其适用性尚不明确。

> 该论文提出了 **LUD-DIF**，一种从变分推断出发的、基于"弱耦合假设+双路径扩散"的未配对数据逆问题求解方法，在多种图像复原任务上超越现有未配对方法，并给出了可解释的理论误差界与超参数选择启发式。
