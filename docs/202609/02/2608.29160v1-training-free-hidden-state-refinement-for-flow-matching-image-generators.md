## 摘要
我们旨在通过向去噪器内部添加推理计算来改进冻结的流匹配图像生成器，而不改变模型权重或外部采样器。现有生成器通常通过增加采样步数来消耗额外的测试时计算，这会重复评估整个去噪器，并将质量提升与采样器成本耦合。一个关键挑战是如何在冻结的Transformer去噪器内部使用额外计算：该方法必须决定哪些标记、层和采样时刻接收重复更新，同时保持原始生成流程不变。我们引入了一个无需训练的循环框架，在每次去噪调用中重复应用选定的Transformer层。密集与稀疏标记循环改变标记范围；采样进度门控和循环层范围指定循环激活的时机与位置；循环次数和强度控制重复更新；循环引导结合了普通和循环的向量场预测。在两个Scale-RAE模型规模上，循环变体改善了主要和辅助质量指标，并具有有竞争力的质量-效率权衡。循环引导进一步在所有三个测试模型上改善了两个主要指标；在Scale-RAE DiT2.4B上，它将GenEval从0.4471提升到0.5691，将DPG-Bench从0.7656提升到0.8053。代码将发布。

## Abstract
We aim to improve frozen flow-matching image generators by adding inference computation inside the denoiser, without changing model weights or the outer sampler. Existing generators usually spend extra test-time computation by increasing the number of sampling steps, which repeatedly evaluates the entire denoiser and couples quality gains to sampler cost. A key challenge is how to use extra computation inside a frozen transformer denoiser: the method must decide which tokens, layers, and sampling times receive repeated updates while preserving the original generation pipeline. We introduce a training-free looping framework that repeatedly applies selected transformer layers inside each denoising call. Dense and Sparse Token Loop vary the token scope; Sampling-Progress Gating and the loop layer range specify when and where looping is active; loop count and strength control the repeated updates; and Loop Guidance combines ordinary and looped vector-field predictions. Across two Scale-RAE model scales, loop variants improve primary and auxiliary quality metrics with competitive quality--efficiency trade-offs. Loop Guidance further improves both primary metrics across all three tested models; on Scale-RAE DiT2.4B, it raises GenEval from 0.4471 to 0.5691 and DPG-Bench from 0.7656 to 0.8053. ### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：在冻结的流匹配（Flow Matching）图像生成器中，如何在**不改变模型权重**、**不更换外部采样器**的前提下，将额外的测试时计算合理投入到**去噪器（denoiser）内部**，从而提升生成质量。
- **背景**：现有方法通常通过增加采样步数来提升质量，但其代价是每次重复评估**整个去噪器**，质量提升与采样成本高度耦合。
- **关键挑战**：冻结的去噪器内部，如何决定**哪些 token**、**哪些层**、**哪些采样时间点**应当接受重复更新，同时保持原始生成流程不受影响。
- **整体含义**：作者尝试将推理时间算力从“外层重新采样”内化为“内部重复精炼隐状态”，这是一种与现有调采样步数正交的质量增强轴。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程
- **方法定位**：训练免费（training-free）的循环计算框架——每次去噪调用中，对选定 transformer 层区间进行重复的前向评估，不改任何权重。
- **Dense Token Loop（密集 Token 循环）**
  - 对全部 token 重复选定层段的计算，每个循环轮次按残差更新控制，避免隐状态过度偏移。
  - 对某一层 \(L_j\)、输入状态 \(h_j\) 的更新为：设 \(\eta = \lambda_{loop}/K\)，迭代 \(K\) 次 \(Z^{(r)} = Z^{(r-1)} + \eta R_j(Z^{(r-1)}; t, c)\)，其中 \(R_j\) 为该层残差映射；默认 \(\lambda_{loop}=1\)，当 \(K=1\) 时退化为普通前向。
- **Sparse Token Loop（稀疏 Token 循环）**
  - 每次仅随机选择一部分 token 进行重复计算，未选中的补集（complement）token 残差只计算一次并缓存复用。
  - 补集与选中 token 在每一轮均被更新，保持循环深度同步，原先未选中的 token 也随循环推进，同时保留全序列的 key/value 上下文。
  - 用 token 采样率 \(\rho_{sel}\) 控制稀疏度，可显著减少计算量但引入少量路由与合并开销。
- **Sampling-Progress Gating（采样进度门控）**
  - 依据流匹配去噪“由粗到细”的过程，只在采样早期的噪声主导阶段激活循环，默认激活区间 \(s_i \in [0, 0.5]\)。
  - 避免在低噪声精细阶段做冗余重复，显著节约算力。
- **Loop Layer Range（循环层范围）**
  - 可指定循环参与的具体 transformer 层区间 \([a, b]\)；消融表明中层到后段（如 12–27 层）收益最大。
- **Loop Guidance（循环引导）**
  - 结合普通路径预测 \(v_{base}\) 与循环路径预测 \(v_{loop}\)，获得预测空间的修正方向：\(v_{lg} = v_{base} + g_{lg}(v_{loop} - v_{base})\)。
  - 引导强度 \(g_{lg}>1\) 可强调循环修正方向；它正交于 token 循环本身，可叠加使用。
- **四个算法总结**（文中给出伪代码）：Dense Token Loop、Sparse Token Loop、Sampling-Progress Gating、Loop Guidance，均保持模型参数冻结。

- **\(g_{lg}\) 等关键超参数依赖人工选择且跨模型漂移大**：文中各模型使用的引导强度差异显著（如 2.8 / 6.0 / 9.0），缺乏自适应取值机制或理论指导，读者难以直接复制出最优配置，存在隐式调参空间。
- **未与同属“内部精炼”思路的既有工作做系统对比**：如基于去噪器隐藏状态自蒸馏、循环注意力细化等方向，文中只与“外层加步”基线对比，难以判断该方法在同赛道方法中的相对定位。
- **评估指标偏向文本-图像对齐**：主指标 GenEval / DPG-Bench 本质上是 caption 遵循度测评，对生成图像的审美质量、细节保真度覆盖不足；定性分析虽补充了观感证据，但缺乏如 FID 或人工偏好评测的量化支撑。
- **统计严谨性有限**：仅在固定 seed（42）上报告单次结果，未提供多次运行方差或置信区间，作者亦自认不做显著性推断，结论的稳健性依赖第三方复现验证。
- **循环机制缺乏理论解释**：为何中层到后段层、高噪声阶段收益最大，论文停留在经验消融观察层面，没有从信息论、优化动力学或网络可辨识性角度给出深层机制解释。
- **高噪声阶段激活门控可能掩盖失效风险**：采样进度 0–50% 门控有效，但其边界（50%）对不同模型、不同步数组合是否始终成立并未被严格理论化，换用其他采样器或步数时界点可能漂移。

### 9. 潜在改进方向与开放问题

- **超参数自适应的下一步**：引导强度 \(g_{lg}\)、循环层区间与激活进度区间目前均为人工指定；若能设计基于隐状态变化率、注意力熵或进度置信度的自动终止/调节信号，则可进一步释放该方法的实用性。
- **与自适应步数策略的结合**：方法有效区间（0–50%）与“外层采样器在何时需要更多步”之间存在天然交集；将二者耦合（在关键区间内自动增加内部循环而非外部步数）有望形成统一的计算调度策略。
- **机制补全的方向**：若能论证“中层后段在流匹配中承担结构合成解缠”或“高噪声阶段主导布局先验”等结论，将有助于把经验增益上升为可预测的方法论，甚至指导未来 RAE 架构的设计。
- **跨生成器族谱的拓展可能性**：当前失败范例集中于 VAE 生成器，但其失败根源（是潜在表征维度、自编码器结构，还是文本编码器差异？）尚未被剥离开；厘清这一混淆变量，或将扩大方法的应用半径。
- **将强化学习式“思考”预算引入生成器**：本文的 token 循环与语言模型中“推理时扩展”思路同构；融合可学习路由或混合专家式的计算分配，可能是训练免费向训练轻量化的自然延伸。

### 10. 总结性评价与论文定位

本文在流匹配图像生成领域提出了一个新颖且实用的“第三轴”：与其增加采样步数或更换采样器，不如在冻结去噪器内部对隐状态做循环精炼，并以 Loop Guidance 将“普通路径”与“循环路径”的预测差异显式注入预测空间。其核心贡献在于**将测试时算力的投放从“时间维度”迁移到“空间—层内维度”**，并通过 Dense/Sparse、进度门控、层区间与引导强度四个正交旋钮实现了可组合、可解释、可消融的调度体系。研究在 RAE 系模型上取得的增益显著且跨模型一致，质量—耗时曲线优于同预算下加采样步数的基线；对 VAE 模型失效的诚实报告与单 seed 等统计局限，则为其结论划定出清晰但稍显狭小的适用范围。整体而言，这是一篇实验扎实、模块设计清晰、思路有开创性的论文，其价值不仅在于多报出几个点的指标，更在于提出了一条“如何在冻结生成器内部将多余算力转化为质量”的可复用范式，并为后续自动计算调度、理论解释与跨架构适配打开了明确的研究窗口。
