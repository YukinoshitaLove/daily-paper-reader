## 摘要
不同图像的退化差异很大，因此一个实用的复原系统必须用单一模型处理多种退化类型。最近一种有效方案是：利用带有文本提示的小型低秩适配器，将大型预训练图像编辑模型适配到复原任务。我们用一种源自退化图像本身的指令来替代该提示。图像通过两条路径到达编辑器：其结构来自模型的 VAE，其语义指令来自一个轻量级 token 映射器，该映射器将退化图像的视觉-语言嵌入朝干净图像所产生的嵌入方向偏移。由于指令是一个连续向量，对其进行缩放可以为目标不唯一的任务（例如低光增强）生成一族有效的复原结果。我们在单块 GPU 上训练约三小时得到单个适配器，将一个 Qwen-Image-Edit 模型适配到六项任务。在匹配比较下，图像指令优于文本条件，并且它支持无需退化标签的任务无关复原，而文本变体无法做到这一点。

## Abstract
Degradations vary widely across images, so a practical restoration system has to handle many degradation types with one model. A recent and effective recipe adapts a large pretrained image-editing model to restoration using a small low-rank adapter with a text prompt. We replace that prompt with an instruction derived from the degraded image itself. The image reaches the editor through two paths: its structure comes from the model's VAE, and its semantic instruction comes from a lightweight token mapper that shifts the degraded image's vision-language embedding toward the embedding a clean image would produce. Because the instruction is a continuous vector, scaling it yields a family of valid restorations for tasks whose target is not unique, such as low-light enhancement. We adapt one Qwen-Image-Edit model to six tasks with a single adapter trained in about three hours on one GPU. The image instruction outperforms text conditioning under a matched comparison, and it supports task agnostic restoration without a degradation label, which the text variant does not.

# ImIR：面向一体化图像复原的图像指令微调 —— 论文总结

## 1. 核心问题与研究背景

- **问题定位**：图像复原（去噪、去雨、去雾、去模糊、低光增强、JPEG 伪影去除等）本质是病态逆问题 $y = A(x)$，退化算子 $A$ 未知且不可逆。不同图像的退化类型差异极大，因此“一模型一任务”的专用网络（Restormer、NAFNet、Retinexformer 等）虽然精度高，但存储、选择和部署成本高。
- **一体化复原的难点**：共享一套权重时，关键是如何告知模型“当前需要去除哪种退化”，同时避免任务间干扰。已有方案包括可学习退化表征、可学习提示向量、频域调制、语言/CLIP 条件等，但多数从零训练在任务数据集并集上。
- **另一条路线**：复用大型生成模型的先验。Edit2Restore 等工作用低秩适配器把预训练图像编辑模型（如 FLUX.1 Kontext）适配到复原任务，并以**任务特定的文本提示**进行引导。
- **文本条件的固有缺陷**（论文动机）：
  - 需要人工提示工程（prompt engineering）；
  - 将模型绑定到封闭的任务词表；
  - 作为离散的全局信号，无法针对眼前这张图像做连续调节。
- **核心洞察**：对图像到图像的逆问题而言，信息量最大的指令本身就是一张图像；理想指令是干净目标的嵌入 $e_x = E(x)$，但 $x$ 正是测试时未知量。因此论文提出**从退化图像 $y$ 学习预测该指令**，既不需要书写提示，也不需要参考图像。

## 2. 方法论

### 2.1 核心思想

- 把一体化复原重铸为**由图像推导指令（image-derived instruction）引导的编辑任务**：$\hat{x} = f_\Theta(y, \tau)$，其中任务标签 $\tau$ 可选，去掉后即为任务无关形式 $\hat{x} = f_\Theta(y)$。
- 用连续指令向量替代离散文本提示，并学习一个轻量 **token mapper** 把退化图像的视觉-语言嵌入朝干净图像的嵌入方向偏移。

### 2.2 骨干与适配

- 骨干：**Qwen-Image-Edit**（主报告 2511 版本），包含 Qwen2.5-VL 语义编码器、VAE 外观编码器与 MMDiT 扩散 Transformer。
- 骨干**完全冻结**，仅用一个**秩为 32 的低秩适配器（LoRA）**，作用于注意力 Q/K/V/输出投影以及前馈与调制模块，六项任务共享同一适配器。
- 与原始编辑模型的关键区别：**从不使用描述任务的文本提示**，指令以图像推导的嵌入形式注入。

### 2.3 两条条件通道

- **结构通道**：$y$ 经 VAE 编码为隐 token，与含噪生成 token 拼接，锚定 $\hat{x}$ 的几何布局（编辑器原生机制）。
- **指令通道**：语义嵌入经模型条件通路注入，文本提示留空；连续嵌入可在送入 MMDiT 前做算术操作，从而支持可控性。

### 2.4 Token Mapper 的具体设计

设 $e_y = E(y)$ 为退化图像的逐 token 嵌入序列，$V$ 为有效（非 padding）token 集合。Mapper 以**残差**形式预测干净指令嵌入：

- 掩码均值池化：$\bar{e}_y = \frac{1}{|V|}\sum_{i \in V} e_y^{(i)}$
- FiLM 生成器：$(\gamma, \beta) = \phi_{agg}(\tau, \bar{e}_y)$
- 逐 token 修正：$\hat{e}_x = e_y + g_\theta(e_y; \gamma, \beta)$

调制方式为 $h \mapsto (1+\gamma)\odot h + \beta$。四个设计要点：

- **逐 token 且长度无关**：$g_\theta$ 是共享权重的 MLP，逐 token 独立作用，适应六套数据的不同分辨率；不加入位置编码，因为 Qwen2.5-VL 的 M-RoPE 已编码 2D 位置，且绝对 token 索引跨尺寸不可比。
- **通过 FiLM 做任务条件**：$\phi_{agg}$ 嵌入任务标识 $\tau$ 并生成 $(\gamma,\beta)$，一套 FiLM 条件网络服务六个任务。
- **感知全局退化程度**：$\phi_{agg}$ 同时读取池化摘要 $\bar{e}_y$，使调制可依赖图像级统计量（低光整体暗度、雾浓度等），这些不是 $e_y$ 的逐 token 函数。
- **初始化即恒等**：$g_\theta$ 输出投影零初始化、FiLM 门置零，使训练前 $(\gamma,\beta)=(0,0)$、$\hat{e}_x = e_y$，训练只在能降低损失处添加修正。

关键的解耦：$g_\theta$ **永远看不到任务标签**，只看到 $e_y$ 与调制参数——这正是任务无关变体可行的基础（去掉标签只改变 $\phi_{agg}$ 的输入，$g_\theta$ 不变）。

### 2.5 两阶段训练与推理

- **阶段一**：预计算成对 (退化, 干净) 图像的视觉-语言嵌入，训练 $g_\theta$ 以掩码均方误差回归干净嵌入的残差：$\mathcal{L}_{map} = \|\hat{e}_x - e_x\|^2_{valid}$（损失与池化仅在有效 token 上计算）。
- **阶段二**：冻结已训练的 mapper，用**流匹配（flow matching）**目标微调 LoRA，以 $y$ 的结构通道 + mapper 产出的 $\hat{e}_x$ 为条件生成干净图像。
- **推理**：仅有 $y$ 可用；对 $y$ 编码一次取结构（VAE）、一次取指令（VLM 编码器 + mapper），再跑流匹配采样器。**无需文本提示、无需干净参考**。

### 2.6 任务无关变体与可控性

- **任务无关**：将 $\tau$ 折叠为单一共享槽位，去掉退化标签，全局上下文分支仍保留图像级退化线索。实验显示该变体与任务感知模型持平。
- **可控性**：对残差位移缩放 $\hat{e}_x = e_y + s \cdot g_\theta(e_y;\gamma,\beta)$，沿“退化→干净”方向移动。对目标不唯一的任务（典型如低光增强，正确曝光是一个区间），扫描 $s$ 可生成**一族有效复原结果**；对目标基本固定的纯去除类任务（去雨、去雾、去噪、去模糊、JPEG），有效工作点较窄。

## 6. 主要结论与发现

- **在基于预训练先验/少数据的层级中，ImIR 在全部六个任务上取得最高 PSNR**；相对其基座模型提升显著（去雾：Qwen-Image-Edit-2511 零样本 17.7 dB → 适配后 24.7 dB）；在五个任务上优于 Edit2Restore（低光 21.3 vs 18.6 dB，去雨 33.2 vs 32.6 dB）。
- **图像指令全面优于文本条件**（同骨干匹配比较）：六项任务全胜；优势最大在**低光增强**（21.3 vs 16.3 dB），即目标最不由输入决定的任务；在目标近乎固定的去除类任务上差距收窄。
- **逐图胜率**：ImIR 在每个任务、每个指标上于多数图像取胜，18 个格子中 **15 个显著**（$p<0.05$）；低光最强（88–91%），去雨最弱（PSNR/SSIM 与文本近乎打平，仅 LPIPS 取胜）。
- **任务无关能力是图像指令独有的**：任务无关 ImIR 与任务感知版本持平（低光 21.2 vs 21.3 dB；去雨 33.0 vs 33.2 dB）；而文本适配器一旦去掉任务标签即崩溃（去雨 32.5 → 17.5 dB），改用 VLM 逐图提示也无改善（各任务与中性提示相差 1 dB 以内）。更关键的是，**任务无关 ImIR 在全部六项任务的 PSNR 上超过“知道退化类型”的任务感知文本适配器**，说明差异不能归因于任务路由缺失，而来自连续视觉表征。
- **消融证实增益来自预测的指令**：相对恒等基线（直接用 $e_y$），mapper 带来 2.6–7.0 dB 提升；Oracle（训练与测试均用 $e_x$）在五个任务上更好、去模糊低 0.1 dB，ImIR 在每个任务上**弥合了恒等—Oracle 差距的至少 82%**。去掉全局上下文分支代价 1.2–4.9 dB（去雨与 JPEG 损失最大），嵌入空间上 MSE 降幅由 25.1% 提升到 30.3%、余弦相似度由 0.724 升至 0.742。
- **可控性有效**：缩放 $s$ 可连续调节低光曝光与去雾程度；$s=0$ 时低光输出接近暗输入、去雾不完整；$s$ 过大则低光过曝，而去雾在超出默认值后未见性能下降。
-

- **效率与代价**：326M 可训练参数、688 对图像、单卡 3 小时，相比从零训练的一体化模型（数万对图像）与 RealRestorer（160 万对、8×H800）在数据与算力上低数个量级；代价是推理 14 秒/图（30 步扩散采样），远慢于前馈式判别网络，作者未对推理效率做优势主张，仅报告数值。
- **定性结果**：在低光、去雾、去雨等示例中，ImIR 的输出更接近 GT 的亮度与对比度，而零样本编辑器普遍出现任务理解偏差（如去雾后仍残留雾、低光增强不足或过度）；文本适配器在任务无关设置下常产生与任务不符的编辑（如对雨天图像做无关修饰）。
- **总体论断**：论文的核心主张不是“超越全量训练的专用模型”，而是“**在极少数据与冻结先验的条件下，用图像推导的连续指令替代文本提示，能更高效地激活预训练生成模型的一体化复原能力**”。

## 7. 局限性与批判性评估

- **任务覆盖的偏置**：六项任务均为“从退化图到干净图”的确定性映射，未涉及需要多解采样或用户意图的任务（如风格化复原、基于文本描述的定向编辑、超分中的细节幻觉）。图像指令在目标唯一时优势收窄，恰好说明其增益与“任务本身的不确定性/欠定性”正相关，而论文未系统刻画这一边界。
- **指令空间的性质未被充分分析**：论文只在嵌入 MSE 与余弦相似度上验证 mapper 更贴近 $e_x$，但**嵌入空间距离更近是否等价于生成质量更高**缺乏机制性解释。Oracle 用 $e_x$ 仍有 0.1 dB 的去模糊劣势，暗示嵌入回归目标与最终感知目标之间存在轻微错配。
- **单骨干依赖**：全部结论建立在 Qwen-Image-Edit（含 2511 与 2509 版本）之上，未验证该“图像指令优于文本提示”的现象是否可迁移到 FLUX、Step1X 等其他骨干。若该现象仅源于 Qwen2.5-VL 语义编码器的特定对齐方式，则结论的普适性受限。
- **数据规模声明需谨慎解读**：688 对图像固然少，但基座模型已在大规模数据上预训练，本质是**把数据成本转移到了先验**；与从零训练基线的比较在“总数据消耗”意义上并非同类，作者已声明不做算力归一化，读者亦不应将其读作纯效率胜利。
- **评测维度的单一性**：全部指标为全参考保真度（PSNR/SSIM/LPIPS）。对低光增强这类目标不唯一的任务，全参考指标惩罚“合理的另一解”，可能低估可控性变体的价值；缺少无参考指标（如 NIQE、CLIP-IQA）或用户研究。
- **统计功效的薄弱点**：去噪仅 32 张测试图，Denoising-LPIPS 的符号检验 $p$ 值略高于 0.05，该格子的“未显著”更可能是样本量问题而非真实无差异；论文未做功效分析或 bootstrap 置信区间。
- **可控性实验的示例性**：$s$ 的扫描仅在低光与去雾两例上展示，未给出跨数据集的最优 $s$ 分布、自动选择 $s$ 的准则，也未讨论 $s$ 与退化强度之间的关系；可控性目前更像定性演示而非可部署机制。
- **训练两阶段的耦合**：阶段一以嵌入回归为目标、阶段二以流匹配为目标，两者目标不一致；mapper 冻结后不再被生成损失修正，若嵌入回归的最优解并非生成最优解，则存在次优性。论文未做“联合微调 mapper + LoRA”的对照。
- **潜在的方法论冗余**：任务感知与任务无关版本表现持平，意味着 $\tau$ 条件几乎无贡献；这在结论上是亮点（说明视觉表征足够），但也削弱了 FiLM 任务条件设计的必要性论证——该模块可被移除而不损性能，其存在价值需进一步说明。

## 8. 可复现性与开放问题

- **可复现性**：方法描述（mapper 结构、FiLM 调制、零初始化恒等、两阶段目标、LoRA 秩与作用模块）较为完整；数据规模、超参、硬件与推理配置均已给出。但论文未提及代码/权重发布情况，且“自行重跑所有基线”的做法虽提升公平性，也意味着复现其基线数值需依赖作者的具体预处理与指标实现。
- **开放问题**：
  1. 图像指令能否与文本指令**组合**，实现“自动复原 + 用户可控编辑”的统一接口？
  2. 能否把 $s$ 的缩放推广为**多维可解释方向**（如分别控制亮度、色偏、噪声强度），而非单一标量？
  3. 在无配对数据或跨域退化下，mapper 能否通过自监督/循环一致性训练，摆脱对 (退化, 干净) 配对的依赖？
  4. 该范式是否适用于**视频复原**与**多退化混合**（如低光 + 噪声 + 模糊同时存在）场景？

## 9. 一句话总结

ImIR 用一个仅在 688 对图像上训练、冻结 Qwen-Image-Edit 骨干的轻量 token mapper，把“当前需要去除哪种退化”这一信息从离散文本提示转化为由退化图像自身预测的连续视觉指令嵌入，从而在六项一体化复原任务上同时实现了任务无关性、优于同骨干文本提示的保真度、以及可连续调节的复原强度，其核心贡献在于**证明了对图像到图像的逆问题而言，图像本身是比语言更好的指令载体**。
