## 摘要
文本到图像扩散模型通常使用固定数量的去噪步骤，以平衡时间成本和图像质量。然而，最优步骤数取决于输入文本提示的复杂度。我们提出一种自适应扩散控制器，无需额外模型训练，即可动态调整步骤数以高效生成高质量图像。通过利用具有不同步长的步骤调度混合，并评估每个时间步的误差项差异，我们的方法在调度之间切换以优化性能。在 COCO 和 DiffusionDB 上的实验表明，我们的方法在保持视觉保真度的同时减少了推理时间，为文本到图像扩散模型提供了一种更高效的替代方案。

## Abstract
Text-to-image diffusion models often use a fixed number of denoising steps, balancing time costs and image quality. However, the optimal number of steps depends on the complexity of the input text prompt. We propose an adaptive diffusion controller that dynamically adjusts the number of steps to generate high-quality images efficiently, without additional model training. By leveraging a mixture of step schedules with varying step sizes and evaluating the error term discrepancy at each timestep, our method transitions between schedules to optimize performance. Experiments on COCO and DiffusionDB show that our approach reduces inference time while maintaining visual fidelity, offering a more efficient alternative for text-to-image diffusion models.

# 论文总结：面向扩散模型的自适应步数调度控制器（ADSC）

## 1. 核心问题与研究动机

- **背景**：文本到图像扩散模型（如 Stable Diffusion）能生成高质量、高多样性的图像，但推理过程需要多次迭代去噪，计算开销大。
- **现有方案的不足**：
  - 知识蒸馏、神经架构搜索、量化等方法虽能减少步数，但**需要额外的模型训练**，成本高昂。
  - 这些方法通常采用**固定步数**的"一刀切"策略，忽视了不同文本提示的复杂度差异以及随机种子（噪声初始化）的影响。
  - 固定调度会导致两种极端：**冗余计算**（简单提示被过度去噪）或**生成不成熟**（复杂提示去噪不足）。
- **核心洞察**：最优去噪步数依赖于文本提示与随机种子的组合，且这一依赖关系已被先前工作所证实（图1）。
- **论文目标**：提出 **ADSC（Adaptive Diffusion Step Controller）**，在**无需额外训练**的前提下，为每个提示动态分配最小必要步数，在保持视觉质量的同时提升推理效率。

## 2. 方法论

### 2.1 核心思想

- 在**异构调度控制空间**中，从最长（步长最小）的调度开始执行，通过实时监测扩散过程的收敛性，逐步切换到更短（步长更大）的调度，从而以混合调度（mixture schedule）完成单次生成。

### 2.2 异构调度控制空间

- 控制空间包含 K 个调度 $C = \{S_1, S_2, ..., S_K\}$，每个调度 $S_k = \{t^k_1, ..., t^k_{N_k}\}$ 具有不同的步数与步长。
- 约束条件：后续调度步数更少、步长更大，即 $N_k > N_{k+1}$，且 $t^{k+1}_{i+1} - t^{k+1}_i > t^k_{j+1} - t^k_j$。
- **动机**：当扩散过程收敛、内容信息大体生成后，更大步长带来的估计误差对最终图像质量影响较小。
- **切换规则**：检测到收敛时，从当前时刻 $t^k_i$ 切换到下一调度中最接近的时刻，即 $j = \arg\min_{j'} |t^{k+1}_{j'} - t^k_i|$。
- **混合调度集合**可形式化为：
$$M = \bigcup_{k=1}^{K} \{t^k_{st}, \ldots, t^k_{end}\}$$

### 2.3 收敛判据（基于余弦距离）

- 在 classifier-free guidance 下，每个去噪步同时产生条件噪声估计 $\epsilon_c$ 与无条件估计 $\epsilon_u$，总噪声估计为 $\epsilon = \epsilon_u + \gamma(\epsilon_c - \epsilon_u)$。
- **启发式假设**：跟踪 $\epsilon_u$ 与 $\epsilon$ 之间的**余弦距离** $d_{cos}(t)$，其随扩散过程呈类反指数下降；当距离趋于平稳时，表明图像已与文本提示对齐、过程收敛。
- **平滑处理**：为抑制波动，使用指数平均平滑曲线：
$$\tilde{d}_{cos}(t_i) = \alpha d_{cos}(t_i) + (1-\alpha)\tilde{d}_{cos}(t_{i-1})$$
- **导数判据**：计算平滑曲线的一阶与二阶差分：
  - $\tilde{d}_{cos}(t_i)' = \tilde{d}_{cos}(t_i) - \tilde{d}_{cos}(t_{i-1})$
  - $\tilde{d}_{cos}(t_i)'' = \tilde{d}_{cos}(t_{i+1}) + \tilde{d}_{cos}(t_{i-1}) - 2\tilde{d}_{cos}(t_i)$
- **收敛条件**：当两者绝对值同时低于阈值 $\delta_1, \delta_2$ 时判定收敛（对应余弦距离曲线的"肘点"），即：
$$C = \begin{cases} 1, & |\tilde{d}_{cos}(t_i)'| < \delta_1 \ \text{and}\ |\tilde{d}_{cos}(t_i)''| < \delta_2 \\ 0, & \text{otherwise} \end{cases}$$

### 2.4 算法流程（Alg. 1）

1. 初始化混合调度 $m \leftarrow \emptyset$，从最长调度开始（$k=1, i=1$）；
2. 循环直到当前调度的末端时刻：
   - 若检测到收敛 → 切换到下一调度，并定位最近时刻；
   - 否则 → 将当前时刻加入混合调度 $m$，前进至下一步。

## 6. 主要结论与发现

- **步数显著减少**：在 COCO 上，ADSC 控制的 DDIM 平均 **18.89 步**、PNDM 平均 **24.48 步**；在 DiffusionDB 上分别为 **18.06 步**与 **24.75 步**，相比默认 50 步在某些情况下减少超过 50%。
- **质量保持或提升**（相对同平均步数的固定基线）：
  - COCO / DDIM：CLIP-I 提升 3.3%（95.70 vs 92.40），DINO 提升 8.30%（92.42 vs 84.12）；
  - COCO / PNDM：CLIP-I 提升 1.50%，DINO 提升 4.28%；
  - DiffusionDB / DDIM：CLIP-I 提升 3.2%，DINO 提升 6.4%；
  - **CLIP-T 在各方法间基本持平**，说明文本对齐不受显著影响。
- **调度器兼容性差异**：ADSC 与 **DDIM 配合最为稳定**；在 DiffusionDB 上，PNDM + ADSC 的 DINO 反而下降 1.59%，提示该方法并非对所有调度器都带来一致增益。
- **延迟基本持平**：ADSC 与等效步数的固定调度器墙钟时间几乎相同（如 0.79s vs 0.78s），说明效率收益来自"更少的平均步数"而非单步加速。
- **定性观察**：复杂提示（如笔记本电脑键盘、路牌文字）需要更多步数；简单常见物体（猫、车、桌子）所需步数较少，与提示复杂度相关。

## 7. 优点（亮点）

- **完全免训练**：不需要蒸馏、微调或架构搜索，可直接挂载到现有扩散管线，部署成本低。
- **提示级自适应**：为每个文本提示（及随机种子）动态定制步数，突破了固定调度的"一刀切"限制。
- **判据设计巧妙且轻量**：利用 classifier-free guidance 中天然存在的条件/无条件噪声估计，仅用**余弦距离的肘点检测**作为收敛信号，几乎不增加额外计算。
- **调度空间设计合理**：$K$ 个调度按半数步数递减，保证相邻调度时间步部分重合，使切换无缝、误差可控。
- **多调度器兼容**：可与 DDIM、PNDM、DDPM、LMS 等主流求解器组合使用，具有较好的通用性。
- **实验对比公平**：以 ADSC 平均/最小/最大步数构造对应的固定步数基线，控制变量较为严谨。
